Typically, the source for a layer is provided to the layer constructor. If you need to set a layer source after construction, this can be done with the layer.setSource() method.

The layer in the map above is constructed with no source. Use the links below to set/unset the layer source. A layer is not rendered until its source is set.

通常情况下，图层的数据源（Source）是在图层实例化构造时传入的。 如果在图层创建完成后需要动态替换或延迟设置数据源，可以通过 layer.setSource() 方法完成。 上方地图中的图层在初始创建时并未指定任何数据源（保持空白）。 点击下方按钮可动态挂载或卸载数据源，只有当图层成功关联数据源后，渲染引擎才会启动瓦片拉取与画面绘制。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 图层外壳（Layer）与数据流引擎（Source）的彻底解耦： 在 OpenLayers 中，Layer 负责的是渲染管线参数（不透明度、Z-Index、可见性、最大最小分辨率、CSS 类名），而 Source 负责几何要素或瓦片流的异步网络获取与解析。 这种设计允许图层容器独立于数据源存在。当 source === null 时，图层安全静默，不会触发任何绘制操作，也不会产生空指针异常。
  • 按需懒加载与内存释放范式（Lazy Loading & GC Pattern）： 在含有成百上千个图层的复杂业务系统中，若在启动时将所有图层的数据源全部初始化，会导致并发网络请求拥塞与巨额内存消耗。 采用懒加载模式，图层树先展示结构外壳，待用户首次勾选时再动态执行 layer.setSource(source)。 而在长时间不使用或内存受限的移动端，调用 layer.setSource(null) 可迅速切断对海量切片和要素对象的强引用，辅助浏览器 V8 引擎进行垃圾回收（GC）。

2. 源码与关键 API 剖析

  • const layer = new TileLayer()：创建一个空的切片图层容器。
  • layer.setSource(source)：注入数据源，自动触发地图重排并派发切片请求。
  • layer.setSource(null)：剥离数据源，图层瞬间转为空白，释放底层资源。

3. 生产实践踩坑与性能调优

  • setVisible(false) vs setSource(null) 的技术选型： - 频繁切换显隐： 优先使用 layer.setVisible(false)，切片和要素缓存驻留内存，再次勾选时实现毫秒级瞬间呈现，体验最佳； - 低频重度大图层： 建议在折叠或关闭时调用 layer.setSource(null)，彻底归还数百兆的切片或网格内存，避免移动端浏览器标签页因 OOM 闪退。
