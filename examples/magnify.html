Magnify / 局部放大镜（像素插值放大）

magnify1 imagemanipulation3 maptiler26

Show a magnified version of imagery under the pointer / 在鼠标指针下方以高倍率插值放大显示局部遥感影像。

This example makes use of the postrender event listener to oversample imagery in a circle around the pointer location. Listeners for this event have access to the Canvas context and can manipulate image data.

Move around the map to see the effect. Use the ↑ up and ↓ down arrow keys to adjust the magnified circle size.

本示例演示了如何通过 postrender 事件监听器对鼠标指针下方的遥感影像进行像素级超采样（Oversampling）与局部放大。事件监听器可以访问图层的 Canvas 2D 绘图上下文，直接读取并重构指定视口包围盒内的像素数据，实现实时圆形放大镜效果。

在地图上移动鼠标即可查看放大镜效果。使用键盘方向键 ↑（向上）和 ↓（向下）可动态调整放大镜的圆形透镜尺寸（25px ~ 150px）。

📚 学习记录与技术深度解读 (Learning Notes)

1. 像素重采样与局部放大数学模型 (Oversampling & Magnification Math)

  • 局部视口采样包围盒: 以鼠标物理像素 $(centerX, centerY)$ 为几何中心，计算边长为 $size = 2 \times radius + 1$ 的外接正方形区域，调用 context.getImageData(originX, originY, size, size) 提取该正方形内的原始像素矩阵。
  • 极坐标几何采样与 2x 缩放映射:
    • 对于目标缓冲区中的每个像素 $(i, j)$，计算其相对于正方形中心 $(half, half)$ 的欧氏距离 $dist = \sqrt{\Delta i^2 + \Delta j^2}$；
    • 当 $dist < radius$（即位于圆形透镜内部）时，采样坐标映射为： $$sourceI = \text{round}\left(half + \frac{\Delta i}{2}\right), \quad sourceJ = \text{round}\left(half + \frac{\Delta j}{2}\right)$$ 相当于从中心向外缩放了 2 倍，实现无缝局域像素放大；
    • 圆形外部像素保持 $sourceI = i, sourceJ = j$ 不做放大。
  • 透镜边缘描边与视觉修饰: 像素写回后，调用 context.arc(centerX, centerY, half, 0, 2 * Math.PI) 为透镜绘制半透明白色高亮轮廓，形成逼真的光学放大镜质感。

2. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices)

  • 数字插值拉伸 vs 真实层级切片: 本例算法本质为近邻像素重采样（数字放大），当地图瓦片分辨率受限时，放大区域会出现阶梯状马赛克或模糊伪影。在追求真实清晰度的 GIS 项目中，更理想的方案是在放大镜内部嵌套渲染高缩放级别（如 $z + 2$）的高清切片源。
  • 视口边缘越界安全防线: 当光标移动到地图边缘（例如最左侧或最上端）时，$originX < 0$ 或 $originY < 0$，调用 getImageData 会因越界抛出 IndexSizeError 异常中断渲染。生产环境中需使用 Math.max(0, ...) 进行边界防范或对裁剪区域求交。
  • 单例离屏 Canvas 性能优化: 示例在每次鼠标移动渲染帧中频繁调用 createImageData 分配内存，在持续高速拖拽或高刷屏上会引起轻度 GC 压力。可通过预先维护一个固定尺寸的最大离屏 Canvas 缓冲区反复重用，减少垃圾回收开销。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import {fromLonLat} from 'ol/proj.js';
import {getRenderPixel} from 'ol/render.js';
import ImageTile from 'ol/source/ImageTile.js';

// MapTiler API Key for satellite imagery access
// MapTiler API 密钥：用于加载卫星遥感影像切片
const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Imagery tile layer
// 遥感影像切片图层
const imagery = new TileLayer({
  source: new ImageTile({
    attributions: attributions,
    url: 'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
    tileSize: 512,
    maxZoom: 20,
  }),
});

const container = document.getElementById('map');

// Initialize map centered on Montana, USA
// 初始化地图实例：中心定位至美国蒙大拿州
const map = new Map({
  layers: [imagery],
  target: container,
  view: new View({
    center: fromLonLat([-109, 46.5]),
    zoom: 6,
  }),
});

// Magnifier lens radius in CSS pixels (default: 75px)
// 放大镜透镜半径（CSS 像素，默认 75px）
let radius = 75;

// Dynamically adjust magnifier radius with arrow keys
// 键盘监听：使用 ↑ / ↓ 方向键动态调整放大镜半径（25px ~ 150px）
document.addEventListener('keydown', function (evt) {
  if (evt.key === 'ArrowUp') {
    radius = Math.min(radius + 5, 150);
    map.render();
    evt.preventDefault();
  } else if (evt.key === 'ArrowDown') {
    radius = Math.max(radius - 5, 25);
    map.render();
    evt.preventDefault();
  }
});

// Track current pointer position in CSS pixels
// 实时追踪鼠标光标在容器中的像素位置
let mousePosition = null;

container.addEventListener('mousemove', function (event) {
  mousePosition = map.getEventPixel(event);
  map.render();
});

container.addEventListener('mouseout', function () {
  mousePosition = null;
  map.render();
});

// After rendering the layer, render an oversampled magnified circle around the pointer
// 在图层渲染完成后（postrender 钩子）：对光标周围区域进行 2x 像素级超采样放大渲染
imagery.on('postrender', function (event) {
  if (mousePosition) {
    // Calculate physical render pixels and radius on Canvas (HiDPI support)
    // 换算 Canvas 物理渲染像素与半径（适配高分屏）
    const pixel = getRenderPixel(event, mousePosition);
    const offset = getRenderPixel(event, [
      mousePosition[0] + radius,
      mousePosition[1],
    ]);
    const half = Math.sqrt(
      Math.pow(offset[0] - pixel[0], 2) + Math.pow(offset[1] - pixel[1], 2),
    );
    const context = event.context;
    const centerX = pixel[0];
    const centerY = pixel[1];
    const originX = centerX - half;
    const originY = centerY - half;
    const size = Math.round(2 * half + 1);

    // Read original pixel data from the square bounding box
    // 从正方形局部包围盒中读取原始像素数据
    const sourceData = context.getImageData(originX, originY, size, size).data;
    const dest = context.createImageData(size, size);
    const destData = dest.data;

    // Resample pixels: 2x zoom within the circle, 1:1 outside
    // 像素重采样循环：在圆形透镜内部执行 2 倍放大采样，在圆外保持原图
    for (let j = 0; j < size; ++j) {
      for (let i = 0; i < size; ++i) {
        const dI = i - half;
        const dJ = j - half;
        const dist = Math.sqrt(dI * dI + dJ * dJ);
        let sourceI = i;
        let sourceJ = j;
        if (dist < half) {
          sourceI = Math.round(half + dI / 2);
          sourceJ = Math.round(half + dJ / 2);
        }
        const destOffset = (j * size + i) * 4;
        const sourceOffset = (sourceJ * size + sourceI) * 4;
        destData[destOffset] = sourceData[sourceOffset];
        destData[destOffset + 1] = sourceData[sourceOffset + 1];
        destData[destOffset + 2] = sourceData[sourceOffset + 2];
        destData[destOffset + 3] = sourceData[sourceOffset + 3];
      }
    }

    // Write magnified pixels back and draw lens highlight border
    // 将重采样后的像素写回画布，并绘制半透明白色圆形光环边框
    context.beginPath();
    context.arc(centerX, centerY, half, 0, 2 * Math.PI);
    context.lineWidth = (3 * half) / radius;
    context.strokeStyle = 'rgba(255,255,255,0.5)';
    context.putImageData(dest, originX, originY);
    context.stroke();
    context.restore();
  }
});
