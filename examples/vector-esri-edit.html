Editable ArcGIS REST Feature Service / 可编辑的 ArcGIS REST 要素服务

vector87 esri3 ArcGIS5 REST3 Feature12 Service2 loading8 server5 edit13 updateFeature1 addFeature1

Example of using an ArcGIS REST Feature Service in an editing application. / 演示如何连接 ArcGIS REST FeatureServer 服务端实现要素的在线绘制新增与修改更新。

This example loads features from ArcGIS REST Feature Service and allows to add new features or update existing features.

本示例演示了如何从 ArcGIS REST FeatureServer（要素服务）瓦片化分块加载矢量数据，并实现前后端联动的在线编辑应用：

  • 绘制新增（Draw / Add）：选择 Draw 模式在地图上绘制多边形，在 drawend 事件中通过 EsriJSON 序列化，向服务端的 addFeatures 接口发送 POST 请求完成入库，并自动获取服务端分配的 objectId；
  • 在线修改（Modify / Update）：选择 Modify 模式，先点击选中要素，拖拽顶点微调；通过脏检查（Dirty Check）机制，当要素取消选中时，自动将修改后的几何通过 updateFeatures 接口回写同步至远程服务。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计机制 (Core Architecture & Mechanics)

  • 瓦片化空间加载策略（Tile-based Loading Strategy）： 数据源采用 strategy: tileStrategy(createXYZ({tileSize: 512}))。OpenLayers 将地图划分为虚拟的 512px 空间网格，仅在视口滑入未曾加载的瓦片区域时，才会按该切片的 BBOX 向 ArcGIS REST /query 接口发起增量请求。这样既避免了单次拉取海量要素导致浏览器内存暴涨，又防止了视口平移时全屏频繁刷新。
  • 前后端事务同步闭环： 与传统静态 GeoJSON 不同，在线要素编辑涉及严格的增量事务操作：
    • 新增入库：客户端生成临时矢量要素 → 序列化为 EsriJSON 报文 → POST /addFeatures → 接收服务端下发的权威 objectId 并回填至要素实例；
    • 微调更新：要素顶点被编辑 → 触发脏标记 → 离焦时 POST /updateFeatures 覆盖持久层几何与属性。

2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns)

  • 现代异步 Loader 规范：
    loader: async (extent, resolution, projection) => {
  const url = serviceUrl + layer + '/query/?...';
  const response = await fetch(url);
  const json = await response.json();
  return esrijsonFormat.readFeatures(json, {featureProjection: projection});
}
    在现代 OpenLayers 中，自定义 loader 支持原生 async/await 并直接返回 Feature 数组，底层自动完成空间 R-Tree 树索引注入与图层重绘。
  • 脏检查与失焦写回（Dirty Checking on Deselection）： 要素进入 Modify 状态时绑定 modifyend 标记 isDirty = true；当在地图空白处点击使其从 Select 集合中移除（select.getFeatures().on('remove', ...)）时，触发条件网络提交，有效降低并发网络 I/O 频次。

3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices)

  • 投影代码格式清洗（SRID Striping）： ArcGIS REST 服务接口要求 spatialReference 必须是纯数字 WKID（如 102100 或 4326），严禁传递带 EPSG: 前缀的字符串，否则服务端会抛出解析错误。
  • 主键绑定与唯一性约束： 新增要素入库后必须同步调用 feature.setId(result.objectId)。若忽略这一步，后续再次修改该要素并提交 /updateFeatures 时，由于缺少服务端主键匹配，请求会被拒绝或演变为重复新增。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import EsriJSON from 'ol/format/EsriJSON.js';
import Draw from 'ol/interaction/Draw.js';
import Modify from 'ol/interaction/Modify.js';
import Select from 'ol/interaction/Select.js';
import {defaults as defaultInteractions} from 'ol/interaction/defaults.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import {tile as tileStrategy} from 'ol/loadingstrategy.js';
import {fromLonLat} from 'ol/proj.js';
import ImageTile from 'ol/source/ImageTile.js';
import VectorSource from 'ol/source/Vector.js';
import {createXYZ} from 'ol/tilegrid.js';

// ArcGIS Online official wildfire feature service URL / ArcGIS Online 官方野火要素服务地址
const serviceUrl =
  'https://sampleserver6.arcgisonline.com/arcgis/rest/services/Wildfire/FeatureServer/';
const layer = '2';

const esrijsonFormat = new EsriJSON();

// Vector source with spatial tile loading strategy / 矢量数据源：根据视口瓦片范围向 ArcGIS REST query 接口动态拉取要素
const vectorSource = new VectorSource({
  loader: async (extent, resolution, projection) => {
    const url =
      serviceUrl +
      layer +
      '/query/?f=json&' +
      'returnGeometry=true&spatialRel=esriSpatialRelIntersects&geometry=' +
      encodeURIComponent(
        '{"xmin":' +
          extent[0] +
          ',"ymin":' +
          extent[1] +
          ',"xmax":' +
          extent[2] +
          ',"ymax":' +
          extent[3] +
          ',"spatialReference":{"wkid":102100}}',
      ) +
      '&geometryType=esriGeometryEnvelope&inSR=102100&outFields=*' +
      '&outSR=102100';
    const response = await fetch(url);
    const json = await response.json();
    if (json.error) {
      alert(json.error.message + '\n' + json.error.details.join('\n'));
      throw new Error(json.error.message);
    } else {
      // Parse features with target map projection / 按照地图投影解析读取 EsriJSON 要素
      const features = esrijsonFormat.readFeatures(json, {
        featureProjection: projection,
      });
      return features;
    }
  },
  strategy: tileStrategy(
    createXYZ({
      tileSize: 512,
    }),
  ),
});

const vector = new VectorLayer({
  source: vectorSource,
});

// ArcGIS World Topo basemap layer / ArcGIS 世界地形底图瓦片图层
const raster = new TileLayer({
  source: new ImageTile({
    attributions:
      'Tiles © <a href="https://services.arcgisonline.com/ArcGIS/' +
      'rest/services/World_Topo_Map/MapServer">ArcGIS</a>',
    url:
      'https://server.arcgisonline.com/ArcGIS/rest/services/' +
      'World_Topo_Map/MapServer/tile/{z}/{y}/{x}',
  }),
});

// Draw interaction for adding new polygon features / 绘制交互：绘制新增多边形要素
const draw = new Draw({
  source: vectorSource,
  type: 'Polygon',
});

// Select and Modify interactions for updating features / 选择与修改交互：选中要素并激活顶点拖拽修改
const select = new Select();
select.setActive(false);
const selected = select.getFeatures();

const modify = new Modify({
  features: selected,
});
modify.setActive(false);

const map = new Map({
  interactions: defaultInteractions().extend([draw, select, modify]),
  layers: [raster, vector],
  target: document.getElementById('map'),
  view: new View({
    center: fromLonLat([-110.875, 37.345]),
    zoom: 5,
  }),
});

const typeSelect = document.getElementById('type');

/**
 * Handle interaction mode change between Draw and Modify. / 处理用户交互模式切换（绘制新增 vs 选择修改）
 */
typeSelect.onchange = function () {
  draw.setActive(typeSelect.value === 'DRAW');
  select.setActive(typeSelect.value === 'MODIFY');
  modify.setActive(typeSelect.value === 'MODIFY');
};

// Dirty flag dictionary for tracking modified features / 脏检查标记：记录哪些被修改过的要素需要回写服务端
const dirty = {};

selected.on('add', function (evt) {
  const feature = evt.element;
  feature.on('change', function (evt) {
    dirty[evt.target.get('objectid')] = true;
  });
});

// When feature is deselected, commit update if dirty / 当要素从选中集合移除时，若存在脏标记则向 updateFeatures 提交更新
selected.on('remove', function (evt) {
  const feature = evt.element;
  const fid = feature.get('objectid');
  if (dirty[fid] === true) {
    const payload =
      '[' +
      esrijsonFormat.writeFeature(feature, {
        featureProjection: map.getView().getProjection(),
      }) +
      ']';
    const url = serviceUrl + layer + '/updateFeatures';
    fetch(url, {
      method: 'POST',
      body: new URLSearchParams({f: 'json', features: payload}),
      headers: {'Content-Type': 'application/x-www-form-urlencoded'},
    })
      .then((response) => response.json())
      .then((data) => {
        const result = typeof data === 'string' ? JSON.parse(data) : data;
        if (result.updateResults && result.updateResults.length > 0) {
          if (result.updateResults[0].success !== true) {
            const error = result.updateResults[0].error;
            alert(error.description + ' (' + error.code + ')');
          } else {
            delete dirty[fid];
          }
        }
      });
  }
});

// On draw completion, send feature to addFeatures endpoint / 绘制结束回调：将新绘制的多边形提交至服务端的 addFeatures 接口入库
draw.on('drawend', function (evt) {
  const feature = evt.feature;
  const payload =
    '[' +
    esrijsonFormat.writeFeature(feature, {
      featureProjection: map.getView().getProjection(),
    }) +
    ']';
  const url = serviceUrl + layer + '/addFeatures';
  fetch(url, {
    method: 'POST',
    body: new URLSearchParams({f: 'json', features: payload}),
    headers: {'Content-Type': 'application/x-www-form-urlencoded'},
  })
    .then((response) => response.json())
    .then((data) => {
      const result = typeof data === 'string' ? JSON.parse(data) : data;
      if (result.addResults && result.addResults.length > 0) {
        if (result.addResults[0].success === true) {
          feature.set('objectid', result.addResults[0]['objectId']);
        } else {
          const error = result.addResults[0].error;
          alert(error.description + ' (' + error.code + ')');
        }
      }
    });
});
