--- layout: example.html title: Scale and Rotate using Modify Interaction / 使用 Modify 交互进行缩放与旋转 shortdesc: Example of using the Modify interaction to scale and rotate geometries. / 演示利用 Modify 交互对几何要素进行实时缩放和旋转变换。 docs: | Example of using the `ol/interaction/Modify` interaction to scale and rotate geometries. Custom style functions produce and display a scaled and rotated version of the original geometry based on the position of a vertex being modified. This is set as the final geometry at the end of the interaction. By default the `ol/geom/Geometry` scale and rotate methods use the center of the geometry extent as anchor. For irregular shapes the extent changes as the geometry is rotated and using its center as anchor could produce different results if rotation was stopped and resumed. To avoid that an anchor point which is fixed relative to the geometry is used - for `ol/geom/Polygon` the centroid of the vertices, and the midpoint for `ol/geom/LineString`. Only outer vertices (more than 1/3 the maximum distance from the anchor) are used to scale and rotate as precise scaling close to the anchor would be difficult. For the convenience of the user the style function highlights the anchor and available vertices. The `ol/interaction/Translate` interaction is also available to reposition geometries. The Modify and Translate interactions have mutually exclusive `condition` options set so they can be available together. Use `Ctrl+Drag` (`Command+Drag` on Mac) to use the Translate interaction. 演示利用 `ol/interaction/Modify` 交互来缩放与旋转几何要素。自定义样式函数会根据被修改顶点的拖拽位置，生成并实时渲染原始几何的缩放与旋转版本。在交互操作结束（`modifyend`）时将其设置为要素的最终几何。 默认情况下，`ol/geom/Geometry` 的 `scale` 与 `rotate` 方法以要素的外包矩形（Extent）中心作为锚点。对于不规则形状，旋转过程中外包矩形会动态变化，如果使用外包矩形中心作为锚点，可能导致暂停并继续旋转时几何发生跳跃抖动。为避免此问题，本例采用相对于几何自身恒定固定的锚点——对于多边形（`ol/geom/Polygon`）使用顶点质心，对于折线（`ol/geom/LineString`）使用中点。 此外，仅允许外部顶点（距锚点距离大于最大距离 1/3 的顶点）参与缩放与旋转，避免在锚点附近难以精细缩放。为方便用户操作，样式函数高亮显示了锚点（红色）以及可供缩放旋转的有效顶点（绿色）。 同时还挂载了平移交互（`ol/interaction/Translate`）用于重新定位几何。`Modify` 与 `Translate` 交互配置了互斥的触发条件（`condition`），以便两者和谐共存：按住 `Ctrl+拖拽`（Mac 上为 `Command+拖拽`）可平移要素。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 为什么常规 Extent 中心无法用于旋转变换？ * **外包框动态形变陷阱**：对于任意非圆形或非正方形几何，只要发生旋转，它的外接水平轴对齐矩形（Bounding Box）宽度和高度就会时刻改变，导致 Extent 几何中心发生物理偏移！如果用户中途松开鼠标再接着转，新的旋转中心与之前的中心产生偏差，图形会瞬间跳跃形变。 * **恒定内禀锚点（Intrinsic Anchor）**： * **多边形（Polygon）**：采用所有顶点坐标的代数平均值作为质心（Centroid），无论多边形在平面上如何旋转，质心坐标相对于多边形本身始终恒定不变。 * **折线（LineString）**：采用沿线长 50% 处的中点 `geometry.getCoordinateAt(0.5)`。 #### 2. 多重交互互斥设计（Modify vs Translate） * **修改交互条件**：`primaryAction && !platformModifierKeyOnly`（纯鼠标主键拖拽顶点，禁止携带 Ctrl/Command 键）。 * **平移交互条件**：`primaryAction && platformModifierKeyOnly`（必须按住 Ctrl/Command 拖拽整体平移）。 * **禁用顶点增删**：配置 `deleteCondition: never` 和 `insertVertexCondition: never`，使 Modify 交互纯粹专注于整体形变缩放旋转，防止误增删节点。 tags: "draw, edit, modify, vector, scale, rotate" ---
