Tiled Layer Rendering in an Offscreen Canvas / OffscreenCanvas 离屏瓦片图层渲染

worker2 offscreencanvas2 tiles8

Simplified example of a tiled layer strategy using a map that lives inside a worker. / 使用 Worker 内部地图实例进行离屏瓦片异步渲染与 ImageBitmap 传输的示例。

The tiles of the map in this example are rendered in a web worker, using OffscreenCanvas. This can be improved by using a pool of workers to enable parallel, multi-threaded rendering.

在此示例中，地图的各个瓦片都在 Web Worker 后台子线程中通过 OffscreenCanvas 进行离屏渲染。通过在主线程自定义 ImageTileSource 的 loader 拦截瓦片请求，由 Worker 内部运行的无头地图完成光栅化并以 ImageBitmap 零拷贝返回。在生产环境中，还可以通过 Worker 线程池（Worker Pool）实现多核并行多线程出图。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 瓦片级微任务架构（Tile-Level Worker Pipeline）： 与整屏全幅委托不同，本示例将每个独立瓦片（512×512）视为一个异步作业单元。主线程的 ImageTileSource 仅负责维护空间视口瓦片网格与缓存，当需要加载新瓦片时，触发自定义 loader 向 Web Worker 发送 [z, x, y] 切片坐标任务。
  • Worker 内部的无头地图（Headless Map）： 在 Worker 子线程中，实例化了一个挂载于 new OffscreenCanvas(512, 512) 的无头 ol/Map。收到切片坐标后，利用 tileGrid.getTileCoordCenter(tile) 与对应层级分辨率动态为该无头地图重设 View，使得 Worker 像微型离线瓦片服务器一样精准烘焙单张瓦片。
  • ImageBitmap 零拷贝 Transferable 管道： 渲染完成后，通过 canvas.transferToImageBitmap() 获取图像显存句柄，并通过 worker.postMessage({ action: 'rendered', imageData }, [imageData]) 进行 Transferable 零拷贝转移，主线程的 Promise 立即 resolve(imageData) 并无缝贴图，全程毫无内存序列化阻塞。

2. 源码与关键 API 剖析

  • ImageTileSource({ loader: (z, x, y) => Promise })：现代 OpenLayers 提供的异步瓦片加载拦截点，返回包含 HTMLImageElement、ImageBitmap 或 HTMLCanvasElement 的 Promise。
  • transition: 0：在 Worker 内部的 OSM 数据源中，显式将瓦片淡入过渡时间设为 0。因为 Worker 中只做单帧烘焙，开启淡入动画会导致透明度未完全显现就提前截帧。
  • map.once('rendercomplete', callback)：单次渲染完成事件监听，确保 Worker 中的底图瓦片完全绘制就绪后再截取 ImageBitmap。
  • tileQueue.shift(); loadNextTile?.()：简易排队队列，保证主线程有序向单个 Worker 发送任务，避免消息堆叠引发时序混乱。

3. 生产实践踩坑与性能调优

  • 单 Worker 吞吐瓶颈与线程池（Worker Pool）： 示例中使用单个 Worker 串行处理瓦片，当快速缩放平移出现数十个瓦片请求时会出现排队等待。在复杂工程中，应构建 navigator.hardwareConcurrency 规模的 Worker 线程池，配合 Round-Robin 算法或空闲窃取（Work Stealing）实现多核满载并行渲染。
  • 请求取消与中止（AbortSignal）： 用户快速拖拽地图时，已滑出视口的瓦片不再需要渲染。若未在主线程向 Worker 发送 cancel 信号，Worker 会浪费 CPU 继续渲染无用瓦片。生产环境需配合 AbortController 实现任务丢弃。
  • 内存泄漏防范： OffscreenCanvas 每次调用 transferToImageBitmap() 都会转移当前画布内容并清空上下文，主线程在使用完毕后应注意垃圾回收，避免大批 ImageBitmap 长期驻留显存。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import ImageTileSource from 'ol/source/ImageTile.js';

// Initialize Web Worker for offscreen tile rendering
// 初始化用于离屏瓦片渲染的 Web Worker
const worker = new Worker(
  new URL(
    './tiled-layer-rendering-in-offscreen-canvas.worker.js',
    import.meta.url,
  ),
  {type: 'module'},
);

const tileQueue = [];

// Initialize map with custom tile loader delegated to worker
// 初始化地图，使用委托给 Worker 的自定义瓦片加载器
new Map({
  layers: [
    new TileLayer({
      source: new ImageTileSource({
        tileSize: 512,
        loader: (z, x, y) => {
          return new Promise((resolve) => {
            const loadTile = () => {
              const handleMessage = ({data: {action, imageData}}) => {
                if (action !== 'rendered') {
                  return;
                }
                worker.removeEventListener('message', handleMessage);
                resolve(imageData);
                tileQueue.shift();
                const loadNextTile = tileQueue[0];
                loadNextTile?.();
              };
              worker.addEventListener('message', handleMessage);
              worker.postMessage({action: 'render', tile: [z, x, y]});
            };
            if (tileQueue.length === 0) {
              loadTile();
            }
            tileQueue.push(loadTile);
          });
        },
        attributions: [
          '<a href="https://www.openstreetmap.org/copyright" target="_blank">© OpenStreetMap contributors</a>',
        ],
      }),
    }),
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

tiled-layer-rendering-in-offscreen-canvas.worker.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';
import {createXYZ} from 'ol/tilegrid.js';

const worker = self;

// Create 512x512 tile grid
// 创建 512×512 像素瓦片网格
const tileGrid = createXYZ({
  tileSize: [512, 512],
});

// Create offscreen canvas as headless map render target
// 创建离屏画布作为无头地图的渲染容器
const canvas = new OffscreenCanvas(512, 512);

// Initialize headless map inside worker
// 在 Worker 内部初始化无头地图
const map = new Map({
  target: canvas,
  layers: [
    new TileLayer({
      source: new OSM({
        // No need to fade in tiles in the worker
        // Worker 中单帧截取无需开启瓦片淡入过渡动画
        transition: 0,
      }),
    }),
  ],
});

// Handle render message from main thread
// 处理来自主线程的瓦片渲染消息
worker.addEventListener('message', async ({data: {action, tile}}) => {
  if (action !== 'render') {
    return;
  }
  // Set view centered on tile extent and resolution
  // 将视图定位到当前瓦片中心与对应层级分辨率
  const view = new View({
    center: tileGrid.getTileCoordCenter(tile),
    resolution: tileGrid.getResolution(tile[0]),
  });
  map.setView(view);

  // Capture rendered frame and transfer to ImageBitmap
  // 监听渲染完成事件，截取离屏帧并通过 ImageBitmap 零拷贝传回
  map.once('rendercomplete', () => {
    const imageData = canvas.transferToImageBitmap();
    worker.postMessage({action: 'rendered', imageData: imageData}, [imageData]);
  });
});
