Layer Swipe (WebGL) / WebGL 卷帘对比（硬件级 Scissor 视口剪裁）

swipe2 webgl19

Cropping a WebGL tile layer. / 利用 WebGL prerender/postrender 钩子与 gl.scissor 硬件剪裁区实现图层卷帘对比。

The prerender and postrender events on a WebGL tile layer can be used to manipulate the WebGL context before and after rendering. In this case, the gl.scissor() method is called to clip the top layer based on the position of a slider.

Note: This example is minimalist and works as there is only one WebGL layer rendered. That might work as well if the layers are drawn to different contexts. This does not apply to several layers drawn to a single context, such as set with the 'className' property to 'canvas3d' on multiple layers. In such case, it would be wise to adapt your code using 'gl.clear' and other tweaks to the prerender/postrender event.

WebGL 瓦片图层上的 prerender 与 postrender 渲染生命周期事件，允许开发者在图层绘制前后直接操作底层的 WebGLRenderingContext 上下文。本例中调用了 WebGL 原生 API gl.scissor()，根据滑块位置动态限制顶层卫星影像图层的可见视口宽度，从而实现丝滑的图层卷帘卷动对比效果。

提示：本示例展示了单一 WebGL 图层上下文裁剪的实现模式。如果多个 WebGL 图层共享同一个绘制上下文（例如为多个图层设置相同的 className: 'canvas3d'），需在 prerender/postrender 中注意配合 gl.clear 及深度/模板缓冲区管理，防止状态冲突。

📚 学习记录与技术深度解读 (Learning Notes)

1. 为什么 WebGL 卷帘要用 gl.scissor() 而不是 Canvas 2D 的 clip()？

  • 零栅格化开销：传统 Canvas 2D 卷帘通过在每帧构建矩形路径并调用 ctx.clip()，底层依靠 CPU/GPU 进行软件掩模计算。
  • GPU 硬件级视口剪裁（Scissor Test）：WebGL 的 gl.scissor(x, y, width, height) 是显卡固化管线支持的基础功能。启用 gl.SCISSOR_TEST 后，GPU 在光栅化测试阶段直接剔除指定矩形窗口之外的所有片元（Fragments），完全不产生额外的像素计算或纹理拷贝开销，无论图层瓦片多么庞大，帧率均保持绝对稳定。

2. 坐标转换细节：CSS 像素与物理渲染设备像素

  • getRenderPixel 的必要性：在高分屏（Retina / devicePixelRatio > 1）下，地图 DOM 的 CSS 尺寸与 WebGL 画布的物理像素分辨率并不一致。
  • 坐标原点对齐：HTML DOM 坐标系以左上角为原点（Y 轴向下），而 WebGL 坐标系以左下角为原点（Y 轴向上）。本例使用 getRenderPixel(event, [0, mapSize[1]]) 获取左下角物理像素坐标，完美对齐了屏幕分辨率与 GPU 裁剪原点。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import {getRenderPixel} from 'ol/render.js';
import ImageTile from 'ol/source/ImageTile.js';
import OSM from 'ol/source/OSM.js';

// Base OSM layer / 底层 OSM 矢量底图
const osm = new TileLayer({
  source: new OSM({wrapX: true}),
});

const key = 'Get your own API key at https://www.maptiler.com/cloud/';

// Top satellite imagery layer to be clipped / 顶层待剪裁的卫星遥感瓦片图层
const imagery = new TileLayer({
  source: new ImageTile({
    url: 'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
    attributions:
      '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
      '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>',
    maxZoom: 20,
  }),
});

const map = new Map({
  layers: [osm, imagery],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

const swipe = document.getElementById('swipe');

// Hook into prerender: enable scissor test and set scissor box based on slider value
// 挂载 prerender 钩子：开启硬件剪裁测试并根据滑块位置动态设置剪裁矩形
imagery.on('prerender', function (event) {
  const gl = event.context;
  gl.enable(gl.SCISSOR_TEST);

  const mapSize = map.getSize(); // [width, height] in CSS pixels / CSS 像素视口宽高

  // Get physical render coordinates and dimensions given CSS coordinates
  // 将 CSS 视口坐标转换为物理渲染像素坐标
  const bottomLeft = getRenderPixel(event, [0, mapSize[1]]);
  const topRight = getRenderPixel(event, [mapSize[0], 0]);

  const width = Math.round(
    (topRight[0] - bottomLeft[0]) * (Number(swipe.value) / 100),
  );
  const height = topRight[1] - bottomLeft[1];

  gl.scissor(bottomLeft[0], bottomLeft[1], width, height);
});

// Hook into postrender: disable scissor test to avoid affecting other layers
// 挂载 postrender 钩子：禁用硬件剪裁测试，防止污染后续图层上下文
imagery.on('postrender', function (event) {
  const gl = event.context;
  gl.disable(gl.SCISSOR_TEST);
});

// Trigger map redraw on slider input / 滑块拖动时触发地图重绘
swipe.addEventListener('input', function () {
  map.render();
});
