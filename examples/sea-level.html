This example uses a ol/source/Raster with MapTiler Terrain-RGB tiles to "flood" areas below the elevation shown on the sea level slider.

本示例演示了如何利用 ol/source/Raster 对 MapTiler Terrain-RGB 地形瓦片 执行客户端逐像素高程解码，并动态模拟海平面上升（Sea Level Rise）的淹没泛洪效果。

通过滑动条调节海平面相对上升高度（0 ~ 100 米），光栅数据源在后台 Web Worker 中实时将地表海拔低于该阈值的陆地区域渲染为半透明水体；同时监听光标移动，调用 raster.getData(coordinate) 实时提取并显示鼠标指针所在位置的亚米级真实地表海拔，并提供旧金山、纽约、孟买、上海等沿海重点城市的快速视角跳转。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计机制 (Core Architecture & Mechanics) - **Mapbox / MapTiler Terrain-RGB 编码协议规范**： Terrain-RGB 是目前数字高程切片（DEM Tiles）的行业通行标准，其高程（单位：米）解码公式为： $$\text{Elevation (m)} = -10000 + (R \times 256^2 + G \times 256 + B) \times 0.1$$ - 基础偏移量：$-10000\text{ m}$，以涵盖全球最深的海沟（如马里亚纳海沟 $-10984\text{ m}$ 附近）； - 垂直精度：$0.1\text{ m}$（10 厘米），足以支持微观城市洪涝与地形分析； - 动态范围：$256^3 \times 0.1 - 10000 \approx 1667721\text{ m}$，覆盖地球所有陆地山峰与深海。 - **地形源必须禁用双线性颜色插值 (`interpolate: false`)**： 这是 Terrain-RGB 处理中最致命的工程避坑点！默认情况下浏览器和 WebGL 会对图像切片进行双线性插值（Bilinear Filter），这在普通视觉照片上能获得平滑过渡，但在以字节数值为语义的 Terrain-RGB 上，插值会导致 $R$、$G$、$B$ 通道独立混合，从而在切片边界或不同色块交界处产生极其怪异的几千米高程尖刺或深谷。**在实例化 `ImageTile` 时必须显式声明 `interpolate: false`（强制采用最近邻采样 Nearest Neighbor）**。 #### 2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns) - **高性能 Web Worker 阈值泛洪着色算子**： ```javascript function flood(pixels, data) { const pixel = pixels[0]; if (pixel[3]) { // Alpha 通道存在有效数据 const height = -10000 + (pixel[0] * 256 * 256 + pixel[1] * 256 + pixel[2]) * 0.1; if (height <= data.level) { // 低于设定水位线，涂装为浅蓝色水体 pixel[0] = 134; pixel[1] = 203; pixel[2] = 249; pixel[3] = 255; } else { pixel[3] = 0; // 高于水位线完全透明，透出底图街道 } } return pixel; } ``` 逐像素操作极其轻量，毫秒级响应滑块拖拽事件。 - **坐标反查原始像素值 (`raster.getData(coordinate)`)**： ```javascript map.on(['pointermove', 'click'], function (event) { const pixels = raster.getData(event.coordinate); const pixel = pixels && pixels[0]; if (pixel && pixel[3]) { const height = -10000 + (pixel[0] * 256 * 256 + pixel[1] * 256 + pixel[2]) * 0.1; elevationOutput.innerText = Math.round(height) + ' m'; } }); ``` `raster.getData()` 能够精准从底层光栅图层的当前离屏像素缓存中提取坐标处输入源的原始 RGBA 值，实现零网络二次请求的即时海拔点选拾取。 #### 3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices) - **地形切片最大层级与超视口拉伸**： Terrain-RGB 切片通常最大仅预生成至 `z: 14`，而城市街区矢量底图可达 `z: 22`。代码中为地形源配置了 `maxZoom: 14`，当用户继续放大时，OpenLayers 会自动将 14 级切片进行空间几何坐标拉伸放大展示，防止放大后高程图层突然空白消失。 - **水体淹没与水动力拓扑连通性区别**： 需注意本示例展示的是**纯几何海拔阈值切分（Simple Inundation Model）**。真实水动力学（如风暴潮、海平面上升）中，地势低洼但四周有防洪堤坝环抱的内陆盆地（如荷兰围海造田区）不会直接被海水淹没。若需高精度灾情评估，建议结合 `region-growing`（区域生长）算法，以入海口为种子点进行水系连通性阻隔计算。 tags: "raster, pixel operation, flood" ---
