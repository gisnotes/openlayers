Mapbox-gl Layer / 深度集成 Mapbox GL JS 渲染引擎图层

Example of a Mapbox-gl-js layer integration. / 演示如何使用自定义 Layer 渲染函数将 Mapbox GL JS 实例挂载为底图，并叠加 OpenLayers 热力图。

Show how to add a mapbox-gl-js layer in an OpenLayers map. Note: Make sure to get your own API key at https://www.maptiler.com/cloud/ when using this example. No map will be visible when the API key has expired. mapbox-gl-js version 1.13.3 is used in this example as starting with version 2 a Mapbox access token is required.

本示例展示了如何将一个完全由 mapbox-gl-js 实例驱动的 WebGL 画布作为自定义图层无缝嵌入到 OpenLayers 的渲染管线中，并在上方完美叠加 OpenLayers 原生的地震震级热力图（HeatmapLayer）。注意：本示例使用 MapTiler 矢量样式底图，需配合有效的 MapTiler API Key 运行。出于开源许可兼容性，本例使用的是无需强制 Mapbox 商业鉴权的 mapbox-gl-js v1.13.3 版本。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计思想 (Core Architecture & Design)

  • 跨地图引擎的双核渲染同步架构： 由 OpenLayers 掌管主视口事件（拖拽平移、滚轮缩放、旋转手势），Mapbox GL JS 仅作为“静默渲染从属节点（Interactive: false）”。在 OpenLayers 的每帧 render(frameState) 周期中，通过 mbMap.jumpTo() 强行将 Mapbox 的视口中心（toLonLat）、缩放层级（zoom - 1，注意 Mapbox 与 OpenLayers 的 Zoom 定义相差 1 级）以及旋转偏角（bearing）与 OpenLayers 保持绝对数学对齐。
  • 同步渲染帧拦截（Synchronous Redraw Hook）： Mapbox GL JS 默认拥有独立的渲染时钟。为了彻底消除两者在快速拖拽时的视口抖动与撕裂，本例通过取消 Mapbox 的排队帧 mbMap._frame.cancel()，并强制调用其底层同步绘制接口 mbMap._render()，确保两者的画布在同一物理刷新帧中完成绘制。

2. 源码与关键 API 剖析 (Source Code & API Analysis)

  • const mbLayer = new Layer({ render: function(frameState) { ... return canvas; } })： OpenLayers 的万能图层接入机制，返回第三方库的 HTML5 Canvas DOM 节点即可将其纳入 OpenLayers 容器树与层级管理。
  • Zoom 级别换算校准： zoom: viewState.zoom - 1，这是因为 OpenLayers 的瓦片切片尺寸基准通常为 256 像素，而 Mapbox GL 瓦片基准为 512 像素，二者层级在物理分辨率上恰好相差一倍（即差 1 个 Zoom 级别）。

3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization)

  • 多 WebGL Context 显存与崩溃风险： 浏览器对同一页面的 WebGL 上下文数量有严格上限（通常在移动端仅 8~16 个）。若页面同时创建了多个 Mapbox GL 实例或同时开启了 OpenLayers 的 WebGLTile 图层，需严格防范 WebGL Context Lost 崩溃。
  • 私有 API 依赖维护警示： 代码中调用的 mbMap._frame 和 mbMap._render() 属于 Mapbox GL JS 的内部私有方法。在升级 Mapbox GL JS 或切换为 MapLibre GL 时，应注意该内部调用的兼容性变更。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import HeatmapLayer from 'ol/layer/Heatmap.js';
import Layer from 'ol/layer/Layer.js';
import {fromLonLat, toLonLat} from 'ol/proj.js';
import Source from 'ol/source/Source.js';
import VectorSource from 'ol/source/Vector.js';

const center = [-98.8, 37.9];
const key = 'Get your own API key at https://www.maptiler.com/cloud/';

const mbMap = new mapboxgl.Map({
  style: 'https://api.maptiler.com/maps/dataviz-light/style.json?key=' + key,
  attributionControl: false,
  boxZoom: false,
  center: center,
  container: 'map',
  doubleClickZoom: false,
  dragPan: false,
  dragRotate: false,
  interactive: false,
  keyboard: false,
  pitchWithRotate: false,
  scrollZoom: false,
  touchZoomRotate: false,
});

const mbLayer = new Layer({
  render: function (frameState) {
    const canvas = mbMap.getCanvas();
    const viewState = frameState.viewState;

    const visible = mbLayer.getVisible();
    canvas.style.display = visible ? 'block' : 'none';
    canvas.style.position = 'absolute';

    const opacity = mbLayer.getOpacity();
    canvas.style.opacity = opacity;

    // adjust view parameters in mapbox
    const rotation = viewState.rotation;
    mbMap.jumpTo({
      center: toLonLat(viewState.center),
      zoom: viewState.zoom - 1,
      bearing: (-rotation * 180) / Math.PI,
      animate: false,
    });

    // cancel the scheduled update & trigger synchronous redraw
    // see https://github.com/mapbox/mapbox-gl-js/issues/7893#issue-408992184
    // NOTE: THIS MIGHT BREAK IF UPDATING THE MAPBOX VERSION
    if (mbMap._frame) {
      mbMap._frame.cancel();
      mbMap._frame = null;
    }
    mbMap._render();

    return canvas;
  },
  source: new Source({
    attributions: [
      '<a href="https://www.maptiler.com/copyright/" target="_blank">© MapTiler</a>',
      '<a href="https://www.openstreetmap.org/copyright" target="_blank">© OpenStreetMap contributors</a>',
    ],
  }),
});

const cities = new HeatmapLayer({
  source: new VectorSource({
    url: 'https://cdn.jsdelivr.net/gh/gisnotes/openlayers@gh-pages/examples/data/geojson/world-cities.geojson',
    format: new GeoJSON(),
  }),
  weight: function (feature) {
    return feature.get('population') / 1e7;
  },
  radius: 15,
  blur: 15,
});

const map = new Map({
  target: 'map',
  view: new View({
    center: fromLonLat(center),
    zoom: 4,
  }),
  layers: [mbLayer, cities],
});
