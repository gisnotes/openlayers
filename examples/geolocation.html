Using geolocation to control a map view. / 使用 HTML5 Geolocation API 获取设备定位与精度圈并联动地图视图。

This example uses the Geolocation API to control the view.

本示例展示了如何使用 OpenLayers 的 ol/Geolocation 组件封装 W3C HTML5 Geolocation 定位服务。通过开启位置跟踪（Tracking），可以实时获取设备的地理坐标、定位精度范围（Accuracy Polygon）、海拔高度、运动航向角（Heading）以及移动速度，并以动态点标与精度圆的形式直观呈现在地图上。

📚 学习记录与技术深度解读 (Learning Notes)

1. ol/Geolocation 核心架构与坐标转换

  • 跨投影坐标自动映射: 原生浏览器 navigator.geolocation 返回的经纬度恒为 WGS84（EPSG:4326）椭球坐标。在构造 new Geolocation({projection: view.getProjection()}) 时绑定视图投影，OpenLayers 会在内部管线中透明完成向视图投影（如 Web 墨卡托）的实时数学转换，geolocation.getPosition() 直接输出视图坐标。
  • 高精度模式与航向获取 (enableHighAccuracy): 配置 trackingOptions: { enableHighAccuracy: true } 是移动设备开启物理 GPS/北斗卫星芯片的必要条件。只有开启高精度模式且设备处于位移运动中时，浏览器才会返回有效的 heading（航向弧度）与 speed（速度 m/s）。

2. 精度范围多边形几何体 (accuracyGeometry)

  • 自动生成米制精度圆: geolocation.getAccuracyGeometry() 依据 GPS 报告的水平精度半径（米）与当前经纬度，在投影坐标系内直接构造一个圆形面多边形（Polygon）。
  • 响应式几何数据绑定: 通过监听 change:accuracyGeometry 与 change:position，将几何体实时绑定至静态要素 accuracyFeature 与 positionFeature，实现与地图矢量渲染管线的解耦联动。

3. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices)

  • HTTPS 强制安全上下文 (Secure Context): 所有主流现代移动端浏览器均将 Geolocation API 限制在 HTTPS 协议下运行。在未经 SSL 证书加密的 HTTP 生产站点中调用，将直接触发用户权限拒绝或被浏览器静默拦截。
  • 能耗控制与生命周期管理: 持续开启高精度追踪会使移动终端的 GPS 射频模块处于高功耗唤醒状态。业务中应在用户最小化应用、锁屏或离开当前页面时调用 geolocation.setTracking(false) 及时挂起定位，按需恢复。
  • 室内弱信号与降级处理: 监听 error 事件（包含 PERMISSION_DENIED 权限被拒、POSITION_UNAVAILABLE 信号丢失、TIMEOUT 请求超时），并在 UI 界面提供用户友好提示或降级采用 IP 粗略定位。
main.js 
import Feature from 'ol/Feature.js';
import Geolocation from 'ol/Geolocation.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Point from 'ol/geom/Point.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';
import CircleStyle from 'ol/style/Circle.js';
import Fill from 'ol/style/Fill.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

// Initialize initial map view centered at [0, 0]
// 初始化地图初始视图：居中于全球原点 [0, 0]
const view = new View({
  center: [0, 0],
  zoom: 2,
});

// Map instance with OpenStreetMap base layer
// 地图实例：挂载标准 OSM 切片底图
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: view,
});

// Initialize OpenLayers Geolocation controller
// 初始化 OpenLayers 地理定位控制器：配置高精度模式并自动绑定视图投影
const geolocation = new Geolocation({
  // enableHighAccuracy must be set to true to have the heading value.
  // 必须将 enableHighAccuracy 设为 true 才能在移动设备上启用物理 GPS 并获取航向角与速度
  trackingOptions: {
    enableHighAccuracy: true,
  },
  projection: view.getProjection(),
});

function el(id) {
  return document.getElementById(id);
}

// Toggle position tracking on checkbox change
// 监听复选框切换：动态启动或暂停 GPS 位置追踪
el('track').addEventListener('change', function () {
  geolocation.setTracking(this.checked);
});

// Update the HTML dashboard when any geolocation attribute changes
// 监听位置及运动指标变更事件：更新网页仪表盘信息
geolocation.on('change', function () {
  el('accuracy').innerText = geolocation.getAccuracy() + ' [m]';
  el('altitude').innerText = geolocation.getAltitude() + ' [m]';
  el('altitudeAccuracy').innerText = geolocation.getAltitudeAccuracy() + ' [m]';
  el('heading').innerText = geolocation.getHeading() + ' [rad]';
  el('speed').innerText = geolocation.getSpeed() + ' [m/s]';
});

// Handle geolocation errors (permission denied, timeout, unavailable)
// 监听定位异常：呈现错误提示信息
geolocation.on('error', function (error) {
  const info = document.getElementById('info');
  info.innerHTML = error.message;
  info.style.display = '';
});

// Accuracy polygon feature representation
// 定位精度范围面要素：监听 change:accuracyGeometry 动态更新圆形包围面
const accuracyFeature = new Feature();
geolocation.on('change:accuracyGeometry', function () {
  accuracyFeature.setGeometry(geolocation.getAccuracyGeometry());
});

// User location marker point feature representation
// 用户当前位置点要素：监听 change:position 动态更新几何位置点
const positionFeature = new Feature();
positionFeature.setStyle(
  new Style({
    image: new CircleStyle({
      radius: 6,
      fill: new Fill({
        color: '#3399CC',
      }),
      stroke: new Stroke({
        color: '#fff',
        width: 2,
      }),
    }),
  }),
);

geolocation.on('change:position', function () {
  const coordinates = geolocation.getPosition();
  positionFeature.setGeometry(coordinates ? new Point(coordinates) : null);
});

// Dedicated vector layer for displaying the user position and accuracy circle
// 独立矢量图层：用于绘制精度范围面与位置点标记
new VectorLayer({
  map: map,
  source: new VectorSource({
    features: [accuracyFeature, positionFeature],
  }),
});
