This example shows how to use a WebGLVectorLayer to show a large amount of points on the map. The layer is given a style in JSON format which allows a certain level of customization of the final representation.

Consult the documentation on expressions to know which operators to use and how.

本示例演示如何使用 WebGLVectorLayer 在地图上高效呈现海量全球城市点位数据。该图层直接接收 JSON 格式的声明式样式表达式（FlatStyle），允许在底层直接调度 GPU 顶点与片元着色器，进行高度定制化的图形渲染与动态计算。

请参考 样式表达式文档（Expressions） 了解各前缀语法操作符（如 get、interpolate、match、zoom、time 等）的具体用法。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 声明式样式表达式语法树（AST Expressions） * **JSON Array 前缀语法**：OpenLayers WebGL 渲染器放弃了必须在 JS 线程中逐个要素执行的回调函数模式（`styleFunction(feature)`），采用可直接序列化并编译为 GLSL 着色器代码的抽象语法树（AST）数组： - `['get', 'population']`：提取要素的 `population` 属性映射为着色器顶点属性（Attribute）； - `['zoom']`：自动读取当前地图层级并在 GPU 顶点着色器中插值； - `['time']`：获取持续递增的动画时钟（秒），驱动几何图形持续自旋或起伏； - `['match', ['get', 'hover'], 1, '#ff3f3f', '#006688']`：三元分支判断，悬停高亮为红色。 #### 2. 多种预设渲染范式解析 * **`triangles`**：利用 `shape-points: 3` 参数化生成正三角形，颜色根据人口从绿色平滑过渡到橙色； * **`circles-zoom`**：使用底数为 2 的指数插值 `['interpolate', ['exponential', 2], ['zoom'], 5, 1.5, 15, 1536]`，使得圆形在地图缩放时能够严格保持真实地理物理尺寸（固定米制大小），而非固定屏幕像素； * **`rotating-bars`**：利用 `shape-rotation: ['*', ['time'], 0.13]` 驱动条形根据时间匀速自转，高度与位移随人口指数放大，实现生动的三维柱状可视化效果； * **`circles-text`**：在 WebGL 中同时绘制几何圆与文字注记（`text-value`），底层依托 SDF（有向距离场）或动态文字图集在 GPU 中栅格化渲染。 tags: "webgl, point, layer, feature" experimental: true ---
