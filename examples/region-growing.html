Region Growing / 种子点区域生长与交互式影像分割

raster7 regiongrowing1 maptiler26

Grow a region from a seed pixel. / 演示如何使用 ol/source/Raster 在 Web Worker 中执行图像级（image operation）区域生长算法（Region Growing / 泛洪填充），根据点击种子点与颜色容差动态提取连通地物。

Click a region on the map. The computed region will be red.

This example uses a ol/source/Raster to generate data based on another source. The raster source accepts any number of input sources (tile or image based) and runs a pipeline of operations on the input data. The return from the final operation is used as the data for the output source.

In this case, a single tiled source of imagery data is used as input. The region is calculated in a single "image" operation using the "seed" pixel provided by the user clicking on the map. The "threshold" value determines whether a given contiguous pixel belongs to the "region" - the difference between a candidate pixel's RGB values and the seed values must be below the threshold.

This example also shows how an additional function can be made available to the operation.

点击地图上的任意区域，系统将以该点击位置为种子点，动态计算并用红色渲染出连通分割区域。

本示例利用 ol/source/Raster 的 operationType: 'image' 整图运算模式，在后台 Web Worker 中运行经典的区域生长（Region Growing / Flood Fill）空间图像分割算法。 当用户点击地图时，地图坐标被转换为栅格像素种子，算法以广度优先搜索（BFS）向四周 4-邻域扩散；若相邻像素与种子像素的 RGB 颜色差异低于滑块设定的容差阈值（Threshold），则将其归入目标区域并高亮着色，实现纯前端、零服务端的交互式遥感水体或农田图斑提取。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计机制 (Core Architecture & Mechanics)

  • 整图操作模式 (operationType: 'image')： 通常的 RasterSource 采用逐像素模式（pixel 模式），每次函数调用只能访问单点孤立的像素数组 [R, G, B, A]，无法获知相邻像素信息。而将 operationType 设为 'image' 时：
    • Web Worker 接收到完整的 ImageData 对象（包含 width、height 与连续紧凑的 Uint8ClampedArray 数据缓冲区）；
    • 开发者可以自由实现依赖空间拓扑与邻域遍历的高级算子（如区域生长、Sobel 边缘检测、高斯模糊、腐蚀膨胀等）。
  • 广度优先搜索（BFS）区域生长状态机： 算法采用双缓冲边缘队列（edge 与 newedge）：
    1. 从种子像素索引 seedIdx 开始，读取基准色 $(R_{seed}, G_{seed}, B_{seed})$；
    2. 弹出当前边缘像素，调用 next4Edges 检查上、下、左、右 4-邻域；
    3. 判定颜色欧氏相似度：$|R - R_{seed}| < \Delta \land |G - G_{seed}| < \Delta \land |B - B_{seed}| < \Delta$；
    4. 命中像素在输出缓冲区染为红色，并将其压入下一轮生长边界；
    5. 原地访问标记（In-place Visited Flag）：巧妙将输入像素的 Alpha 通道置零（inputData[ci + 3] = 0），无需额外分配庞大的布尔访问标记矩阵，彻底杜绝回溯死循环并优化垃圾回收。

2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns)

  • 视口坐标到栅格像素坐标的映射：
    map.on('click', function (event) {
  coordinate = event.coordinate; // 记录地理坐标
  raster.changed();              // 触发栅格数据源重新执行计算
});

raster.on('beforeoperations', function (event) {
  const data = event.data;
  data.delta = thresholdControl.value;
  if (coordinate) {
    // 将地理投影坐标即时解算为当前视口屏幕像素坐标 [x, y]
    data.pixel = map.getPixelFromCoordinate(coordinate);
  }
});
    通过在 beforeoperations 中完成坐标系换算，将轻量级的 {pixel, delta} 纯数据对象传递至后台 Worker，保持前后端数据交互契约解耦。

3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices)

  • 长任务与大视口堆栈溢出防护： 区域生长若采用传统递归实现，在高分辨率大屏幕（如 4K 屏幕，数百万像素）遇到大面积纯色湖泊或天空时，极易发生 Maximum call stack size exceeded 调用栈崩溃。本示例采用迭代式队列（while-loop BFS）与边缘数组双缓冲，完全规避了栈溢出风险。
  • 跨视口重绘时种子点失效处理： 当用户点击确定种子点后，若随后拖拽平移了地图视口，屏幕像素坐标对应的地理目标会发生偏移。生产项目中建议记录地理坐标（Coordinate），并在每次重绘时根据最新的视口位置重新调用 map.getPixelFromCoordinate(coordinate) 计算新的种子像素；若种子点已滑出当前视口，则直接提前返回原始图像，防止出现错误的定位投影。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ImageLayer from 'ol/layer/Image.js';
import TileLayer from 'ol/layer/Tile.js';
import {fromLonLat} from 'ol/proj.js';
import ImageTile from 'ol/source/ImageTile.js';
import RasterSource from 'ol/source/Raster.js';

/**
 * Region growing segmentation algorithm running as an image operation in Web Worker.
 * 在 Web Worker 线程中运行的整图级区域生长空间分割算法
 * @param {Array<ImageData>} inputs Input images / 输入图像数据数组
 * @param {Object} data Context data from beforeoperations / 外部注入的上下文参数
 * @return {ImageData|Object} Output image with segmented region highlighted / 标记高亮后的输出图像
 */
function growRegion(inputs, data) {
  const image = inputs[0];
  let seed = data.pixel;
  const delta = parseInt(data.delta, 10);
  if (!seed) {
    return image;
  }

  seed = seed.map(Math.round);
  const width = image.width;
  const height = image.height;
  const inputData = image.data;
  const outputData = new Uint8ClampedArray(inputData);
  const seedIdx = (seed[1] * width + seed[0]) * 4;
  const seedR = inputData[seedIdx];
  const seedG = inputData[seedIdx + 1];
  const seedB = inputData[seedIdx + 2];
  let edge = [seed];
  while (edge.length) {
    const newedge = [];
    for (let i = 0, ii = edge.length; i < ii; i++) {
      // Access next4Edges provided through the lib option / 访问通过 lib 注入的 4-邻域搜索纯函数
      const next = next4Edges(edge[i]);
      for (let j = 0, jj = next.length; j < jj; j++) {
        const s = next[j][0];
        const t = next[j][1];
        if (s >= 0 && s < width && t >= 0 && t < height) {
          const ci = (t * width + s) * 4;
          const cr = inputData[ci];
          const cg = inputData[ci + 1];
          const cb = inputData[ci + 2];
          const ca = inputData[ci + 3];
          // If alpha is zero, it was already visited / 若 Alpha 为 0，说明此前已访问过，直接跳过
          if (ca === 0) {
            continue;
          }
          if (
            Math.abs(seedR - cr) < delta &&
            Math.abs(seedG - cg) < delta &&
            Math.abs(seedB - cb) < delta
          ) {
            // Highlight region pixel with opaque red / 满足容差阈值时染成不透明纯红
            outputData[ci] = 255;
            outputData[ci + 1] = 0;
            outputData[ci + 2] = 0;
            outputData[ci + 3] = 255;
            newedge.push([s, t]);
          }
          // Mark as visited in-place by zeroing alpha / 原地将 Alpha 置零充当访问标记
          inputData[ci + 3] = 0;
        }
      }
    }
    edge = newedge;
  }
  return {data: outputData, width: width, height: height};
}

/**
 * Return 4-connected neighbor pixel coordinates.
 * 获取当前像素上下左右 4-邻域连通坐标
 * @param {Array<number>} edge Pixel coordinates [x, y] / 当前像素坐标
 * @return {Array<Array<number>>} 4-connected neighbors / 四邻域坐标数组
 */
function next4Edges(edge) {
  const x = edge[0];
  const y = edge[1];
  return [
    [x + 1, y],
    [x - 1, y],
    [x, y + 1],
    [x, y - 1],
  ];
}

// MapTiler key and attributions / MapTiler 访问凭证与版权声明
const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Base satellite imagery tile layer / 卫星遥感正射底图瓦片图层
const imagery = new TileLayer({
  source: new ImageTile({
    attributions: attributions,
    url: 'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
    tileSize: 512,
    maxZoom: 20,
  }),
});

// Raster source configured with image-level operation / 配置为整图运算模式的栅格数据源
const raster = new RasterSource({
  sources: [imagery.getSource()],
  operationType: 'image',
  operation: growRegion,
  // Functions in the `lib` object are serialized to the web worker / lib 中的辅助函数会被序列化注入到 Web Worker
  lib: {
    next4Edges: next4Edges,
  },
});

// Semi-transparent overlay displaying computed segmented region / 半透明栅格图层展示计算得出的分割区域
const rasterImage = new ImageLayer({
  opacity: 0.7,
  source: raster,
});

// Initialize map centered near Grand Coulee, WA / 初始化地图并定位至华盛顿州大库力水库
const map = new Map({
  layers: [imagery, rasterImage],
  target: 'map',
  view: new View({
    center: fromLonLat([-119.07, 47.65]),
    zoom: 11,
  }),
});

let coordinate;

// Click event records geographic seed coordinate and triggers re-computation
// 点击地图记录种子地理坐标，并触发栅格数据源重新计算
map.on('click', function (event) {
  coordinate = event.coordinate;
  raster.changed();
});

const thresholdControl = document.getElementById('threshold');

// Inject latest parameters into worker before operation execution / 在计算前将最新参数装配入 Worker 上下文
raster.on('beforeoperations', function (event) {
  const data = event.data;
  data.delta = thresholdControl.value;
  if (coordinate) {
    data.pixel = map.getPixelFromCoordinate(coordinate);
  }
});

function updateControlValue() {
  document.getElementById('threshold-value').innerText = thresholdControl.value;
}
updateControlValue();

// Threshold slider changes re-trigger region growing / 滑块调节颜色容差并即时重新执行分割
thresholdControl.addEventListener('input', function () {
  updateControlValue();
  raster.changed();
});
