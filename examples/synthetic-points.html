Synthetic Points / 海量合成离散点图元压测与即时渲染动画

vector87

Synthetic points example. / 演示如何动态生成 20000 个带属性的散点要素，并使用 postrender 挂载即时矢量动画。

Synthetic points example creating 20,000 Point features with custom styles to benchmark vector rendering performance and demonstrate animation effects.

本示例是一个用于评估点要素海量并发渲染与动画性能的基准测试。在内存中随机生成 20,000 个带有尺寸属性的 Point 点要素，采用预建样式字典查表避免 GC 抖动，并通过 postrender 事件拦截 Canvas 绘图上下文绘制旋转动态扫描线，验证在高负载状态下的动画平滑度。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计思想 (Core Architecture & Design)

  • 基于字典查表的动态样式函数（Lookup Style Pattern）： 每个要素拥有不同的属性值（本例为 size: 10 或 size: 20）。初学者容易在样式函数中每次都 new Style(...)，这会导致浏览器在每秒 60 帧的渲染循环中创建和销毁数十万个对象，造成严重的内存泄漏与垃圾回收卡死。本例预先实例化 styles = { '10': ..., '20': ... }，函数内仅执行极其廉价的字典下标查询 return styles[feature.get('size')]。
  • postrender 驱动的每帧动画管线： 利用地图层的 postrender 事件，调用 getVectorContext(event) 获取即时矢量绘图上下文（Immediate Rendering），将一根随时间旋转的扫描线直接绘制在顶层，并通过 map.render() 形成稳定的 60FPS 动画循环。

2. 源码与关键 API 剖析 (Source Code & API Analysis)

  • getVectorContext(event)： 轻量即时渲染接口，允许跳过数据源和要素树，直接将任意几何对象（LineString）瞬时投射在视口上。
  • 极坐标扫描线旋转数学： 利用正弦和余弦函数：x = Math.sin(angle) * radius，y = Math.cos(angle) * radius，以视口几何中心为原点计算动态线段端点。

3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization)`

  • 海量离散点的技术选型演进： 20,000 个点已达到普通 Canvas 2D 路径绘制的性能拐点。如果点位数量进一步增加（如 10万~100万点），在 OpenLayers 中应优先选用 WebGLPointsLayer（基于 GPU 实例化渲染，数百万点依旧 60FPS），或结合 ol/source/Cluster 进行基于屏幕像素距离的聚类聚合。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import LineString from 'ol/geom/LineString.js';
import Point from 'ol/geom/Point.js';
import VectorLayer from 'ol/layer/Vector.js';
import {getVectorContext} from 'ol/render.js';
import VectorSource from 'ol/source/Vector.js';
import CircleStyle from 'ol/style/Circle.js';
import Fill from 'ol/style/Fill.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

const count = 20000;
const features = new Array(count);
const e = 18000000;
for (let i = 0; i < count; ++i) {
  features[i] = new Feature({
    'geometry': new Point([
      2 * e * Math.random() - e,
      2 * e * Math.random() - e,
    ]),
    'i': i,
    'size': i % 2 ? 10 : 20,
  });
}

const styles = {
  '10': new Style({
    image: new CircleStyle({
      radius: 5,
      fill: new Fill({color: '#666666'}),
      stroke: new Stroke({color: '#bada55', width: 1}),
    }),
  }),
  '20': new Style({
    image: new CircleStyle({
      radius: 10,
      fill: new Fill({color: '#666666'}),
      stroke: new Stroke({color: '#bada55', width: 1}),
    }),
  }),
};

const vectorSource = new VectorSource({
  features: features,
  wrapX: false,
});
const vector = new VectorLayer({
  source: vectorSource,
  style: function (feature) {
    return styles[feature.get('size')];
  },
});

const map = new Map({
  layers: [vector],
  target: document.getElementById('map'),
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

let point = null;
let line = null;
const displaySnap = function (coordinate) {
  const closestFeature = vectorSource.getClosestFeatureToCoordinate(coordinate);
  if (closestFeature === null) {
    point = null;
    line = null;
  } else {
    const geometry = closestFeature.getGeometry();
    const closestPoint = geometry.getClosestPoint(coordinate);
    if (point === null) {
      point = new Point(closestPoint);
    } else {
      point.setCoordinates(closestPoint);
    }
    if (line === null) {
      line = new LineString([coordinate, closestPoint]);
    } else {
      line.setCoordinates([coordinate, closestPoint]);
    }
  }
  map.render();
};

map.on('pointermove', function (evt) {
  if (evt.dragging) {
    return;
  }
  const coordinate = map.getEventCoordinate(evt.originalEvent);
  displaySnap(coordinate);
});

map.on('click', function (evt) {
  displaySnap(evt.coordinate);
});

const stroke = new Stroke({
  color: 'rgba(255,255,0,0.9)',
  width: 3,
});
const style = new Style({
  stroke: stroke,
  image: new CircleStyle({
    radius: 10,
    stroke: stroke,
  }),
});

vector.on('postrender', function (evt) {
  const vectorContext = getVectorContext(evt);
  vectorContext.setStyle(style);
  if (point !== null) {
    vectorContext.drawGeometry(point);
  }
  if (line !== null) {
    vectorContext.drawGeometry(line);
  }
});

map.on('pointermove', function (evt) {
  if (evt.dragging) {
    return;
  }
  const hit = map.hasFeatureAtPixel(evt.pixel);
  map.getTargetElement().style.cursor = hit ? 'pointer' : '';
});
