A raster source allows arbitrary manipulation of pixel values. In this example, RGB values on the input tile source are adjusted in a pixel-wise operation before being rendered with a second raster source. The raster operation takes pixels in RGB space, converts them to HCL color space, adjusts the values based on the controls above, and then converts them back to RGB space for rendering.

栅格数据源（RasterSource）允许开发者在客户端对任意图层的像元像素进行深度数学运算。在这一示例中，输入的底图切片源像素在被渲染之前，由后台独立 Web Worker 执行逐像素数学变换：将原生 RGB 颜色空间映射到更加贴合人类视觉感知的 HCL（Hue 色相, Chroma 色度, Lightness 亮度） 色彩空间，根据界面控件动态调整对应分量后，再逆变换回 RGB 空间渲染输出。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - **`RasterSource` 客户端栅格代数计算管线**： 传统的地图滤镜大多基于 CSS `filter`（如 `brightness()`、`contrast()`），其调整粗糙且无法针对非线性色彩空间操作。`RasterSource` 在独立于 UI 主线程的 Web Worker 中接收输入图层（如 `StadiaMaps` 水彩底图）的原始 `ImageData` 像素流，通过并行像元循环执行像素重构，彻底杜绝主线程卡顿。 - **为什么要从 RGB 转换到 HCL 色彩空间？**： RGB 空间是面向硬件发光管（红绿蓝）设计的，其三个通道在数学上与人类的主观明暗感知高度非线性耦合（例如绿色发光强度远高于蓝色）。而 **HCL（基于 CIE L\*a\*b\* 柱面极坐标）** 具有严格的**感知均匀性（Perceptually Uniform）**： - 调节 `Lightness` 只改变明暗，完全不影响色相； - 调节 `Hue` 在色环上均匀旋转，不会像 HSV 一样在黄色区域产生刺眼的假亮； - 调节 `Chroma` 线性改变色彩饱和纯度。 #### 2. 源码与关键 API 剖析 (Source Code & API Analysis) - `RasterSource({ sources, operation, lib })`： - `sources`：输入图层源数组（支持多个源同时输入进行波段代数运算）。 - `operation(pixels, data)`：每个像元执行的核心算法回调函数。必须保持为纯函数（无外部闭包变量引用）。 - `lib`：将 Worker 所需的纯数学辅助函数（如 `rgb2hcl`、`hcl2rgb`）序列化后注入 Worker 运行上下文。 - `beforeoperations` 数据注入与 `raster.changed()` 刷新通知： 监听 `raster.on('beforeoperations', (evt) => { evt.data.hue = ... })`，将 UI 主线程当前的滑动条数值打包写入 Worker 每帧执行上下文；滑块滑动时调用 `raster.changed()` 立即触发新一轮 Worker 运算。 #### 3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - **Worker 函数作用域隔离（`lib` 陷阱）**： `operation` 函数内部绝不能访问主线程的 `window`、`document` 或模块闭包作用域变量。所有依赖的数学常量（如 `twoPi`、`Xn`）和辅助函数必须显式列在 `lib` 属性字典中，否则在 Worker 线程解析时会报 `ReferenceError` 致命异常。 - **跨域切片 CORS 限制**： `RasterSource` 依赖 `ctx.getImageData()` 提取图像像素。如果底图瓦片服务器未正确配置 CORS 跨域响应头（`Access-Control-Allow-Origin: *`），浏览器会直接判定 Canvas 被污染（Tainted Canvas）并抛出安全安全错误拒绝导出像素。 tags: "color, hue, lightness, chroma" ---
