Drawing Features Style / 绘制要素时的自定义样式

draw17 style27

Example of using the ol/interaction/Draw interaction with drawing style configured. / 使用配置了自定义绘制草绘样式的 ol/interaction/Draw 交互示例。

The Draw interaction in this example uses a custom drawing style. Select a geometry type from the dropdown above to start drawing. To finish drawing, click the last point. To activate freehand drawing for lines, polygons, and circles, hold the Shift key.

此示例中的 Draw 交互使用了自定义的草绘样式（Drawing Style）。从上方的下拉列表中选择几何类型即可开始绘制。若要完成绘制，请双击或点击最后一个点。对于线、多边形和圆，按住 Shift 键可激活自由手绘模式（Freehand）。

📚 学习记录与技术笔记 (Learning Notes)

1. 这里是如何更改绘制点线面时的样式的？

  • 样式定义方式（Flat / Literal Style）： 代码中没有使用传统的 new Style({ ... })，而是采用了 OpenLayers 的字面量扁平样式对象（Flat Style）：
    • Point：'circle-radius': 5, 'circle-fill-color': 'red'（鼠标光标所在顶点显示红色圆点）。
    • LineString：黄色线条描边（宽度 2px），顶点伴随红色圆点。
    • Polygon：黄色边框，内部填充蓝色，顶点伴随红色圆点。
    • Circle：蓝色边框，内部填充黄色，顶点伴随红色圆点。
  • 样式注入方式： 在 addInteraction() 函数中，将对应几何类型的样式直接作为 style 配置项传入 new Draw({ source, type, style: styles[value] })。

2. 这个例子是在什么时机下更改样式的？

这里包含两个维度的关键时机：

  • 交互切换时机（用户交互层面）： 当用户在顶部下拉列表中切换几何类型时，触发 typeSelect.onchange 事件。逻辑中先通过 map.removeInteraction(draw) 销毁移除旧的交互实例，再调用 addInteraction() 重新创建一个绑定了新几何类型和对应 styles[value] 的 Draw 实例并重新挂载到地图上。
  • 要素生命周期时机（渲染生效阶段 - 核心原理）： 传给 Draw({ style }) 的样式仅仅在“正在绘制中（草绘状态 Sketching）”这一阶段生效。
    • 绘制中（草绘要素 Sketch Feature）：由 Draw 实例的 style 管控，呈现自定义的红点、黄线、蓝面等高对比度指示效果；
    • 绘制完成后（正式要素 Finished Feature）：一旦完成绘制（双击或点击最后一点），要素便脱离 Draw 交互并提交存入 VectorSource 中。此时要素不再由 Draw 管控，而是立刻转变为由所在 VectorLayer 图层的样式来渲染（因示例中矢量图层未配置自定义 style，故要素瞬间变回 OpenLayers 默认的蓝灰矢量样式）。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Draw from 'ol/interaction/Draw.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';

// Base map raster layer (OpenStreetMap)
// 基础底图栅格图层（OpenStreetMap）
const raster = new TileLayer({
  source: new OSM(),
});

// Vector source to store finished drawn features
// 用于存储绘制完成要素的矢量数据源
const source = new VectorSource({wrapX: false});

// Vector layer displaying the features (uses default OpenLayers style for finished features)
// 用于显示要素的矢量图层（绘制完成后的要素使用图层的默认样式显示）
const vector = new VectorLayer({
  source: source,
});

// Initialize the map
// 初始化地图
const map = new Map({
  layers: [raster, vector],
  target: 'map',
  view: new View({
    center: [-11000000, 4600000],
    zoom: 4,
  }),
});

// Custom sketch styles for each geometry type during the drawing interaction
// 绘制交互进行过程中针对各几何类型的自定义草绘样式（使用声明式字面量样式语法）
const styles = {
  Point: {
    'circle-radius': 5,
    'circle-fill-color': 'red',
  },
  LineString: {
    'circle-radius': 5,
    'circle-fill-color': 'red',
    'stroke-color': 'yellow',
    'stroke-width': 2,
  },
  Polygon: {
    'circle-radius': 5,
    'circle-fill-color': 'red',
    'stroke-color': 'yellow',
    'stroke-width': 2,
    'fill-color': 'blue',
  },
  Circle: {
    'circle-radius': 5,
    'circle-fill-color': 'red',
    'stroke-color': 'blue',
    'stroke-width': 2,
    'fill-color': 'yellow',
  },
};

const typeSelect = document.getElementById('type');

let draw; // global so we can remove it later / 全局变量，便于后续移除或重新绑定
function addInteraction() {
  const value = typeSelect.value;
  if (value !== 'None') {
    draw = new Draw({
      source: source,
      type: typeSelect.value,
      style: styles[value], // Apply custom sketch style during drawing / 应用绘制过程中的自定义草绘样式
    });
    map.addInteraction(draw);
  }
}

/**
 * Handle change event.
 * 处理下拉选项变更事件。
 */
typeSelect.onchange = function () {
  map.removeInteraction(draw);
  addInteraction();
};

addInteraction();
