Box Selection / 框选要素

Using a DragBox interaction to select features. / 使用 DragBox（拉框）交互进行矩形范围多选要素。

This example shows how to use a DragBox interaction to select features. Features are selected using a select interaction (ol/interaction/Select), to receive highlighting and apply filters (features with color #CC6767 are not selectable)

Use Ctrl+Drag (Command+Drag on Mac) to draw boxes.

本示例演示如何使用 DragBox（拉框）交互进行要素批量框选。所选要素由选择交互（ol/interaction/Select）进行统筹管理，提供选中高亮显示与业务过滤控制（颜色为 #CC6767 的要素被过滤为不可选择）。

按住 Ctrl+拖拽（Mac 上为 Command+拖拽）可在地图上拉出矩形框选要素。本例还特别处理了跨反子午线（180°）多世界投影范围拆分，以及视图处于斜向旋转角时的几何精确相交判定。

📚 学习记录与技术深度解读 (Learning Notes)

1. 跨反子午线（180° 日界线）的多世界拆解

  • 现象：Web 墨卡托投影世界在横向是无限循环平铺的（Multi-world Wrapping）。当用户横跨太平洋拉框时，拉出的矩形范围在单一世界坐标系下会跨出原始边界。
  • 解决方案：
    1. 计算当前世界的物理宽度：worldWidth = getWidth(worldExtent)；
    2. 计算拉框起始点与终止点分别处于第几个世界周期（startWorld 到 endWorld）；
    3. 遍历每个世界周期，分别计算局部相交要素并合并入选中集合。

2. 斜向旋转视图（Oblique View）下的几何旋转纠偏

  • 为什么不能直接用 intersectsExtent()？ 当视图存在旋转角时（rotation !== 0），屏幕上拉出的矩形在真实地理坐标系下其实是一个倾斜的平行四边形。如果直接使用其外包矩形测试相交，四周空白角区的大量无关要素会被假阳性误选。
  • 反向旋转算法： 将拉框几何与候选要素几何均绕原点 [0, 0] 反向旋转 -rotation，使拉框几何在数学空间上回归为轴对齐的标准矩形，然后再进行 intersectsExtent 判定，保证框选结果与用户肉眼在屏幕上框出的边界完全一致。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {platformModifierKeyOnly} from 'ol/events/condition.js';
import {getWidth} from 'ol/extent.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import DragBox from 'ol/interaction/DragBox.js';
import Select from 'ol/interaction/Select.js';
import VectorLayer from 'ol/layer/Vector.js';
import VectorSource from 'ol/source/Vector.js';
import Fill from 'ol/style/Fill.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

const vectorSource = new VectorSource({
  url: 'https://openlayers.org/data/vector/ecoregions.json',
  format: new GeoJSON(),
});

const style = new Style({
  fill: new Fill({
    color: '#eeeeee',
  }),
});

const map = new Map({
  layers: [
    new VectorLayer({
      source: vectorSource,
      background: '#1a2b39',
      style: function (feature) {
        const color = feature.get('COLOR_BIO') || '#eeeeee';
        style.getFill().setColor(color);
        return style;
      },
    }),
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
    constrainRotation: 16,
  }),
});

const selectedStyle = new Style({
  fill: new Fill({
    color: 'rgba(255, 255, 255, 0.6)',
  }),
  stroke: new Stroke({
    color: 'rgba(255, 255, 255, 0.7)',
    width: 2,
  }),
});

// a normal select interaction to handle click
// 常规 Select 交互用于处理点击选择与高亮样式过滤
const select = new Select({
  filter: function (feature) {
    return !(feature.get('COLOR_BIO') === '#CC6767');
  },
  style: function (feature) {
    const color = feature.get('COLOR_BIO') || '#eeeeee';
    selectedStyle.getFill().setColor(color);
    return selectedStyle;
  },
});
map.addInteraction(select);

// a DragBox interaction used to select features by drawing boxes
// DragBox 交互：通过修饰键（Ctrl/Command+拖拽）拉框框选要素
const dragBox = new DragBox({
  condition: platformModifierKeyOnly,
});

map.addInteraction(dragBox);

dragBox.on('boxend', function () {
  const boxExtent = dragBox.getGeometry().getExtent();

  // if the extent crosses the antimeridian process each world separately
  // 若外包矩形跨越了 180° 反子午线，则对每一个世界副本分别计算
  const worldExtent = map.getView().getProjection().getExtent();
  const worldWidth = getWidth(worldExtent);
  const startWorld = Math.floor((boxExtent[0] - worldExtent[0]) / worldWidth);
  const endWorld = Math.floor((boxExtent[2] - worldExtent[0]) / worldWidth);

  for (let world = startWorld; world <= endWorld; ++world) {
    const left = Math.max(boxExtent[0] - world * worldWidth, worldExtent[0]);
    const right = Math.min(boxExtent[2] - world * worldWidth, worldExtent[2]);
    const extent = [left, boxExtent[1], right, boxExtent[3]];

    const boxFeatures = vectorSource
      .getFeaturesInExtent(extent)
      .filter((feature) => feature.getGeometry().intersectsExtent(extent));

    // features that intersect the box geometry are added to the
    // collection of selected features
    // 与拉框几何相交的要素将被添加到选中要素集合中

    // if the view is not obliquely rotated the box geometry and
    // its extent are equalivalent so intersecting features can
    // be added directly to the collection
    // 如果视图未旋转（或为直角旋转），拉框几何与其外包矩形等价，可直接将相交要素添加至选中集合
    const rotation = map.getView().getRotation();
    const oblique = rotation % (Math.PI / 2) !== 0;

    // when the view is obliquely rotated the box extent will
    // exceed its geometry so both the box and the candidate
    // feature geometries are rotated around a common anchor
    // to confirm that, with the box geometry aligned with its
    // extent, the geometries intersect
    // 当视图处于倾斜旋转时，拉框的外包矩形会大于几何本身，
    // 需绕原点反向旋转拉框几何与候选要素几何，对齐后再判定相交
    if (oblique) {
      const anchor = [0, 0];
      const geometry = dragBox.getGeometry().clone();
      geometry.translate(-world * worldWidth, 0);
      geometry.rotate(-rotation, anchor);
      const extent = geometry.getExtent();
      boxFeatures.forEach(function (feature) {
        const geometry = feature.getGeometry().clone();
        geometry.rotate(-rotation, anchor);
        if (geometry.intersectsExtent(extent)) {
          select.selectFeature(feature);
        }
      });
    } else {
      boxFeatures.forEach(select.selectFeature.bind(select));
    }
  }
});

// clear selection when drawing a new box and when clicking on the map
// 开始新拉框绘制时清空之前的选择
dragBox.on('boxstart', function () {
  select.clearSelection();
});

const infoBox = document.getElementById('info');

select.on('select', function () {
  const names = select
    .getFeatures()
    .getArray()
    .map((feature) => {
      return feature.get('ECO_NAME');
    });
  if (names.length > 0) {
    infoBox.innerHTML = names.join(', ');
  } else {
    infoBox.innerHTML = 'None / 无';
  }
});
