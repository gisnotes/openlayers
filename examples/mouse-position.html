Mouse Position / 鼠标位置坐标控件 (MousePosition)

Example of a mouse position control, outside the map. / 在地图外部 DOM 容器中实时呈现鼠标指针坐标、支持投影与精度切换的示例。

Example of a mouse position control, outside the map.

本示例展示了 ol/control/MousePosition 控件的高级用法。该控件被挂载在地图视口外部的独立 DOM 容器中，随光标移动实时显示地理坐标，并支持在 EPSG:4326（经纬度）与 EPSG:3857（墨卡托米制）投影间动态切换，同时允许用户自由调节小数点精度。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 外部 DOM 挂载托管（External Target Mounting）： OpenLayers 的所有 UI 控件（Control）默认都挂载在地图内部的 .ol-overlaycontainer-stopevent 视口中。但通过配置 target: HTMLElement，可以将控件的实际 DOM 输出重定向到网页主布局的任何位置（例如系统底部的全景状态栏、侧边仪表盘），实现与外部 UI 框架的无缝咬合。
  • 动态投影解算通道（Real-Time Dynamic Projection）： 无论地图底层使用的 View 投影是什么（示例为 EPSG:3857），MousePosition 控件均可在内部根据配置的 projection: 'EPSG:4326' 自动执行坐标反算（toLonLat），直接将墨卡托米坐标转换为人类可读的经纬度度数，无需开发者编写额外的事件侦听转换代码。

2. 源码与关键 API 剖析

  • createStringXY(digits)：OpenLayers 内置的坐标格式化工具函数，接收一个数字作为小数位数，生成如 "116.3912, 39.9045" 的标准坐标字符串。
  • mousePositionControl.setProjection(proj)：动态更新当前输出投影体系，立即对当前坐标进行实时重投影。
  • mousePositionControl.setCoordinateFormat(formatFn)：支持传入自定义格式化函数，例如转换为度分秒（DMS）、军用 MGRS 网格或追加 经度/纬度 中文前缀。

3. 生产实践踩坑与性能调优

  • 光标离开视口处理： 当鼠标指针移出地图边界时，控件默认保留最后一次有效位置。若业务要求离开时清空显示或显示提示文字（如“请将光标移入地图”），可通过 undefinedHTML: '光标已移出视口' 配置项优雅实现。
  • 高刷屏（120Hz/144Hz）下的性能保障： 由于 pointermove 触发极其频繁，如果格式化函数内包含过重的字符串操作或复杂的 DOM 计算，可能会引起微小卡顿。推荐尽量采用简洁的原生字符串拼接。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import MousePosition from 'ol/control/MousePosition.js';
import {defaults as defaultControls} from 'ol/control/defaults.js';
import {createStringXY} from 'ol/coordinate.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';

// Initialize mouse position control targeted to external DOM container
// 初始化鼠标位置控件，并挂载到地图外部的 DOM 容器中
const mousePositionControl = new MousePosition({
  coordinateFormat: createStringXY(4),
  projection: 'EPSG:4326',
  // comment the following two lines to have the mouse position
  // be placed within the map.
  // 若需将鼠标位置控件放置在地图内部，可注释以下两行配置
  className: 'custom-mouse-position',
  target: document.getElementById('mouse-position'),
});

// Initialize map with mouse position control
// 初始化地图并挂载鼠标位置控件
const map = new Map({
  controls: defaultControls().extend([mousePositionControl]),
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// Handle projection select change
// 处理坐标投影切换
const projectionSelect = document.getElementById('projection');
projectionSelect.addEventListener('change', function (event) {
  mousePositionControl.setProjection(event.target.value);
});

// Handle coordinate precision change
// 处理坐标小数精度切换
const precisionInput = document.getElementById('precision');
precisionInput.addEventListener('change', function (event) {
  const format = createStringXY(event.target.valueAsNumber);
  mousePositionControl.setCoordinateFormat(format);
});
index.html 
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <title>Mouse Position / 鼠标位置坐标控件 (MousePosition)</title>
    <link rel="stylesheet" href="node_modules/ol/ol.css">
    <style>
      .map {
        width: 100%;
        height: 400px;
      }
    </style>
  </head>
  <body>
    <div id="map" class="map"></div>
    <div id="mouse-position"></div>
    <form>
      <label for="projection">Projection / 坐标系投影：</label>
      <select id="projection">
        <option value="EPSG:4326">EPSG:4326 (WGS84 经纬度)</option>
        <option value="EPSG:3857">EPSG:3857 (Web 墨卡托米制)</option>
      </select>
      <label for="precision">Precision / 小数精度：</label>
      <input id="precision" type="number" min="0" max="12" value="4"/>
    </form>

    <script type="module" src="main.js"></script>
  </body>
</html>
