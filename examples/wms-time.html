WMS Time / WMS 时间维度时序雷达动态播放

wms14 time4 dimensions4 transition4 nexrad2

Example of smooth tile transitions when changing the time dimension of a tiled WMS layer. / 演示连续切换瓦片式 WMS 图层的时间维度 (TIME 参数) 时的平滑瓦片过渡与雷达回波动态播放。

Demonstrates smooth reloading of layers when changing the time dimension continuously. Data shown: IEM generated CONUS composite of NWS NEXRAD WSR-88D level III base reflectivity. 本示例演示在连续动态切换时间维度时，瓦片图层如何平滑重载与过渡。 所展示的数据为爱荷华环境网（IEM）生成的美国国家气象局（NWS）NEXRAD WSR-88D 三级基数据雷达反射率全国雷达拼图。

📚 学习记录与技术深度解读 (Learning Notes)

1. WMS 时间维度规范（WMS-T / TIME 参数） * 在气象监测（雷达、卫星云图、台风路径）、海洋洋流、空气质量监测等业务场景中，地学栅格具有强烈的时序属性。 * OGC WMS 规范定义了标准的 TIME 参数：

https://.../wms?SERVICE=WMS&REQUEST=GetMap&LAYERS=...&TIME=2026-10-15T10:00:00.000Z
  • 时间参数格式采用 ISO 8601 标准字符串（UTC 时间）。

2. 原地热更新与双缓冲平滑过渡：updateParams({'TIME': ...}) * 传统重置图层的痛点：如果每次切换时间帧都调用 layer.setSource(newSource)，上一时刻的瓦片会瞬间消失，造成强烈的白屏闪烁。 * source.updateParams({'TIME': isoString}) 的优雅机制：

  • OpenLayers 内部维护了瓦片双缓冲机制（Tile Double Buffering）；
  • 当调用 updateParams 修改查询参数时，数据源会保留旧时间帧的瓦片继续在屏幕上显示；
  • 只有当新时间帧对应的所有新瓦片在后台完全下载解码完毕后，OpenLayers 才会平滑切换到新时间帧，实现毫无闪烁的电影级连续雷达播放！
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {getCenter} from 'ol/extent.js';
import TileLayer from 'ol/layer/Tile.js';
import {transformExtent} from 'ol/proj.js';
import StadiaMaps from 'ol/source/StadiaMaps.js';
import TileWMS from 'ol/source/TileWMS.js';

const interval = 3 * 60 * 60 * 1000;
const step = 15 * 60 * 1000;
const frameRate = 0.5; // frames per second / 每秒 0.5 帧
const extent = transformExtent([-126, 24, -66, 50], 'EPSG:4326', 'EPSG:3857');

let wmsTime = new Date();
let animationId = null;

// Base terrain layer from StadiaMaps
// StadiaMaps 地形底图图层
const stadiaLayer = new TileLayer({
  source: new StadiaMaps({
    layer: 'stamen_terrain',
  }),
});

// Weather radar WMS layer with time dimension
// 带有时间维度的气象雷达 WMS 图层
const tileWmsLayer = new TileLayer({
  extent: extent,
  source: new TileWMS({
    attributions: ['Iowa State University'],
    url: 'https://mesonet.agron.iastate.edu/cgi-bin/wms/nexrad/n0r-t.cgi',
    params: {'LAYERS': 'nexrad-n0r-wmst'},
  }),
});

const map = new Map({
  layers: [stadiaLayer, tileWmsLayer],
  target: 'map',
  view: new View({
    center: getCenter(extent),
    zoom: 4,
  }),
});

const el = document.getElementById('info');
function updateInfo(time) {
  el.innerHTML = time.toISOString();
}

function threeHoursAgo() {
  return new Date(Math.floor((Date.now() - interval) / step) * step);
}

// Advance time step and smoothly update WMS layer TIME parameter
// 推进时间步长并通过 updateParams 平滑更新 WMS 图层的 TIME 查询参数
function setTime() {
  wmsTime.setMinutes(wmsTime.getMinutes() + 15);
  if (wmsTime.getTime() > Date.now()) {
    wmsTime = threeHoursAgo();
  }
  tileWmsLayer.getSource().updateParams({'TIME': wmsTime.toISOString()});
  updateInfo(wmsTime);
}
setTime();

// Animation controls: play and pause
// 动画时序播放与暂停控制逻辑
const stop = function () {
  if (animationId !== null) {
    window.clearInterval(animationId);
    animationId = null;
  }
};

const play = function () {
  stop();
  animationId = window.setInterval(setTime, 1000 / frameRate);
};

const startButton = document.getElementById('play');
startButton.addEventListener('click', play, false);

const stopButton = document.getElementById('pause');
stopButton.addEventListener('click', stop, false);
