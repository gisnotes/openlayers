集成 Proj4js 的单图像 WMS (Single Image WMS with Proj4js)

wms14 singleimage1 proj4js6 projection14 mapserver5

演示通过集成 Proj4js 注册自定义投影定义，实现非内置投影下的单图像 WMS (ImageWMS) 渲染与坐标转换。

本例展示了 OpenLayers 与 Proj4js 的深度透明集成机制：通过注册自定义投影定义，在单图像 WMS（ol/source/ImageWMS）图层中无缝实现任意投影间的坐标正反算。

核心机制与原理解析

  1. 单图像 WMS（ImageWMS）的工作机制：

    • 与将地图切分为 256x256 固定网格的瓦片式 TileWMS 不同，ImageWMS 会在每次地图视口平移、缩放或窗口尺寸变化后，发起单次 HTTP 请求索要一幅与当前视口像素尺寸完全对应的全屏大图（参数中携带动态的 BBOX、WIDTH、HEIGHT 与 CRS）。
    • 适用场景：对于注记密集、水系复杂的专题业务图（如本例中瑞士环境局的全国洪水警戒图），单图像模式能完美避免瓦片接缝处的文字被截断、图标断裂或重复绘制的问题。

  2. 透明的 Proj4js 注册与绑定（register(proj4)）：

    • 调用 proj4.defs('EPSG:21781', '+proj=somerc ...') 声明瑞士旧国家投影（CH1903 / LV03，斜轴等角圆柱投影 / 贝塞尔椭球）；
    • 执行 register(proj4) 后，OpenLayers 的核心投影系统会自动与 Proj4js 建立双向函数查找映射。
    • 随后无论是创建 new Projection(...)，还是直接调用 fromLonLat([8.23, 46.86], projection)，OpenLayers 都能自动拾取底层正逆解算函数，实现经纬度到目标平面英制/米制坐标的即时计算。

  3. 投影合法范围（Extent）对视图分辨率的决定性作用：

    • 在创建 Projection 实例时配置 extent: [minx, miny, maxx, maxy]；
    • OpenLayers 视图（View）依据此包围盒计算 Zoom 0 级别的初始点分辨率与世界漫游约束，避免因未定义空间范围导致缩放级别错乱。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ScaleLine from 'ol/control/ScaleLine.js';
import {defaults as defaultControls} from 'ol/control/defaults.js';
import ImageLayer from 'ol/layer/Image.js';
import {fromLonLat} from 'ol/proj.js';
import Projection from 'ol/proj/Projection.js';
import {register} from 'ol/proj/proj4.js';
import ImageWMS from 'ol/source/ImageWMS.js';
import proj4 from 'proj4';

/**
 * Proj4js 透明集成机制说明：
 *
 * 1. 通过 proj4.defs() 注册 EPSG:21781 (瑞士国家投影 CH1903 / LV03) 的 Proj 字符串定义；
 * 2. 调用 register(proj4) 将 Proj4js 内部已注册的所有投影转换规则同步至 OpenLayers 全局投影表；
 * 3. 当我们通过 new Projection({code: 'EPSG:21781', ...}) 创建投影实例时，OpenLayers 会自动绑定 Proj4js 提供的正反算函数；
 *    若需直接获取带有单位、轴向等完整元数据的已注册投影对象，也可以直接调用 ol/proj#get('EPSG:21781')；
 * 4. 为投影配置的 extent 包围盒范围非常关键，OpenLayers 视图（View）依据该范围计算 Zoom 级别 0 时的默认初始分辨率。
 *    各投影的推荐有效范围可在 https://spatialreference.org/ 检索获取。
 */

// 注册瑞士国家投影定义（基于贝塞尔 1841 椭球体的斜轴等角圆柱投影 / 瑞士斜轴墨卡托）
proj4.defs(
  'EPSG:21781',
  '+proj=somerc +lat_0=46.95240555555556 +lon_0=7.439583333333333 +k_0=1 ' +
    '+x_0=600000 +y_0=200000 +ellps=bessel ' +
    '+towgs84=660.077,13.551,369.344,2.484,1.783,2.939,5.66 +units=m +no_defs',
);
// 同步注册至 OpenLayers
register(proj4);

// 创建带有合法有效范围的投影实例
const projection = new Projection({
  code: 'EPSG:21781',
  extent: [485869.5728, 76443.1884, 837076.5648, 299941.7864],
});

// 瑞士区域适用的显示范围 [minX, minY, maxX, maxY]（米）
const extent = [420000, 30000, 900000, 350000];

// 业务图层列表（均采用单图像 ImageLayer + ImageWMS）
const layers = [
  // 底图：瑞士联邦地形局 1:1,000,000 彩色像元地图（单图像 WMS）
  new ImageLayer({
    extent: extent,
    source: new ImageWMS({
      url: 'https://wms.geo.admin.ch/',
      crossOrigin: 'anonymous',
      attributions:
        '© <a href="https://shop.swisstopo.admin.ch/en/products/maps/national/lk1000"' +
        'target="_blank">Pixelmap 1:1000000 / geo.admin.ch</a>',
      params: {
        'LAYERS': 'ch.swisstopo.pixelkarte-farbe-pk1000.noscale',
        'FORMAT': 'image/jpeg',
      },
      serverType: 'mapserver',
    }),
  }),
  // 专题图层：瑞士环境局全国洪水警戒分布图
  new ImageLayer({
    extent: extent,
    source: new ImageWMS({
      url: 'https://wms.geo.admin.ch/',
      crossOrigin: 'anonymous',
      attributions:
        '© <a href="https://www.hydrodaten.admin.ch/en/notes-on-the-flood-alert-maps.html"' +
        'target="_blank">Flood Alert / geo.admin.ch</a>',
      params: {'LAYERS': 'ch.bafu.hydroweb-warnkarte_national'},
      serverType: 'mapserver',
    }),
  }),
];

// 初始化地图实例
const map = new Map({
  controls: defaultControls().extend([new ScaleLine()]),
  layers: layers,
  target: 'map',
  view: new View({
    projection: projection,
    // 通过 fromLonLat 自动利用 Proj4js 将经纬度中心点 [8.23°E, 46.86°N] 转换为 EPSG:21781 平面米制坐标
    center: fromLonLat([8.23, 46.86], projection),
    extent: extent,
    zoom: 2,
  }),
});
