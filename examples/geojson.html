const styleFunction = function (feature) { // 通过 feature.getGeometry().getType() 动态命中样式规则 return styles[feature.getGeometry().getType()]; }; ``` 相较于为每个几何类型分别创建不同的图层，通过单一样式函数动态分发，极大减少了图层管理成本与 WebGL/Canvas 状态切换开销。 - **从内存对象同步读取要素**： ```javascript const vectorSource = new VectorSource({ features: new GeoJSON().readFeatures(geojsonObject), }); ``` 当 GeoJSON 已在前端内存中就绪（如来自 WebSocket 推送或本地配置）时，直接通过 `readFeatures()` 读取数组传入 `features` 配置项，瞬间完成空间 R-Tree 树索引构建。 #### 3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices) - **坐标投影参数的声明时机**： 本示例中的 GeoJSON 坐标已预先换算为 Web 墨卡托米制单位（如 `[4e6, -2e6]`）。但在实际生产中，99% 的 GeoJSON 数据均为 WGS 84 经纬度（`EPSG:4326`）。在读取外部 GeoJSON 时，**必须显式指定投影转换选项**： ```javascript new GeoJSON().readFeatures(geojson, { dataProjection: 'EPSG:4326', // 原始数据投影 featureProjection: 'EPSG:3857', // 当前地图视图投影 }); ``` 否则要素将直接被当作米制坐标绘制在非洲几内亚湾的微小范围内（呈现为“地图空白”）。 - **GeometryCollection 样式穿透**： 当样式应用于 `GeometryCollection` 时，该样式必须同时包含 `stroke`、`fill` 与 `image`，否则其中的子图元（如点或线）将由于缺少对应子样式而隐形。 tags: "geojson, vector, openstreetmap" ---
