Example of GeoJSON features.

本示例演示了如何通过 OpenLayers 的 ol/format/GeoJSON 解析器反序列化包含 OGC 简单要素规范（Simple Feature Specification）全谱系几何类型的标准 GeoJSON 格式数据对象。

示例中展示了点（Point）、多点（MultiPoint）、折线（LineString）、多折线（MultiLineString）、多边形（Polygon）、多多边形（MultiPolygon）以及复合几何集合（GeometryCollection）在同一个矢量图层中的统一加载；同时结合动态样式函数（styleFunction），根据各要素的运行时几何类型应用不同风格的描边、填充与点符号样式，并兼容了 OpenLayers 内置的解析圆（Circle）要素。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计机制 (Core Architecture & Mechanics)

  • RFC 7946 GeoJSON 标准几何模型： IETF RFC 7946 规范定义了地理信息交互的核心载体：
    • 单体要素：Point（[x, y]）、LineString（[[x, y], ...]）、Polygon（外环与若干内环孔洞 [[[x, y], ...], ...]）；
    • 复合要素：MultiPoint、MultiLineString、MultiPolygon，用于将空间上离散但语义唯一的实体（如群岛国家）聚合为单一要素；
    • 异构集合：GeometryCollection，可在同一个几何容器中打包线段、点与多边形。
  • OpenLayers 超集几何图元拓展： 除 RFC 7946 标准外，OpenLayers 额外支持数学解析圆（ol/geom/Circle）。虽然标准 GeoJSON 并不包含圆形定义（通常由 GIS 软件离散化为正多边形），但 OpenLayers 的 VectorSource 可以无缝混用标准要素与解析圆对象，兼顾标准化互操作性与高精度交互。

2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns)

  • 基于几何类型的多态样式字典（Polymorphic Style Dictionary）：
    const styles = {
  'Point': new Style({ image: ... }),
  'LineString': new Style({ stroke: ... }),
  'Polygon': new Style({ stroke: ..., fill: ... }),
  'GeometryCollection': new Style({ stroke: ..., fill: ..., image: ... }),
  'Circle': new Style({ stroke: ..., fill: ... }),
};

const styleFunction = function (feature) {
  // 通过 feature.getGeometry().getType() 动态命中样式规则
  return styles[feature.getGeometry().getType()];
};
    相较于为每个几何类型分别创建不同的图层，通过单一样式函数动态分发，极大减少了图层管理成本与 WebGL/Canvas 状态切换开销。
  • 从内存对象同步读取要素：
    const vectorSource = new VectorSource({
  features: new GeoJSON().readFeatures(geojsonObject),
});
    当 GeoJSON 已在前端内存中就绪（如来自 WebSocket 推送或本地配置）时，直接通过 readFeatures() 读取数组传入 features 配置项，瞬间完成空间 R-Tree 树索引构建。

3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices)

  • 坐标投影参数的声明时机： 本示例中的 GeoJSON 坐标已预先换算为 Web 墨卡托米制单位（如 [4e6, -2e6]）。但在实际生产中，99% 的 GeoJSON 数据均为 WGS 84 经纬度（EPSG:4326）。在读取外部 GeoJSON 时，必须显式指定投影转换选项：
    new GeoJSON().readFeatures(geojson, {
  dataProjection: 'EPSG:4326',      // 原始数据投影
  featureProjection: 'EPSG:3857',   // 当前地图视图投影
});
    否则要素将直接被当作米制坐标绘制在非洲几内亚湾的微小范围内（呈现为“地图空白”）。
  • GeometryCollection 样式穿透： 当样式应用于 GeometryCollection 时，该样式必须同时包含 stroke、fill 与 image，否则其中的子图元（如点或线）将由于缺少对应子样式而隐形。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import Circle from 'ol/geom/Circle.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';
import CircleStyle from 'ol/style/Circle.js';
import Fill from 'ol/style/Fill.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

// Default circle marker style for points / 点要素的默认红色圆圈符号样式
const image = new CircleStyle({
  radius: 5,
  fill: null,
  stroke: new Stroke({color: 'red', width: 1}),
});

// Style dictionary mapped by geometry types / 按照几何图元类型映射的样式规则字典
const styles = {
  'Point': new Style({
    image: image,
  }),
  'LineString': new Style({
    stroke: new Stroke({
      color: 'green',
      width: 1,
    }),
  }),
  'MultiLineString': new Style({
    stroke: new Stroke({
      color: 'green',
      width: 1,
    }),
  }),
  'MultiPoint': new Style({
    image: image,
  }),
  'MultiPolygon': new Style({
    stroke: new Stroke({
      color: 'yellow',
      width: 1,
    }),
    fill: new Fill({
      color: 'rgba(255, 255, 0, 0.1)',
    }),
  }),
  'Polygon': new Style({
    stroke: new Stroke({
      color: 'blue',
      lineDash: [4],
      width: 3,
    }),
    fill: new Fill({
      color: 'rgba(0, 0, 255, 0.1)',
    }),
  }),
  'GeometryCollection': new Style({
    stroke: new Stroke({
      color: 'magenta',
      width: 2,
    }),
    fill: new Fill({
      color: 'magenta',
    }),
    image: new CircleStyle({
      radius: 10,
      fill: null,
      stroke: new Stroke({
        color: 'magenta',
      }),
    }),
  }),
  'Circle': new Style({
    stroke: new Stroke({
      color: 'red',
      width: 2,
    }),
    fill: new Fill({
      color: 'rgba(255,0,0,0.2)',
    }),
  }),
};

/**
 * Polymorphic style function resolving style by geometry type.
 * 根据要素运行时几何类型动态匹配样式的多态样式函数
 * @param {import('ol/Feature.js').default} feature Vector feature / 矢量要素
 * @return {Style} Style instance / 样式对象
 */
const styleFunction = function (feature) {
  return styles[feature.getGeometry().getType()];
};

// In-memory GeoJSON FeatureCollection containing various geometry types / 包含各种几何类型的内存 GeoJSON 数据集
const geojsonObject = {

  'features': [

      'geometry': {

    },

      'geometry': {
        'type': 'LineString',

          [4e6, -2e6],
          [8e6, 2e6],
        ],
      },
    },
    {
      'type': 'Feature',
      'geometry': {
        'type': 'LineString',
        'coordinates': [
          [4e6, 2e6],
          [8e6, -2e6],
        ],
      },
    },
    {
      'type': 'Feature',
      'geometry': {
        'type': 'Polygon',
        'coordinates': [
          [
            [-5e6, -1e6],
            [-3e6, -1e6],
            [-4e6, 1e6],
            [-5e6, -1e6],

    {

      'geometry': {

        'coordinates': [
          [
            [-1e6, -7.5e5],
            [-1e6, 7.5e5],

// Create VectorSource by reading GeoJSON object / 从 GeoJSON 对象读取要素并初始化矢量数据源
const vectorSource = new VectorSource({
  features: new GeoJSON().readFeatures(geojsonObject),
});

// Add an OpenLayers native analytic Circle geometry / 额外添加一个 OpenLayers 原生解析圆几何要素
vectorSource.addFeature(new Feature(new Circle([5e6, 7e6], 1e6)));

// Vector layer with polymorphic style function / 绑定多态样式函数的矢量图层
const vectorLayer = new VectorLayer({
  source: vectorSource,
  style: styleFunction,
});

// Initialize map with OSM basemap and vector layer / 初始化包含 OSM 底图与矢量图层的地图实例
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
    vectorLayer,
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});
