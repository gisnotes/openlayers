const code = `EqualEarth${lon0}`; let prj = getProjection(code); if (!prj) { proj4.defs( code, `+proj=eqearth +lon_0=${lon0} +x_0=0 +y_0=0 +R=6371008.7714 +units=m +no_defs +type=crs`, ); register(proj4); prj = getProjection(code); prj.setGlobal(true); prj.setExtent([-17243959.06, -8392927.6, 17243959.06, 8392927.6]); prj.setWorldExtent([-180, -90, 180, 90]); } return prj; } ``` 通过为每个离散步长（如 5°）生成唯一命名投影代码，避免重复定义开销。 - **RenderFeature 极速轻量渲染图元**： ```javascript new GeoJSON({ featureProjection: projection, featureClass: RenderFeature, // 关键：使用只读轻量渲染要素 }).readFeatures(geojson) ``` 通常 `readFeatures` 会生成拥有完整属性访问器和事件机制的 `ol/Feature` 对象，在包含数万个顶点的复杂多边形数据集下会带来可观的内存压力。传入 `featureClass: RenderFeature` 可直接输出高度紧凑的扁平内存坐标数组，渲染性能提升数倍。 #### 3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices) - **视口变更监听防死循环**： 在 `handleCenterChange` 中，当检测到需要切换投影时，必须在更新视图前通过 `curView.un('change:center', handleCenterChange)` 解绑事件监听；新 View 实例化完成后，再重新挂载监听器，防止视图重置触发的连续嵌套递归。 - **多边形拓扑简并防御**： 在进行坐标钳位（Clamping）处理时，某些细长岛屿或海岬被裁切后可能退化为共线点甚至单点。代码中通过 `if (clamped < ncoords)` 进行了防御性校验，主动丢弃简并图元，避免底层 Canvas 渲染管线抛出拓扑异常。 tags: "vector, geojson, equal-earth" ---
