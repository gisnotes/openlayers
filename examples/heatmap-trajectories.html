Trajectories Heatmap / 航迹热力图（折线要素 WebGL 热力场渲染）

heatmap2 geojson11 vector87 trajectory1 webgl19

Demonstrates the use of a heatmap layer with linear geometries. / 演示如何使用 Heatmap 热力图层对线型航迹几何要素进行 WebGL 核密度热力渲染。

This example shows linear geometries rendered using a ol/layer/Heatmap layer.
Data is AIS maritime traffic around Gothenburg transformed into GeoJSON, taken from this example.

本示例展示如何使用 ol/layer/Heatmap 热力图层直接渲染线几何（LineString）要素。
底图数据来源于瑞典哥德堡周边海域真实 AIS 船舶航行轨迹转换生成的 GeoJSON 数据集。

📚 学习记录与技术深度解读 (Learning Notes)

1. 折线要素（Linear Geometries）热力场渲染机制

  • 不仅支持点要素：传统 GIS 热力图通常仅针对点要素计算高斯核密度（Kernel Density Estimation）。OpenLayers 的 HeatmapLayer 同样支持线几何要素（LineString）。
  • 线采样与离屏合成：底层渲染管线将折线按像素分辨率抽样或利用阴影模糊算法将线段光栅化到离屏 Canvas/Texture 中，各线段交汇与重叠区域的透明度通道（Alpha）进行线性叠加累加，再通过内置或自定义调色板（Color Gradient Ramp）进行最终上色。

2. WebGL 动态样式变量联动（updateStyleVariables）

  • 核半径与模糊半径的动态调优：
    • radius：控制单一要素的影响核半径，值越大扩散范围越广；
    • blur：控制高斯衰减过渡的柔和程度。
  • 片元过滤与属性联动：本例在热力图层中配置了 filter 表达式： ['any', ['==', ['var', 'shipType'], 'All'], ['==', ['var', 'shipType'], ['get', 'ShipType']]] 当切换船舶类型筛选框时，调用 heatmap.updateStyleVariables({shipType: ...})，瞬间在 GPU 层面完成特定船种热力图的重算，无需清空或重新解析原始数据源。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import HeatmapLayer from 'ol/layer/Heatmap.js';
import TileLayer from 'ol/layer/Tile.js';
import {fromLonLat} from 'ol/proj.js';
import StadiaMaps from 'ol/source/StadiaMaps.js';
import VectorSource from 'ol/source/Vector.js';

// DOM input elements / 控制滑块与筛选器 DOM 元素
const blur = document.getElementById('blur');
const radius = document.getElementById('radius');

// WebGL Heatmap layer for trajectories / 轨迹热力图层配置
const heatmap = new HeatmapLayer({
  source: new VectorSource({
    url: 'data/geojson/ship-trajectories.json',
    format: new GeoJSON(),
    attributions: 'Danish Maritime Authority',
  }),
  blur: ['/', ['var', 'blur'], 2],
  radius: ['/', ['var', 'radius'], 2],
  variables: {
    blur: parseInt(blur.value, 10),
    radius: parseInt(radius.value, 10),
    shipType: 'All',
  },
  filter: [
    'any',
    ['==', ['var', 'shipType'], 'All'],
    ['==', ['var', 'shipType'], ['get', 'ShipType']],
  ],
  weight: () => 0.1,
});

const raster = new TileLayer({
  source: new StadiaMaps({
    layer: 'alidade_smooth_dark',
  }),
});

const map = new Map({
  layers: [raster, heatmap],
  target: 'map',
  view: new View({
    center: fromLonLat([11.86, 57.67]),
    zoom: 12,
  }),
});

// Event listeners for blur and radius sliders / 监听模糊度与核半径滑块输入
blur.addEventListener('input', function () {
  heatmap.updateStyleVariables({blur: parseInt(blur.value, 10)});
});

radius.addEventListener('input', function () {
  heatmap.updateStyleVariables({radius: parseInt(radius.value, 10)});
});

// Ship type selector event listener / 监听船舶类型下拉菜单切换
const shipTypeSelect = document.getElementById('shiptype-filter');
shipTypeSelect.addEventListener('input', function () {
  heatmap.updateStyleVariables({shipType: shipTypeSelect.value});
  map.render();
});
