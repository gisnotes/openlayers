Projection and Scale / 投影切换与比例尺保持

projection14 scale4

Example of maintaining scale when changing projection. / 演示在动态切换地图视图投影（如 EPSG:4326 与 EPSG:3857 互转）时，如何保持真实的地面物理比例尺与视口比例不变。

Example of maintaining scale when changing projection. getPointResolution() is used to calculate the resolution for the new projection which corresponds to that for the old projection.

本示例演示在动态切换地图投影坐标系时，如何保持地面物理比例尺的一致性。通过 getPointResolution() 计算新旧投影在视口中心点处的点分辨率换算关系，确保切换投影后地图的缩放比例尺视觉大小无缝对齐。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心痛点：为什么切换投影时地图缩放比例会失真？

  • 坐标单位维度不同：
    • EPSG:4326（WGS 84 经纬度）：名义单位是度（Degrees）。在赤道处，经度 1° 对应的地表距离约为 111.32 千米；
    • EPSG:3857（Web 墨卡托）：名义单位是米（Meters）。
    • 如果在切换投影时直接沿用旧视图的 resolution（标称分辨率），地图尺寸会产生数十万倍的剧烈错位。
  • 高纬度投影拉伸变形：
    • Web 墨卡托投影属于正形圆柱投影，具有纬度越高拉伸越严重的几何特性，其局部长度拉伸系数为 $\sec(\varphi) = 1 / \cos(\varphi)$（其中 $\varphi$ 为地理纬度）。
    • 在北纬 60° 地区，墨卡托投影的经线拉伸系数达到赤道的 2 倍。如果仅靠简单的缩放级别（Zoom Level）对齐，不仅度与米无法精确转换，更无法补偿不同纬度处的投影变形。

2. 数学原理：getPointResolution() 与真实地表分辨率推导

OpenLayers 的 ol/proj 模块提供了核心函数 getPointResolution(projection, resolution, point, opt_units)，用于求解指定坐标点在真实地球椭球体表面上的实际分辨率（单位：米/像素）。

换算与推导逻辑如下：

  1. 读取投影的标称米系数（Meters Per Unit）：

    const currentMPU = currentProjection.getMetersPerUnit();
const newMPU = newProjection.getMetersPerUnit();

  2. 计算指定点处的真实地表点分辨率系数： 传入 1 / MPU 计算单位标称分辨率在当前位置对应的地表真实米数：

    const currentPointResolution =
  getPointResolution(currentProjection, 1 / currentMPU, currentCenter, 'm') * currentMPU;
const newPointResolution =
  getPointResolution(newProjection, 1 / newMPU, newCenter, 'm') * newMPU;

  3. 推导新标称分辨率： 由于当前屏幕中心点的真实地表物理分辨率为： $$R_{\text{ground}} = R_{\text{current}} \times \text{currentPointResolution}$$

    若要使目标投影在屏幕上呈现相同的地面物理比例尺，新标称分辨率应满足： $$R_{\text{new}} \times \text{newPointResolution} = R_{\text{current}} \times \text{currentPointResolution}$$

    由此推导出计算公式： $$R_{\text{new}} = \frac{R_{\text{current}} \times \text{currentPointResolution}}{\text{newPointResolution}}$$

3. 控件联动：ScaleLine（比例尺控件）的高级参数

示例中挂载了专业的条形比例尺控件：

const scaleControl = new ScaleLine({
  units: 'metric', // 公制单位 (m / km)
  bar: true,       // 启用带分段刻度的标尺条外观
  steps: 4,        // 划分为 4 个主要刻度区间
  text: true,      // 在刻度上方直观显示距离文本
  minWidth: 140,   // 控件最小宽度 (px)
});

在切换投影时仔细观察左下角的比例尺：

  • 无论是从 WGS 84（经纬度度数）切到 Web 墨卡托（米制投影），还是反向切换；
  • 比例尺上显示的物理像素宽度与实际地理公里数均严密保持一致，证明视口地表比例尺实现了平滑无损过渡。

4. 技术方案对比

切换策略 实现代码 视觉与测量表现 适用场景
直接复用 Zoom new View({ zoom: oldView.getZoom(), ... }) 比例尺剧烈跳变；度数与米制缩放级别无法对齐；高纬度失真严重 粗略定位，对比例精度无要求的场景
直接复用 Resolution new View({ resolution: oldView.getResolution(), ... }) 灾难性形变（度与米相差五到六个数量级，整图全黑或瞬间飞出地球） 严禁跨单位使用
getPointResolution 动态换算（本示例） newResolution = (currRes * currPointRes) / newPointRes 完美保持地表真实比例尺；严谨抵消单位差异与纬度投影变形 专业 GIS、精准量测、多坐标系切换标准实现
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ScaleLine from 'ol/control/ScaleLine.js';
import {defaults as defaultControls} from 'ol/control/defaults.js';
import TileLayer from 'ol/layer/Tile.js';
import {getPointResolution, get as getProjection, transform} from 'ol/proj.js';
import OSM from 'ol/source/OSM.js';

// Get projection selector element and initial projection
// 获取页面上的投影下拉选择框元素以及初始选中的投影对象
const viewProjSelect = document.getElementById('view-projection');
const projection = getProjection(viewProjSelect.value);

// Configure a segmented metric scale bar control with text labels
// 配置带分段刻度和距离数值标注的公制比例尺控件
const scaleControl = new ScaleLine({
  units: 'metric',
  bar: true,
  steps: 4,
  text: true,
  minWidth: 140,
});

// Initialize the map with default controls + ScaleLine and OpenStreetMap base layer
// 初始化地图实例，配置默认控件并挂载比例尺控件，底图使用标准 OSM 瓦片
const map = new Map({
  controls: defaultControls().extend([scaleControl]),
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: new View({
    // Transform coordinates [0, 52] from EPSG:4326 to the initial projection
    // 将坐标点 [0, 52] 从 EPSG:4326 转换为当前视图初始投影下的坐标
    center: transform([0, 52], 'EPSG:4326', projection),
    zoom: 6,
    projection: projection,
  }),
});

/**
 * Handle projection change while keeping the physical ground scale identical
 * 监听投影切换事件，在转换视图坐标系的同时精准维持地表真实比例尺不变
 */
function onChangeProjection() {
  const currentView = map.getView();
  const currentProjection = currentView.getProjection();
  const newProjection = getProjection(viewProjSelect.value);
  const currentResolution = currentView.getResolution();
  const currentCenter = currentView.getCenter();
  const currentRotation = currentView.getRotation();

  // 1. Transform view center coordinates to the target projection
  // 1. 将当前视图中心点坐标转换到目标投影坐标系
  const newCenter = transform(currentCenter, currentProjection, newProjection);

  // 2. Read meters per nominal projection unit (e.g., 1 for EPSG:3857, ~111319.49 for EPSG:4326)
  // 2. 获取新旧投影每个标称单位对应的米数（例如 EPSG:3857 为 1，EPSG:4326 赤道处约为 111319.49）
  const currentMPU = currentProjection.getMetersPerUnit();
  const newMPU = newProjection.getMetersPerUnit();

  // 3. Compute real-world ground meters per nominal map unit at the respective center latitudes
  // 3. 分别计算当前中心点与目标中心点在真实地表处的点分辨率（消除投影纬度形变影响）
  const currentPointResolution =
    getPointResolution(currentProjection, 1 / currentMPU, currentCenter, 'm') *
    currentMPU;
  const newPointResolution =
    getPointResolution(newProjection, 1 / newMPU, newCenter, 'm') * newMPU;

  // 4. Derive new nominal resolution to maintain the exact same ground scale on screen
  // 4. 计算使屏幕上物理比例尺保持不变的新标称分辨率：(旧标称分辨率 × 旧点分辨率系数) / 新点分辨率系数
  const newResolution =
    (currentResolution * currentPointResolution) / newPointResolution;

  // 5. Construct and apply the new View instance
  // 5. 构造新的 View 实例并替换地图当前视图
  const newView = new View({
    center: newCenter,
    resolution: newResolution,
    rotation: currentRotation,
    projection: newProjection,
  });
  map.setView(newView);
}

// Bind change event to the projection dropdown
// 为投影下拉选择框绑定切换事件
viewProjSelect.addEventListener('change', onChangeProjection);
