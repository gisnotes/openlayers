Updating the style of a WebGL tile layer / 更新 WebGL 瓦片图层的样式

When you want to change the style of a WebGL tile layer based on some change in your application state, you should use the layer.updateStyleVariables() method. A layer can be efficiently rendered even if style variables are changed on every render frame. In cases where you need to completely replace the style of a layer, you can call the layer.setStyle() method. This method should not be called in response to frequent user events (e.g. mouse movement, dragging a slider, etc.).

当您希望根据应用程序状态的变化来更改 WebGL 瓦片图层的样式时，应使用 layer.updateStyleVariables() 方法。即使在每个渲染帧上都更改样式变量，图层也能够被高效渲染。在需要完全替换图层样式的情况下，您可以调用 layer.setStyle() 方法。不应在响应高频用户事件（例如鼠标移动、拖动滑块等）时调用此方法。

📚 学习记录与技术笔记 (Learning Notes)

1. 下拉选项与调色板说明

  • w/ 的含义：英文日常与技术文档中常见的 with（带有/使用）缩写（与之对应的是 w/o = without）。例如 NDVI w/ palette 1 即代表 NDVI with palette 1（使用调色板 1 的 NDVI）。在中文语境下可简称为“NDVI 调色板 1”。
  • palette 1 与 palette 2：
    • palette 1 (ndviPalettePlasma)：采用科学可视化经典的 Plasma（等离子体） 色阶（蓝紫 → 紫红 → 明黄）。
    • palette 2 (ndviPaletteViridis)：采用著名的 Viridis（翠绿） 色阶（深紫 → 蓝 → 绿 → 黄），具备感知均匀性且对色盲色弱人群极度友好。

2. 本示例中 style 标签的核心演示机制

本示例演示的并非传统的矢量要素样式，而是 OpenLayers 极具特色的 WebGL 瓦片图层声明式着色表达式（WebGL Tile Layer Style Expressions）：

  • 客户端解耦计算：数据源（GeoTIFF，包含 4 个原始波段）完全不变，所有图像效果纯粹由前端 GPU 片段着色器根据样式表达式逐像素计算生成。
  • 波段提取与运算（Band Math）：利用 ['band', n] 提取特定波段，通过算术操作符 ['/', value, max] 做动态归一化。
  • 多通道色彩合成（RGB Composite）：
    • 真彩色（True Color）：将红、绿、蓝波段分别送入 RGB 通道，配合 gamma: 1.1 提升暗部对比度。
    • 标准假彩色（False Color）：用近红外（NIR）替代红通道，使植被呈现醒目的红色。
  • 连续插值渐变（interpolate）：在 GPU 上实时计算 NDVI 植被指数公式 (NIR - Red) / (NIR + Red)，并根据断点平滑插值输出颜色。
  • 调色板映射（palette）：将归一化后的指标映射至离散颜色数组。
  • API 运行时建议：彻底更换着色算法使用 layer.setStyle(style)；如需高频平滑调节参数（如对比度、亮度），推荐在样式中配置 variables 并使用 layer.updateStyleVariables()。

3. 遥感与多波段基础概念速记

  • 普通照片 vs. 卫星遥感：普通手机照片只有红绿蓝（RGB）3 个通道；卫星遥感相机是多光谱相机，不仅能拍到可见光，还能捕获人眼不可见的近红外（NIR）、短波红外等。每个波段本质上是一张特定波长下的黑白灰度图矩阵。
  • 本例 4 个波段：Band 1 (红光 Red)、Band 2 (绿光 Green)、Band 3 (蓝光 Blue)、Band 4 (近红外 NIR)。
  • 为什么近红外（NIR）如此关键：健康植物叶绿素强烈吸收红光（用于光合作用），同时叶片细胞强烈反射近红外光（防止被晒伤）。因此植物在近红外波段下格外明亮（数值极高），在红光波段极暗（数值极低）。
  • NDVI 归一化植被指数：(NIR - Red) / (NIR + Red)，结果在 -1.0 到 1.0 之间。云、雪、水体为负值；裸土在 0 左右；稀疏草地到茂密森林在 0.2~0.8。

4. 代码中的 const max = 3000 是如何确定的？换新影像怎么处理？

  • 为什么是 3000：欧空局哨兵2号（Sentinel-2）L2A 地表反射率真实范围为 0.0 到 1.0（0% 到 100%），为了以 16 位整数（Uint16）紧凑存储，数据放大了 10,000 倍。然而地球表面绝大部分地物（树木、土壤、水体）的自然反射率都在 0% 到 30%（即 0 到 3000）之间。若直接除以 10000，大部分画面会集中在 0.0 到 0.3 而极度昏暗。因此将 3000 作为白平衡上限进行视觉拉伸截断，使地物细节更加明亮饱满。
  • 更换 TIF 影像时的判定规则：
    • 8位影像（Uint8，如航拍图）：像素范围 0 到 255，max 取 255（或启用数据源自带的 normalize: true 自动处理）。
    • 其他 16 位卫星影像（如 Landsat、高分卫星）：查阅产品元数据说明，或在 QGIS / gdalinfo -stats 中查看直方图的 98% 累积截断值（通常在 3000 到 6000）。
    • 32位浮点影像（Float32）：数值本身即 0.0 到 1.0，直接使用即可，无需除以 max。
    • DEM 高程数据：像素代表海拔高度（如 -50 到 8848 米），需根据区域实际的 min 和 max 进行区间线性拉伸。
    • 动态工程实践：推荐通过 variables: { max: 3000 } 与 ['var', 'max'] 配合滑动条组件，使用 layer.updateStyleVariables() 供用户交互式调节对比度（可参考同目录下的 cog-stretch.html 示例）。

5. ndvi 对象的 color 属性中众多数值是如何确定的？（API 规范 vs NDVI 业务概念）

  • 外层语法骨架（OpenLayers API 严格规定）：
    • 规范参见 src/ol/expr/expression.js 中关于 ['interpolate', interpolation, input, stop1, output1, ...stopN, outputN] 的标准定义。
    • 规则要求：'interpolate' 为固定操作符；第二项为插值算法（如 ['linear'] 线性插值）；第三项为输入自变量表达式（此处为计算出的 NDVI）；后续参数必须成对提供严格升序排列的断点数值（stop）与其对应的输出颜色数组（output，如 [R, G, B]）。底层 GPU 着色器会自动在相邻断点之间进行线性渐变过渡。
  • 内层数值与色阶（结合 NDVI 物理概念自定义）：
    • API 文档绝不规定具体的断点数值与颜色。数组里的数值完全是遥感中经典的 NDVI 植被色阶（Color Ramp）：
      • < 0（-0.2 到 -0.1）：水体、雪、厚云，赋予灰色（[191, 191, 191] 等）；
      • 0 到 0.1：裸土、岩石、荒漠，赋予米黄色至浅土黄色（[255, 255, 224] 到 [204, 199, 130]）；
      • 0.1 到 0.3：低矮植被、稀疏草地，由黄绿逐渐过渡为草绿；
      • 0.35 到 0.65+：茂密树冠、健康森林，由浅绿深入浓郁的深绿（[0, 69, 0]）。
    • 为什么 0 到 0.2 之间断点如此密集（0.025, 0.05, 0.075...）：自然地表从寸草不生到稍有杂草覆盖，NDVI 变化极其敏锐。密集断点是为了让荒漠、裸土和低植被区域呈现丰富细腻的视觉层次，避免大片单一单调色彩。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import GeoTIFF from 'ol/source/GeoTIFF.js';

// Normalization function: scale Sentinel-2 reflectance values (0-3000) to 0-1 range
// 归一化函数：将哨兵2号（Sentinel-2）反射率值（0-3000）缩放到 0-1 范围
const max = 3000;
function normalize(value) {
  return ['/', value, max];
}

// 4 bands of Sentinel-2: Band 1 (Red), Band 2 (Green), Band 3 (Blue), Band 4 (NIR)
// 哨兵2号的 4 个波段：波段 1（红光）、波段 2（绿光）、波段 3（蓝光）、波段 4（近红外 NIR）
const red = normalize(['band', 1]);
const green = normalize(['band', 2]);
const blue = normalize(['band', 3]);
const nir = normalize(['band', 4]);

// True Color style (RGB composite)
// 真彩色样式（RGB 合成）
const trueColor = {
  color: ['array', red, green, blue, 1],
  gamma: 1.1,
};

// False Color style (NIR, Red, Green composite) - useful for highlighting vegetation
// 标准假彩色样式（近红外、红光、绿光合成）—— 常用于突出显示植被
const falseColor = {
  color: ['array', nir, red, green, 1],
  gamma: 1.1,
};

// NDVI: (NIR - Red) / (NIR + Red)
// 归一化植被指数 NDVI: (近红外 - 红光) / (近红外 + 红光)
const ndvi = {
  color: [
    'interpolate',
    ['linear'],
    ['/', ['-', nir, red], ['+', nir, red]],
    // color ramp for NDVI values, ranging from -1 to 1
    // NDVI 值的颜色渐变（Color Ramp），取值范围从 -1 到 1
    -0.2,
    [191, 191, 191],
    -0.1,
    [219, 219, 219],
    0,
    [255, 255, 224],
    0.025,
    [255, 250, 204],
    0.05,
    [237, 232, 181],
    0.075,
    [222, 217, 156],
    0.1,
    [204, 199, 130],
    0.125,
    [189, 184, 107],
    0.15,
    [176, 194, 97],
    0.175,
    [163, 204, 89],
    0.2,
    [145, 191, 82],
    0.25,
    [128, 179, 71],
    0.3,
    [112, 163, 64],
    0.35,
    [97, 150, 54],
    0.4,
    [79, 138, 46],
    0.45,
    [64, 125, 36],
    0.5,
    [48, 110, 28],
    0.55,
    [33, 97, 18],
    0.6,
    [15, 84, 10],
    0.65,
    [0, 69, 0],
  ],
};

// NDVI using Plasma discrete color palette
// 使用 Plasma 离散调色板渲染的 NDVI
const ndviPalettePlasma = {
  color: [
    'palette',
    [
      'interpolate',
      ['linear'],
      ['/', ['-', nir, red], ['+', nir, red]],
      -0.2,
      0,
      0.65,
      4,
    ],
    ['#0d0887', '#7e03a8', '#cb4778', '#f89540', '#f0f921'],
  ],
};

// NDVI using Viridis discrete color palette
// 使用 Viridis 离散调色板渲染的 NDVI
const ndviPaletteViridis = {
  color: [
    'palette',
    [
      'interpolate',
      ['linear'],
      ['/', ['-', nir, red], ['+', nir, red]],
      -0.2,
      0,
      0.65,
      4,
    ],
    ['#440154', '#3b528b', '#21918c', '#5ec962', '#fde725'],
  ],
};

// Create a WebGL tile layer with a Cloud Optimized GeoTIFF (COG) source
// 创建带有云优化 GeoTIFF (COG) 数据源的 WebGL 瓦片图层
const layer = new TileLayer({
  style: trueColor,
  source: new GeoTIFF({
    normalize: false,
    sources: [
      {
        url: 'https://cloudlessdownloads.eox.at/api/public/dl/jvu06wnt/exploitation-ready-epsg-4326/exploitation-ready_eoxcloudless-sentinel-2-2024_zoom-1_4bands_16bit.tif',
      },
    ],
  }),
});

// Initialize the map
// 初始化地图
const map = new Map({
  target: 'map',
  layers: [layer],
  view: new View({
    projection: 'EPSG:4326',
    center: [0, 0],
    zoom: 2,
    maxZoom: 6,
  }),
});

const styles = {
  trueColor,
  falseColor,
  ndvi,
  ndviPalettePlasma,
  ndviPaletteViridis,
};

const styleSelector = document.getElementById('style');

// Update layer style when user changes the dropdown selection
// 用户切换下拉框选择时更新图层样式
function update() {
  const style = styles[styleSelector.value];
  layer.setStyle(style);
}
styleSelector.addEventListener('change', update);
