--- layout: example.html title: Select Features / 选择要素 shortdesc: Example of using the Select interaction. / 演示使用 Select 交互进行要素拾取与单选/复选。 docs: | Choose between Single-click, Click, Hover and Alt+Click as the event type for selection in the combobox below. When using Single-click or Click you can hold the Shift key to toggle the feature in the selection.

Note: when Single-click is used double-clicks won't select features. This in contrast to Click, where a double-click will both select the feature and zoom the map (because of the DoubleClickZoom interaction). Note that Single-click is less responsive than Click because of the delay it uses to detect double-clicks.

In this example, a listener is registered for the Select interaction's select event in order to update the selection status above. 在下方下拉框中可选择不同的触发条件类型：Click（单击）、Single-click（真单选/延时判定）、Hover（悬停） 或 Alt+Click（Alt+单击）。当使用 Single-click 或 Click 时，按住 Shift 键可复选或反选要素。

注意：使用 Single-click 模式时，双击操作不会误触发要素选择；而 Click 模式下双击既会选中要素又会触发地图缩放（因为存在 DoubleClickZoom 交互）。此外，Single-click 因需要等待一段防抖延时来检测是否属于双击，响应灵敏度略低于 Click。

本示例注册了 Select 交互的 select 事件监听器，实时在界面展示当前选中的要素总数以及最新操作增删的要素详情。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. `click` vs `singleclick` 底层事件差异 * **`click`（即时响应）**：鼠标抬起（`pointerup`）且未发生拖拽时立即触发，零时延。但如果用户快速双击，系统会先后派发两次 `click` 事件外加一次 `dblclick` 事件，导致双击放大地图的同时误触发了要素选择。 * **`singleclick`（延时防抖）**：首次点击后启动约 250ms 的定时器，只有在超时且未侦测到第二次点击时才派发 `singleclick` 事件。彻底隔绝了双击缩放的误触，但代价是每次点击都有轻微感知时延。 #### 2. `toggleCondition` 与 Shift 闪烁防治 * 在悬停选择（`condition: pointerMove`）模式下，若使用默认的 `toggleCondition: shiftKeyOnly`，当用户按住 `Shift` 键并在要素上方晃动鼠标时，每次 `pointermove` 都会对要素进行“选中/取消”反复反转，造成视觉剧烈闪烁。 * **解决方案**：在悬停模式下显式配置 `toggleCondition: never`，禁止按键反转，从而保证鼠标悬停高亮平稳连贯。 tags: "select, vector" ---
