WMTS Capabilities Parsing / 解析 WMTS 元数据能力文档

wmts7 capabilities3 getcapabilities3

Example of parsing a WMTS GetCapabilities response. / 演示如何使用 WMTSCapabilities 格式解析器读取 XML 能力文档并输出结构化 JSON 对象。

This example shows the contents of the result object from parsing a WMTS capabilities response.

本示例展示了如何使用 ol/format/WMTSCapabilities 格式解析器，将 OGC WMTS 服务返回的标准 XML 格式 GetCapabilities 响应文档高效反序列化为易于前端程序访问的结构化 JavaScript/JSON 对象。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计思想 (Core Architecture & Design)

  • OGC 元数据 XML 的客户端语义解析： WMTS 服务的 GetCapabilities XML 包含极其繁杂的命名空间（如 ows:, xlink: 等）与层级嵌套。OpenLayers 提供了轻量级的专用 XML 解析器，负责提取关键实体：图层列表（Contents.Layer）、瓦片矩阵集定义（Contents.TileMatrixSet）以及操作元数据（OperationsMetadata）。

2. 源码与关键 API 剖析 (Source Code & API Analysis)

  • const parser = new WMTSCapabilities()： 专职负责解析 WMTS 1.0.0 规范 XML 字符串的格式化解析类。
  • parser.read(text)： 同步执行 DOM 解析与树状字典映射，返回包含 version, ServiceIdentification, ServiceProvider, Contents 等顶层字段的纯 JavaScript 对象。
  • 核心提取字段：
    • Contents.Layer[]：包含各个图层的标识符 Identifier、标题 Title、支持的 TileMatrixSetLink、样式 Style 与瓦片格式 Format。
    • Contents.TileMatrixSet[]：包含坐标系定义 SupportedCRS 及各分辨率矩阵 TileMatrix（比例尺分母 ScaleDenominator、矩阵宽高、瓦片物理像素尺寸及左上角矩阵原点 TopLeftCorner）。

3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization)

  • 首屏异步元数据加载开销： 完整的 WMTS Capabilities XML 往往达到数百 KB 甚至数 MB。在企业级单页面应用（SPA）中，不建议在用户每次进入页面时都通过网络重新发起一次耗时的 GetCapabilities 请求。推荐在服务端代理缓存、构建期静态序列化或将解析后的轻量级配置保存在前端 LocalStorage / IndexedDB 中。
main.js 
import WMTSCapabilities from 'ol/format/WMTSCapabilities.js';

const parser = new WMTSCapabilities();

fetch('https://cdn.jsdelivr.net/gh/gisnotes/openlayers@gh-pages/examples/data/WMTSCapabilities.xml')
  .then(function (response) {
    return response.text();
  })
  .then(function (text) {
    const result = parser.read(text);
    document.getElementById('log').innerText = JSON.stringify(result, null, 2);
  });
