This example shows how to create the configuration for accessing a WMTS from a GetCapabilities response. The WMTS example shows how to create the configuration manually.

本示例展示了如何基于 GetCapabilities 响应文档自动生成访问 OGC WMTS 服务所需的图层与瓦片网格配置。对比 手动配置 WMTS 瓦片服务示例，这种方式免去了开发者自行计算分辨率数组、原点坐标及 MatrixId 矩阵标识符的繁复数学工作。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - **optionsFromCapabilities 自动化胶水函数**： 这是 OpenLayers 为 WMTS 设计的最具生产力的工具函数之一。它接收解析后的 Capabilities 对象以及目标图层名与矩阵集名，自动提取对应的原点、切片尺寸、比例尺分母换算分辨率、矩阵层级列表以及服务 URL 模板，一键构造出传递给 new WMTS(options) 所需的完整配置字典。 #### 2. 源码与关键 API 剖析 (Source Code & API Analysis) - optionsFromCapabilities(result, config)： - result：WMTSCapabilities.prototype.read(text) 的解析产物； - config.layer：目标图层标识符（如 'layer-7328'）； - config.matrixSet：匹配的切片矩阵集（如 'EPSG:3857'）。 - 返回对象结构： 内部自动生成了具备对应 origin, resolutions, matrixIds 的 WMTSTileGrid，并配置了 urls, layer, matrixSet, format 与 style。 #### 3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - **多矩阵集与当前视图坐标系匹配**： 大型 WMTS 服务（如天地图、法国 IGN）往往支持多个矩阵集（如 EPSG:4326、EPSG:3857、CGCS2000）。调用 optionsFromCapabilities 时，必须确保指定的 matrixSet 与当前地图视图 ol/View 的投影坐标系统保持一致，否则瓦片将无法正确投影渲染。 - **异步加载未就绪保护**： 能力文档是通过异步 fetch 获取的。在网络请求返回前，地图必须有优雅的骨架屏、底图加载态或占位提示，避免因网络延迟导致页面显示空白。 tags: "wmts, capabilities, getcapabilities" ---
