Example of a scale line and scale bar control. OpenLayers provides a versatile scale line control that supports multiple unit systems and interactive customization.

本示例展示了 OpenLayers 的比例尺（ScaleLine）与分段比例条（ScaleBar）控件的灵活配置。支持公制（metric）、英制（imperial）、美制（us）、海里（nautical）与经纬度（degrees）五大度量单位体系切换，并支持动态调整分段数（steps）、注记文本展示以及黑白交替色反相。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 地理尺度自适应与纬度动态修正： 由于 Web 墨卡托投影（EPSG:3857）在离开赤道向两极延展时存在显著的几何拉伸变形，固定像素长度对应的现实物理距离会随纬度剧烈变化。OpenLayers 的 ol/control/ScaleLine 内部在地图每次平移（Move）或缩放（Zoom）时，都会重新采样当前视口中心点的真实地理纬度，实时重算标尺长度，保证数值绝对真实可信。
  • 经典线型（ScaleLine）vs 分段块型（ScaleBar）：
    • ScaleLine：传统的单条折角线，结构紧凑轻量，适合常规日常网页地图。
    • ScaleBar：黑白斑马交替分段块，常用于国家测绘标准图纸、规划出版物与海洋/军事制图，便于使用圆规或直尺进行多级目测估算。

2. 源码与关键 API 剖析

  • units: 'metric' | 'imperial' | 'us' | 'nautical' | 'degrees'：覆盖从民用陆地、航海运输到天文测绘的全场景单位转换。
  • bar: true：激活分段条渲染模式。
  • steps: 4：指定分段的格子数量（如 4 段式将 1000km 细分为 4 个 250km 的黑白方块）。
  • text: true：在标尺各分段节点上标出具体的距离数值刻度。
  • ol-scale-bar-inverted：CSS 反相类名，将白黑交替翻转为黑白交替，适配浅色或深色不同主题底图。

3. 生产实践踩坑与性能调优

  • 动态切换配置的重构策略： 由于 bar、steps 等核心渲染模式由构造函数内部 DOM 结构决定，在运行时变更形态时不能只调用属性 setter，应遵循示例中的 map.removeControl(control) → map.addControl(new ScaleLine(...)) 模式重新注入。
  • 高 DPI 打印支持（setDpi）： 在前端导出高清 PDF 时，默认 96 DPI 的比例尺会被缩小，必须通过 scaleLine.setDpi(targetDpi) 显式指定打印 DPI，以获得毫米级严格物理尺寸。
  • 全图层遮挡避让： 比例尺默认位于视口左下角。在移动端有底部导航栏或包含悬浮面板时，应通过 CSS 覆盖 .ol-scale-line { bottom: 30px; left: 15px; } 留出安全间距。
