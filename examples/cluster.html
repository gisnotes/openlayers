This example shows how to do clustering on point features.

本示例展示了如何使用 ol/source/Cluster 对海量点要素进行动态空间距离聚合（Clustering）。聚类分析能够有效解决大比例尺下大量重叠要素造成的屏幕视觉遮挡与性能瓶颈。支持动态调整 distance（聚类判定像素半径）与 minDistance（聚合簇之间的最小间距阈值），并使用动画展示聚合数量气泡。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - **ol/source/Cluster 代理设计模式**： Cluster 是一个包装层（Wrapper Source），它包裹一个底层的 VectorSource（原始点要素源）。其内部根据当前视口分辨率将相邻点归并在一个虚拟的“聚合要素”中，该聚合要素的属性 features 包含了所有被收拢的原始要素数组。 - **distance 与 minDistance 协同机制**： - distance：当两个点在屏幕上的像素距离小于该值时，自动合并为一个聚合簇； - minDistance：聚合簇质心之间的最小允许间距，防止两个密集簇彼此挨得过近。 #### 2. 源码与关键 API 剖析 (Source Code & API Analysis) - 动态聚类样式函数： 通过 feature.get('features').length 读取聚合数量，数量为 1 时展示单个图钉，大于 1 时展示带有数量文本的圆形徽章气泡。 - clusterSource.setDistance(value) 与 clusterSource.setMinDistance(value)： 实时响应滑动条变动，触发内部重新空间分区索引计算。 #### 3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - **点击聚合簇展开动画（Cluster Spiderfy / Zoom to Cluster Extent）**： 在实际生产中，用户点击聚合簇通常期望“自动放大地图至恰好容纳该簇内所有原始点的包围盒范围”。可以通过 map.getView().fit(ol.extent.boundingExtent(coords), { duration: 500, padding: [50, 50, 50, 50] }) 极简实现。 tags: "cluster, vector" resources: - https://cdn.jsdelivr.net/npm/bootstrap@5.2.0/dist/css/bootstrap.min.css ---
