Listen to DeviceOrientation events. / 监听设备陀螺仪与加速度传感器（DeviceOrientation）事件以倾斜平移地图。

This example shows how to track changes in device orientation. gyronorm.js library is used to access and normalize the events from the browser.

本示例展示了如何监听移动终端设备的物理姿态变化。通过引入 gyronorm.js 传感器归一化库，跨平台统一解析手机的陀螺仪与重力加速度事件（$\alpha$、$\beta$、$\gamma$ 欧拉角），并将手机倾斜角度实时映射为地图视图的平移矢量，实现体感操控漫游地图。

📚 学习记录与技术深度解读 (Learning Notes)

1. 设备空间姿态欧拉角动力学 (Euler Angles Model)

  • 三维旋转参考系: W3C 姿态规范定义了设备坐标系相对于地球参考坐标系的变换：
    • $\alpha$（Yaw / 航向角）：绕垂直于屏幕向外的 Z 轴旋转，范围 $[0, 2\pi)$，表征地理北极或罗盘朝向；
    • $\beta$（Pitch / 俯仰角）：绕屏幕横向水平的 X 轴旋转，范围 $[-\pi, \pi]$，表征手机前后仰合；
    • $\gamma$（Roll / 滚转角）：绕屏幕纵向纵轴的 Y 轴旋转，范围 $[-\pi/2, \pi/2]$，表征手机左右侧翻。

2. 尺度自适应平移映射算法

  • 分辨率相关动力学公式: $$\Delta X = -\text{resolution} \times \gamma \times 25, \quad \Delta Y = \text{resolution} \times \beta \times 25$$
  • 算法中将倾斜弧度与当前视图的分辨率（view.getResolution()）相乘，确保无论用户在大比例尺（城市微观街道）还是小比例尺（全国宏观）下，晃动手机相同的物理手感角度，屏幕地图内容均发生恒定适中的视觉位移。

3. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices)

  • iOS 13+ 权限交互前置要求: 在苹果 Safari 浏览器中，未经用户直接点击（如点击“开启体感”按钮）直接调用传感器接口会被静默拒绝。必须先执行 DeviceOrientationEvent.requestPermission() 并获取 'granted' 授权承诺。
  • 防抖与死区（Deadzone）控制: 移动终端传感器普遍存在微小的静态电磁噪声与手部生理颤抖。生产级工程应设置死区过滤（例如当 $|\beta| < 2^\circ$ 或 $|\gamma| < 2^\circ$ 时视为零位移），配合低通滤波（Low-pass Filter）消除高频微震，保障视觉平稳。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import {toRadians} from 'ol/math.js';
import OSM from 'ol/source/OSM.js';

// Initial view centered at [0, 0]
// 初始化视图：居中于原点 [0, 0]
const view = new View({
  center: [0, 0],
  zoom: 2,
});

// Map instance with OSM basemap
// 地图实例：加载基础 OSM 瓦片图层
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: view,
});

function el(id) {
  return document.getElementById(id);
}

// Instantiate GyroNorm to normalize cross-browser device orientation events
// 实例化 GyroNorm：跨平台抹平不同浏览器陀螺仪与加速度计的原始数据差异
const gn = new GyroNorm();

gn.init().then(
  function () {
    // Start sensor listening loop
    // 启动物理传感器监听循环
    gn.start(function (event) {
      const center = view.getCenter();
      const resolution = view.getResolution();
      // Extract normalized Euler angles in radians
      // 提取归一化后的弧度角（α 航向角，β 俯仰角，γ 滚转角）
      const alpha = toRadians(event.do.alpha);
      const beta = toRadians(event.do.beta);
      const gamma = toRadians(event.do.gamma);

      el('alpha').innerText = alpha + ' [rad]';
      el('beta').innerText = beta + ' [rad]';
      el('gamma').innerText = gamma + ' [rad]';

      // Map device tilt angles to map pan offset scaled by current view resolution
      // 将设备倾斜度按当前分辨率比例映射为地图视图平移量
      center[0] -= resolution * gamma * 25;
      center[1] += resolution * beta * 25;

      view.setCenter(center);
    });
  },
  function (e) {
    // Handle devices without gyroscope/orientation support
    // 处理不支持陀螺仪或传感器受限的环境提示
    el('unsupported').innerText =
      typeof e === 'string' ? e : 'Could not initialize sensors';
  },
);
