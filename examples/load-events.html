--- layout: example.html title: Loading Spinner / 地图加载微动效旋转器 shortdesc: Example using load events to show a loading spinner. / 演示如何使用地图实例的 loadstart 与 loadend 事件驱动 CSS 加载旋转器（Spinner）。 docs: | You can listen for the map's loadstart and loadend events to show a loading spinner on top of the map. 通过监听地图实例的 loadstart 和 loadend 事件，可以在地图进行数据拉取和重绘时在地图容器上方展示一个优雅的 CSS 加载旋转器（Spinner）。 本示例演示了如何通过简单的 DOM 类名切换（classList.add('spinner') / classList.remove('spinner')），在所有底层图层（包括瓦片、矢量等）完成数据加载与栅格渲染期间为用户提供直观的加载状态视觉反馈。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计机制 (Core Architecture & Mechanics) - **地图容器级加载状态聚合（Map Level Event Aggregation）**： 在多图层混合地图中，每个图层的数据源可能同时发起数十个瓦片或要素请求。OpenLayers 在 ol/Map 层面内置了状态聚合机： - 当任意图层开始加载数据且当前未处于 loading 状态时，触发全局 loadstart； - 当地图视口内的所有图层、瓦片队列及渲染管道全部空闲（Idle）时，触发全局 loadend。 - **零侵入式 CSS 蒙版方案**： 通过将旋转动画抽离到 CSS 伪元素（:after）中，不仅保持 JavaScript 逻辑高度极简（仅需 2 行类名增删），还利用了 GPU 硬件加速合成器（transform: rotate()）执行平滑旋转，避免阻塞 JS 主线程。 #### 2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns) - **事件绑定与类名切换**： ```javascript map.on('loadstart', function () { map.getTargetElement().classList.add('spinner'); }); map.on('loadend', function () { map.getTargetElement().classList.remove('spinner'); }); ``` 通过 map.getTargetElement() 直接获取当前地图绑定的根 DOM 节点，动态追加或移除 .spinner 类。 #### 3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices) - **超时兜底保护（Timeout Fallback）**： 如果第三方底图服务偶尔出现瓦片挂起（TCP 握手挂死且未返回错误），loadend 可能会被严重推迟。在生产项目中，建议配合一个 5-8 秒的兜底定时器（setTimeout），超时后强制移除加载态，避免遮挡用户操作。 - **短频闪烁消除（Flicker Prevention）**： 对于本地缓存命中率较高的场景，瓦片可能在数十毫秒内瞬间就绪，造成 Spinner "闪现"。推荐通过 CSS transition-delay（如延迟 200ms 显示）或 Lodash 防抖，仅当加载耗时超过阈值时才展示加载动画，从而大幅提升用户体验。 tags: "events, loading, spinner" ---
