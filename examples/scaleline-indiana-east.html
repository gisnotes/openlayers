带比例尺控件的 OpenStreetMap 客户端重投影 (OpenStreetMap Reprojection with ScaleLine Control)

reprojection8 projection14 openstreetmap22 nad831 tile10 scaleline2

演示在客户端将 OpenStreetMap (EPSG:3857) 实时重投影至 NAD83 印第安纳州东部投影坐标系，并配合美制单位比例尺控件显示。

本例展示了 OpenLayers 在客户端将标准 Web 墨卡托投影的 OpenStreetMap 瓦片实时重投影至美国州平面坐标系（State Plane Coordinate System）中的 NAD83 Indiana East（印第安纳州东区），并演示了美制单位比例尺控件（ScaleLine）的动态适配机制。

核心机制与原理解析

  1. 自定义州平面投影与非公制单位注册：

    • 许多地区性测绘工程采用定制的州平面投影（SPCS），本例使用 WKT 字符串向 Proj4js 注册命名为 'Indiana-East' 的坐标系（对应 EPSG:2965）。
    • 该坐标系基于 GRS 1980 椭球体的横轴墨卡托投影（Transverse Mercator），其名义长度单位为美国测量英尺（US Survey Foot，1 英尺 $\approx 0.3048006$ 米），而非国际标准公制米。
    • OpenLayers 结合 Proj4js 注册表，不仅能处理不同曲率椭球体间的几何转换，更能自动解析并处理跨非米制单位（米制 $\leftrightarrow$ 美制英尺）的像元比例重采样。

  2. 美制比例尺控件（ScaleLine({units: 'us'})）：

    • 控件配置 units: 'us' 后，OpenLayers 会自动将视口底部的地表距离标注格式化为英里（miles）或英尺（ft）。
    • 比例尺底层自动调用新投影与 WGS84 之间的点分辨率（Point Resolution）反解函数，确保在局部投影长度变形与美制单位缩放下，比例尺数值依然严格反映真实地面物理跨度。

  3. 投影合法范围（Extent）约束：

    • 横轴墨卡托属于局部等角投影，超出其有效经度范围（远离中央经线 $-85.667^\circ$）时会产生剧烈的几何畸变与数学奇点。
    • 代码通过 transformExtent([-172.54, 23.81, -47.74, 86.46], 'EPSG:4326', 'Indiana-East') 将经纬度有效范围转换为目标投影坐标，并赋予 View 的 extent 与 minZoom，有效约束了用户平移漫游和缩放边界。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ScaleLine from 'ol/control/ScaleLine.js';
import TileLayer from 'ol/layer/Tile.js';
import {fromLonLat, transformExtent} from 'ol/proj.js';
import {register} from 'ol/proj/proj4.js';
import OSM from 'ol/source/OSM.js';
import proj4 from 'proj4';

// 向 Proj4js 注册美国北美 1983 大地基准印第安纳州东区投影坐标系 (NAD83 Indiana East)
// 投影特性：
// - 椭球体：GRS 1980
// - 投影类型：横轴墨卡托 (Transverse Mercator)
// - 中央子午线：-85°40' (-85.666667°)
// - 原点纬度：37°30' (37.5°)
// - 长度单位：美国测量英尺 (Foot_US，1 英尺 ≈ 0.3048006 米)
proj4.defs(
  'Indiana-East',
  'PROJCS["IN83-EF",GEOGCS["LL83",DATUM["NAD83",' +
    'SPHEROID["GRS1980",6378137.000,298.25722210]],PRIMEM["Greenwich",0],' +
    'UNIT["Degree",0.017453292519943295]],PROJECTION["Transverse_Mercator"],' +
    'PARAMETER["false_easting",328083.333],' +
    'PARAMETER["false_northing",820208.333],' +
    'PARAMETER["scale_factor",0.999966666667],' +
    'PARAMETER["central_meridian",-85.66666666666670],' +
    'PARAMETER["latitude_of_origin",37.50000000000000],' +
    'UNIT["Foot_US",0.30480060960122]]',
);
// 将 Proj4js 投影定义同步注册到 OpenLayers 投影表
register(proj4);

// 初始化地图实例
const map = new Map({
  layers: [
    // 基础 OSM 瓦片图层（原生投影为 EPSG:3857 Web 墨卡托，米制单位）
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: new View({
    // 将视图设置为刚注册的 Indiana-East 投影（美国测量英尺单位）
    projection: 'Indiana-East',
    // 将经纬度点 [-85.685°W, 39.891°N]（印第安纳州首府印第安纳波利斯以东）转换为目标投影平面英尺坐标
    center: fromLonLat([-85.685, 39.891], 'Indiana-East'),
    zoom: 7,
    // 限制视图有效平移漫游范围，防止超出横轴墨卡托投影的定义域产生数学奇异
    extent: transformExtent(
      [-172.54, 23.81, -47.74, 86.46],
      'EPSG:4326',
      'Indiana-East',
    ),
    minZoom: 6,
  }),
});

// 添加比例尺控件，并配置美制单位（units: 'us'，自动显示英里 miles 或英尺 ft）
map.addControl(new ScaleLine({units: 'us'}));
