1 : 0)); const right = str.substring(p + 1); return left + spaceReplacer + stringDivider(right, width, spaceReplacer); } } return str; } ``` 通过算法在单词边界插入换行符 `\n`，配合 `lineHeight` 实现优雅的多行折行，杜绝硬切断单词导致语义断裂。 - **Web 字体异步注入与重绘**： Canvas 文本绘制要求对应字体必须在浏览器本地就绪。通过动态创建 `` 引入 Google Fonts，并在字体就绪后调用 `vectorLayer.changed()` 或重新应用样式函数，即可完成高品质个性化字体渲染。 #### 3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices) - **沿线标注字形方向反向颠倒防护**： 折线要素在绘制时方向可能自西向东或自东向西。若直接按顶点顺序排列，会导致自东向西的道路注记呈现“倒立文字”。OpenLayers 内置了智能翻转机制，但在极端近乎垂直（90° 附近）的线段上，微小的视口旋转可能导致文字在正反向之间跳动闪烁。推荐在线要素处理中统一线拓扑流向。 - **文本光晕（Text Halo / Outline）性能优化**： 为了保证文字在复杂底图背景上的清晰辨识度，配置高对比度的白色描边（`stroke: new Stroke({color: '#fff', width: 3})`）是制图标准做法。但需注意：Canvas 2D 在绘制每个字元的描边时开销是纯填充的两倍。对于海量点位，建议开启图层的 `declutter: true`（标注避让）机制，自动剔除重叠冲突的文字。 tags: "geojson, vector, openstreetmap, label" ---
