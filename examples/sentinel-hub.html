Sentinel Hub / 欧空局哨兵卫星影像（Sentinel Hub Processing API）

SentinelHub4 process4

A tile source using the Sentinel Hub Processing API / 演示如何使用 ol/source/SentinelHub 接入欧空局哨兵2号多光谱遥感影像并执行客户端波段合成。

This example renders a tile layer with a source that uses the Sentinel Hub Processing API to generate tiles. The Processing API requires an access token. The form above can be used to provide an OAuth client id and secret. The default client id and secret used in this example is severely rate limited. For the example to perform well, you should register for your own client id and secret. With this information, the source will fetch an access token. If an access token is fetched by other means, the source.setAuth() method can be called the token directly. See the Sentinel Hub authentication documentation for details.

本示例展示如何利用 ol/source/SentinelHub 数据源直接对接欧洲航天局（ESA）Sentinel-2 遥感影像的 Processing API 生成切片。Processing API 要求通过 OAuth2 进行安全认证，上方弹窗可输入您的 Client ID 与 Client Secret（示例内置的默认凭证存在严苛的限流阈值，建议申请独立凭证测试）。数据源会自动获取并维护 Access Token；若通过后端代理获取令牌，亦可直接调用 source.setAuth() 注入 Token。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构原理 (Core Architecture)

传统遥感影像服务通常仅提供离线静态合成的 RGB 切片。Sentinel Hub 开创了“按需动态即时解译处理（On-the-fly Processing）”云原生模式：

  • 多光谱原始波段抽取：Sentinel-2 卫星配备 13 个多光谱波段（覆盖可见光、近红外 NIR、短波红外 SWIR）。本例通过请求短波红外 B12、近红外 B08 与红光 B04，在服务端以 16 位精度动态组合，渲染出极具透视感的遥感假彩色地质与地貌影像。
  • Evalscript 算子运行机制：在数据源配置中声明的 evalscript 脚本（包含 setup() 与 evaluatePixel()）会被直接发送至 Sentinel Hub 分布式云端算力集群，按像素并行执行系数缩放（如 2.5 * sample.B12）与色彩映射，随后切片压缩输出到前端。
  • WebGLTile 硬件加速呈现：OpenLayers 采用专为现代多波段和浮点切片优化的 ol/layer/WebGLTile 进行渲染，保证视口缩放与平移时的极致平滑度。

      2 * sample.B08,
      2 * sample.B04,
    ],
  },
});

3. 生产实战避坑与考量 (Production Pitfalls)

  • Client Secret 泄露风险：在公网商用系统中，严禁直接在前端暴露真实生产环境的 Client Secret。推荐由后端服务器调用 Sentinel Hub 接口换取短生命周期的临时 Access Token，前端通过 source.setAuth({ token }) 纯令牌接入。
  • 云层遮挡与云掩膜过滤：Sentinel-2 光学卫星极易受多云天气影响。可在 dataFilter 中追加 maxCloudCoverage: 20（限制云量小于 20%），并在 evalscript 中引入 CLM（Cloud Mask）质量波段，将厚云或阴影像素动态透明化。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import {useGeographic} from 'ol/proj.js';
import SentinelHub from 'ol/source/SentinelHub.js';

// Enable geographic coordinates (lon, lat) directly across View and geometry
// 启用地理坐标系模式，允许直接使用经纬度配置 View 与空间范围
useGeographic();

// Configure Sentinel Hub Processing API source with custom spectral band combination
// 配置 Sentinel Hub 数据源：拉取 Sentinel-2 L2A 多光谱数据并执行云端波段运算合成
const source = new SentinelHub({
  data: [
    {
      type: 'sentinel-2-l2a', // Sentinel-2 Level-2A Bottom-Of-Atmosphere reflectance / 哨兵2号L2A地表反射率产品
      dataFilter: {
        timeRange: {
          from: '2024-05-30T00:00:00Z',
          to: '2024-06-01T00:00:00Z',
        },
      },
    },
  ],
  evalscript: {
    // Declare requested bands (SWIR-2 B12, NIR B08, Red B04)
    // 声明订阅的波段：短波红外 B12、近红外 B08、红光 B04
    setup: () => ({
      input: ['B12', 'B08', 'B04'],
      output: {bands: 3},
    }),
    // Pixel-level dynamic stretching formula evaluated in the cloud
    // 云端像素级波段线性拉伸公式
    evaluatePixel: (sample) => [
      2.5 * sample.B12,
      2 * sample.B08,
      2 * sample.B04,
    ],
  },
});

// Render with WebGLTile layer for optimal rendering performance
// 采用 WebGLTile 图层实现高吞吐硬件加速渲染
const map = new Map({
  layers: [new TileLayer({source})],
  target: 'map',
  view: new View({
    center: [-121.75, 46.85],
    zoom: 10,
    minZoom: 7,
    maxZoom: 13,
  }),
});

// Listen to OAuth authentication form submission
// 监听认证弹窗提交事件，注入 OAuth 凭证换取 Token
document.getElementById('auth-form').addEventListener('submit', (event) => {
  const clientId = event.target.elements['id'].value;
  const clientSecret = event.target.elements['secret'].value;
  source.setAuth({clientId, clientSecret});
});

// Handle authentication or processing errors
// 监听数据源状态变更，捕获并提示认证失败或请求超限异常
source.on('change', () => {
  if (source.getState() === 'error') {
    alert(source.getError());
  }
});
