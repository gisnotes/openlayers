--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构原理 (Core Architecture) 传统遥感影像服务通常仅提供离线静态合成的 RGB 切片。Sentinel Hub 开创了“按需动态即时解译处理（On-the-fly Processing）”云原生模式： - **多光谱原始波段抽取**：Sentinel-2 卫星配备 13 个多光谱波段（覆盖可见光、近红外 NIR、短波红外 SWIR）。本例通过请求短波红外 `B12`、近红外 `B08` 与红光 `B04`，在服务端以 16 位精度动态组合，渲染出极具透视感的遥感假彩色地质与地貌影像。 - **Evalscript 算子运行机制**：在数据源配置中声明的 `evalscript` 脚本（包含 `setup()` 与 `evaluatePixel()`）会被直接发送至 Sentinel Hub 分布式云端算力集群，按像素并行执行系数缩放（如 `2.5 * sample.B12`）与色彩映射，随后切片压缩输出到前端。 - **WebGLTile 硬件加速呈现**：OpenLayers 采用专为现代多波段和浮点切片优化的 `ol/layer/WebGLTile` 进行渲染，保证视口缩放与平移时的极致平滑度。 #### 2. 关键实现与代码拆解 (Code Deep Dive) ```javascript useGeographic(); // 启用经纬度直接传参模式 const source = new SentinelHub({ data: [{ type: 'sentinel-2-l2a', // 指定欧洲空间局 Sentinel-2 L2A 大气校正底表反射率产品 dataFilter: { timeRange: { from: '2024-05-30T00:00:00Z', to: '2024-06-01T00:00:00Z', }, }, }], evalscript: { setup: () => ({ input: ['B12', 'B08', 'B04'], // 订阅所需光谱波段 output: {bands: 3}, }), evaluatePixel: (sample) => [ 2.5 * sample.B12, // 动态拉伸对比度 2 * sample.B08, 2 * sample.B04, ], }, }); ``` #### 3. 生产实战避坑与考量 (Production Pitfalls) - **Client Secret 泄露风险**：在公网商用系统中，严禁直接在前端暴露真实生产环境的 Client Secret。推荐由后端服务器调用 Sentinel Hub 接口换取短生命周期的临时 Access Token，前端通过 `source.setAuth({ token })` 纯令牌接入。 - **云层遮挡与云掩膜过滤**：Sentinel-2 光学卫星极易受多云天气影响。可在 `dataFilter` 中追加 `maxCloudCoverage: 20`（限制云量小于 20%），并在 `evalscript` 中引入 `CLM`（Cloud Mask）质量波段，将厚云或阴影像素动态透明化。 tags: "Sentinel Hub, process" ---
