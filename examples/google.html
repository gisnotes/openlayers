This example demonstrates how to display tiles from Google's Map Tiles API in a map. To use the Google Map Tiles API, you need to set up a Google Cloud project and create an API key for your application. See the Map Tiles API documentation for instructions.
The ol/source/Google source can be used with a tile layer and is configured by passing properties to the constructor that are used in creating the session token request for accessing the tiles. The mapType defaults to 'roadmap' and can be changed to any of the supported map types.
When using the Google source, please make sure you comply with the Google Map Tiles API Policies, by adding the Google logo in the bottom-left corner of the map. You can add the logo as a static image by using a custom OpenLayers control, as shown in the example below.

本示例展示了如何在 OpenLayers 地图中接入谷歌官方正式开放的 Google Map Tiles API。接入前需在 Google Cloud 控制台中启用该 API 并申请凭据 API Key。
OpenLayers 提供了专用的 ol/source/Google 数据源，内部全自动调度向谷歌端点申请双向通信的 Session Token（会话令牌），并携带该 Token 拉取瓦片切片。mapType 默认为 'roadmap'（标准路线图），亦可根据业务需求设置为 'satellite'（卫星图）或 'terrain'（地形图）。
商用法规合规警示：根据 Google Map Tiles API 政策条款，使用谷歌底图时，必须在地图视口左下角显式保留合规尺寸的 Google 官方品牌 Logo。本例通过自定义一个静态控件（ol/control/Control）实现了该法定品牌标示。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - **基于 Session Token 的短期会话生命周期**： 与普通静态 XYZ 瓦片仅靠 API Key 直连不同，Google Map Tiles API 采用了高度安全的双阶段架构：首先使用用户的 API Key 向 tile.googleapis.com/v1/createSession 发起一次 POST 请求，换取一个有效期通常为 2 周的加密 session 令牌；后续所有切片请求（2d-tiles/{z}/{x}/{y}?session=...）均使用该 Token。ol/source/Google 在内部全自动处理了会话获取与刷新。 - **自定义商标 Control 控件注入**： 通过继承 ol/control/Control 创建一个纯 DOM 控件并将带有 Google Logo 的图片图标定位在视口左下方，OpenLayers 保证了在全屏或视口调整时该 Logo 始终稳定悬浮于所有业务图层之上。 #### 2. 源码与关键 API 剖析 (Source Code & API Analysis) - new Google({ key: apiKey, mapType: 'roadmap', highDpi: true })： OpenLayers 内置 Google 数据源。开启 highDpi: true（如果设备支持）会自动请求 512 像素视网膜切片，在高分辨率屏幕上达到极高锐利度。 #### 3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - **Google Cloud 计费与预算保护**： Google Map Tiles API 是按会话请求次数计费的商业服务。在生产部署时，务必在 Google Cloud 控制台设置每日配额上限与预算警报，并限制 API Key 的 HTTP Referrer，防止盗用产生非预期扣费。 tags: "google" ---
