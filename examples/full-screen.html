Full Screen Control / 全屏显示控件 (FullScreen)

full-screen3 xyz6 maptiler26

Example of a full screen control. / 使用 FullScreen 控件将地图容器一键切换为沉浸式全屏视图的示例。

Click the control in the top right corner to go full screen. Click it again to exit full screen.

If there is no button on the map, your browser does not support the Full Screen API.

点击地图右上角的全屏控件按钮可进入全屏沉浸式体验。再次点击该按钮（或按下 Esc 键）即可退出全屏模式。

如果地图上未出现全屏按钮，说明当前运行环境或浏览器不支持 Full Screen API，或处于未授予权限的 iframe 沙箱中。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • W3C Fullscreen API 原生封装： OpenLayers 的 ol/control/FullScreen 封装了底层各大浏览器的全屏能力（包括 requestFullscreen、webkitRequestFullscreen 及对应的退出全屏方法），屏蔽了厂商前缀与老旧设备差异，并具备运行时设备能力自检机制（若不支持则自动隐藏 DOM 按钮）。
  • 视口尺寸响应式重算（Automatic Resize）： 当进入或退出全屏时，浏览器视口尺寸瞬间发生巨大跃迁。FullScreen 控件内部监听了标准的 fullscreenchange 原生事件，并自动调用 map.updateSize()，迫使 WebGL 渲染管线与瓦片队列重新按全屏分辨率调度出图，杜绝任何黑边拉伸。

2. 源码与关键 API 剖析

  • controls: defaultControls().extend([new FullScreen()])：挂载全屏控件，默认采用经典的外向四角箭头图标。
  • className: 'ol-full-screen'：默认 CSS 类名，利用绝对定位固定于右上角（top: .5em; right: .5em;）。

3. 生产实践踩坑与性能调优

  • iframe 嵌入场景权限阻断： 若地图嵌入在第三方平台的 <iframe> 中，iframe 标签必须显式追加 allow="fullscreen"（或历史属性 allowfullscreen="true"），否则浏览器控制台将抛出 Permissions policy violation: fullscreen is not allowed in this document 并导致全屏失效。
  • 全屏状态下的 CSS 层叠上下文： 当元素进入全屏状态时，浏览器会创建一个顶层堆叠层（Top Layer），常规页面的 z-index 将全部失效。所有需要随地图一起在全屏下可见的自定义业务面板，必须隶属于全屏容器内部。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import FullScreen from 'ol/control/FullScreen.js';
import {defaults as defaultControls} from 'ol/control/defaults.js';
import Layer from 'ol/layer/WebGLTile.js';
import Source from 'ol/source/ImageTile.js';

const view = new View({
  center: [-9101767, 2822912],
  zoom: 14,
});

const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Initialize map with FullScreen control and WebGLTile satellite layer
// 初始化地图，挂载全屏控件与 WebGLTile 卫星影像图层
const map = new Map({
  controls: defaultControls().extend([new FullScreen()]),
  layers: [
    new Layer({
      source: new Source({
        attributions: attributions,
        url:
          'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
        tileSize: 512,
        maxZoom: 20,
      }),
    }),
  ],
  target: 'map',
  view: view,
});
index.html 
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <title>Full Screen Control / 全屏显示控件 (FullScreen)</title>
    <link rel="stylesheet" href="node_modules/ol/ol.css">
    <style>
      .map {
        width: 100%;
        height: 400px;
      }
      .map:-webkit-full-screen {
        height: 100%;
        margin: 0;
      }
      .map:fullscreen {
        height: 100%;
      }
      .map .ol-rotate {
        top: 3em;
      }
    </style>
  </head>
  <body>
    <div id="map" class="map"></div>

    <script type="module" src="main.js"></script>
  </body>
</html>
