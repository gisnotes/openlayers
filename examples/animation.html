--- layout: example.html title: View Animation / 视图动画（平移、缩放、旋转与飞行巡检） shortdesc: Demonstrates animated pan, zoom, and rotation. / 演示如何使用 view.animate() 实现平滑平移、回弹缩放、锚点旋转以及多阶段飞行巡检动画。 docs: > This example shows how to use the view.animate() method to run one or more animations. 本示例展示如何使用 view.animate() 方法运行单一或多阶段链式视图动画。涵盖视角中心平移、缩放等级推拉、基于任意地理锚点（Anchor）的旋转、Raphael 经典弹性（Elastic）与弹跳（Bounce）缓动函数集成、两阶段两倍缩放的“弧形起飞降落（FlyTo）”模拟，以及通过回调递归构建的跨洲际城市自动飞行巡检（Tour）。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构原理 (Core Architecture) 在 WebGIS 导航中，突兀的瞬移切换会割裂用户的空间感知。OpenLayers 提供了基于时间驱动的 view.animate(options, ...) 动画引擎： - **参数并行与链式串行**： - 单个配置对象中的属性（如同时指定 center、zoom、rotation）会在相同时间窗口内**并行插值执行**。 - 传入多个配置对象作为连续参数：view.animate(stage1, stage2)，系统会自动按顺序**串行链式衔接**。 - **飞行动画（FlyTo）视差原理**：通过将视口中心平移与两段式缩放（前半段先放大视野 zoom - 1，后半段精确降落 zoom）并发组合，营造出“拉高巡航再俯冲着陆”的极具立体感的镜头体验。 - **旋转最短弧度避坑与 360° 全旋转**：OpenLayers 默认沿最短角弧度插值。若直接设置 rotation + 2*Math.PI，系统计算夹角差值为 0 从而不产生任何旋转。因此完整的一圈旋转必须通过两段式串联执行：前半圈加 $\pi$，后半圈再加 $\pi$。 #### 2. 关键实现与代码拆解 (Code Deep Dive) ```javascript // 经典 FlyTo 两阶段起飞俯冲并发动画 function flyTo(location, done) { const duration = 2000; const zoom = view.getZoom(); let parts = 2; let called = false; function callback(complete) { --parts; if (called) return; if (parts === 0 || !complete) { called = true; done(complete); } } // 轨迹平移：历时 2000ms view.animate({ center: location, duration: duration }, callback); // 高度起落：前 1000ms 缩小视野拉高巡航，后 1000ms 降落还原 view.animate( { zoom: zoom - 1, duration: duration / 2 }, { zoom: zoom, duration: duration / 2 }, callback ); } ``` #### 3. 生产实战避坑与考量 (Production Pitfalls) - **瓦片预加载（Preload）防白屏**：在高速大跨度飞行或旋转期间，当前视口内的高清瓦片可能因下载不及而闪烁白屏。在底图图层配置 preload: 4，可促使 OpenLayers 预加载当前层级上下若干级的低清金字塔切片作为过渡底衬，彻底消除白屏。 - **用户打断响应（Interruption Handling）**：在执行长达数秒的漫游动画时，用户若手动拖拽地图，OpenLayers 会立即中止当前动画并调用 callback(false)。业务代码必须妥善处理 complete === false 的中止信号，及时注销后续巡检定时器。 tags: "animation" ---
