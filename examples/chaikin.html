Smoothing lines using Chaikins algorithm / 基于 Chaikin 算法的折线平滑化

smooth1 smoothing1 chaikin1


This uses Chaikins algorithm to smooth drawn lines. / 利用 Chaikin 割角算法对交互绘制的折线几何进行多轮迭代平滑化处理。

This example uses the npm package [`chaikin-smooth`](https://www.npmjs.com/package/chaikin-smooth) which implements [Chaikins algorithm](http://graphics.cs.ucdavis.edu/education/CAGDNotes/Chaikins-Algorithm/Chaikins-Algorithm.html) to smooth drawn lines.

Start by drawing on the map. Once you finish a drawing, the feature's geometry will be smoothed as configured via the form elements.

本示例借助 npm 包 chaikin-smooth 实现了经典的 Chaikin 割角（Corner-Cutting）平滑算法，对用户在地图上交互绘制的折线进行平滑化曲线逼近。

在地图上单击连续画线，双击结束绘制。绘制完成后，要素几何将根据下方表单中配置的迭代次数自动计算并替换为平滑的曲线坐标。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - Chaikin 割角算法数学原理（Corner-Cutting Algorithm）： 由 George Chaikin 于 1974 年提出，是细分曲线（Subdivision Surfaces）的鼻祖。对于折线段上的任意相邻两点 $P_i$ 与 $P_{i+1}$，算法在每次迭代中将原线段分割，用位于 $1/4$ 处的新顶点 $Q_i = \frac{3}{4}P_i + \frac{1}{4}P_{i+1}$ 与 $3/4$ 处的新顶点 $R_i = \frac{1}{4}P_i + \frac{3}{4}P_{i+1}$ 取代旧拐点。随着迭代次数 $N$ 增加，折线迅速收敛逼近均匀二次 B 样条（Quadratic B-Spline）光滑曲线。 - 矢量交互与几何后处理管线： `Draw` 交互负责捕获用户的手势输入并生成初始 `LineString`，而 `drawend` 事件构成了几何进入 `VectorSource` 之前的拦截处理拦截器。通过在 `drawend` 回调中就地修改 `geometry.setCoordinates(smoothened)`，整个过程无需销毁重建要素，性能极高。

2. 源码与关键 API 剖析 (Source Code & API Analysis) - makeSmooth(path, numIterations)：

  • 入参：原始坐标数组 [[x1, y1], [x2, y2], ...]，迭代次数（建议限制在 1~10 之间）。
  • 边界收敛与顶点爆炸：每增加一次迭代，折线顶点数量近似翻倍（$V_{new} = 2V_{old} - 2$）。若迭代次数过大（如超过 12 次），顶点数将成千上万，不仅无法带来视觉上的进一步平滑提升，还会造成浏览器内存和渲染瓶颈。因此在函数内部使用 Math.min(Math.max(numIterations, 1), 10) 进行安全截断。
  • draw.on('drawend', (event) => ...)： 事件对象提供 event.feature，直接读取其底层几何并修改其坐标。

3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - 首尾端点固定（Fixed Endpoints）：

标准 Chaikin 算法可能会导致曲线的首末端点向内轻微收缩。在 GIS 规划和测绘业务中，折线的起点和终点往往具有绝对现实意义（如传感器点位、路口），在实现平滑算法时需确保首点 $P_0$ 和末点 $P_n$ 保持严格不动。

  • 大尺度缩放与 Douglas-Peucker 结合： 平滑算法生成了大量高密度拐点。当用户大幅缩小地图视口时，密集的平滑顶点会导致 Overdraw。生产级方案通常建议在缩放时结合 simplify()（Douglas-Peucker 抽稀算法）动态降低渲染点数。
main.js 
import smooth from 'chaikin-smooth';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Draw from 'ol/interaction/Draw.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';

/**
 * Apply Chaikin's corner-cutting algorithm iteratively to smooth a coordinate path
 * 迭代调用 Chaikin 割角切角平滑算法平滑给定的坐标序列
 * @param {Array<Array<number>>} path Input coordinate array / 原始坐标数组
 * @param {number} numIterations Number of smoothing rounds / 平滑迭代轮次
 * @return {Array<Array<number>>} Smoothed coordinate array / 平滑后的坐标数组
 */
function makeSmooth(path, numIterations) {
  // Clamp iterations between 1 and 10 to prevent exponential vertex explosion
  // 将迭代次数限制在 1 到 10 之间，防止顶点数量指数级爆炸
  numIterations = Math.min(Math.max(numIterations, 1), 10);
  while (numIterations > 0) {
    path = smooth(path);
    numIterations--;
  }
  return path;
}

// Vector source storing the drawn features
// 存储用户绘制要素的矢量数据源
const vectorSource = new VectorSource({});

// Main map instance with OSM basemap and vector overlay
// 地图主实例，包含半透明 OSM 底图与矢量绘制图层
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
      opacity: 0.5,
    }),
    new VectorLayer({
      source: vectorSource,
    }),
  ],
  target: 'map',
  view: new View({
    center: [1078373.595, 6871994.591],
    zoom: 5,
  }),
});

const shallSmoothen = document.getElementById('shall-smoothen');
const numIterations = document.getElementById('iterations');

// Add Draw interaction for LineString
// 添加折线交互绘制工具
const draw = new Draw({
  source: vectorSource,
  type: 'LineString',
  // Stop drawing when double-clicking
});
map.addInteraction(draw);

// Intercept drawend to apply Chaikin smoothing before storing into vector source
// 监听 drawend 绘制完成事件，在几何最终确认前执行 Chaikin 算法平滑重置坐标
draw.on('drawend', function (event) {
  if (!shallSmoothen.checked) {
    return;
  }
  const feat = event.feature;
  const geometry = feat.getGeometry();
  const coords = geometry.getCoordinates();
  const smoothened = makeSmooth(coords, parseInt(numIterations.value, 10) || 5);
  geometry.setCoordinates(smoothened);
});
