--- layout: example.html title: Layer Zoom Limits / 图层缩放级别可见性区间（minZoom 与 maxZoom） shortdesc: Using minZoom and maxZoom to control layer visibility. / 使用图层的 minZoom 与 maxZoom 控制不同层级下的图层显示与切换。 docs: > Layers support `minZoom` and `maxZoom` options for controlling visibility based on the view's zoom level. If min or max zoom are set, the layer will only be visible at zoom levels greater than the `minZoom` and less than or equal to the `maxZoom`. After construction, the layer's `setMinZoom` and `setMaxZoom` can be used to set limits. This example shows an OSM layer at zoom levels 14 and lower and a USGS layer at zoom levels higher than 14. 图层（Layer）支持通过 minZoom 与 maxZoom 选项精确控制其在不同地图缩放级别下的可见性。当设置了该区间时，图层**仅在缩放级别大于 `minZoom` 且小于等于 `maxZoom`（即左开右闭区间 `(minZoom, maxZoom]`）时处于可见状态**。图层实例化后，亦可通过调用 setMinZoom 与 setMaxZoom 动态更新可见性范围。本示例在 14 级及以下显示宏观 OSM 底图，而在 14 级以上自动无缝切换为精细的高清等高线地形底图（MapTiler Outdoor）。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构原理 (Core Architecture) 在多尺度电子地图（Multi-scale Cartography）架构中，宏观大比例尺需要概况性矢量或轻量瓦片，而微观小比例尺需要高精细度影像、等高线或建筑白模： - **图层可见性区间的半开半闭数学定义**： $$\text{Visible} \iff \text{minZoom} < z \le \text{maxZoom}$$ 注意：minZoom 为**严格大于（开区间）**，而 maxZoom 为**小于等于（闭区间）**！ 例如： - OSM 图层：设置 maxZoom: 14，当 $z \le 14$ 时可见； - Outdoor 图层：设置 minZoom: 14，当 $z > 14$ 时可见； 在临界点 $z=14$ 时，恰好只有 OSM 可见，不会产生两层同尺寸瓦片重合造成的双重渲染浪费。 - **动态分辨率计算 (`resolution`)**：在 OpenLayers 内部渲染帧调度器中，每帧计算 viewState.resolution 时，系统优先比对图层的 minResolution 与 maxResolution。minZoom 和 maxZoom 在底层被自动转换为对应的等价分辨率进行极速常数时间比对。 #### 2. 关键实现与代码拆解 (Code Deep Dive) ```javascript const map = new Map({ layers: [ new TileLayer({ maxZoom: 14, // 14 级及以下显示（zoom <= 14） source: new OSM(), }), new TileLayer({ minZoom: 14, // 超过 14 级显示（zoom > 14） source: new TileJSON({ url: 'https://api.maptiler.com/maps/outdoor-v2/tiles.json?key=' + key, tileSize: 512, }), }), ], view: new View({ center: fromLonLat([-112.18688965, 36.057944835]), zoom: 15, maxZoom: 18, constrainOnlyCenter: true, }), }); ``` #### 3. 生产实战避坑与考量 (Production Pitfalls) - **图层重合闪烁与并发消耗（Z-fighting）**：切勿将低精度图层设为 maxZoom: 14 的同时将高精度图层设为 minZoom: 13，重叠层级会导致两个图层的瓦片并发请求并重叠绘制，造成严重的网络与 GPU 浪费。遵循 LayerA.maxZoom === LayerB.minZoom 可确保完美的无缝单层衔接。 - **未激活图层的网络静默**：当视口处于图层可见区间之外时，OpenLayers 的切片加载流水线会直接跳过该图层，**绝不会向服务器发起任何瓦片网络请求**，极大节省网络带宽。 tags: "minZoom, maxZoom, layer" ---
