--- layout: example.html title: Rich Text Labels / 富文本排版注记 shortdesc: Rich text labels. / 在单个注记中使用多重字体、粗细与样式的富文本排版（Rich Text）。 docs: > The labels in this map use different fonts to create clear context - an alphabetic sort key prefixing the state name in bold, and the population density in an extra line with a smaller font and italic. 本示例中的注记通过混合使用多种字体与排版样式建立清晰的信息层级：在州名前缀加粗显示字母排序代号，在换行后以更小字号的斜体字展示人口密度信息。利用 OpenLayers Text.setText() 接收文本片段数组的特性，开发者无需借助繁琐的 HTML 覆盖物，即可在高性能 Canvas 上直接渲染具备复杂排版的富文本标注。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 数组化富文本语法规范 (Array-based Rich Text Syntax) - **交替式文本与字体配置**: `Text.setText([...])` 允许传入一维平铺数组，结构规则为： `[文本片段1, 字体描述1, 文本片段2, 字体描述2, ...]`。 - **字体继承机制**: 当某个片段对应的字体描述为空字符串 `''` 时，自动继承当前 `Text` 实例构造时传入的默认基准字体（如 `13px Calibri,sans-serif`）。 - **多行复合排版**: 通过传入换行符 `'\n'` 实现多行分段，并允许第一行为标题加粗大字、第二行为副标题说明小字、第三行为统计数据斜体，大幅丰富地图专题注记的视觉表现力。 #### 2. 单例样式动态复用架构 - **避免高频 GC 垃圾回收**: 在大数据量要素渲染中，绝不能在矢量图层的 `style` 动态函数内部反复调用 `new Style()` 或 `new Text()`。 - 示例中将 `labelStyle` 和 `countryStyle` 作为全局单例缓存，仅在要素遍历时动态更新 `labelStyle.getText().setText(...)` 并返回固定的样式数组引用，极大保障了地图在缩放漫游时的渲染帧率。 #### 3. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices) - **词间空格丢失陷阱**: 数组中的连续文本片段拼接时不会自动插入空格。若相邻片段需要间隔，必须手动在字符串前置或后置补齐空格（如 `' ' + name`）。 - **文字描边 (Halo/Stroke) 统一穿透**: 外部 `Stroke` 属性会均匀包裹数组中的所有富文本片段。为保证在各类卫星影像或深色底图上的可读性，推荐常态化配置高对比度描边（如浅色底图配深色字加白描边，卫星影像配亮色字加黑描边）。 tags: "vector, rich-text, labels" ---
