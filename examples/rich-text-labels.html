Rich Text Labels / 富文本排版注记

vector87 rich-text1 labels3

Rich text labels. / 在单个注记中使用多重字体、粗细与样式的富文本排版（Rich Text）。

The labels in this map use different fonts to create clear context - an alphabetic sort key prefixing the state name in bold, and the population density in an extra line with a smaller font and italic.

本示例中的注记通过混合使用多种字体与排版样式建立清晰的信息层级：在州名前缀加粗显示字母排序代号，在换行后以更小字号的斜体字展示人口密度信息。利用 OpenLayers Text.setText() 接收文本片段数组的特性，开发者无需借助繁琐的 HTML 覆盖物，即可在高性能 Canvas 上直接渲染具备复杂排版的富文本标注。

📚 学习记录与技术深度解读 (Learning Notes)

1. 数组化富文本语法规范 (Array-based Rich Text Syntax)

  • 交替式文本与字体配置: Text.setText([...]) 允许传入一维平铺数组，结构规则为： [文本片段1, 字体描述1, 文本片段2, 字体描述2, ...]。
  • 字体继承机制: 当某个片段对应的字体描述为空字符串 '' 时，自动继承当前 Text 实例构造时传入的默认基准字体（如 13px Calibri,sans-serif）。
  • 多行复合排版: 通过传入换行符 '\n' 实现多行分段，并允许第一行为标题加粗大字、第二行为副标题说明小字、第三行为统计数据斜体，大幅丰富地图专题注记的视觉表现力。

2. 单例样式动态复用架构

  • 避免高频 GC 垃圾回收: 在大数据量要素渲染中，绝不能在矢量图层的 style 动态函数内部反复调用 new Style() 或 new Text()。
  • 示例中将 labelStyle 和 countryStyle 作为全局单例缓存，仅在要素遍历时动态更新 labelStyle.getText().setText(...) 并返回固定的样式数组引用，极大保障了地图在缩放漫游时的渲染帧率。

3. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices)

  • 词间空格丢失陷阱: 数组中的连续文本片段拼接时不会自动插入空格。若相邻片段需要间隔，必须手动在字符串前置或后置补齐空格（如 ' ' + name）。
  • 文字描边 (Halo/Stroke) 统一穿透: 外部 Stroke 属性会均匀包裹数组中的所有富文本片段。为保证在各类卫星影像或深色底图上的可读性，推荐常态化配置高对比度描边（如浅色底图配深色字加白描边，卫星影像配亮色字加黑描边）。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import VectorLayer from 'ol/layer/Vector.js';
import VectorSource from 'ol/source/Vector.js';
import Fill from 'ol/style/Fill.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';
import Text from 'ol/style/Text.js';

// Initialize map with a constrained extent over the contiguous United States
// 初始化地图实例：视图限制在美国本土空间范围并启用全视口自适应
const map = new Map({
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
    extent: [-13882269, 2890586, -7456136, 6340207],
    showFullExtent: true,
  }),
});

// Reusable text label style singleton with high-contrast white stroke halo
// 可复用的文本注记样式单例：配置黑色填充与 4px 白色高对比度文字描边
const labelStyle = new Style({
  text: new Text({
    font: '13px Calibri,sans-serif',
    fill: new Fill({
      color: '#000',
    }),
    stroke: new Stroke({
      color: '#fff',
      width: 4,
    }),
  }),
});

// Reusable polygon boundary and fill style
// 可复用的多边形边界描边与半透明填充样式
const countryStyle = new Style({
  fill: new Fill({
    color: 'rgba(255, 255, 255, 0.6)',
  }),
  stroke: new Stroke({
    color: '#319FD3',
    width: 1,
  }),
});
const style = [countryStyle, labelStyle];

// Vector layer loading US states GeoJSON and applying dynamic rich text labels
// 矢量图层：加载美国各州边界 GeoJSON 数据，并在要素样式回调中动态组装富文本注记
const vectorLayer = new VectorLayer({
  background: 'white',
  source: new VectorSource({
    url: 'https://openlayers.org/data/vector/us-states.json',
    format: new GeoJSON(),
  }),
  style: function (feature) {
    // Pass an array of alternating [text, font] segments to build rich typography
    // 传入交替的 [文本片段, 字体描述] 数组以构建多行、多粗细字号的富文本排版
    labelStyle
      .getText()
      .setText([
        feature.getId(),
        'bold 13px Calibri,sans-serif',
        ` ${feature.get('name')}`,
        '',
        '\n',
        '',
        `${feature.get('density')} people/mi²`,
        'italic 11px Calibri,sans-serif',
      ]);
    return style;
  },
});

map.addLayer(vectorLayer);
