Icon Colors / 图标动态着色（单图多色复用）

vector87 style27 icon10 marker6

Example assigning a custom color to an icon / 演示如何通过 color 属性为白色底图图标动态赋予自定义颜色与透明度。

Example assigning a custom color to an icon. The icon styles in this example use images with a white fill. For some features, custom colors set using the color property. Note that icon files need to obey the same origin policy or send proper CORS headers for this to work. When relying on CORS headers, the ol/style/Icon must be configured with crossOrigin: 'anonymous'.

本示例演示如何通过 color 属性为图标（ol/style/Icon）动态赋予自定义颜色。示例中的图标源文件均采用纯白色填充设计：其中部分城市要素（罗马、伦敦、巴黎）通过 color 属性进行了动态染色，而另一些城市（马德里、柏林）则保留了原始的白色外观作为对照。 注意：由于图标染色需要在 Canvas 中进行像素级合成处理，图标文件必须遵循浏览器的同源策略（Same-Origin Policy）或由服务端返回正确的 CORS 跨域响应头。当使用跨域图片资源时，必须在 ol/style/Icon 中显式配置 crossOrigin: 'anonymous'。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心业务价值：为什么要用 color 动态染色？

在复杂的 WebGIS 项目中，同一类点位图标（如监控摄像头、传感器、车辆、定位针）往往有多种状态色（正常绿、告警橙、故障红、离线灰）：

  • 传统笨办法：让设计师切出 camera-green.png、camera-red.png 等十几种颜色的图片。不仅维护成本高，前端还需要发起多次 HTTP 请求。
  • OpenLayers 最佳实践：只需准备 1 张纯白色的母版图标（PNG 或 SVG），在前端通过 new Icon({ src: '...', color: '#ff0000' }) 即可衍生出任意 RGB 颜色和透明度的图标，且多处复用同一张底层图片纹理缓存！

2. 底层渲染原理：为什么母版图标必须是“白色填充”？

OpenLayers 对图标染色采用的是计算机图形学中的 正片叠底（Color Multiply / 通道相乘） 算法：

最终颜色(R, G, B, A) = (原图像素(R, G, B, A) / 255) × (目标 Color(R, G, B, A) / 255)
  • 纯白色区域 (255, 255, 255)：归一化后为 1.0。1.0 × 目标颜色 = 目标颜色本身！因此白色部分会被 100% 精准染成你指定的 color。
  • 黑色描边或阴影 (0, 0, 0)：归一化后为 0.0。0.0 × 目标颜色 = 0.0（依然是黑色）！这意味着如果母版图标带有黑色轮廓线或灰度立体阴影，染色后立体感与黑边依然能完美保留！
  • ⚠️ 常见踩坑：如果母版图标本身是纯红色的 (255, 0, 0)，你设置 color: 'blue' (0, 0, 255)，两者通道相乘后结果为 (0, 0, 0) —— 图标会直接变成死黑色！因此母版图标主体务必设计为纯白色。

3. 5 个欧洲城市的染色对照表

城市要素 图标源文件 color 配置值 最终渲染视觉效果
罗马 (rome) data/square.svg '#BADA55' 染成黄绿色方块
伦敦 (london) data/bigdot.png 'rgba(255, 0, 0, .5)' 染成半透明红色圆点（同时通过 rgba 控制了 Alpha 透明度）
马德里 (madrid) data/bigdot.png 未设置（对照组） 展示 bigdot.png 原始的纯白色圆点外观
巴黎 (paris) data/dot.svg '#8959A8' 染成紫罗兰色圆点
柏林 (berlin) data/dot.svg 未设置（对照组） 展示 dot.svg 原始的纯白色圆点外观

4. 关键避坑指南：跨域污染（Tainted Canvas）与 crossOrigin: 'anonymous'

  • 为什么染色需要配置 crossOrigin: 'anonymous'？
    • 普通不染色的图标直接绘制即可，但一旦配置了 color 属性，OpenLayers 内部需要在离屏 Canvas 上读取像素并执行颜色混合。
    • 如果图片来自第三方 CDN 或独立的对象存储域名，且没有声明 crossOrigin: 'anonymous'，浏览器的安全机制会将画布锁死为 Tainted Canvas（受污染画布），导致像素操作抛出安全异常或图标无法显示。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Point from 'ol/geom/Point.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import {fromLonLat} from 'ol/proj.js';
import OGCMapTile from 'ol/source/OGCMapTile.js';
import VectorSource from 'ol/source/Vector.js';
import Icon from 'ol/style/Icon.js';
import Style from 'ol/style/Style.js';

// Create 5 point features for European capitals (converting [lon, lat] to EPSG:3857 via fromLonLat)
// 创建 5 个欧洲首都城市的点要素（使用 fromLonLat 将 WGS84 经纬度转换为默认的 EPSG:3857 墨卡托坐标）
const rome = new Feature({
  geometry: new Point(fromLonLat([12.5, 41.9])), // Rome / 罗马
});

const london = new Feature({
  geometry: new Point(fromLonLat([-0.12755, 51.507222])), // London / 伦敦
});

const madrid = new Feature({
  geometry: new Point(fromLonLat([-3.683333, 40.4])), // Madrid / 马德里
});
const paris = new Feature({
  geometry: new Point(fromLonLat([2.353, 48.8566])), // Paris / 巴黎
});
const berlin = new Feature({
  geometry: new Point(fromLonLat([13.3884, 52.5169])), // Berlin / 柏林
});

// 1. Rome: Tint white square.svg with hex color '#BADA55' (yellow-green)
// 1. 罗马：将纯白底图 square.svg 动态染成 '#BADA55'（黄绿色）
rome.setStyle(
  new Style({
    image: new Icon({
      color: '#BADA55',
      crossOrigin: 'anonymous', // Required for pixel manipulation when using CORS images / 像素级染色需开启跨域匿名声明
      src: 'data/square.svg',
    }),
  }),
);

// 2. London: Tint white bigdot.png with semi-transparent red 'rgba(255, 0, 0, .5)'
// 2. 伦敦：将纯白底图 bigdot.png 动态染成半透明红色（同时控制了颜色与 50% 透明度）
london.setStyle(
  new Style({
    image: new Icon({
      color: 'rgba(255, 0, 0, .5)',
      crossOrigin: 'anonymous',
      src: 'data/bigdot.png',
      scale: 0.2,
    }),
  }),
);

// 3. Madrid: Control group using the same bigdot.png WITHOUT 'color' (renders original white icon)
// 3. 马德里：对照组，使用同一张 bigdot.png 但不配置 color 属性（保持原图默认的纯白色外观）
madrid.setStyle(
  new Style({
    image: new Icon({
      crossOrigin: 'anonymous',
      src: 'data/bigdot.png',
      scale: 0.2,
    }),
  }),
);

// 4. Paris: Tint white dot.svg with purple '#8959A8'
// 4. 巴黎：将纯白底图 dot.svg 动态染成 '#8959A8'（紫罗兰色）
paris.setStyle(
  new Style({
    image: new Icon({
      color: '#8959A8',
      crossOrigin: 'anonymous',
      src: 'data/dot.svg',
    }),
  }),
);

// 5. Berlin: Control group using the same dot.svg WITHOUT 'color' (renders original white icon)
// 5. 柏林：对照组，使用同一张 dot.svg 但不配置 color 属性（保持原图默认的纯白色外观）
berlin.setStyle(
  new Style({
    image: new Icon({
      crossOrigin: 'anonymous',
      src: 'data/dot.svg',
    }),
  }),
);

// Create vector source and layer containing all 5 city features
// 创建包含上述 5 个城市要素的矢量数据源与矢量图层
const vectorSource = new VectorSource({
  features: [rome, london, madrid, paris, berlin],
});

const vectorLayer = new VectorLayer({
  source: vectorSource,
});

// Create OGC Map Tile raster basemap layer
// 创建基于 OGC API - Tiles 规范的 NaturalEarth 自然地貌栅格底图
const rasterLayer = new TileLayer({
  source: new OGCMapTile({
    url: 'https://maps.gnosis.earth/ogcapi/collections/NaturalEarth:raster:HYP_HR_SR_OB_DR/map/tiles/WebMercatorQuad',
    crossOrigin: '',
  }),
});

// Initialize map centered over Western Europe
// 初始化地图并将视野中心定位在西欧上空
const map = new Map({
  layers: [rasterLayer, vectorLayer],
  target: document.getElementById('map'),
  view: new View({
    center: fromLonLat([2.896372, 44.6024]),
    zoom: 3,
  }),
});
