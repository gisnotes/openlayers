'anonymous'`。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心业务价值：为什么要用 `color` 动态染色？ 在复杂的 WebGIS 项目中，同一类点位图标（如监控摄像头、传感器、车辆、定位针）往往有多种状态色（正常绿、告警橙、故障红、离线灰）： * **传统笨办法**：让设计师切出 `camera-green.png`、`camera-red.png` 等十几种颜色的图片。不仅维护成本高，前端还需要发起多次 HTTP 请求。 * **OpenLayers 最佳实践**：只需准备 **1 张纯白色的母版图标（PNG 或 SVG）**，在前端通过 `new Icon({ src: '...', color: '#ff0000' })` 即可衍生出任意 RGB 颜色和透明度的图标，且多处复用同一张底层图片纹理缓存！ #### 2. 底层渲染原理：为什么母版图标必须是“白色填充”？ OpenLayers 对图标染色采用的是计算机图形学中的 **正片叠底（Color Multiply / 通道相乘）** 算法： ```text 最终颜色(R, G, B, A) = (原图像素(R, G, B, A) / 255) × (目标 Color(R, G, B, A) / 255) ``` * **纯白色区域 `(255, 255, 255)`**：归一化后为 `1.0`。`1.0 × 目标颜色 = 目标颜色本身`！因此白色部分会被 100% 精准染成你指定的 `color`。 * **黑色描边或阴影 `(0, 0, 0)`**：归一化后为 `0.0`。`0.0 × 目标颜色 = 0.0（依然是黑色）`！这意味着如果母版图标带有黑色轮廓线或灰度立体阴影，染色后**立体感与黑边依然能完美保留**！ * **⚠️ 常见踩坑**：如果母版图标本身是纯红色的 `(255, 0, 0)`，你设置 `color: 'blue'` `(0, 0, 255)`，两者通道相乘后结果为 `(0, 0, 0)` —— **图标会直接变成死黑色**！因此母版图标主体务必设计为纯白色。 #### 'anonymous'`？** * 普通不染色的图标直接绘制即可，但一旦配置了 `color` 属性，OpenLayers 内部需要在离屏 Canvas 上读取像素并执行颜色混合。 * 如果图片来自第三方 CDN 或独立的对象存储域名，且没有声明 `crossOrigin: 'anonymous'`，浏览器的安全机制会将画布锁死为 **Tainted Canvas（受污染画布）**，导致像素操作抛出安全异常或图标无法显示。 tags: "vector, style, icon, marker, 矢量, 样式, 图标, 染色, 颜色" ---
