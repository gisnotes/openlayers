Shaded Relief / 动态日照山体阴影（Hillshade）实时渲染

raster7 shadedrelief2

°
°

Calculate shaded relief from elevation data. / 演示如何使用 ol/source/Raster 在 Web Worker 中通过 3x3 邻域梯度计算坡度与坡向，结合太阳高度角与方位角实时解算朗伯日照山体阴影。

This example uses a ol/source/Raster to generate data based on another source. The raster source accepts any number of input sources (tile or image based) and runs a pipeline of operations on the input data. The return from the final operation is used as the data for the output source.

In this case, a single tiled source of elevation data is used as input. The shaded relief is calculated in a single "image" operation. By setting operationType: 'image' on the raster source, operations are called with an ImageData object for each of the input sources. Operations are also called with a general purpose data object. In this example, the sun elevation and azimuth data from the inputs above are assigned to this data object and accessed in the shading operation. The shading operation returns an array of ImageData objects. When the raster source is used by an image layer, the first ImageData object returned by the last operation in the pipeline is used for rendering.

本示例演示了如何利用 ol/source/Raster 的整图（operationType: 'image'）运算模式，根据数字高程切片（DEM）在后台 Web Worker 中实时计算并渲染出具有立体三维质感的日照山体阴影（Shaded Relief / Hillshade）。

算法采用 $3 \times 3$ 邻域有限差分算子解算每个像素点的坡度（Slope）与坡向（Aspect），并依据朗伯漫反射光学模型（Lambertian Reflectance），结合用户实时调节的垂直夸大系数（Vertical Exaggeration）、太阳高度角（Sun Elevation）与太阳方位角（Sun Azimuth）进行光照强度解算，生成半透明地形光影覆盖层叠于 OSM 底图之上。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计机制 (Core Architecture & Mechanics) - 朗伯漫反射日照阴影模型 (Lambertian Shaded Relief Model)： 山体阴影根据太阳入射角与地表微元法线向量的夹角计算光照照度。其核心物理公式为： $$\cos(\theta_{\text{incidence}}) = \sin(\text{SunEl}) \cdot \cos(\text{Slope}) + \cos(\text{SunEl}) \cdot \sin(\text{Slope}) \cdot \cos(\text{SunAz} - \text{Aspect})$$ - $\theta_{\text{incidence}}$：太阳光线与地表法线的入射角； - $\text{SunEl}$：太阳高度角（从地平线向上仰角，弧度制）； - $\text{SunAz}$：太阳方位角（自地理正北顺时针旋转，弧度制）； - $\text{Slope}$：当前地表的坡度斜角； - $\text{Aspect}$：当前地表下坡方向的坡向角。 - $3 \times 3$ 邻域有限差分梯度解算： 为了在离散光栅网格中计算地表法向量，算法在 $X$（东西）和 $Y$（南北）方向进行中心有限差分近似求偏导： $$\frac{\partial z}{\partial x} = \frac{z(x+1, y) - z(x-1, y)}{2 \times \text{Resolution}}$$ $$\frac{\partial z}{\partial y} = \frac{z(x, y+1) - z(x, y-1)}{2 \times \text{Resolution}}$$ 坡度为梯度幅值：$\text{Slope} = \arctan\left(\sqrt{(\frac{\partial z}{\partial x})^2 + (\frac{\partial z}{\partial y})^2}\right)$；坡向为方位角：$\text{Aspect} = \text{atan2}(\frac{\partial z}{\partial y}, -\frac{\partial z}{\partial x})$。

2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns) - 整图级切片参数传递与分辨率感知：

raster.on('beforeoperations', function (event) {
  const data = event.data;
  data.resolution = event.resolution; // 传入当前视口真实物理分辨率 (米/像素)
  data.vert = Number(controls.vert.value);   // 垂直夸大系数
  data.sunEl = Number(controls.sunEl.value); // 太阳高度角
  data.sunAz = Number(controls.sunAz.value); // 太阳方位角
});

导数计算必须依赖 event.resolution。若不考虑地图分辨率（例如固定按像素距离算导数），则地图在缩放层级变化时阴影对比度会失真崩溃；绑定 event.resolution 能保证山体阴影在任意缩放级别下均保持严格一致的物理光影对比度。

  • 象限规整与角度变换： 标准数学 atan2(y, x) 以正 X 轴为 0 度且逆时针旋转。算法中经过象限转换（halfPi - aspect），将坡向角校准为地理标准（正北为 0 度，顺时针旋转），以与标准的太阳方位角（sunAz）保持同构对齐。

3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices) - 视觉凹凸反转倒错错觉（Pseudoscopic Inversion Illusion）：

人类视觉大脑对光影的认知存在强烈的“顶光假定（Light from Above）”。在地图制图中，如果太阳方位角设为正南方（如 $180^\circ$），山脊在视觉上会被大脑误判为深陷的峡谷，而峡谷反被误看为山脊。因此，行业制图标准始终将太阳方位角设定在西北方向（$315^\circ$ 附近）或偏北方向，本示例默认提供的 $45^\circ$ 或 $315^\circ$ 均能有效防止视错觉。

  • 垂直夸大（Vertical Exaggeration）的平衡度： 在宏观平原或低矮丘陵地区，微弱的高程起伏无法形成明显阴影，需要通过 vert（如 $2 \times \sim 5 \times$）进行适度夸大；但在安第斯山脉或喜马拉雅等极端陡峭地区，过高的夸大会导致斜率溢出为全黑深影，此时应回退至 $1 \times$ 以保留山体背光面的纹理细节。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ImageLayer from 'ol/layer/Image.js';
import TileLayer from 'ol/layer/Tile.js';
import ImageTile from 'ol/source/ImageTile.js';
import OSM from 'ol/source/OSM.js';
import Raster from 'ol/source/Raster.js';

/**
 * Generates a shaded relief image given elevation data.
 * Uses a 3x3 neighborhood for determining slope and aspect.
 * 基于数字高程切片使用 3x3 邻域解算坡度与坡向，生成日照山体阴影图像
 * @param {Array<ImageData>} inputs Array of input images. / 输入图像数组
 * @param {Object} data Data added in the "beforeoperations" event. / 外部上下文参数
 * @return {ImageData|Object} Output image. / 计算生成的山体阴影图像
 */
function shade(inputs, data) {
  const elevationImage = inputs[0];
  const width = elevationImage.width;
  const height = elevationImage.height;
  const elevationData = elevationImage.data;
  const shadeData = new Uint8ClampedArray(elevationData.length);
  const dp = data.resolution * 2;
  const maxX = width - 1;
  const maxY = height - 1;
  const pixel = [0, 0, 0, 0];
  const twoPi = 2 * Math.PI;
  const halfPi = Math.PI / 2;
  const sunEl = (Math.PI * data.sunEl) / 180;
  const sunAz = (Math.PI * data.sunAz) / 180;
  const cosSunEl = Math.cos(sunEl);
  const sinSunEl = Math.sin(sunEl);
  let pixelX,
    pixelY,
    x0,
    x1,
    y0,
    y1,
    offset,
    z0,
    z1,
    dzdx,
    dzdy,
    slope,
    aspect,
    cosIncidence,
    scaled;

  /**
   * Extract elevation in meters from Terrarium DEM format.
   * 从 Terrarium 格式像素解码真实高程（米）
   * @param {Array<number>} pixel RGBA values / 像素数组
   * @return {number} Elevation in meters / 高程（米）
   */
  function calculateElevation(pixel) {
    // Terrarium encoding: red * 256 + green + blue / 256 - 32768
    // Mapbox format alternative: (red * 256 * 256 + green * 256 + blue) * 0.1 - 10000
    return pixel[0] * 256 + pixel[1] + pixel[2] / 256 - 32768;
  }

  // Iterate over all pixels calculating gradients in X and Y / 遍历视口像素计算 X 与 Y 方向有限差分梯度
  for (pixelY = 0; pixelY <= maxY; ++pixelY) {
    y0 = pixelY === 0 ? 0 : pixelY - 1;
    y1 = pixelY === maxY ? maxY : pixelY + 1;
    for (pixelX = 0; pixelX <= maxX; ++pixelX) {
      x0 = pixelX === 0 ? 0 : pixelX - 1;
      x1 = pixelX === maxX ? maxX : pixelX + 1;

      // Determine elevation for (x0, pixelY) / 计算西侧邻域高程
      offset = (pixelY * width + x0) * 4;
      pixel[0] = elevationData[offset];
      pixel[1] = elevationData[offset + 1];
      pixel[2] = elevationData[offset + 2];
      pixel[3] = elevationData[offset + 3];
      z0 = data.vert * calculateElevation(pixel);

      // Determine elevation for (x1, pixelY) / 计算东侧邻域高程
      offset = (pixelY * width + x1) * 4;
      pixel[0] = elevationData[offset];
      pixel[1] = elevationData[offset + 1];
      pixel[2] = elevationData[offset + 2];
      pixel[3] = elevationData[offset + 3];
      z1 = data.vert * calculateElevation(pixel);

      // Partial derivative dz/dx / X 方向偏导数
      dzdx = (z1 - z0) / dp;

      // Determine elevation for (pixelX, y0) / 计算北侧邻域高程
      offset = (y0 * width + pixelX) * 4;
      pixel[0] = elevationData[offset];
      pixel[1] = elevationData[offset + 1];
      pixel[2] = elevationData[offset + 2];
      pixel[3] = elevationData[offset + 3];
      z0 = data.vert * calculateElevation(pixel);

      // Determine elevation for (pixelX, y1) / 计算南侧邻域高程
      offset = (y1 * width + pixelX) * 4;
      pixel[0] = elevationData[offset];
      pixel[1] = elevationData[offset + 1];
      pixel[2] = elevationData[offset + 2];
      pixel[3] = elevationData[offset + 3];
      z1 = data.vert * calculateElevation(pixel);

      // Partial derivative dz/dy / Y 方向偏导数
      dzdy = (z1 - z0) / dp;

      // Slope calculation / 计算坡度角
      slope = Math.atan(Math.sqrt(dzdx * dzdx + dzdy * dzdy));

      // Aspect calculation aligned to compass azimuth / 计算坡向角并对齐罗盘方位角
      aspect = Math.atan2(dzdy, -dzdx);
      if (aspect < 0) {
        aspect = halfPi - aspect;
      } else if (aspect > halfPi) {
        aspect = twoPi - aspect + halfPi;
      } else {
        aspect = halfPi - aspect;
      }

      // Lambertian diffuse reflectance illumination / 朗伯漫反射光照余弦值解算
      cosIncidence =
        sinSunEl * Math.cos(slope) +
        cosSunEl * Math.sin(slope) * Math.cos(sunAz - aspect);

      offset = (pixelY * width + pixelX) * 4;
      scaled = 255 * cosIncidence;
      shadeData[offset] = scaled;
      shadeData[offset + 1] = scaled;
      shadeData[offset + 2] = scaled;
      shadeData[offset + 3] = elevationData[offset + 3];
    }
  }

  return {
    data: shadeData,
    width,
    height,
    colorSpace: 'srgb',
  };
}

// AWS Mapzen Terrarium DEM tile source / AWS 托管的 Mapzen Terrarium 高程数据源
const elevation = new ImageTile({
  url: 'https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png',
  maxZoom: 15,
  attributions:
    '<a href="https://github.com/tilezen/joerd/blob/master/docs/attribution.md" target="_blank">Data sources and attribution</a>',
});

// Raster source with image operation running in worker / 在 Worker 中执行光照运算的光栅数据源
const raster = new Raster({
  sources: [elevation],
  operationType: 'image',
  operation: shade,
});

// Map instance with OSM basemap and shaded relief overlay / 初始化地图与半透明山体阴影层
const map = new Map({
  target: 'map',
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
    new ImageLayer({
      opacity: 0.3,
      source: raster,
    }),
  ],
  view: new View({
    center: [-13615645, 4497969],
    zoom: 13,
  }),
});

// Interactive controls for vertical exaggeration and sun angles / 垂直夸大与太阳入射角交互控件
const controlIds = ['vert', 'sunEl', 'sunAz'];
const controls = {};
controlIds.forEach(function (id) {
  const control = document.getElementById(id);
  const output = document.getElementById(id + 'Out');
  control.addEventListener('input', function () {
    output.innerText = control.value;
    raster.changed();
  });
  output.innerText = control.value;
  controls[id] = control;
});

// Pass parameters and resolution before operations start / 运算前注入真实分辨率与光照参数
raster.on('beforeoperations', function (event) {
  const data = event.data;
  data.resolution = event.resolution;
  for (const id in controls) {
    data[id] = Number(controls[id].value);
  }
});
