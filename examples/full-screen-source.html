Click the control in the top right corner to go full screen. Click it again to exit full screen.

If there is no button on the map, your browser does not support the Full Screen API.

点击地图右上角的全屏控件可进入全屏模式。再次点击可退出全屏。

本示例通过为全屏控件配置 source: 'fullscreen'，使得点击全屏时，不仅是将地图自身放大，而是将包含**侧边面板（Side Panel）**在内的整个外层父级容器一同带入全屏，非常适合包含控制仪表盘的综合监控大屏场景。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 父级容器委托全屏（Fullscreen Container Delegation）： 若直接使用默认的 new FullScreen()，浏览器仅将 #map 元素提升到屏幕顶层，原本位于地图旁边的侧边栏、工具栏和数据表格会被浏览器自动剥离并遮挡在视口之外。通过指定 source: 'fullscreen'（或传入 DOM 元素节点），OpenLayers 能够把指定的父容器整体提升为全屏渲染上下文，实现了地图与业务看板的整体全屏。
  • CSS 弹性布局协同（Flex Layout）： 外层容器采用 display: flex，地图占据弹性扩展区（flex: 1），侧边栏采用固定宽度。在进入全屏模式后，地图自动撑满剩余全屏宽度，侧边栏保持优雅停靠，UI 布局极度稳固。

2. 源码与关键 API 剖析

  • new FullScreen({ source: 'fullscreen' })：source 参数可传入元素 ID 字符串或 HTML 节点引用，指示具体哪个 DOM 节点应接收 requestFullscreen() 指令。
  • :-webkit-full-screen / :fullscreen 伪类适配：为外层容器注入全屏伪类样式，确保全屏下具备背景色与高度撑满。

3. 生产实践踩坑与性能调优

  • 弹窗（Modal / Popup）全屏可见性问题： 进入全屏后，如果业务弹窗挂载在 document.body 下而非 #fullscreen 内部，弹窗会被浏览器顶层全屏元素彻底盖住不可见。生产环境必须将所有动态弹窗与提示浮层的宿主容器放置在 source 元素内部。
