Layer Z-Index / 图层层级顺序与托管/非托管图层 (Layer Z-Index & Stacking Context)

layer4 ordering1 z-index1


Example of ordering layers using Z-index. / 演示如何使用 Z-index 动态控制图层渲染堆叠顺序，以及受控托管图层（Managed）与独立非托管图层（Unmanaged）的渲染机制差异。

There are are two managed layers (square and triangle) and one unmanaged layer (star).
The Z-index determines the rendering order; with {square: 1, triangle: 0, star: unmanaged} indices, the rendering order is triangle, square and star on top.

在此示例中，包含两个受控托管图层（蓝色正方形与红色三角形）和一个独立非托管图层（绿色五角星）。
Z-index（层级索引）决定了图层的渲染先后顺序：当初始设置为 {square: 1, triangle: 0, star: unmanaged} 时，渲染管线将先绘制红色三角形、再覆盖蓝色正方形，而非托管的绿色五角星由于直接通过 setMap() 绑定，将始终常驻在所有托管图层的最顶层。 在下方数字输入框中修改 Z-index，可实时观察图形的遮挡覆盖层次变动。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 受控托管图层（Managed Layers）的层级排序管线： 传入 new Map({ layers: [...] }) 或通过 map.addLayer() 添加的图层均由 OpenLayers 内置的 ol/layer/Group 容器统一管理。 渲染引擎在每一帧按以下规则对托管图层排序： 1. 优先按 layer.getZIndex() 升序排列（数值越小越先绘制，位于底层；数值越大越后绘制，覆盖在上方）； 2. 当两个图层的 Z-index 相同时（默认均为 0 或未指定），严格按照其在图层数组中的下标先后顺序绘制（后加入者在上）。
  • 独立非托管图层（Unmanaged Layers）的特殊顶层特权： 通过直接调用 layer.setMap(map) 而未将其放入 map.getLayers() 集合的图层被称为“非托管图层”。 非托管图层绕过了 LayerGroup 的排序与生命周期管理，其 Canvas / DOM 容器会被渲染管线强制放置在所有普通托管图层之上。 这种模式非常适合作为高频擦除重绘的临时标绘层、测距/测面测量橡皮筋图层，避免污染业务图层树。

2. 源码与关键 API 剖析

  • vectorLayer.setZIndex(number)：动态设置图层的 Z 轴渲染优先级，触发地图微任务队列重新排序并重绘。
  • layer0.setMap(map)：将图层声明为非托管层绑定至目标地图。

3. 生产实践踩坑与性能调优

  • 负数 Z-index 导致图层被底图湮没： 底图通常位于索引 0。若为业务矢量层赋予了负数（如 zIndex: -1），该图层将被底图切片彻底遮挡，在控制台无报错但屏幕完全不可见。
  • 动态图层树层级跨度规范： 在复杂业务系统（如融合底图、热力图、网格面、轨迹线、POI 标记的多源一张图）中，建议采用步长为 10 或 100 的层级区间规划（如底图 0~9、面图层 10~19、线图层 20~29、点图标 30~39），预留足够的插槽，避免频繁动态计算排序。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Point from 'ol/geom/Point.js';
import VectorLayer from 'ol/layer/Vector.js';
import VectorSource from 'ol/source/Vector.js';

// Declarative webgl/canvas vector styles for shapes (square, triangle, star)
// 几何图形矢量样式定义（蓝色正方形、红色三角形、绿色五角星）
const styles = {
  square: {
    'shape-points': 4,
    'shape-radius': 80,
    'shape-angle': Math.PI / 4,
    'shape-stroke-color': 'black',
    'shape-stroke-width': 1,
    'shape-fill-color': 'blue',
  },
  triangle: {
    'shape-points': 3,
    'shape-radius': 80,
    'shape-rotation': Math.PI / 4,
    'shape-stroke-color': 'black',
    'shape-stroke-width': 1,
    'shape-fill-color': 'red',
  },
  star: {
    'shape-points': 5,
    'shape-radius': 80,
    'shape-radius2': 40,
    'shape-rotation': Math.PI / 4,
    'shape-stroke-color': 'black',
    'shape-stroke-width': 1,
    'shape-fill-color': 'green',
  },
};

// Factory function to create a vector layer with a single point feature and initial zIndex
// 工厂函数：创建包含单点要素与初始 Z-index 优先级的矢量图层
function createLayer(coordinates, style, zIndex) {
  const feature = new Feature(new Point(coordinates));

  const source = new VectorSource({
    features: [feature],
  });

  const vectorLayer = new VectorLayer({
    source: source,
    style,
  });
  vectorLayer.setZIndex(zIndex);

  return vectorLayer;
}

// Create layers: star (unmanaged), square (managed, zIndex: 1), triangle (managed, zIndex: 0)
// 创建图层：五角星（非托管层）、方形（托管层，初始 Z-index=1）、三角形（托管层，初始 Z-index=0）
const layer0 = createLayer([40, 40], styles.star);
const layer1 = createLayer([0, 0], styles.square, 1);
const layer2 = createLayer([0, 40], styles.triangle, 0);

// Managed layers collection passed into the map constructor
// 传入地图构造函数的托管图层集合
const layers = [];
layers.push(layer1);
layers.push(layer2);

// Initialize map with managed layers
// 初始化地图并挂载托管图层
const map = new Map({
  layers: layers,
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 18,
  }),
});

// Set unmanaged layer directly on map: renders on top of all managed layers
// 直接通过 setMap 挂载非托管图层：脱离普通排序管线，始终置于托管图层之上
layer0.setMap(map);

// Bind input number controls to dynamically change layer Z-index
// 将输入框控件与对应图层的 Z-index 属性双向绑定
function bindInputs(id, layer) {
  const idxInput = document.getElementById('idx' + id);
  idxInput.onchange = function () {
    layer.setZIndex(parseInt(this.value, 10) || 0);
  };
  idxInput.value = String(layer.getZIndex());
}
bindInputs(1, layer1);
bindInputs(2, layer2);
