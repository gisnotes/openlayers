XYZ Retina Tiles / XYZ 视网膜高清切片 (@2x)

retina3 hidpi4 xyz6 maptiler26 @2x1 devicePixelRatio1

Example of Retina / HiDPI mercator tiles (512x512px) available as XYZ. / 基于 XYZ 协议的 512×512 像素 Retina / HiDPI 墨卡托高清瓦片加载示例。

The ImageTile generates 256x256 pixel tiles by default. If the requested images are larger than that, they will be scaled to fit. This example uses 512x512 tiles, which are scaled to 256x256 for display.

ImageTile 默认生成 256×256 像素尺寸的瓦片。如果服务端返回的图像尺寸大于该值，OpenLayers 将自动进行等比缩放以适配瓦片网格。本示例请求了 512×512 像素的高清瓦片，并在地图中以 256×256 逻辑像素视口进行超采样高清显示。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • CSS 逻辑像素 vs 设备物理像素： 现代移动端屏幕、4K 监视器以及苹果 Retina 显示屏的设备像素比（window.devicePixelRatio）普遍为 2 或 3。若直接在 2× 屏幕上渲染 256×256 像素的普通地图瓦片，浏览器会进行双线性放大插值，导致地图文字注记、细线道路呈现明显的模糊与毛刺。
  • 超采样高清渲染（Retina Oversampling）： 本示例采用 @2x 高清瓦片，服务端按 512×512 像素烘焙制图，而在客户端渲染管线中，将其精确投射到 256×256 逻辑像素的空间网格内。单位逻辑像素容纳了 4 倍的物理像素采样信息，使得地图文字极其锐利、道路边缘极度平滑。
  • WebGL 硬件加速管线（WebGLTile）： 示例选用 ol/layer/WebGLTile，将 512×512 瓦片直接作为 GPU 纹理显存上传，依托 WebGL 硬件级别的多级渐远纹理（Mipmap）与双线性过滤，极大降低了 CPU 绘图负荷，缩放旋转过程保持 60FPS。

2. 源码与关键 API 剖析

  • useGeographic()：开启全局地理坐标模式，允许直接在 View 的 center 中传入 WGS84 [经度, 纬度]（如示例中的 [-112.21, 36.10]），无需手动调用 fromLonLat() 进行投影转换。
  • url: '.../outdoor-v2/256/{z}/{x}/{y}@2x.png?key=...'：在 MapTiler 矢量切片转栅格接口中，路径中的 /256/ 声明了逻辑切片网格标准，而后缀 @2x.png 则指示服务端输出 512×512 物理像素的高清图片。
  • ImageTile 自动缩放自适应：当瓦片源未显式声明 tileSize: 512 时，OpenLayers 检测到实际图片宽度为 512px，会自动依据默认的 256px 网格将图像以 0.5 倍物理比例压缩绘制，达到完美的 Retina 效果。

3. 生产实践踩坑与性能调优

  • 带宽与流量权衡： 512×512 高清切片的单张文件体积通常是 256×256 普通切片的 2.5 至 4 倍。在移动端低速蜂窝网络下，全量强制请求 @2x 会显著拉长首屏白屏时间。生产环境建议通过 window.devicePixelRatio > 1 动态按需决定是否请求 @2x 资源。
  • 缩放级别偏差陷阱： 部分开发者在自定义切片服务器时，误将 512px 瓦片当成普通 256px 瓦片提供，若未同步设置切片网格的 resolutions 或 tilePixelRatio: 2，会导致地图注记文字过小或层级比例尺错位。
  • 跨域与缓存配置（CORS）： 在 WebGLTile 模式下，所有瓦片纹理必须支持 CORS 跨域（Access-Control-Allow-Origin: *），否则浏览器 WebGL 安全上下文将拒绝加载跨域图像纹理。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Layer from 'ol/layer/WebGLTile.js';
import {useGeographic} from 'ol/proj.js';
import Source from 'ol/source/ImageTile.js';

// Enable geographic coordinates (longitude, latitude)
// 启用地理坐标系（经度，纬度）
useGeographic();

const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Initialize map with WebGL tile layer and Retina @2x source
// 使用 WebGLTile 图层和 Retina @2x 高清源初始化地图
const map = new Map({
  target: 'map',
  layers: [
    new Layer({
      source: new Source({
        attributions: attributions,
        url:
          'https://api.maptiler.com/maps/outdoor-v2/256/{z}/{x}/{y}@2x.png?key=' +
          key,
      }),
    }),
  ],
  view: new View({
    center: [-112.21324137318899, 36.105337765976756],
    zoom: 13,
  }),
});
