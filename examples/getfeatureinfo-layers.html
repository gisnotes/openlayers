WMS GetFeatureInfo (Layers) / WMS 多图层穿透属性查询与按层解析

Shows how to fetch features per layer name in a single WMS GetFeatureInfo request / 演示如何使用 WMSGetFeatureInfo 格式解析器的 layers 选项在单次多图层查询响应中按图层名字隔离提取要素。

Demonstrates the use of the layers option in the ol/format/WMSGetFeatureInfo format object, which allows features returned by a single WMS GetFeatureInfo request that asks for more than one layer to be read by layer name.

本示例演示了如何在 ol/format/WMSGetFeatureInfo 格式解析器中使用 layers 选项。当客户端通过单次 WMS GetFeatureInfo 请求同时查询多个图层（例如宾馆 hotel 与餐馆 restaurant 两个业务图层）时，该选项允许按照指定的图层名称分别对返回的 XML/GML 数据进行隔离过滤与定向反序列化，极大简化了多专题数据穿透查询的业务代码。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计思想 (Core Architecture & Design)

  • 一次网络 I/O 穿透多层： 在 WMS 规范中，GetFeatureInfo 允许在 QUERY_LAYERS 参数中传入以逗号分隔的多个图层名称（如 QUERY_LAYERS=hotel,restaurant）。服务端会在点选位置垂直向下穿透，一次性返回所有命中图层的空间要素，显著减少网络往返耗时（RTT）。
  • 客户端多层级语义过滤解析： 早期解析方式通常一次性读取全局所有要素，开发者需手写二次循环遍历属性来区分所属图层。WMSGetFeatureInfo 内置的 layers: ['hotel'] 参数在 XML 流式解析阶段即可完成节点路由与筛选，性能更优。

2. 源码与关键 API 剖析 (Source Code & API Analysis)

  • new WMSGetFeatureInfo().readFeatures(response)： 默认模式，读取响应文档中出现的所有图层的所有要素。
  • new WMSGetFeatureInfo({ layers: ['hotel'] }).readFeatures(response)： 过滤模式，仅提取图层名称匹配 hotel 的要素数组，自动排除其他图层的干扰要素。

3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization)

  • INFO_FORMAT 格式与兼容性： WMSGetFeatureInfo 格式解析器专为解析 GML2 / GML3 格式设计（如请求参数 INFO_FORMAT=application/vnd.ogc.gml）。若服务端返回的是 text/html 或 application/json（GeoServer 扩展），则需使用对应的 HTML 容器或直接用 ol/format/GeoJSON 解析。
main.js 
import WMSGetFeatureInfo from 'ol/format/WMSGetFeatureInfo.js';

fetch('data/wmsgetfeatureinfo/osm-restaurant-hotel.xml')
  .then(function (response) {
    return response.text();
  })
  .then(function (response) {
    // this is the standard way to read the features
    const allFeatures = new WMSGetFeatureInfo().readFeatures(response);
    document.getElementById('all').innerText = allFeatures.length.toString();

    // when specifying the 'layers' options, only the features of those
    // layers are returned by the format
    const hotelFeatures = new WMSGetFeatureInfo({
      layers: ['hotel'],
    }).readFeatures(response);
    document.getElementById('hotel').innerText =
      hotelFeatures.length.toString();

    const restaurantFeatures = new WMSGetFeatureInfo({
      layers: ['restaurant'],
    }).readFeatures(response);
    document.getElementById('restaurant').innerText =
      restaurantFeatures.length.toString();
  });
