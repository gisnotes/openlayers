Street Labels / 沿线道路注记（线型文本跟随）

vector87 label4 streets1 maptiler26

Render street names. / 使用 placement: 'line' 沿道路线状几何体弯曲渲染街道名称。

Example showing the use of a text style with placement: 'line' to render text along a path. 本示例展示了如何使用 placement: 'line' 文本样式沿道路线状几何路径弯曲渲染街道名称。通过启用智能避让（declutter: true），沿线注记会自动根据道路曲率与视口空间进行动态排版与防冲突抽稀，实现清晰自然的城市路网制图注记效果。

📚 学习记录与技术深度解读 (Learning Notes)

1. 沿线切线排版与弯曲文字渲染 (placement: 'line') - 切线分段与逐字旋转: 当配置 placement: 'line' 时，OpenLayers 放弃传统的水平轴对齐光栅化策略，转为对道路线段进行长度参数化采样。引擎计算每个字符在折线骨架上的瞬时切线斜率与法向量，并对每个字形执行仿射旋转变换，实现文字如水流般顺滑贴合道路曲率。 - 正向阅读角度保障 (Keep Upright): 现实路网走向复杂多样（自东向西、自北向南等）。引擎内部内置了防颠倒算法，当线段方向可能导致文字出现倒挂翻转时，算法会自动反转排版采样矢量，确保始终符合从左至右或人眼正常自上而下的阅读习惯。

2. 曲率约束与沿线避让控制 - 最大曲率折角保护 (maxAngle): 当道路出现接近直角或发卡弯等剧烈折角时，过大角度的字符旋转会导致字体挤压撕裂。Text 样式的 maxAngle 属性默认过滤超标锐角，自动选择在较为平直的线段区间排布注记。 - 定向碰撞包围盒 (Oriented Bounding Box): 结合矢量图层的 declutter: true，沿线文字生成沿切线方向的倾斜碰撞多边形，在复杂交叉立交桥与十字路口自动仲裁优先级，杜绝路名穿插打架。

3. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices) - 短线段自动静默剔除: 若整条道路在当前视口缩放分辨率下的总像素长度小于文字排版所需的总长度，引擎会自动隐藏该注记。在瓦片矢量切片制作中，应在数据源层面尽量执行同名道路要素拓扑合并（Line Dissolve/Merge），将碎片小线段聚合成贯通主干道，以获得更高的线型注记展现率。 - 长干道周期性重复注记 (repeat): 针对跨越数千像素的高速公路或跨市干道，推荐配置 repeat: 500（每隔 500 像素重复渲染一次路名），防止用户在大屏幕中拖拽几屏都无法获知当前行驶道路名称。

main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {getCenter} from 'ol/extent.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import ImageTile from 'ol/source/ImageTile.js';
import VectorSource from 'ol/source/Vector.js';
import Fill from 'ol/style/Fill.js';
import Style from 'ol/style/Style.js';
import Text from 'ol/style/Text.js';

// Reusable text style configured for line-following rendering
// 可复用的沿线文本注记样式：启用 placement: 'line' 沿道路线段弯曲排布
const style = new Style({
  text: new Text({
    font: 'bold 11px "Open Sans", "Arial Unicode MS", "sans-serif"',
    placement: 'line',
    fill: new Fill({
      color: 'white',
    }),
  }),
});

// MapTiler API Key for satellite basemap tiles
// MapTiler API 密钥：用于加载高分辨率卫星影像底图
const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Spatial extent constraining the view over Vienna city center
// 限制在奥地利维也纳市中心的特定空间坐标范围
const viewExtent = [1817379, 6139595, 1827851, 6143616];

// Initialize map containing satellite imagery basemap and street labels vector layer
// 初始化地图实例：包含卫星遥感底图与开启智能避让的维也纳街道名称矢量图层
const map = new Map({
  layers: [
    new TileLayer({
      source: new ImageTile({
        attributions: attributions,
        url:
          'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
        tileSize: 512,
        maxZoom: 20,
      }),
    }),
    new VectorLayer({
      declutter: true,
      source: new VectorSource({
        format: new GeoJSON(),
        url: 'data/geojson/vienna-streets.geojson',
      }),
      style: function (feature) {
        // Dynamically assign street name from GeoJSON attributes
        // 动态读取 GeoJSON 要素中的 name 字段并赋给沿线样式
        style.getText().setText(feature.get('name'));
        return style;
      },
    }),
  ],
  target: 'map',
  view: new View({
    extent: viewExtent,
    center: getCenter(viewExtent),
    zoom: 17,
    minZoom: 14,
  }),
});
