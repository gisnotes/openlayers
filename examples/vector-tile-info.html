Move your pointer over rendered features to display feature properties.

移动鼠标指针悬停在已渲染的地图矢量要素上方，可在悬浮面板中实时探测并展示该要素的完整 JSON 属性字典。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - **MVT（Mapbox Vector Tiles）二进制协议与属性载荷**： 矢量切片与传统栅格切片（PNG/JPEG）的根本区别在于，它在网络传输的是 Protocol Buffers（PBF/MVT）二进制几何编码与键值对属性字典，而非静态像元。OpenLayers 通过 `ol/format/MVT` 解码器在客户端实时将二进制流逆向还原为轻量级 `ol/Feature`（或 `ol/render/Feature`）。这使得客户端天然具备空间要素的**完全属性访问能力**，无需向服务器发起次级 `GetFeatureInfo` 或 WFS 请求。 - **像素级要素拾取管线 (`getFeaturesAtPixel`)**： OpenLayers 针对矢量切片提供高效的几何碰撞检测。当触发 `pointermove` 时，引擎根据视口像素坐标转换到各切片本地图元空间，遍历命中当前像素顶层的矢量图元集合，并在极短时间内返回 `FeatureLike[]`。 #### 2. 源码与关键 API 剖析 (Source Code & API Analysis) - `map.getFeaturesAtPixel(pixel, [options])`： 基于硬件/Canvas 渲染上下文拾取视口指定像素下的要素。与 `ol/source/Vector` 不同，矢量切片在默认 `renderMode: 'hybrid'` 下切片会被光栅化到离屏 Canvas，但 OpenLayers 依然在内部保留切片图元索引树，可精确提取几何与 properties。 - `pointerleave` 视口越界生命周期兜底： 监听地图容器外层的原生 `pointerleave` 事件，确保当光标离开地图窗口时主动隐藏信息面板（`opacity: 0`），避免视口边缘残留幽灵悬浮窗。 - 防抖与拖拽节流守卫： 在 `pointermove` 回调中前置校验 `if (evt.dragging) return;`。当用户按住鼠标平移地图视口时，直接打断要素拾取计算，杜绝拖拽过程中的无效高频 DOM 刷新与 CPU 浪费。 #### 3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - **切片裁切边界属性丢失问题**： 由于切片瓦片化时，跨越瓦片边缘的多边形（如大型行政区划、湖泊）会被打散分割到多个切片中。`getFeaturesAtPixel` 返回的只是命中瓦片内的局部图元，其几何对象通常被裁剪并带有瓦片缓冲（buffer），且各瓦片中可能多次返回该要素；若业务需要获取完整未裁剪几何，需结合跨瓦片 ID 索引或空间聚合服务。 - **高频 Move 事件的 DOM 渲染瓶颈**： 在复杂底图（如密集道路网、建筑物面）上移动光标，若频繁调用 `JSON.stringify` 并更新 innerText，会导致主线程布局重排（Reflow/Repaint）卡顿。生产环境推荐使用 `requestAnimationFrame` 或 30~50ms 的防抖函数，或仅显示关键字段。 tags: "vector tiles" ---
