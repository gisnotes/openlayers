In this example, a listener is registered on the map's pointermove to display the feature information in a tooltip when the pointer hovers over a feature.

在此示例中，为地图注册了 pointermove 指针移动事件监听器，当鼠标指针悬停在矢量要素上方时，通过 Tooltip 浮层实时展示该要素的生态区属性信息。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 地理覆盖物（Overlay）vs 像素级悬浮框（Pixel Tooltip）： ol/Overlay 适用于锚定在地理投影坐标（Coordinate）上的标注、气泡框或标记点，随地图缩放与平移同步运动；而 Tooltip 则是纯粹跟随屏幕光标像素坐标（Pixel）的 UI 交互组件。直接利用绝对定位 DOM 元素结合 pixel[0] / pixel[1] 驱动，免去了地理坐标与屏幕坐标的高频相互转换，交互响应极度平滑。
  • 高效的命中检测（Hit Detection）： map.forEachFeatureAtPixel(pixel, callback) 利用 OpenLayers 内部维护的离屏 Hit-Detect Canvas 与空间索引（RBush R-Tree），在用户光标滑动到要素上方时毫秒级命中拾取对应的 Feature 实例。
  • 事件边界控制（Event Boundary Guard）： 通过 target.closest('.ol-control') 判断光标是否落在地图内置控件（如 ol-zoom 放大缩小按钮、全屏控件等）上。若是控件区域则主动跳过要素拾取，彻底杜绝了鼠标点击地图缩放按钮时下方要素被意外激活的穿透问题。

2. 源码与关键 API 剖析

  • evt.dragging 检测：当用户正按住鼠标左键拖拽平移地图时，立即隐藏 Tooltip 并将 currentFeature 置为 undefined，避免地图平移过程中出现浮层残影和无谓的命中计算。
  • currentFeature !== feature 差异化更新：仅在鼠标从要素 A 移动到要素 B（或从空白移入要素）时才更新 innerText 与可见性，避免光标在同一要素内部微动时反复触发 DOM 布局重排（Reflow）。
  • map.getTargetElement().addEventListener('pointerleave', ...)：为地图宿主外层元素绑定 pointerleave 原生监听，一旦光标划出地图可视区即刻销毁浮窗状态，保证 UI 干净利落。
  • 声明式矢量样式表达式：['string', ['get', 'COLOR'], '#eeeeee'] 使用 OpenLayers WebGL/Canvas 通用样式表达式，直接从 GeoJSON 属性中动态获取颜色字符串，无需编写动态 Style Function。

3. 生产实践踩坑与性能调优

  • 高频事件节流（Throttle）： 浏览器 pointermove 在高刷新率屏幕（120Hz/144Hz）上会以极高频率触发。对于包含数万个复杂多边形的矢量图层，建议结合 requestAnimationFrame 对 displayFeatureInfo 进行节流调度，确保帧率稳定在 60FPS。
  • 视口边缘防溢出处理（Boundary Collision）： 直接设置 info.style.left = pixel[0] + 'px' 在光标滑到地图右下角时会导致 Tooltip 超出地图边界甚至触发外层页面滚动条。生产环境应计算：若 pixel[0] + tooltipWidth > mapWidth，则改用 info.style.left = (pixel[0] - tooltipWidth) + 'px' 动态翻转方向。
  • CSS 穿透与交互阻断： 由于 Tooltip 紧贴光标，如果不设置 CSS pointer-events: none;，光标再次微移时可能会命中 Tooltip 自身的 DOM 节点而非底层 Canvas，导致要素拾取丢失并产生严重闪烁。
