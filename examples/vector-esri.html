--- layout: example.html title: ArcGIS REST Feature Service / ArcGIS REST 矢量要素服务瓦片化动态加载 shortdesc: Example of using an ArcGIS REST Feature Service with a Tile strategy. / 演示如何结合 Tile 空间切片策略与 EsriJSON 格式流式加载 ArcGIS REST FeatureServer 矢量图斑并进行交互属性拾取。 docs: | This example loads new features from ArcGIS REST Feature Service when the view extent changes. 本示例演示了如何在视图范围变化时，从 ArcGIS REST FeatureServer（要素服务）按需动态拉取新的矢量要素。 通过将 VectorSource 的数据加载策略配置为基于空间瓦片切片的 tileStrategy，数据源会根据屏幕当前分辨率将视口切分为 512 像素网格。仅当视口漫游至未被加载覆盖的切片网格时，才向服务端发起 query 空间范围过滤请求，配合 EsriJSON 格式解析实现海量土地利用多边形的高效流式呈现与鼠标悬停属性探测。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计机制 (Core Architecture & Mechanics) - **Tile 瓦片化空间分块策略（Tile Loading Strategy）**： 与整屏一次性拉取整个视口 BBOX 的 bboxStrategy 相比，tileStrategy(createXYZ({tileSize: 512})) 引入了标准金字塔网格： - 地图视口平移数个像素时，由于大部分切片已存在于已加载索引中，完全不会触发网络请求； - 仅在视口边缘滑入新的 512px 网格单元时，才发起针对该网格 BBOX 的轻量级查询； - 结合浏览器的 HTTP 缓存与 OpenLayers 内部的 loadedExtentsRtree_ 空间缓存，大幅节省服务器算力与网络带宽。 - **动态 URL 函数与空间求交契约**： VectorSource 的 url 属性被配置为一个动态函数： url: function (extent, resolution, projection) { ... } 函数内部负责拼接 ArcGIS REST API 规范所要求的 geometry（JSON 格式包络线矩形）、spatialRel=esriSpatialRelIntersects 以及 geometryType=esriGeometryEnvelope。 #### 2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns) - **投影代码 SRID 动态清洗**： ```javascript // ArcGIS Server 仅接收纯数字的投影 ID（例如 3857 或 102100），需剥离 'EPSG:' 前缀 const srid = projection.getCode().split(/:(?=\d+$)/).pop(); ``` 通过正则匹配最后一个冒号后的数字部分，兼容 EPSG:3857、urn:ogc:def:crs:EPSG::3857 等多种不同标准的投影标识符。 - **EsriJSON 数据解析与样式工厂**： ```javascript const vectorSource = new VectorSource({ format: new EsriJSON(), url: function (extent, resolution, projection) { ... }, strategy: tileStrategy(createXYZ({tileSize: 512})), }); ``` format: new EsriJSON() 使得 OpenLayers 能够自动反序列化 ArcGIS 服务返回的特有 JSON 几何结构（如 rings 多边形、paths 多线），无缝转换为内置的 ol/Feature 对象。 #### 3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices) - **跨切片要素去重（Feature Deduplication）**： 由于多边形图斑可能跨越多个 512px 瓦片网格，服务端在响应不同瓦片请求时可能返回同一个图斑要素。OpenLayers 的 VectorSource 内部通过要素的唯一 id 进行去重管理。因此在配置 ArcGIS 图层时，必须确保 outFields 包含 OBJECTID 或主键字段，使 readFeatures 能正确设置 feature.setId()。 - **高并发请求风暴防护**： 当用户极速连续滚动缩放时，可能会瞬间激发出几十个切片请求。在生产环境中，ArcGIS Server 通常具有最大并发连接限制。建议在数据源层面或网关层配合并发节流，或根据视口分辨率设置最小可见层级（minZoom），防止在超宏观缩放时因请求全图海量要素导致服务崩溃。 tags: "vector, esri, ArcGIS, REST, Feature, Service, loading, server" ---
