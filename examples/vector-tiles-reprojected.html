Vector tile layers support reprojection to other projections. This example shows EPSG:4326 vector tiles reprojected to North Pole Lambert Azimuthal Equal Area (ESRI:102017). For polar regions, vector tiles in a geographic projection are preferred, because web mercator tiles are severely distorted or truncated past 85 degrees latitude.

矢量切片图层（VectorTileLayer）原生支持动态重投影到任意目标坐标系。本示例演示如何将地理坐标系（EPSG:4326）下的矢量切片动态重投影为北极朗伯等面积方位投影（ESRI:102017，North Pole Lambert Azimuthal Equal Area）。

对于极地高纬度区域，强烈推荐使用基于地理坐标系的矢量切片作为数据源，因为常规 Web 墨卡托切片（EPSG:3857）在纬度超过南北纬 85.05° 后会发生极端形变乃至直接截断。

**提示**：在实际项目中使用本示例时，请务必前往 https://www.maptiler.com/cloud/ 申请并配置专属 API Key。若 API Key 过期或无效，底图将无法加载显示。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - **矢量切片重投影与栅格重投影的架构差异**： - **栅格切片重投影**：基于三角形网格变形与像素重采样（Nearest / Bilinear），虽然速度快但可能引起文字与边缘模糊，且切片接缝处可能产生走样。 - **矢量切片重投影**：OpenLayers 在图元级别对切片内的几何顶点执行 Proj4 坐标数学转换，随后在目标投影坐标系下直接执行矢量渲染（线型、填充、注记）。这意味着重投影后的线条依然保持原生物理分辨率，边缘极其锐利，文本沿正确角度排列，不存在栅格模糊失真。 - **极地投影（Polar Projections）的战略优势**： 传统 EPSG:3857 在极地数学趋于无穷大，故直接将北冰洋和南极洲截断。而 ESRI:102017（North Pole Lambert Azimuthal Equal Area）以北极点（90°N）为切平面中心，真实保面积地展现整个北极圈及周边大陆，是极地科考、北极航道和高纬度气候仿真的标准底图。 #### 2. 源码与关键 API 剖析 (Source Code & API Analysis) - `proj4.defs('ESRI:102017', '+proj=laea +lat_0=90 ...')` 与 `register(proj4)`： 通过 Proj4 字符串定义北极等面积方位投影参数，并将其注册到 OpenLayers 全局投影字典中。 - `VectorTileSource({ projection: 'EPSG:4326', tileGrid })`： 数据源声明自己的原始坐标系是经纬度（EPSG:4326），并以对应的 TileGrid 向服务器拉取瓦片。 - `View({ projection: 'ESRI:102017', center: fromLonLat([0, 90], 'ESRI:102017') })`： 地图视图声明自身采用目标极地投影。OpenLayers 的渲染渲染管线在获取到切片几何后，检测到 `source.getProjection() !== view.getProjection()`，自动在客户端主线程或工人线程中调用重投影数学函数，将图元顶点转换到 ESRI:102017 像素空间后渲染。 #### 3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - **重投影下文本注记（Declutter & Rotation）的计算负担**： 矢量重投影会对几何顶点进行密集的非线性三角变换。在含有数万条路网或注记的大型切片中，建议启用 `declutter: true` 并合理配置 `maxZoom/minZoom`，避免在全景尺度下因巨量几何重投影导致帧率降低。 - **极点闭合与跨经线剪裁**： 等面积方位投影在远离极点的边缘可能出现几何奇点。在生成切片时应确保切片瓦片含有适当的缓冲（Buffer = 64~128 像素），防止重投影后多边形在瓦片缝隙处产生裂纹。 tags: "vector tiles, tile, mapbox, maplibre, ol-mapbox-style, reprojection" ---
