Wind Arrows / 气象风向标箭头（RegularShape 组合与动态缩放位移）

vector87 symbol3 regularshape2 style27 arrow2

Example of Wind Arrows styled using Regular Shapes / 演示如何使用两个 RegularShape（箭杆与箭头）组合绘制气象站点风向标，并根据实时风速与风向动态缩放箭杆长度、计算箭头位移与旋转角。

This example shows wind arrows styled using regular shapes for the arrow shaft and head. The shaft is scaled based on the wind speed and a corresponding displacement is used to position the unscaled arrow head at the end of the scaled shaft. The weather data is provided by OpenWeather.

本示例展示了如何仅使用两个 ol/style/RegularShape 几何符号（分别代表箭杆 shaft 和箭头 head）组合绘制离散气象站点的风向标箭头。其中，箭杆会根据实时风速（wind.speed）沿纵向动态拉伸，而箭头则保持固定大小不变，并通过精确的像素位移（displacement）严丝合缝地拼接到拉伸后的箭杆末端。 示例中的全球实况气象站点数据由 OpenWeather 提供。

📚 学习记录与技术深度解读 (Learning Notes)

1. OpenLayers 两种风场可视化方案对比：wind-arrows vs wind

OpenLayers 提供了两种截然不同但互为补充的气象风场可视化范式：

对比维度 wind-arrows（离散站点风向箭头，本示例） wind（连续粒子流场动画，ol/layer/Flow）
核心图层与技术 ol/layer/Vector + 两个 ol/style/RegularShape 组合符号 ol/layer/Flow（WebGL GPU 粒子轨迹模拟）+ ol/source/DataTile
输入数据形态 离散气象观测站 / 抽稀格网点（GeoJSON / JSON 点要素，含 speed 与 deg 属性） 连续二维风场栅格矩阵（PNG / COG / GeoZarr，第一波段存东西向风速 U，第二波段存南北向风速 V）
视觉表达特点 静态严谨的矢量箭头：箭杆长短直接量化风速大小，箭头朝向明确指示风的去向 类似 Windy.com 的全屏数千条动态流线粒子，颜色随风速渐变（如 viridis 色带）
适用业务场景 气象台站实况监测图、航道/港口离散浮标风向图、制图打印输出 全球/区域大尺度大气环流态势感知、台风路径流场大屏展示

2. 几何巧思：如何用 RegularShape 拼出一支“杆长可变、箭头不变形”的风向标？

如果使用一张现成的箭头 PNG 图片（Icon），当你根据风速放大图片时，箭头三角形也会跟着变宽变胖，线条也会变粗，视觉非常失真。本示例通过拆分两个 RegularShape 完美解决了这一痛点：

（1）箭杆（shaft）：points: 2 画直线段！
const shaft = new RegularShape({
  points: 2,
  radius: 5,
  stroke: new Stroke({width: 2, color: 'black'}),
  rotateWithView: true,
});
  • 在 regularshape.html 示例中我们见过 points: 3（三角形）、points: 4（正方形）。当 points: 2 时，在半径为 5 的圆周上等分取 2 个顶点（上顶点 (0, 5) 与下顶点 (0, -5)），连起来就是一条穿过圆心、总长度为 2 × radius = 10px 的垂直线段！
（2）单轴拉伸箭杆（shaft.setScale([1, scale])）
  • 假设当前站点风速 wind.speed = 20，则 scale = 20 / 10 = 2。
  • 调用 shaft.setScale([1, scale])：X 轴缩放保持为 1（确保无论风多大，箭杆线条宽度永远是 2px 不会变粗），仅将 Y 轴长度乘以 scale！
（3）箭头（head）的精确拼接位移公式
head.setDisplacement([
  0,
  head.getRadius() / 2 + shaft.getRadius() * scale,
]);
  • 为什么纵向位移 dy 等于 head.getRadius() / 2 + shaft.getRadius() * scale？
                  ▲  <-- 箭头顶点 (距离箭头中心 +R_head)
             / \
            / • \ <-- 箭头外接圆中心 (圆心到底边的垂直距离正好是 R_head × sin(30°) = R_head / 2)
           /_____\ <-- 箭头底边 与 箭杆顶端 在此处严丝合缝对接！
              |
              |   <-- 箭杆上半截长度 = R_shaft × scale
              ●   <-- 要素地理坐标原点 [0, 0]（也是旋转锚点中心）
              |   <-- 箭杆下半截长度 = R_shaft × scale
              |
    1. 箭杆以 [0, 0] 为中心向上延伸了 shaft.getRadius() * scale 像素。
    2. 箭头是一个正立等边三角形（points: 3），根据初中几何，等边三角形外接圆圆心到底边的距离恰好是外接圆半径的一半（head.getRadius() * sin(30°) = head.getRadius() / 2）。
    3. 因此，将箭头中心从 [0, 0] 向上平移 head.getRadius() / 2 + shaft.getRadius() * scale 像素，箭头的底边就会刚好贴在箭杆的最顶端！

3. 气象学风向角转换：为什么要 wind.deg - 180？

在代码第 51 行中：

const angle = ((wind.deg - 180) * Math.PI) / 180;
  • 气象学风向定义（风的来向）：气象数据中的 wind.deg 指的是风吹来的方向（顺时针与正北夹角）。例如“北风（0°）”是从北向南吹，“东风（90°）”是从东向西吹。
  • 箭头视觉朝向（风的去向）：箭头符号应当指向风吹去的方向（即背离风源方向）。因此必须将气象角度减去 180°（反向掉头），再乘以 Math.PI / 180 转换为弧度制传给 setRotation(angle)。

4. 关键属性：rotateWithView: true 与零内存分配样式复用

  1. 为什么必须开启 rotateWithView: true？ 风向是真实的地理方位（真北方向）。当用户按住 Alt + Shift + 鼠标拖拽 旋转地图视口时，风向箭头必须跟随地图一起旋转（rotateWithView: true），才能继续指向正确的地理东南西北方向！
  2. 高性能样式对象复用： shaft、head 和 styles 数组在文件顶部只实例化了一次。在 VectorLayer 的 style 函数中，遍历每个气象站要素时直接调用 setScale()、setRotation()、setDisplacement() 原地修改属性并返回同一个 styles 数组，实现了零垃圾回收（Zero GC）开销。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Point from 'ol/geom/Point.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import {fromLonLat} from 'ol/proj.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';
import Fill from 'ol/style/Fill.js';
import RegularShape from 'ol/style/RegularShape.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

// 1. 定义风向标的“箭杆（shaft）”符号：
// 使用 points: 2 在半径为 5 的圆上取上下两个顶点，生成一条总长为 10px 的垂直线段
const shaft = new RegularShape({
  points: 2,
  radius: 5,
  stroke: new Stroke({
    width: 2,
    color: 'black',
  }),
  rotateWithView: true, // 必须开启：风向属于地理真北方位，地图旋转时箭头需同步跟随旋转
});

// 2. 定义风向标的“箭头（head）”符号：
// 使用 points: 3 生成一个半径为 5、顶点朝向正上方的实心等边三角形
const head = new RegularShape({
  points: 3,
  radius: 5,
  fill: new Fill({
    color: 'black',
  }),
  rotateWithView: true,
});

// 预创建包含箭杆与箭头的复合样式数组（全局复用，避免在渲染循环中重复 new 对象）
const styles = [new Style({image: shaft}), new Style({image: head})];

// 3. 创建气象站点矢量数据源
const source = new VectorSource({
  attributions:
    'Weather data by <a href="https://openweathermap.org/current">OpenWeather</a>',
});

// 4. 初始化地图与动态风向标矢量图层
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
    new VectorLayer({
      source: source,
      // 动态样式函数：根据每个气象站点的风向（deg）与风速（speed）实时调整箭杆长度与箭头位置
      style: function (feature) {
        const wind = feature.get('wind');
        // 气象学风向 deg 是“风吹来的方向”，减去 180° 转换为“风吹去的方向（箭头指向）”，并转为弧度
        const angle = ((wind.deg - 180) * Math.PI) / 180;
        // 根据风速计算箭杆的纵向拉伸倍率
        const scale = wind.speed / 10;
        // 仅沿 Y 轴拉伸箭杆长度，保持 X 轴宽度为 1（使箭杆线条粗细保持恒定 2px）
        shaft.setScale([1, scale]);
        shaft.setRotation(angle);

        // 将不缩放的三角形箭头沿 Y 轴向上推移至拉伸后的箭杆顶端：
        // 偏移量 = 等边三角形中心到底边的距离 (radius / 2) + 箭杆上半截拉伸后的长度 (radius * scale)
        head.setDisplacement([
          0,
          head.getRadius() / 2 + shaft.getRadius() * scale,
        ]);
        head.setRotation(angle);
        return styles;
      },
    }),
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// 5. 异步加载 OpenWeather 实况气象站点数据，构造点要素并自动缩放视图至数据范围
fetch('data/openweather/weather.json')
  .then(function (response) {
    return response.json();
  })
  .then(function (data) {
    const features = [];
    data.list.forEach(function (report) {
      // 将经纬度坐标 [lon, lat] 转换为 Web Mercator 投影坐标创建点要素
      const feature = new Feature(
        new Point(fromLonLat([report.coord.lon, report.coord.lat])),
      );
      // 将站点气象报告的所有字段（包含 wind: { speed, deg } 等）批量写入要素属性
      feature.setProperties(report);
      features.push(feature);
    });
    source.addFeatures(features);
    // 自动缩放和平移地图视图，使所有气象站点完整呈现在视野内
    map.getView().fit(source.getExtent());
  });
