Demonstrates smooth reloading of layers when changing a dimension continuously. The demonstration layer is a global sea-level computation (flooding computation from SCALGO, underlying data from CGIAR-CSI SRTM) where cells that are flooded if the sea-level rises to more than x m are colored blue. The user selects the sea-level dimension using a slider.

本示例演示了在连续动态调整多维服务维度（Dimension）参数时，瓦片图层如何实现平滑无缝的重载过渡。演示图层为全球海平面上升淹没模拟计算（淹没算法由 SCALGO 提供，高程基础数据源自 CGIAR-CSI SRTM 90 米数字高程数据库）。当海平面上升超过 x 米时被淹没的网格像元被着色为蓝色，用户可以通过滑动条动态改变海平面高程维度。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - **WMTS 标准 Dimensions 维度扩展协议**： OGC WMTS 规范除了标准的 TileMatrix, TileRow, TileCol 外，支持任意自定义业务维度（Dimensions），如时间序列 TIME、海拔高度 ELEVATION、垂直水深或自定义门槛阈值 threshold。 - **动态平滑过渡与瓦片缓存复用**： 频繁拖动滑动条时，若每次都直接销毁重建图层，会导致页面产生剧烈白屏闪烁。OpenLayers 提供了 wmtsSource.updateDimensions(...) 方法，在请求新维度瓦片的同时，旧维度的切片会保留在屏幕上作为临时过渡底图，直到新切片完全加载解码完毕后才无缝切换，实现丝滑流畅的视觉体验。 #### 2. 源码与关键 API 剖析 (Source Code & API Analysis) - dimensions: { 'threshold': 100 } 初始绑定： 在构建 ol/source/WMTS 时通过 dimensions 字典声明自定义维度参数。OpenLayers 会自动将其拼接到 KVP（键值对）URL 请求参数中或根据 REST 模板注入路径变量。 - wmtsSource.updateDimensions({ 'threshold': slider.value })： 当滑动条触发 input 事件时动态更新维度值。内部会自动使受影响范围的缓存瓦片失效并排队发起新 URL 的切片并发拉取。 #### 3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - **高频滑动事件的请求风暴与节流**： 原生 <input type="range"> 的 input 事件在鼠标拖拽或触控滑动时以极高频率触发。如果服务端处理能力有限，过快的请求可能导致服务端瓦片生成拥堵甚至 503 报错。生产中建议结合 requestAnimationFrame 或 50~100ms 的防抖/节流函数（Throttle）来调度 updateDimensions。 tags: "wmts, parameter, transition, grid" ---
