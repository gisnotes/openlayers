The Draw and Modify interactions have a trace option to enable tracing around existing features. This example uses the traceSource option to trace features from one source and add them to another source. When drawing, the first click on an edge of the target feature will start tracing. The second click on the edge will stop tracing. When modifying, dragging a vertex onto an edge of the target feature will activate tracing for the next drag. Now when an adjacent vertex is dragged onto the edge, the segment between the two vertices will be traced along the target feature. If a different vertex is dragged, no tracing will occur.

Draw 和 Modify 交互均内置了 trace 选项，用于沿现有要素的边界拓扑进行自动追踪描摹。本示例配置了 traceSource 选项，实现从底图目标图层追踪要素轮廓，并将绘制结果存入独立的绘制图层中。

绘制模式（Drawing）：点击目标要素边缘上的某一点开始追踪，随后点击边缘上的第二点即可自动沿两点间最短拓扑边界完成描摹并结束追踪。

修改模式（Modifying）：将多边形的某一个顶点拖拽吸附到目标要素边界上，即可为下一次拖拽激活追踪状态；此时拖拽其相邻顶点到同一边界上，两顶点之间的整段线段便会自动吸附并紧贴目标边界进行拓扑追踪重合；若拖拽非相邻顶点，则不会触发追踪。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 边界拓扑追踪（Boundary Tracing）在 GIS 制图中的刚需： 在国土空间规划、地籍测绘和行政网格划分中，相邻地块必须严格“无缝拼接（Seamless Concurrency）”。 传统人工手动描点极易在边界之间产生微小的缝隙（Slivers）或重叠多边形（Overlaps），导致拓扑校验失败。 通过开启 trace: true 并指定 traceSource，绘制或修改交互能够在两点之间自动顺应参考图层要素的复杂几何曲线进行高精度拓扑跟随描摹。
  • 双点最短拓扑寻径描摹状态机（Two-Click Tracing State Machine）： 在绘制（Draw）交互中： 1. 第一击：光标被 Snap 捕捉并吸附在目标多边形边缘时，确定追踪起点； 2. 移动漫游：系统在后台沿目标多边形环状点序列计算两点间的最短路径（Shortest Path）并绘制动态预览； 3. 第二击：点击边缘上的目标点，系统瞬间将中间沿途数十个顶点一次性注入当前绘制几何中，完成无缝贴合。

2. 源码与关键 API 剖析

  • new Draw({ trace: true, traceSource, type })：启用追踪绘制，从 traceSource 参考源追踪边界并写入 source。
  • new Modify({ trace: true, traceSource, source })：启用追踪编辑，支持相邻顶点吸附贴合。
  • new Snap({ source: traceSource })：必须协同挂载 Snap 交互，确保鼠标能精准捕捉到参考边界的线段与顶点。

3. 生产实践踩坑与性能调优

  • 环状多边形追踪顺逆时针歧义： 闭合多边形边界有两个方向可达。系统默认选择包含较少顶点的较短路径。若用户希望沿较长的一侧环绕追踪，可以在中间拐角处增加一次点击作为途经锚点（Via-point）。
