--- layout: example.html title: Vector Tile Selection / 矢量切片要素交互拾取与高亮 shortdesc: Select features from vector tiles. / 从 MVT 矢量切片中选择单选、多选或悬停高亮地理要素。 docs: >

Click a rendered vector-tile feature to highlight it on the map. Click on an empty spot (ocean) to reset the selection. By changing the action type to "Multi Select" you can select multiple features at a time. With "Single Select on hover", features will be highlighted when the pointer is above them.

The selection layer is configured with renderMode: 'vector' for better performance on frequent redraws, i.e. when "Single Select on hover" is selected.

点击已渲染的矢量切片要素可在地图上将其高亮显示；点击空白区域（如海洋）可重置重设选择集。 通过切换交互模式为“Multi Select（多选）”，可同时累加选中多个要素；切换为“Single Select on hover（悬停单选）”时，鼠标指针悬浮处即可实时高亮要素。

高亮选择图层（selectionLayer）配置了 renderMode: 'vector'，以便在频繁触发重绘（例如指针悬停连续高亮）时保持极高帧率与渲染性能。

--- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构与设计思想 (Core Architecture & Design) - **双图层覆盖架构（Base VT Layer + Selection VT Layer）**： 在矢量切片应用中，通常不会直接对底图切片本身的所有要素进行就地状态修改，因为矢量切片具有离屏栅格化和缓存机制。本示例采用经典的高性能双图层模式： 1. **基础图层 (`vtLayer`)**：以默认样式渲染所有瓦片要素。 2. **选择图层 (`selectionLayer`)**：直接复用底层 `vtLayer.getSource()`，自身不额外发起任何瓦片 HTTP 请求，仅根据外部全局 `selection` 字典决定是否为对应要素附加高亮样式。 - **`renderMode: 'vector'` vs 默认 `'hybrid'`**： 矢量切片图层默认 `renderMode: 'hybrid'`，它将切片预渲染为位图缓存以提供极限缩放平移性能，但在动态高亮时重建切片纹理开销大。高亮图层使用 `renderMode: 'vector'`，强制保持纯矢量图元实时绘制，当 `selectionLayer.changed()` 触发时可瞬间局部重绘，达到 60fps 丝滑交互。 #### 2. 源码与关键 API 剖析 (Source Code & API Analysis) - `MVT({ idProperty: 'iso_a3' })`： 在矢量瓦片规范中，跨瓦片分割的相同多边形必须依赖唯一标识符来统一身份。通过配置 `idProperty: 'iso_a3'`，MVT 解析器将属性字典中的国家三字代码提取为要素的唯一 `feature.getId()`。这样当选中切片 A 内的局部多边形时，切片 B 内同属该国家的局部多边形亦能依据相同 ID 同时被高亮，彻底杜绝跨瓦片缝隙丢失现象。 - `vtLayer.getFeatures(pixel)` 异步 Promise 拾取： 区别于 `map.getFeaturesAtPixel`，`layer.getFeatures(pixel)` 返回一个 Promise，它直接从底层切片源中检索图元并按层级解析，支持精细过滤。 - `selectionLayer.changed()` 通知机制： 更新 `selection` 字典（增删选中的 featureId）后，直接调用 `selectionLayer.changed()` 发出刷新信号，触发样式函数重新评估，开销极低。 #### 3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization) - **跨切片要素 ID 缺失导致的“断裂高亮”陷阱**： 若发布的 MVT 矢量切片在生成（如 tippecanoe 或 GeoServer GWC）时未注入唯一 `id`，或者前端没有显式配置 `idProperty`，`feature.getId()` 将返回 `undefined` 或局部生成 ID，导致点击国家只能高亮所在瓦片的一半。生产环境必须确保矢量切片生产管线携带全局唯一业务主键。 - **Hover 模式下的节流优化**： 在 `pointermove` 模式下，快速滑过复杂要素会导致大量 `layer.getFeatures` 触发。生产中可将当前命中要素的 ID 缓存，仅在 ID 发生变化时才调用 `selectionLayer.changed()`，避免不必要的重绘循环。 tags: "vector tiles, selection" ---
