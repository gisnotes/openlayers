--- layout: example.html title: Panning and page scrolling / 双指平移与页面协作滚动（Cooperative Gesture） shortdesc: Shows a map that allows page scrolling unless two fingers or Cmd/Ctrl are used to pan the map. / 演示如何配置协作手势：触屏上单指滚动网页、双指拖拽地图；桌面端按住 Cmd/Ctrl 键才允许拖拽平移与滚轮缩放。 docs: | This example shows a common behavior for page scrolling: on touch devices, when one finger is placed on the map, it can be used to scroll the page. Only two fingers will perform drag pan. For mouse or trackpad devices, the platform modifier key (Cmd or Ctrl) will enable drag pan on the map, otherwise the page will scroll. 本示例展示在现代 Web 应用中极为通用的“协作手势模式（Cooperative Gesture Handling）”：在触控屏设备（手机/平板）上，单指在地图上滑动依然用于顺畅滚动外层网页，唯有使用**双指触摸（Two-Finger）**时才会触发地图的拖拽平移；在桌面鼠标与触控板设备上，需同时按住操作系统修饰键（macOS 上的 `Cmd` 或 Windows 上的 `Ctrl`）才能对地图进行拖动与滚轮缩放，否则滚轮与滑动手势将继续平滑滚动页面。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构原理 (Core Architecture) “滚轮与手势陷阱”是嵌入式地图组件破坏宿主页面可用性的头号痛点。主流地图平台普遍采用该协作交互范式： - **默认交互的禁用与重构**：默认情况下，OpenLayers 内部装载了无条件的 DragPan 与 MouseWheelZoom。本示例通过 defaults({ dragPan: false, mouseWheelZoom: false }) 移除默认实例，换上配置了复合条件谓词（Condition Predicates）的定制实例。 - **触摸点数探测机制 (`this.getPointerCount()`)**：在自定义 DragPan 的 condition 函数中，通过访问当前交互实例的 this.getPointerCount()，可实时精确探测屏幕当前的活动触控点数。当且仅当触控点数为 2 时返回 true，触发地图平移；触控点为 1 时条件不满足，OpenLayers 放弃拦截事件，原生触摸事件驱动页面正常顺滑上下滚动。 - **跨平台修饰键适配 (`platformModifierKeyOnly`)**：OpenLayers 封装了跨平台的事件条件工具函数 platformModifierKeyOnly(event)，在 macOS 上自动匹配 metaKey（Command 键），在 Windows / Linux 上自动匹配 ctrlKey，无需开发者编写繁琐的平台分支兼容代码。 #### 2. 关键实现与代码拆解 (Code Deep Dive) ```javascript const map = new Map({ interactions: defaults({ dragPan: false, // 卸载默认无条件拖拽 mouseWheelZoom: false, // 卸载默认无条件滚轮缩放 }).extend([ // 1. 双指或配合修饰键的拖拽平移 new DragPan({ condition: function (event) { return this.getPointerCount() === 2 || platformModifierKeyOnly(event); }, }), // 2. 必须按住 Cmd/Ctrl 才响应的滚轮缩放 new MouseWheelZoom({ condition: platformModifierKeyOnly, }), ]), layers: [new TileLayer({ source: new OSM() })], target: 'map', view: new View({ center: [0, 0], zoom: 2 }), }); ``` #### 3. 生产实战避坑与考量 (Production Pitfalls) - **浮层手势引导提示（User Guidance Overlay）**：在商用落地页中，建议搭配交互提示遮罩（如提示：“使用双指移动地图”或“按住 ⌘/Ctrl 滚轮缩放地图”），当用户触发单指滑动或未按键滚轮时短暂停留 1.5 秒后自动淡出。 - **捏合缩放（Pinch Zoom）协同**：即使重构了平移逻辑，默认的 PinchZoom（双指捏合缩放）依然可以正常保留，与双指平移（getPointerCount() === 2）天然完美契合。 tags: "trackpad, mousewheel, zoom, scroll, page" ---
