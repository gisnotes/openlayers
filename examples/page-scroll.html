Page Scrolling / 页面滚动与焦点隔离（tabindex 缩放陷阱防御）

trackpad2 mousewheel2 zoom9 scroll2 page2

Shows a map that does not interrupt page scrolling. / 展示如何通过配置 tabindex 防止地图捕获滚轮事件从而阻断长网页的正常向下滚动。

To perform wheel/trackpad zoom and drag-pan actions only when the map has the focus, configure your map div with a tabindex attribute. 在长网页（如产品落地页、新闻专栏、技术博客）中嵌入地图时，用户快速滚动鼠标滚轮极易被地图拦截并触发缩放，导致页面无法继续向下滚动（俗称“滚轮缩放陷阱 Scroll Trap”）。只需为地图挂载的宿主容器（<div>）添加 tabindex="1"（或任意有效数值），OpenLayers 便会自动切换为焦点优先模式：仅当地图容器被用户点击获得焦点后，滚轮和触控板手势才会触发地图缩放；失去焦点时，滚轮事件直接穿透给外层浏览器窗口，页面正常上下滚动。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构原理 (Core Architecture) 默认情况下，<div> 元素是不具备键盘焦点（Non-focusable）的纯布局容器。当用户滚轮滑动经过地图视口时，浏览器的 wheel 事件直接冒泡至 OpenLayers 绑定的监听器，触发 preventDefault() 并引发地图视口放大或缩小。 - tabindex 赋能交互焦点隔离：通过为 HTML 元素注入 tabindex 属性，浏览器将该 div 提升为可聚焦元素（Focusable Element），支持键盘 Tab 导航与鼠标点击对焦。 - OpenLayers MouseWheelZoom 内部焦点检测：OpenLayers 的 MouseWheelZoom 交互在收到 wheel 事件时，会检查宿主元素是否声明了 tabindex 且当前是否持有焦点。若未获得焦点，OpenLayers 会主动放弃捕获该事件，允许事件继续冒泡给浏览器外层 Window，驱动长网页上下平滑滚动。

3. 生产实战避坑与考量 (Production Pitfalls) - 焦点高亮样式定制（Focus Outline）：在某些浏览器中，获得焦点的 div 会出现默认外边框。建议在 CSS 中显式声明精致的柔和轮廓，向用户清晰传达“地图已激活，滚轮已切换为缩放模式”的视觉反馈：

.map:focus {
  outline: 2px solid rgba(0, 102, 204, 0.4);
  outline-offset: -2px;
}
  • 移动端多指交互配合：tabindex 机制主要解决桌面端鼠标滚轮与笔记本触控板问题。在手机或平板触摸屏上，单指滑动依然可能触发地图平移。如需在移动端也彻底防误触，需结合 two-finger-pan-scroll（双指拖动）协作模式。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';

// Initialize map attached to a target element configured with tabindex="1"
// 初始化地图实例，挂载到配置有 tabindex="1" 的容器上，实现仅在聚焦状态下响应滚轮缩放
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});
