--- layout: example.html title: Declutter Group / 避让分组（独立避让组） shortdesc: Group decluttering of vector symbols and text. / 矢量符号与文本注记的分组独立避让（Declutter Group）。 docs: | Different truthy `declutter` values enable declutter groups. If `declutter` was set to `true` on the vector layer in this example, the symbol and texts of the vector layer would prevent overlapping symbols and texts from the Mapbox styled layers below. Because it is set to `"separate"`, which is a different value than `true`, the vector layer is decluttered separate from the Mapbox styled layers below. Symbols and texts of the Mapbox styled layers below can overlap those of the vector layer. 为 declutter 属性设置不同的真值（Truthy Value，如字符串或分组名）可以启用避让分组（Declutter Groups）。如果在矢量图层上设置 declutter: true，该图层的图标与注记将与下方的 Mapbox 样式图层共享同一个避让碰撞树，互相遮挡碰撞；而当将其设置为 "separate"（或自定义分组标识）时，该矢量图层会与下方图层隔离，形成独立的避让组。下方 Mapbox 样式的注记将能够穿透并与上层矢量注记重叠显示。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 多图层避让碰撞树与独立分组架构 (Decluttering Spatial Index & Isolation) - **全局碰撞树 (`declutter: true`)**: 当多个图层均将 `declutter` 配置为 `true` 时，OpenLayers 内部在渲染时会分配一个共享的 R 树空间索引（RBush）。按照图层渲染顺序，先绘制的文字或图标所占用的屏幕包围盒会被标记，后续相交的标注将直接被剔除隐藏，防止文字重叠混乱。 - **命名分组隔离机制 (`declutter: 'separate'` / 自定义组名)**: 当赋予字符串类型的分组名时，OpenLayers 会为该标识创建独立的避让通道。组内元素依然保持碰撞剔除，但跨组之间完全互不干涉。这解决了业务关键标注（如应急救援点、警戒线）与底图路网注记由于全局避让而导致某一方被意外清空的工程难题。 #### 2. Flat Style 声明式样式语法在注记中的应用 - 示例中使用了现代 Flat Style 对象规范： - `'text-value': ['get', 'text']`：基于要素属性动态提取文本表达式； - `'text-overflow': true`：忽略多边形几何外包约束，即使文本长于几何面也正常输出并参与避让碰撞； - `'circle-*'` 与 `'text-*'` 复合组合：实现单个样式规则同时控制点图标与文本标签的统一渲染。 #### 3. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices) - **避让优先级与渲染顺序**: 默认情况下，先渲染的图层具有更高的占位优先级。如果需要特定重要图层优先占据屏幕空间，建议调整图层的 `zIndex` 或在图层组中置顶。 - **海量要素避让性能损耗**: 避让算法需要在 CPU 侧为每个文字和图标计算投影后的像素包围盒（Bounding Box）并进行 R 树碰撞查询。若未配置分辨率阈值而在全图范围内对数万个注记同时执行避让，会显著拖慢地图缩放与平移的响应帧率。推荐配合 `maxResolution` / `minResolution` 仅在合适缩放层级激活复杂避让图层。 tags: "mapbox, declutter, decluttering, labels, vector" ---
