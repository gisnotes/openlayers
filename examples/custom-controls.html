--- layout: example.html title: Custom Controls / 自定义地图控件（指北针） shortdesc: Shows how to create custom controls. / 展示如何继承 ol/control/Control 封装自定义地图控件。 docs: | This example creates a "rotate to north" control with an inline SVG north arrow. The control's render method rotates the arrow together with the map, so it always points north, and hides the control with the ol-hidden class when the map is not rotated. The control replaces the default ol/control/Rotate control, which is left out of the map's controls. Use Alt+Shift+Drag to rotate the map. 本示例通过继承基类 ol/control/Control 实现一个带有内联 SVG 指针的“一键复位指北针”自定义控件。该控件重写了 render 渲染帧回调方法，使指北针图标随着地图视口旋转同步变换，始终指向正北方向；并在地图回归正北（旋转角为 0）时通过 ol-hidden 样式类自动隐藏。该控件替换了默认的 ol/control/Rotate 控件。可按住 Alt + Shift + 鼠标拖拽 旋转地图测试效果。 --- ### 📚 学习记录与技术深度解读 (Learning Notes) #### 1. 核心架构原理 (Core Architecture) OpenLayers 控件（Control）是浮动在地图视口之上的 DOM UI 组件（如缩放按钮、比例尺、版权归属等），与基于 Canvas 绘制的图层不同，控件完全由 HTML/CSS/DOM 事件模型驱动： - **继承基类 `ol/control/Control`**：自定义控件通过 ES6 class MyControl extends Control 继承基类。在构造函数中通过 super({ element, target }) 将自定义创建的 DOM 根节点注入 OpenLayers 控件管理体系。 - **视口动画与平滑交互**：控件通过 this.getMap() 访问关联的地图实例，获取其 View 并调用 animate({ rotation: 0, duration: 250 }) 触发平滑过渡的视角复位动画。 - **每帧渲染钩子 `render(mapEvent)`**：每当地图视口触发一次重绘（平移、缩放、惯性旋转），地图都会向所有注册的控件广播 render(mapEvent)。控件可从 mapEvent.frameState.viewState.rotation 中读取当前帧精确到弧度的旋转值，实现 60fps 无滞后的 CSS Transform 硬件加速同步更新。 #### 2. 关键实现与代码拆解 (Code Deep Dive) ```javascript class RotateNorthControl extends Control { constructor(opt_options) { const options = opt_options || {}; const button = document.createElement('button'); button.type = 'button'; button.title = 'Rotate to north / 复位至正北'; button.innerHTML = northArrowSvg; const element = document.createElement('div'); element.className = 'rotate-north ol-unselectable ol-control'; element.appendChild(button); super({ element: element, target: options.target }); this.arrow_ = button.querySelector('svg'); this.rotation_ = undefined; button.addEventListener('click', this.handleRotateNorth.bind(this), false); } handleRotateNorth() { // 触发 250ms 优雅回弹缓动动画 this.getMap().getView().animate({rotation: 0, duration: 250}); } render(mapEvent) { const frameState = mapEvent.frameState; if (!frameState) return; const rotation = frameState.viewState.rotation; // 仅在旋转角变动时更新 DOM，避免多余重排重绘 if (rotation !== this.rotation_) { this.arrow_.style.transform = `rotate(${rotation}rad)`; this.element.classList.toggle('ol-hidden', rotation === 0); this.rotation_ = rotation; } } } ``` #### 3. 生产实战避坑与考量 (Production Pitfalls) - **样式类规范与层叠上下文**：自定义控件根节点必须包含 ol-unselectable（防止鼠标双击或拖拽误选中文本）和 ol-control（OpenLayers 预置的绝对定位容器层级和毛玻璃背景风格）。 - **渲染性能守则**：render(mapEvent) 在地图交互期间每秒调用高达 60 次甚至 120 次。在此方法内严禁执行耗时的 DOM 查询或引起全页 Layout Reflow 的重度操作。务必在构造函数中预先缓存 DOM 节点引用，并利用本地变量做脏检查判断。 - **替换默认控件机制**：初始化地图时，若需替换默认控件（如禁用原装 Rotate 并追加自定义指北针），推荐通过 defaultControls({ rotate: false }).extend([new RotateNorthControl()]) 声明式组合构建。 tags: "custom, control, rotate, north, svg" ---
