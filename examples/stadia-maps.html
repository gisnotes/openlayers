Example showing the Alidade Smooth Dark theme from Stadia Maps, using the retina (HiDPI) tiles.

本示例展示了如何使用 Stadia Maps 数据源加载 Alidade Smooth Dark 暗黑平滑主题，并开启 Retina（HiDPI）视网膜高清切片渲染。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 高度封装的商业级数据源（StadiaMaps Source）： Stadia Maps 作为 Stamen 地图设计风格的官方托管服务商，提供了专用的 ol/source/StadiaMaps。相比于手动拼接 XYZ URL 模板，该专用数据源内置了多套经典精美主题（如 alidade_smooth_dark、outdoors、stamen_toner、stamen_watercolor 等），并对高清切片与矢量注记进行了高度优化。
  • 一键开启的高清视网膜适配（retina 开关）： 开发者仅需设置 retina: true，底层数据源将自动在瓦片请求路径后追加 @2x 后缀，并自动将图层的 tilePixelRatio 设为 2，免去了手动管理切片网格与分辨率换算的复杂度。
  • 暗黑主题与视觉对比度： 暗色主题（Dark Mode）在夜间监控大屏、智慧园区大屏中应用极广。在 2× Retina 高分屏下，微细的等高线、细支路注记能保持极其锐利的对比度，杜绝了常规切片在放大后的虚焦发灰现象。

2. 源码与关键 API 剖析

  • layer: 'alidade_smooth_dark'：指定 Stadia Maps 的主题标识符，包含道路等级着色、水体着色与暗黑背景色。
  • retina: true：自动化高分参数，驱动内部的 Urls 构造器拼接 512×512 物理分辨率的高清图片流。
  • fromLonLat([24.75, 59.44])：将爱沙尼亚首都塔林的 WGS84 经纬度投影转换为 EPSG:3857 墨卡托平面坐标。
  • apiKey 选项：开发阶段在 localhost 下无需任何 API Key 即可自由调用；生产环境部署需传入注册的商业鉴权 Key。

3. 生产实践踩坑与性能调优

  • 商业调用量配额与风控拦截： 生产环境部署如果未配置 apiKey 或未在控制台绑定线上域名白名单，服务端将返回 403 错误或注入带水印的水印瓦片。必须通过安全配置管理环境变量注入密钥。
  • 暗黑底图上的矢量要素配色规范： 使用深色底图时，上层叠加的业务要素（如点标注、面图层）切忌使用深蓝、灰黑等低明度色彩；应采用高饱和度发光色系（如青色 #00f0ff、亮橙色 #ff7700、荧光绿 #00ff66），并配合 rgba() 外发光阴影以确保视觉辨识度。
  • 全球服务访问延迟（CDN 网络）： Stadia Maps 在全球部署了分布式 Edge CDN，但某些企业内网或特定地域可能存在延迟。跨国或离线内网项目建议在内网架设切片代理缓存或部署开源离线瓦片服务器。
