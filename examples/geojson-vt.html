data.features : [], }, replacer); const features = format.readFeatures(geojson, { extent: vectorSource.getTileGrid().getTileCoordExtent(tileCoord), featureProjection: map.getView().getProjection(), }); tile.setFeatures(features); } ``` 通过自定义数据替换器（`replacer`），将 `geojson-vt` 内部简化的数字几何类型（1: Point, 2: Line, 3: Polygon）还原为符合 GeoJSON 规范的嵌套坐标结构。 #### 3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices) - **瓦片边界几何裂缝防护（Extent & Buffer）**： 在初始化 `geojsonvt(json, options)` 时，`extent`（通常设为 4096）必须与 OpenLayers 的 `Projection` extent 严格保持一致；同时建议保留适当的 `buffer`（默认 64 像素），防止多边形描边或大半径点符号在切片边缘出现截断瑕疵。 - **多边形拓扑降采样控制（Index MaxZoom）**： `geojson-vt` 默认仅索引至 `maxZoom: 14`，在更深层级则复用父切片进行坐标放缩。如果应用需要支持街区微观级细致测量（如 zoom 18+），应在初始化时显式指定更高 `maxZoom` 与更小的 `tolerance`，平衡内存占用与几何保真度。 tags: "mapbox, vector, tiles, geojson" ---
