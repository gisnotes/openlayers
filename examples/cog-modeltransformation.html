COG with ModelTransformation / 包含模型仿射变换矩阵的 COG

cog16 projection14 ModelTransformation1


COG with ModelTransformation. / 展示包含 ModelTransformation 仿射变换矩阵（旋转/倾斜）的云原生 GeoTIFF (COG) 在客户端的重投影与渲染。

Example of using a COG with ModelTransformation. A ModelTransformation may rotate or skew the tile grid relative to the reported projection. This can be reprojected to that or any other supported projection. To apply the ModelTransformation to ol/source/TileDebug use the source option.

本示例演示如何加载和渲染带有 ModelTransformation（模型变换矩阵） 的云原生 GeoTIFF（COG）影像。 ModelTransformation 可能会使瓦片网格相对于其报告的投影产生旋转或倾斜剪切。 OpenLayers 可以在客户端将其动态重投影到目标投影（如 EPSG:3857），或保持其原始几何特征。 若要将模型变换矩阵应用到 ol/source/TileDebug 调试图层中，只需配置 source 选项即可。

📚 学习记录与技术深度解读 (Learning Notes)

1. 什么是 ModelTransformation 标签？

  • 标准正交网格定位（PixelScale + Tiepoint）： 常规 GeoTIFF 文件通常使用 ModelPixelScaleTag（像元物理尺寸）和 ModelTiepointTag（控制点地理坐标）来锚定图像。这种方式假定像元网格与地图投影坐标轴完全正交（即图像没有旋转，像素列方向精确平行于 Y 轴，行方向平行于 X 轴）。
  • 倾斜/旋转成像（SAR、航拍与斜向轨道）： 合成孔径雷达（SAR，如本例中 Umbra 卫星拍摄的瓦努阿图塔纳岛影像）或无人机航拍斜拍时，传感器视线与地面投影坐标系存在显著的旋转角（Rotation）或剪切（Skew）。
  • GeoTIFF Tag 34264 仿射变换矩阵： GeoTIFF 规范使用 Tag 34264（ModelTransformationTag）定义一个完整的 $4 \times 4$ 仿射变换矩阵，将栅格像元坐标 $(\text{col}, \text{row})$ 直接变换为空间地表投影坐标 $(X, Y)$： $$\begin{bmatrix} X \ Y \ 1 \end{bmatrix} = \begin{bmatrix} a & b & c \ d & e & f \ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} \text{col} \ \text{row} \ 1 \end{bmatrix}$$ 其中非对角线系数 $b$ 与 $d$ 明确刻画了旋转与剪切形变。

2. OpenLayers 客户端硬件重投影机制

  • ol/source/GeoTIFF 能够直接解析 TIFF 头部中的 ModelTransformation 矩阵，并在内存中构建具有旋转角度的非正交瓦片网格。
  • 配合 WebGL 瓦片渲染管线（ol/layer/WebGLTile），OpenLayers 在 GPU 片元着色器中执行反向坐标投影寻址，将具有空间倾斜的 COG 像元平滑、无缝地映射到 Web 墨卡托（EPSG:3857）底图上，与标准 OSM 底图严丝合缝地对齐。

3. 倾斜瓦片调试器：new TileDebug({source: cogSource})

  • 当勾选“显示数据源瓦片坐标 (Show source tile coordinates)”时，通过传入 source: cogSource，TileDebug 图层会直接继承 COG 数据源内部的仿射变换矩阵。
  • 从而在地图表面精确绘制出带有倾斜与旋转角度的原始 COG 瓦片边界与层级/行列编号（$z/x/y$）。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import {transformExtent} from 'ol/proj.js';
import {fromEPSGCode, register} from 'ol/proj/proj4.js';
import GeoTIFF from 'ol/source/GeoTIFF.js';
import OSM from 'ol/source/OSM.js';
import TileDebug from 'ol/source/TileDebug.js';
import proj4 from 'proj4';

// Register proj4 with OpenLayers projection system
// 将 proj4 实例注册到 OpenLayers 投影体系
register(proj4);

// Create GeoTIFF source pointing to Umbra synthetic aperture radar (SAR) GEC image.
// This image contains a ModelTransformation tag defining affine skew/rotation.
// 创建 COG 数据源，加载来自 Umbra 开放数据目录的高分辨率合成孔径雷达（SAR）GEC 级影像。
// 该 GeoTIFF 文件内部嵌入了 ModelTransformation 标签，定义了包含旋转与倾斜的像元仿射映射关系。
const cogSource = new GeoTIFF({
  sources: [
    {
      url:
        'https://umbra-open-data-catalog.s3.amazonaws.com/sar-data/tasks/Tanna%20Island,%20Vanuatu/' +
        '9c76a918-9247-42bf-b9f6-3b4f672bc148/2023-02-12-21-33-56_UMBRA-04/2023-02-12-21-33-56_UMBRA-04_GEC.tif',
    },
  ],
});

// Tile debug layer: by providing source: cogSource, TileDebug adopts the affine matrix of the COG,
// rendering rotated tile boundaries and indices directly on the map.
// 瓦片调试图层：通过传入 source: cogSource，TileDebug 将自动应用 COG 的 ModelTransformation 仿射矩阵，
// 在倾斜旋转的瓦片边界上精准绘制原始网格及层级编号。
const showTilesCheckbox = document.getElementById('show-tiles');
const debugLayer = new TileLayer({
  source: new TileDebug({source: cogSource}),
  visible: showTilesCheckbox.checked,
});
showTilesCheckbox.addEventListener('change', () => {
  debugLayer.setVisible(showTilesCheckbox.checked);
});

// Initialize map instance
// 初始化地图实例
const map = new Map({
  target: 'map',
  layers: [
    // Base OSM layer / 基础 OSM 底图
    new TileLayer({
      source: new OSM(),
    }),
    // WebGL accelerated COG layer / WebGL 硬件加速 COG 图层
    new TileLayer({
      source: cogSource,
      opacity: 0.8,
    }),
    debugLayer,
  ],
  view: new View(),
});

// Asynchronously resolve COG metadata and fit view to the image extent
// 异步解析 COG 元数据并自动将视口调整至影像外包范围
cogSource.getView().then((viewConfig) =>
  fromEPSGCode(viewConfig.projection.getCode()).then(() => {
    const view = map.getView();
    view.fit(
      transformExtent(
        viewConfig.extent,
        viewConfig.projection,
        view.getProjection(),
      ),
    );
  }),
);
