包含模型仿射变换矩阵的 COG (COG with ModelTransformation)

cog16 projection14 ModelTransformation1


展示包含 ModelTransformation 仿射变换矩阵（旋转/倾斜）的云原生 GeoTIFF (COG) 在客户端的重投影与渲染。

本例展示了如何加载和渲染带有 ModelTransformation（模型变换矩阵） 的云原生 GeoTIFF（COG）影像。

核心机制与原理解析

  1. 什么是 ModelTransformation 标签？

    • 标准的 GeoTIFF 文件通常使用 ModelPixelScaleTag（像元比例）和 ModelTiepointTag（控制点）来定位图像，这种方式假定像元网格与地图投影坐标轴完全正交（无旋转）。
    • 然而，合成孔径雷达（SAR，如本例中 Umbra 卫星拍摄的瓦努阿图塔纳岛影像）或遥感卫星沿轨道倾斜扫描成像时，图像坐标系相对于地表投影存在明显的旋转角（Rotation）或剪切（Skew）。
    • GeoTIFF 规范使用 Tag 34264（ModelTransformationTag）定义一个完整的仿射变换矩阵，将栅格像元坐标 $(\text{col}, \text{row})$ 映射至地理模型坐标 $(X, Y)$： $$\begin{bmatrix} X \ Y \ 1 \end{bmatrix} = \begin{bmatrix} a & b & c \ d & e & f \ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} \text{col} \ \text{row} \ 1 \end{bmatrix}$$ 其中非对角线系数 $b$ 和 $d$ 描述了旋转与剪切变形。

  2. OpenLayers 客户端动态重投影：

    • ol/source/GeoTIFF 能够自动解析 ModelTransformation 矩阵并构建非正交倾斜瓦片网格。
    • 结合 WebGL 瓦片渲染管线（ol/layer/WebGLTile），OpenLayers 能在 GPU 中实时将具有仿射旋转的 COG 切片重投影到标准 Web 墨卡托（EPSG:3857）或其他任意投影中，与 OSM 底图无缝精确重叠。

  3. 倾斜瓦片调试（TileDebug with source）：

    • 勾选“显示数据源瓦片坐标”时，new TileDebug({source: cogSource}) 会直接继承数据源的变换矩阵，从而在地图上直观勾勒出带有旋转角度的原始 COG 瓦片边界与编号。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import {transformExtent} from 'ol/proj.js';
import {fromProjectionCode, register} from 'ol/proj/proj4.js';
import GeoTIFF from 'ol/source/GeoTIFF.js';
import OSM from 'ol/source/OSM.js';
import TileDebug from 'ol/source/TileDebug.js';
import proj4 from 'proj4';

// 将 proj4 实例注册到 OpenLayers 投影体系
register(proj4);

/**
 * 创建 COG 数据源
 * 加载来自 Umbra 开放数据目录的高分辨率合成孔径雷达（SAR）GEC 级影像。
 * 该 GeoTIFF 文件内部嵌入了 ModelTransformation 标签，定义了包含旋转与倾斜的像元仿射映射关系。
 */
const cogSource = new GeoTIFF({
  sources: [
    {
      url:
        'https://umbra-open-data-catalog.s3.amazonaws.com/sar-data/tasks/Tanna%20Island,%20Vanuatu/' +
        '9c76a918-9247-42bf-b9f6-3b4f672bc148/2023-02-12-21-33-56_UMBRA-04/2023-02-12-21-33-56_UMBRA-04_GEC.tif',
    },
  ],
});

// 瓦片调试图层：通过传入 source: cogSource，TileDebug 将自动应用 COG 的 ModelTransformation 仿射矩阵，
// 在倾斜旋转的瓦片边界上精准绘制原始网格及层级编号。
const showTilesCheckbox = document.getElementById('show-tiles');
const debugLayer = new TileLayer({
  source: new TileDebug({source: cogSource}),
  visible: showTilesCheckbox.checked,
});
showTilesCheckbox.addEventListener('change', () => {
  debugLayer.setVisible(showTilesCheckbox.checked);
});

// 初始化地图实例
const map = new Map({
  target: 'map',
  layers: [
    // 基础 OSM 底图
    new TileLayer({
      source: new OSM(),
    }),
    // WebGL 硬件加速 COG 图层
    new TileLayer({
      source: cogSource,
      opacity: 0.8,
    }),
    debugLayer,
  ],
  view: new View(),
});

// 异步解析 COG 元数据并自动适配地图视口
// 1. cogSource.getView() 读取 TIFF 头部并返回适用的投影与外包范围；
// 2. fromProjectionCode 动态确保该投影已被 proj4 定义；
// 3. transformExtent 将 COG 范围转换为当前视图投影（EPSG:3857）；
// 4. view.fit 将地图平滑缩放至影像所在区域（南太平洋瓦努阿图塔纳岛）。
cogSource.getView().then((viewConfig) =>
  fromProjectionCode(viewConfig.projection.getCode()).then(() => {
    const view = map.getView();
    view.fit(
      transformExtent(
        viewConfig.extent,
        viewConfig.projection,
        view.getProjection(),
      ),
    );
  }),
);
