Example of various ZoomSlider controls / 演示如何向地图添加 ZoomSlider 缩放滑块控件，以及如何完全通过 CSS 定制其位置、外观甚至自动切换水平/垂直滑动方向。

This example shows how to add a zoom slider to a map and how to customize it.

本示例展示了如何向地图添加缩放滑块控件（ol/control/ZoomSlider），并演示了 3 种不同风格的定制效果：默认垂直样式（#map1）、嵌入在放大/缩小按钮之间的组合样式（#map2），以及位于右上角的橙色水平滑块样式（#map3）。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心疑问解答：为什么这个示例也带有 style 标签？它的样式怎么全是在 CSS 里写的？

你观察得非常准确！在本示例中，main.js 里的 3 个地图调用了完全相同的 createMap(divId) 函数，没有任何一行关于颜色、位置或方向的 JavaScript 配置，3 个滑块截然不同的外观和交互方向100% 是由 zoomslider.css 决定的！

这里体现了 OpenLayers 架构设计中 “图层渲染样式（Layer Style）” 与 “控件 UI 样式（Control CSS Styling）” 的严格分离原则：

对比维度 地图图层（VectorLayer / WebGLTile 等） 地图控件（Zoom / ZoomSlider / ScaleLine 等）
底层渲染载体 绘制在 <canvas> 画布像素（Canvas 2D 或 WebGL） 内部 挂载在地图上层 .ol-overlaycontainer-stopevent 容器中的原生 HTML DOM 元素
样式控制方式 必须通过 JS API（ol/style/Style、Stroke、Fill、Icon 或 WebGL 表达式）控制 完全通过标准 CSS 类名（如 .ol-zoomslider、.ol-zoomslider-thumb）控制位置、颜色、圆角与尺寸
style 标签含义 指代要素符号化与图层渲染样式 此处的 style, styling, css 标签仅代表英文广义的“UI 外观样式定制（CSS Styling）”

2. 源码级黑科技揭秘：为什么 #map3 只改了 CSS 宽高，滑块就自动从“上下拖动”变成了“左右拖动”？

仔细对比 main.js 会发现：map3 在初始化 new ZoomSlider() 时根本没有传入任何类似 direction: 'horizontal' 的参数（事实上 ZoomSlider 构造函数里也压根没有 direction 这个配置项）！那它是怎么知道在 #map3 里要变成水平左右滑动的呢？

翻看 OpenLayers 源码 src/ol/control/ZoomSlider.js 中的 initSlider_() 方法，就能揭晓这个极佳的自适应设计：

// OpenLayers 源码 src/ol/control/ZoomSlider.js 核心逻辑摘录：
const containerStyle = getComputedStyle(container);
// 计算去除内边距后的容器实际内容宽高
containerWidth -= parseFloat(containerStyle['paddingRight']) + parseFloat(containerStyle['paddingLeft']);
containerHeight -= parseFloat(containerStyle['paddingTop']) + parseFloat(containerStyle['paddingBottom']);

// 核心奥秘：根据 CSS 最终渲染出的“宽 vs 高”自动决定滑块物理拖拽方向！
if (containerWidth > containerHeight) {
  this.direction_ = Direction.HORIZONTAL; // 宽 > 高：自动切换为【水平左右滑动】模式！
  this.widthLimit_ = containerWidth - thumbWidth;
} else {
  this.direction_ = Direction.VERTICAL;   // 宽 <= 高：默认【垂直上下滑动】模式！
  this.heightLimit_ = containerHeight - thumbHeight;
}
  • 结论：ZoomSlider 在首次渲染时会通过 getComputedStyle() 自动测量自身 DOM 容器的宽高：
    • 在 #map1 和 #map2 中，默认样式为竖长条（宽 < 高），因此自动启用垂直滑动（VERTICAL）。
    • 在 #map3 中，CSS 设置了 width: 200px; height: 15px;（宽 > 高），ZoomSlider 检测到宽度大于高度后，自动将内部拖拽方向切换为水平模式（HORIZONTAL）！

3. 三种 ZoomSlider 布局样式的 CSS 实现拆解

地图实例 视觉与布局特征 核心 CSS 选择器与实现技巧
#map1（默认样式） 位于左上角 + / - 按钮正下方，白色半透明竖直轨道 直接使用 ol.css 内置的 .ol-zoomslider 与 .ol-zoomslider-thumb 默认样式
#map2（嵌入 + 与 - 按钮之间） 将缩小按钮 - 向下推开 200px，把滑块轨道刚好嵌在 + 和 - 中间，宛如一体式控件 1. #map2 .ol-zoom .ol-zoom-out { margin-top: 200px; } 把 - 号按钮往下推；
2. #map2 .ol-zoomslider 设置 background-color: transparent 隐藏外框，并用 top: calc(0.5em + 2px + 1px + 1.14 * 1.375em) 精确对齐到 + 号按钮底边；
3. 针对触摸屏（.ol-touch 按钮更大）单独微调 margin-top: 212px 与 top: 2.75em
#map3（右上角水平胶囊滑块） 移至地图右上角，水平放置，橙色发光圆角胶囊外观 1. left: auto; right: 8px; top: 8px; 将定位从左上角移至右上角；
2. width: 200px; height: 15px; 触发 宽 > 高 水平滑动模式；
3. 将滑块手柄 .ol-zoomslider-thumb 设为 15px × 15px、border-radius: 7.5px 的圆形滑块
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ZoomSlider from 'ol/control/ZoomSlider.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';

/**
 * 创建地图并挂载 ZoomSlider 缩放滑块控件的通用工厂函数。
 * 注意：三个地图在 JS 层的代码完全一致，滑块的位置、外观以及垂直/水平滑动方向均由 zoomslider.css 控制。
 *
 * @param {string} divId 地图目标容器 DOM 的 id（'map1' | 'map2' | 'map3'）
 * @return {Map} 创建完成的 OpenLayers Map 实例
 */
function createMap(divId) {
  const source = new OSM();
  const layer = new TileLayer({
    source: source,
  });
  const map = new Map({
    layers: [layer],
    target: divId,
    view: new View({
      center: [0, 0],
      zoom: 2,
    }),
  });
  // 实例化缩放滑块控件并添加到地图上
  const zoomslider = new ZoomSlider();
  map.addControl(zoomslider);
  return map;
}

// 1. 默认垂直滑块样式
const map1 = createMap('map1');
// 2. 嵌入在放大（+）和缩小（-）按钮之间的垂直滑块样式
const map2 = createMap('map2');
// 3. 右上角自定义橙色水平滑块样式（通过 CSS 设置 width > height 自动触发水平滑动）
const map3 = createMap('map3');
index.html 
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <title>Zoom Sliders / 缩放滑块控件与纯 CSS 样式定制（ZoomSlider）</title>
    <link rel="stylesheet" href="node_modules/ol/ol.css">
    <style>
      .map {
        width: 100%;
        height: 400px;
      }
      /**
       * 样式二（#map2）：将缩放滑块（ZoomSlider）嵌入到默认缩放控件的“放大（+）”与“缩小（-）”按钮正中间
       */
      /* 1. 将“缩小（-）”按钮向下推开 200px，为中间的滑块腾出垂直空间 */
      #map2 .ol-zoom .ol-zoom-out {
        margin-top: 200px;
      }
      #map2 .ol-zoomslider {
        background-color: transparent;
        /*
         * 精确计算滑块顶部（top）偏移量，使其紧贴在“放大（+）”按钮正下方：
         * Zoom 控件外层 top: 0.5em
         * Zoom 控件内边距 padding: 2px
         * Zoom-in 按钮上外边距 margin-top: 1px
         * Zoom-in 按钮自身高度: 字体大小 1.14em * 行高 1.375
         */
        top: calc(0.5em + 2px + 1px + 1.14 * 1.375em);
      }
      
      /* 针对移动触摸设备（.ol-touch 下按钮尺寸更大）的间距适配 */
      #map2 .ol-touch .ol-zoom .ol-zoom-out {
        margin-top: 212px;
      }
      #map2 .ol-touch .ol-zoomslider {
        top: 2.75em;
      }
      
      /* 修正按钮悬停/聚焦时的内置无障碍提示框（tooltip）垂直对齐位置 */
      #map2 .ol-zoom-in.ol-has-tooltip:hover [role=tooltip],
      #map2 .ol-zoom-in.ol-has-tooltip:focus [role=tooltip] {
        top: 3px;
      }
      
      #map2 .ol-zoom-out.ol-has-tooltip:hover [role=tooltip],
      #map2 .ol-zoom-out.ol-has-tooltip:focus [role=tooltip] {
        top: 232px;
      }
      
      /**
       * 样式三（#map3）：将缩放滑块移至地图右上角，改为橙色发光圆角外观，并切换为“水平滑动”模式
       * 核心机制：当 CSS 设置 width (200px) > height (15px) 时，OpenLayers 的 ZoomSlider.prototype.initSlider_()
       * 会通过 getComputedStyle 自动检测到宽度大于高度，从而将内部滑动方向自动切换为水平（HORIZONTAL）！
       */
      #map3 .ol-zoomslider {
        top: 8px;
        left: auto; /* 取消默认的左上角定位 */
        right: 8px; /* 停靠在地图右上角 */
        background-color: rgba(255,69,0,0.2);
        width: 200px; /* 宽度大于高度（200px > 15px），触发 ZoomSlider 自动进入水平滑动模式 */
        height: 15px;
        padding: 0;
        box-shadow: 0 0 5px rgb(255,69,0);
        border-radius: 7.5px;
      }
      
      #map3 .ol-zoomslider:hover {
        background-color: rgba(255,69,0,0.3);
      }
      
      /* 自定义滑块拖拽手柄（.ol-zoomslider-thumb）为 15x15 的正圆形橙色按钮 */
      #map3 .ol-zoomslider-thumb {
        height: 15px;
        width: 15px;
        margin: 0;
        filter: none;
        background-color: rgba(255,69,0,0.6);
        border-radius: 7.5px;
      }
      #map3 a.ol-zoomslider-handle:hover {
        background-color: rgba(255,69,0,0.7);
      }
    </style>
  </head>
