WebGL Vector Layer / WebGL 矢量多边形面图层与悬停高亮

vector87 geojson11 webgl19

Hover or click an ecoregion / 悬停或点击生态区以查看名称

Example of a vector layer rendered using WebGL. / 使用 WebGLVectorLayer 渲染包含数千个复杂生态多边形面要素的 GeoJSON 数据，支持 GPU 条件分支高亮与文字标注。

The ecoregions are loaded from a GeoJSON file.

本示例展示如何使用 ol/layer/WebGLVector 渲染复杂的多边形矢量面要素。全球生态区（Ecoregions）数据从 GeoJSON 文件异步加载，并在 WebGL 中实现多边形填充、描边外轮廓、注记文本与鼠标悬停即时高亮。

📚 学习记录与技术深度解读 (Learning Notes)

1. WebGL 多边形面要素三角剖分（Polygon Triangulation）

  • GPU 图元要求：GPU 硬件原生只能绘制点、线、三角形，无法直接填充任意凹多边形或带内环（Holes）的多边形面。
  • Earcut 算法装配：WebGLVectorLayer 在后台 Worker 线程中自动调用 Earcut 耳切三角剖分算法，将每个复杂多边形分解为成百上千个三角形顶点网格，并生成顶点缓冲区（VBO）写入 GPU 显存。

2. 着色器分支语法：filter 与 else: true

  • 样式规则数组中声明了条件分支：
    • 规则 1：filter: ['==', ['var', 'highlightedId'], ['id']]，命中当前悬停 ID 的要素被绘制为加粗白色外框与高亮填充；
    • 规则 2：else: true，其余未选中要素以自身属性颜色（COLOR）进行渲染；
    • 规则 3：叠加注记文本（text-value: ['coalesce', ['get', 'ECO_NAME'], 'unknown']）。

3. 悬停交互性能：零重建的 Uniform 高亮

  • 在鼠标移动时，通过 vectorLayer.updateStyleVariables({highlightedId}) 仅把当前要素 ID 作为 Uniform 标量传给 GPU，GPU 片元着色器瞬间改变绘制分支，完全避免了传统 Canvas 重新遍历所有要素生成样式对象的开销。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import WebGLVectorLayer from 'ol/layer/WebGLVector.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';

// WebGL FlatStyle rules with conditional branching (highlighted vs standard) and labels
// WebGL FlatStyle 规则：利用条件分支实现高亮对比与文本注记

const style = [
  {
    filter: ['==', ['var', 'highlightedId'], ['id']],
    style: {
      'stroke-color': 'white',
      'stroke-width': 3,
      'stroke-offset': -1,
      'fill-color': [255, 255, 255, 0.4],
    },
  },
  {
    else: true,
    style: {
      'stroke-color': ['*', ['get', 'COLOR'], [220, 220, 220]],
      'stroke-width': 2,
      'stroke-offset': -1,
      'fill-color': ['*', ['get', 'COLOR'], [255, 255, 255, 0.6]],
    },
  },
  {
    style: {
      'text-value': ['coalesce', ['get', 'ECO_NAME'], 'unknown'],
      'text-font': 'bold 12px "Open Sans", "Arial Unicode MS", sans-serif',
      'text-fill-color': 'rgb(0,0,0)',
      'text-stroke-color': 'rgba(255, 255, 255, 0.8)',
      'text-stroke-width': 2,
      'text-overflow': false,
    },
  },
];

const osm = new TileLayer({
  source: new OSM(),
});

const vectorLayer = new WebGLVectorLayer({
  source: new VectorSource({
    url: 'https://openlayers.org/data/vector/ecoregions.json',
    format: new GeoJSON(),
  }),
  style,
  variables: {
    highlightedId: -1,
  },
});

const map = new Map({
  layers: [osm, vectorLayer],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 1,
  }),
});

let highlightedId = -1;

// Retrieve feature at pixel and update highlightedId variable
// 获取鼠标位置像素要素并更新 highlightedId 样式变量
const displayFeatureInfo = function (pixel) {
  const feature = map.forEachFeatureAtPixel(pixel, function (feature) {
    return feature;
  });

  const info = document.getElementById('info');
  if (feature) {
    info.innerHTML = feature.get('ECO_NAME') || '&nbsp;';
  } else {
    info.innerHTML = 'Hover or click an ecoregion / 悬停或点击生态区以查看名称';
  }

  const id = feature ? feature.getId() : -1;
  if (id !== highlightedId) {
    highlightedId = id;
    vectorLayer.updateStyleVariables({highlightedId});
  }
};

map.on('pointermove', function (evt) {
  if (evt.dragging) {
    return;
  }
  displayFeatureInfo(evt.pixel);
});

map.on('click', function (evt) {
  displayFeatureInfo(evt.pixel);
});
