Tissot Indicatrix / 蒂索变形椭圆与投影失真分析 (Tissot's Indicatrix)

EPSG:4326 (WGS84 等距矩形投影 / Plate Carrée)

EPSG:3857 (Web 墨卡托正形等角投影 / Web Mercator)

Draw Tissot's indicatrices on maps. / 在 EPSG:4326 等经纬度投影与 EPSG:3857 Web 墨卡托投影中绘制真实测地等径圆（蒂索变形椭圆），可视化分析投影的面积膨胀与角度变形。

Example of Tissot indicatrix maps. The map on the top is an EPSG:4326 map. The one on the bottom is EPSG:3857.

此示例展示了制图学中经典的蒂索变形指示线（Tissot's Indicatrix / 蒂索椭圆）。 上方地图采用 EPSG:4326（WGS84 板块方格等距圆柱投影），下方地图采用 EPSG:3857（Web 墨卡托等角正形投影）。 通过在两个地图中均匀绘制半径同为 800 公里的球面真实测地圆，可以清晰直观地对比不同地图投影在不同纬度所造成的面积膨胀与几何形状形变。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 蒂索变形指示线（Tissot's Indicatrix）数学定理： 德国与法国制图学家证明：任何将三维不可展球面投射至二维平面的转换必然产生形变（长度、面积或角度至少有一项发生畸变）。 在地球表面取一个理论上的无穷小微元圆，经过平面投影映射后，在二维图纸上必然呈现为一个椭圆。 通过观察该椭圆的长半轴（$a$）、短半轴（$b$）与旋转主轴方向，可以精确量化该投影在各纬度的形变特征。
  • 等角正形投影（Conformal） vs 等距柱面投影（Equirectangular）的几何差异： - EPSG:3857 (Web 墨卡托)：属于等角正形投影（Conformal），在任意局部点上的各个方向比例尺均严格相等（$a = b$）。因此，所有的球面测地圆在平面上依然呈现为完美的正圆形；但其代价是面积严重失真，面积放大因子随纬度 $\varphi$ 呈 $\sec^2(\varphi)$ 指数级膨胀（格陵兰岛在视觉上看起来与非洲面积相当）。 - EPSG:4326 (Plate Carrée 等距柱面)：经线与纬线均被强制展开为均匀正方形格网。随着纬度向极地升高，纬线圈周长急速收缩，但在投影图上依然被拉扯得与赤道一样宽，导致原本对称的圆形被横向强烈拉长，呈现为扁平椭圆。

2. 源码与关键 API 剖析

  • circularPolygon([x, y], radius, 64) 来自 ol/geom/Polygon.js：利用球面大圆测地线（Geodesic）数学算法，在真实三维球体表面生成具有真实物理半径（800,000 米）的正多边形测地圆。
  • circle4326.clone().transform('EPSG:4326', 'EPSG:3857')：将球面坐标动态转换投影至墨卡托平面空间。

3. 生产实践踩坑与性能调优

  • 极地纬度不可达性（Mercator Singularity）： 墨卡托投影在 $\pm 90^\circ$ 极点处的数学展开值为无穷大，Web 墨卡托的有效纬度被限定在 $\pm 85.051129^\circ$ 以内。在循环生成测地圆时，高纬度圆的边缘可能会跨越极限纬度，导致计算异常，生产中需控制采样纬度上限。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {circular as circularPolygon} from 'ol/geom/Polygon.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import TileWMS from 'ol/source/TileWMS.js';
import VectorSource from 'ol/source/Vector.js';

// Vector layers to hold Tissot indicatrices for both projections
// 用于存放两个投影对应蒂索变形椭圆要素的矢量图层
const vectorLayer4326 = new VectorLayer({
  source: new VectorSource(),
});

const vectorLayer3857 = new VectorLayer({
  source: new VectorSource(),
});

// Map 1: WGS84 Equirectangular / Plate Carrée projection (EPSG:4326)
// 第一个地图实例：基于 WGS84 等距矩形圆柱投影（EPSG:4326）
const map4326 = new Map({
  layers: [
    new TileLayer({
      source: new TileWMS({
        url: 'https://ahocevar.com/geoserver/wms',
        params: {
          'LAYERS': 'ne:NE1_HR_LC_SR_W_DR',
          'TILED': true,
        },
      }),
    }),
    vectorLayer4326,
  ],
  target: 'map4326',
  view: new View({
    projection: 'EPSG:4326',
    center: [0, 0],
    zoom: 2,
  }),
});

// Map 2: Web Mercator conformal projection (EPSG:3857)
// 第二个地图实例：基于 Web 墨卡托正形等角投影（EPSG:3857）
const map3857 = new Map({
  layers: [
    new TileLayer({
      source: new TileWMS({
        url: 'https://ahocevar.com/geoserver/wms',
        params: {
          'LAYERS': 'ne:NE1_HR_LC_SR_W_DR',
          'TILED': true,
        },
      }),
    }),
    vectorLayer3857,
  ],
  target: 'map3857',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// Radius of geodesic circles: 800,000 meters (800 km)
// 测地等径圆真实半径：800,000 米（800 公里）
const radius = 800000;
let x, y;

// Generate geodesic circles across global longitude and latitude grid (step: 30 degrees)
// 沿全球经纬网格（步长 30 度）循环生成真实的球面测地圆
for (x = -180; x < 180; x += 30) {
  for (y = -90; y <= 90; y += 30) {
    // Generate geodesic circle polygon with 64 vertices on the WGS84 ellipsoid
    // 在 WGS84 椭球体上生成具有 64 个顶点的测地圆多边形
    const circle4326 = circularPolygon([x, y], radius, 64);
    // Clone and transform geometry into EPSG:3857 projected coordinate space
    // 克隆该几何多边形并将其坐标转换至 EPSG:3857 墨卡托投影平面
    const circle3857 = circle4326.clone().transform('EPSG:4326', 'EPSG:3857');
    vectorLayer4326.getSource().addFeature(new Feature(circle4326));
    vectorLayer3857.getSource().addFeature(new Feature(circle3857));
  }
}
