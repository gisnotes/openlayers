Sea Level (with WebGL) / WebGL 海平面上升淹没模拟与 DEM 高程着色器计算

webgl19 math1 flood2


Go to / 快速跳转城市： San Francisco / 旧金山, New York / 纽约, Mumbai / 孟买, or Shanghai / 上海

Render sea level at different elevations. / 使用 WebGLTile 动态解码 RGB 地形高程瓦片，结合着色器数学表达式模拟不同海平面上升高度下的淹没区域。

The style property of a WebGL tile layer accepts a color expression that can be used to modify pixel values before rendering. Here, RGB tiles representing elevation data are loaded and rendered so that values at or below sea level are blue, and values above sea level are transparent. The color expression operates on normalized pixel values ranging from 0 to 1. The band operator is used to select normalized values from a single band.

After converting the normalized RGB values to elevation, the case expression is used to pick colors to apply at a given elevation. Instead of using constant numeric values as the stops in the colors array, the var operator allows you to use a value that can be modified by your application. When the user drags the sea level slider, the layer.updateStyleVariables() function is called to update the level style variable with the value from the slider.

WebGL 瓦片图层的 style 配置接收声明式 color 表达式，可在最终渲染前在 GPU 片元着色器中实时处理每个像素。本例加载了经过 Terrain-RGB 编码的高程栅格切片：低于或等于当前模拟海平面的像素被渲染为水体蓝色，高于海平面的陆地像素则被设为完全透明。表达式中的 band 操作符提取对应波段的归一化像素值（范围 0 到 1）。

将归一化的 RGB 值通过数学公式反算还原为真实海拔高程后，利用 case 条件分支表达式确定当前高程的显示色彩。借助 var 操作符，应用程序可动态传入外部样式变量。用户拖动海平面滑块时，调用 layer.updateStyleVariables() 即可毫秒级动态刷新 level 变量，直观模拟暴雨洪水或海平面上升对各沿海主要城市的淹没态势。

📚 学习记录与技术深度解读 (Learning Notes)

1. Terrain-RGB 高程编码与着色器波段解算（Band Math）

  • 编码原理：MapTiler / Mapbox 的 Terrain-RGB 协议利用 24 位 RGB 颜色通道存储高精度 DEM 高程： $$Elevation = -10000 + (R \times 256 \times 256 + G \times 256 + B) \times 0.1$$
  • 着色器归一化系数适配： 由于 WebGL 的 ['band', n] 取出的像素强度已自动归一化到 $[0, 1]$，因此在着色器数学表达式中需要额外乘以 $255$ 还原字节分量：
    • R 分量权重：$0.1 \times 255 \times 256 \times 256 = 1671168$
    • G 分量权重：$0.1 \times 255 \times 256 = 6528$
    • B 分量权重：$0.1 \times 255 = 25.5$
    • 常数偏移：$-10000$

2. GPU 条件分支与动态水体遮罩

  • 零重绘开销：传统方式计算淹没图需要后端 GIS 引擎执行栅格代数切图。而在 WebGL 中，['case', ['<=', elevation, ['var', 'level']], [139, 212, 255, 1], [139, 212, 255, 0]] 在片元着色器内部直接完成逐像素测试，拖拽滑块时帧率稳定在 60 FPS。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import {fromLonLat} from 'ol/proj.js';
import ImageTile from 'ol/source/ImageTile.js';

const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Band math operates on normalized values from 0-1, so we scale by 255 to align with elevation formula
// 着色器波段数学运算使用 0-1 范围的归一化像素值，因此乘以 255 对齐 Terrain-RGB 真实海拔反算公式
const elevation = [
  '+',
  -10000,
  ['*', 0.1 * 255 * 256 * 256, ['band', 1]],
  ['*', 0.1 * 255 * 256, ['band', 2]],
  ['*', 0.1 * 255, ['band', 3]],
];

const layer = new TileLayer({
  opacity: 0.6,
  source: new ImageTile({
    url:
      'https://api.maptiler.com/tiles/terrain-rgb-v2/{z}/{x}/{y}.webp?key=' +
      key,
    tileSize: 512,
    maxZoom: 14,
  }),
  style: {
    variables: {
      level: 0,
    },
    color: [
      'case',
      // Use the `level` style variable to determine color (blue if submerged, transparent otherwise)
      // 使用 `level` 样式变量判断像素颜色（被水淹没区域显示为蓝色，陆地部分完全透明）
      ['<=', elevation, ['var', 'level']],
      [139, 212, 255, 1],
      [139, 212, 255, 0],
    ],
  },
});

const map = new Map({
  target: 'map',
  layers: [
    new TileLayer({
      source: new ImageTile({
        url:
          'https://api.maptiler.com/maps/streets-v2/{z}/{x}/{y}.png?key=' + key,
        attributions: attributions,
        tileSize: 512,
        maxZoom: 22,
      }),
    }),
    layer,
  ],
  view: new View({
    center: fromLonLat([-122.3267, 37.8377]),
    zoom: 11,
  }),
});

const control = document.getElementById('level');
const output = document.getElementById('output');
control.addEventListener('input', function () {
  output.innerText = control.value;
  layer.updateStyleVariables({level: parseFloat(control.value)});
});
output.innerText = control.value;

const locations = document.getElementsByClassName('location');
for (let i = 0, ii = locations.length; i < ii; ++i) {
  locations[i].addEventListener('click', relocate);
}

// Quick jump to city coordinates / 快速跳转至指定城市中心点
function relocate(event) {
  const data = event.target.dataset;
  const view = map.getView();
  view.setCenter(fromLonLat(data.center.split(',').map(Number)));
  view.setZoom(Number(data.zoom));
}
