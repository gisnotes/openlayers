NDVI from a COG with a raster source / 使用 Raster 数据源计算 COG 的 NDVI

cog16 ndvi4 raster7

NDVI at pointer / 光标处 NDVI 数值:  

Running a pixel operation over multi-band data tiles. / 基于 ol/source/Raster 在 Web Worker 多线程中执行像素级运算计算 NDVI。

This example computes the Normalized Difference Vegetation Index (NDVI) from two Sentinel 2 bands using an ol/source/Raster operation. The raster source takes a GeoTIFF data tile source as input, samples it at its native tile resolution, and runs a pixel operation that maps NDVI to a color ramp. The map view is in Web Mercator, so the operation runs in the source's own projection and its result is reprojected to the view - the OSM base layer shows the alignment. Compare with the NDVI from a Sentinel 2 COG example, which uses a WebGL layer style instead. Move the pointer over the map to read the NDVI value from the source's getData() lookup. 本示例使用 ol/source/Raster 像元算子从两个哨兵 2 号波段中计算归一化植被指数（NDVI）。 栅格数据源将 GeoTIFF 数据瓦片源作为输入，按其原生瓦片分辨率进行像元采样，并在后台线程执行像素级算法，将计算出的 NDVI 映射到色带中。 地图视图采用 Web 墨卡托投影（EPSG:3857），运算在数据源自身投影（UTM）中执行，运算结果动态重投影至地图视图——底部的 OSM 图层印证了严密的坐标吻合度。 可与 基于哨兵 2 号 COG 计算 NDVI 示例进行对比，后者采用 WebGL 图层声明式着色器实现。 移动鼠标指针，可以通过数据源的 getData() 查询当前坐标下的实际 NDVI 数值。

📚 学习记录与技术深度解读 (Learning Notes)

1. 架构对比：ol/layer/WebGLTile (GPU) vs ol/source/Raster (CPU Web Worker) 在 OpenLayers 中处理遥感影像像元计算有两种经典技术架构：

| 对比维度 | WebGL 着色器架构 (WebGLTile) | 栅格算子流水线 (RasterSource) | | :--- | :--- | :--- | | 计算单元 | GPU 显卡片元着色器 (Fragment Shader) | CPU 多线程 Web Worker | | 算法表达方式 | 声明式 AST 表达式树（编译为 GLSL） | 原生 JavaScript 任意数学函数与逻辑 | | 算法复杂度上限 | 适合纯数学/矩阵运算，难以执行复杂循环、递归或图搜索 | 无限制，支持任意复杂算法（如区域生长、连通域分析、形态学滤波） | | 性能特点 | 百万像素每秒 60 FPS 瞬时刷新，适合交互调参 | 后台异步计算，计算密集时可能有轻微延迟，适合复杂特征提取 | | 投影与图层类型 | 直接在 GPU 贴图中采样重投影 | 输出为客户端单张动态图像 (ol/layer/Image) |

2. ol/source/Raster 的 Web Worker 通信机制 * 代码注入与序列化：

由于 Web Worker 运行在独立的 JavaScript 线程中，无法直接访问主线程的作用域。 RasterSource 提供了专门的 lib 选项：

const raster = new RasterSource({
  sources: [cog],
  operation: ndviToColor,
  lib: { colorFromRamp: colorFromRamp }, // 注入到 Worker 内部的辅助函数
});

OpenLayers 会在 Worker 启动时将 operation 与 lib 内的函数转为字符串传输并在子线程中 eval 恢复。

  • beforeoperations 事件： 用于在每轮瓦片计算前，向 Worker 传递外部数据字典（如颜色渐变阈值数组 data.stops）。

3. 拾取像元数值：raster.getData(coordinate) 通过 raster.getData(event.coordinate)，直接传入地理坐标，OpenLayers 会自动定位到底层对应的 Float32Array 像元数组，取得 Red 与 NIR 原始辐射反射率，在主线程实时算出精确浮点 NDVI。

main.js 
import Map from 'ol/Map.js';
import ImageLayer from 'ol/layer/Image.js';
import GeoTIFF from 'ol/source/GeoTIFF.js';
import RasterSource from 'ol/source/Raster.js';

// `normalize: false` keeps the raw 16-bit reflectance as Float32Array data, so
// the operation runs the NDVI math on the actual band values.
// `normalize: false` 保留原始 16 位反射率数据为 Float32Array，使像素算子能够基于真实辐射度数值计算 NDVI。
const cog = new GeoTIFF({
  normalize: false,
  sources: [
    {
      // Visible red / 可见光红光
      url: 'https://sentinel-cogs.s3.us-west-2.amazonaws.com/sentinel-s2-l2a-cogs/36/Q/WD/2020/7/S2A_36QWD_20200701_0_L2A/B04.tif',
    },
    {
      // Near infrared / 近红外
      url: 'https://sentinel-cogs.s3.us-west-2.amazonaws.com/sentinel-s2-l2a-cogs/36/Q/WD/2020/7/S2A_36QWD_20200701_0_L2A/B08.tif',
    },
  ],
});

// NDVI color ramp, handed to the operation in "beforeoperations".
// NDVI 颜色渐变阶梯，在 "beforeoperations" 事件中传递给后台算子。
const ndviStops = [
  -0.2,
  [191, 191, 191],
  -0.1,
  [219, 219, 219],
  0,
  [255, 255, 224],
  0.025,
  [255, 250, 204],
  0.05,
  [237, 232, 181],
  0.075,
  [222, 217, 156],
  0.1,
  [204, 199, 130],
  0.125,
  [189, 184, 107],
  0.15,
  [176, 194, 97],
  0.175,
  [163, 204, 89],
  0.2,
  [145, 191, 82],
  0.25,
  [128, 179, 71],
  0.3,
  [112, 163, 64],
  0.35,
  [97, 150, 54],
  0.4,
  [79, 138, 46],
  0.45,
  [64, 125, 36],
  0.5,
  [48, 110, 28],
  0.55,
  [33, 97, 18],
  0.6,
  [15, 84, 10],
  0.65,
  [0, 69, 0],
];

/**
 * Map a value to an `[r, g, b, a]` color using a ramp of `value, [r, g, b]` stops.
 * 将数值通过 `[value, [r, g, b]]` 梯度插值为 `[r, g, b, a]` 颜色。
 * @param {number} value The value to map.
 * @param {Array<number|Array<number>>} stops Flat `value, color` ramp stops.
 * @return {Array<number>} The `[r, g, b, a]` color.
 */
function colorFromRamp(value, stops) {
  if (value <= stops[0]) {
    const first = stops[1];
    return [first[0], first[1], first[2], 255];
  }
  for (let i = 2; i < stops.length; i += 2) {
    if (value <= stops[i]) {
      const lowValue = stops[i - 2];
      const lowColor = stops[i - 1];
      const highValue = stops[i];
      const highColor = stops[i + 1];
      const f = (value - lowValue) / (highValue - lowValue);
      return [
        lowColor[0] + f * (highColor[0] - lowColor[0]),
        lowColor[1] + f * (highColor[1] - lowColor[1]),
        lowColor[2] + f * (highColor[2] - lowColor[2]),
        255,
      ];
    }
  }
  const last = stops[stops.length - 1];
  return [last[0], last[1], last[2], 255];
}

/**
 * Compute NDVI from the two input bands and map it through the color ramp.
 * 从两个输入波段中计算 NDVI 并通过色带映射出颜色。
 * @param {Array<Array<number>>} pixels One pixel per input source / 每个输入源的一个像素
 * @param {Object} data The object populated in the "beforeoperations" event / 在 beforeoperations 中注入的数据
 * @return {Array<number>} An `[r, g, b, a]` pixel.
 */
function ndviToColor(pixels, data) {
  const red = pixels[0][0];
  const nir = pixels[0][1];
  const sum = nir + red;
  if (!sum) {
    // Transparent outside the data / 数据有效范围之外设为全透明
    return [0, 0, 0, 0];
  }
  return colorFromRamp((nir - red) / sum, data.stops);
}

// Create RasterSource running calculation in Web Workers
// 创建在 Web Worker 多线程中执行像元算子的 RasterSource
const raster = new RasterSource({
  sources: [cog],
  operation: ndviToColor,
  // Functions in the `lib` object are available to the operation in the worker.
  // lib 中的辅助函数会被序列化并注入到 Web Worker 子线程中供算子调用
  lib: {
    colorFromRamp: colorFromRamp,
  },
});

raster.on('beforeoperations', (event) => {
  event.data.stops = ndviStops;
});

const map = new Map({
  target: 'map',
  layers: [new ImageLayer({source: raster})],
  view: cog.getView(),
});

// getData() returns the input band values at a coordinate, so we can compute
// and show the NDVI value the color above was derived from.
// getData() 返回指定地理坐标处的输入波段值，供主线程计算并展示光标下的精确 NDVI 数值
const output = document.getElementById('output');
map.on(['pointermove', 'click'], function (event) {
  const pixels = raster.getData(event.coordinate);
  if (!pixels) {
    output.textContent = ' ';
    return;
  }
  const [red, nir] = pixels[0];
  const sum = nir + red;
  output.textContent = sum ? ((nir - red) / sum).toFixed(2) : ' ';
});
