Icon Sprites with WebGL / WebGL 图标精灵图（Sprite Atlas）海量点渲染

webgl19 icon10 sprite2 point2 ufo1

Current sighting / 当前目击信息：None / 暂无

Rendering many icons with WebGL. / 使用 WebGL 矢量图层配合纹理图集（Sprite Atlas）高效渲染 8 万个 UFO 目击事件点位。

This example shows how to use ol/layer/WebGLVector to render a very large amount of sprites. The above map is based on a dataset from the National UFO Reporting Center: each icon marks a UFO sighting according to its reported shape (disk, light, fireball...). The older the sighting, the redder the icon.

A very simple sprite atlas is used in the form of a PNG file containing all icons on a grid. Then, the style object given to the ol/layer/WebGLVector constructor is used to specify which sprite to use according to the sighting shape.

The dataset contains around 80k points and can be found here: https://www.kaggle.com/NUFORC/ufo-sightings

本示例展示如何利用 ol/layer/WebGLVector 渲染海量图标精灵（Sprites）。地图数据来源于美国国家不明飞行物报告中心（NUFORC）记录的约 8 万条目击事件：每个图标根据目击报告的几何外形（如圆盘形、光点、火球、椭圆形等）显示不同的精灵贴图。目击年份越早，图标颜色在着色器中被插值渲染得越偏红。

图层通过一张轻量的 PNG 精灵纹理图集（Sprite Atlas，将各种形态图标规整排布在一个网格图像中），随后在 WebGL 样式表达式中利用 match 算子根据要素的 shape 属性动态映射对应的纹理偏移量（icon-offset），免除频繁切换纹理绑定的 GPU 开销。

📚 学习记录与技术深度解读 (Learning Notes)

1. 纹理图集（Sprite Atlas / Texture Atlas）在 WebGL 中的核心优势

  • 批处理与 Draw Call 优化：在标准 WebGL 渲染管线中，如果 8 万个点位使用多张分散的图片贴图，每次更换图片都必须触发 gl.bindTexture 并拆分 Draw Call，导致严峻的 CPU/GPU 切换开销。
  • UV 纹理子域采样：通过将所有图标打包到一张 128x64 像素的贴图网格中，并配置 icon-size: [32, 32] 以及基于属性匹配的 icon-offset（如 light: [0, 0], sphere: [32, 0], fireball: [0, 32]），着色器在单次批处理中仅通过调整纹理坐标（UV Coordinates）即可渲染完全不同形态的图标。

2. GPU 片元色彩插值（Color Tinting）

  • 样式中直接使用 icon-color: ['interpolate', ['linear'], ['get', 'year'], 1950, oldColor, 2013, newColor]，在片元着色器中将纹理灰度与目标颜色进行乘法调制（Texture Tinting），无需生成数十种不同颜色的预制图片。

3. 拾取交互与动态属性过滤

  • 借助 map.forEachFeatureAtPixel 在海量点下高效检索鼠标悬停命中要素。
  • 配合 updateStyleVariables({filterShape}) 在着色器层面毫秒级完成按特定外形（如盘状、球状）实时筛选显示。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Point from 'ol/geom/Point.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import WebGLVectorLayer from 'ol/layer/WebGLVector.js';
import {fromLonLat} from 'ol/proj.js';
import ImageTile from 'ol/source/ImageTile.js';
import VectorSource from 'ol/source/Vector.js';

const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

const map = new Map({
  layers: [
    new TileLayer({
      source: new ImageTile({
        attributions: attributions,
        url:
          'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
      }),
    }),
  ],
  target: document.getElementById('map'),
  view: new View({
    center: [0, 4000000],
    zoom: 2,
  }),
});

const oldColor = [255, 160, 110];
const newColor = [180, 255, 200];

// WebGL literal style with sprite atlas offset mapping and color interpolation
// WebGL 字面量样式：结合精灵图偏移映射与年份颜色插值
const style = {
  'icon-src': 'data/ufo_shapes.png',
  'icon-width': 128,
  'icon-height': 64,
  'icon-color': [
    'interpolate',
    ['linear'],
    ['get', 'year'],
    1950,
    oldColor,
    2013,
    newColor,
  ],
  'icon-offset': [
    'match',
    ['get', 'shape'],
    'light',
    [0, 0],
    'sphere',
    [32, 0],
    'circle',
    [32, 0],
    'disc',
    [64, 0],
    'oval',
    [64, 0],
    'triangle',
    [96, 0],
    'fireball',
    [0, 32],
    [96, 32],
  ],
  'icon-size': [32, 32],
  'icon-scale': 0.5,
};

const pointsLayer = new WebGLVectorLayer({
  variables: {
    filterShape: 'all',
  },
  source: new VectorSource({
    features: [],
    attributions: 'National UFO Reporting Center',
  }),
  style: [
    {
      style,
      filter: [
        'any',
        ['==', ['var', 'filterShape'], 'all'],
        ['==', ['var', 'filterShape'], ['get', 'shape']],
      ],
    },
  ],
});

const shapeSelect = document.getElementById('shape-filter');
shapeSelect.addEventListener('input', function () {
  pointsLayer.updateStyleVariables({filterShape: shapeSelect.value});
  map.render();
});

function fillShapeSelect(shapeTypes) {
  Object.keys(shapeTypes)
    .sort(function (a, b) {
      return shapeTypes[b] - shapeTypes[a];
    })
    .forEach(function (shape) {
      const option = document.createElement('option');
      const sightings = shapeTypes[shape];
      const displayName = shape === 'all' ? 'All shapes / 全部形态' : shape;
      option.text = `${displayName} (${sightings} sighting${
        sightings === 1 ? '' : 's'
      } / 次)`;
      option.value = shape;
      shapeSelect.appendChild(option);
    });
}

// Load UFO sightings CSV dataset (approx 80k points)
// 异步读取 UFO 目击事件 CSV 数据集（约 8 万条记录）
const client = new XMLHttpRequest();
client.open('GET', 'data/csv/ufo_sighting_data.csv');
client.addEventListener('load', function () {
  const csv = client.responseText;
  // Key is shape name, value is sightings count / 统计各形态频次
  const shapeTypes = {};
  const features = [];

  let prevIndex = csv.indexOf('\n') + 1; // Scan past header line / 跳过表头
  let curIndex;
  while ((curIndex = csv.indexOf('\n', prevIndex)) !== -1) {
    const line = csv.substring(prevIndex, curIndex).split(',');
    prevIndex = curIndex + 1;

    const coords = [parseFloat(line[5]), parseFloat(line[4])];
    const shape = line[2];
    shapeTypes[shape] = (shapeTypes[shape] || 0) + 1;

    features.push(
      new Feature({
        datetime: line[0],
        year: parseInt(/[0-9]{4}/.exec(line[0])[0], 10), // Extract year as int / 提取目击年份
        shape: shape,
        duration: line[3],
        geometry: new Point(fromLonLat(coords)),
      }),
    );
  }
  shapeTypes['all'] = features.length;
  pointsLayer.getSource().addFeatures(features);
  map.addLayer(pointsLayer);
  fillShapeSelect(shapeTypes);
});
client.send();

// Feature hover hit detection / 鼠标移动要素拾取探测
const info = document.getElementById('info');
map.on('pointermove', function (evt) {
  if (map.getView().getInteracting() || map.getView().getAnimating()) {
    return;
  }
  const text = map.forEachFeatureAtPixel(evt.pixel, function (feature) {
    const datetime = feature.get('datetime');
    const duration = feature.get('duration');
    const shape = feature.get('shape');
    return `On ${datetime}, lasted ${duration} seconds and had a "${shape}" shape. / 时间：${datetime}，持续 ${duration} 秒，形态为 "${shape}"。`;
  });
  info.innerText = text || 'None / 暂无';
});
