IGN WMTS / 法国国家地理 IGN 官方 WMTS 底图服务

french1 ign1 geoportail1 wmts7 grid8

Demonstrates displaying IGN (France) WMTS layers. / 演示如何接入并展示法国国家地理信息与林业局（IGN Géoportail / Géoplateforme）官方 WMTS 影像与地图切片。

In this example an IGN WMTS layer is displayed. For more information on IGN's WMTS service see the IGN Géoportail API web page and Documentation de l’offre de données et services de l’IGN (french).

本示例展示了如何接入法国国家地理与林业信息局（IGN - Institut national de l'information géographique et forestière）通过其国家地理平台（Géoplateforme / Géoportail）提供的官方标准 WMTS 瓦片服务。更多法国官方地理底图接口文档与数据说明，请参阅 IGN Géoportail API 官网 与 IGN 数据与服务产品文档（法语）。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计思想 (Core Architecture & Design)

  • 国家级 GIS 开放服务架构： 法国 IGN 维护了欧洲最高精度且完全开放的国家地理基底数据，其全新平台（Géoplateforme data.geopf.fr）通过 OGC WMTS 向公众免费免 Key 提供高分辨率标准底图 PLANIGNV2。
  • 切片网格与分辨率层级定义： IGN 采用标准的 Web 墨卡托投影（EPSG:3857），切片网格集合标识符为 PM（Pseudo-Mercator）。其瓦片网格矩阵集定义了从 0 级到 19 级的 20 个缩放金字塔层级，原点为标准墨卡托左上角 [-20037508, 20037508]。

2. 源码与关键 API 剖析 (Source Code & API Analysis)

  • matrixSet: 'PM'： 指定法国 IGN 服务端注册的墨卡托切片矩阵集名称（注意并非默认的 EPSG:3857 或 GoogleMapsCompatible，这是接入 IGN 服务最核心的协议参数）。
  • attributions 品牌与法定义务合规标识： 根据法国知识产权法及开放数据条款，加载官方底图时必须渲染 IGN 官方标志与版权链接。OpenLayers 允许在 attributions 中直接传入富文本 HTML 标签，自动在地图右下角合规展示。

3. 生产实践踩坑与性能调优 (Production Pitfalls & Optimization)

  • 旧版 API 域名迁移（wxs.ign.fr $\rightarrow$ data.geopf.fr）： 早期 IGN 服务运行在 wxs.ign.fr 且需要申请专用 API Key 拼接在 URL 中；现已全面升级为法国国家地理云平台 https://data.geopf.fr/wmts，采用免 Key 开放访问模式，迁移时切勿继续沿用过时的旧域名。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {getWidth} from 'ol/extent.js';
import TileLayer from 'ol/layer/Tile.js';
import {fromLonLat, get as getProjection} from 'ol/proj.js';
import WMTS from 'ol/source/WMTS.js';
import WMTSTileGrid from 'ol/tilegrid/WMTS.js';

const map = new Map({
  target: 'map',
  view: new View({
    zoom: 5,
    center: fromLonLat([5, 45]),
  }),
});

const resolutions = [];
const matrixIds = [];
const proj3857 = getProjection('EPSG:3857');
const maxResolution = getWidth(proj3857.getExtent()) / 256;

for (let i = 0; i < 20; i++) {
  matrixIds[i] = i.toString();
  resolutions[i] = maxResolution / Math.pow(2, i);
}

const tileGrid = new WMTSTileGrid({
  origin: [-20037508, 20037508],
  resolutions: resolutions,
  matrixIds: matrixIds,
});

const ign_source = new WMTS({
  url: 'https://data.geopf.fr/wmts',
  layer: 'GEOGRAPHICALGRIDSYSTEMS.PLANIGNV2',
  matrixSet: 'PM',
  format: 'image/png',
  projection: 'EPSG:3857',
  tileGrid: tileGrid,
  style: 'normal',
  attributions:
    '<a href="https://www.ign.fr/" target="_blank">' +
    '<img src="https://data.geopf.fr/annexes/ressources/logos/ign.gif" title="Institut national de l\'' +
    'information géographique et forestière" alt="IGN"></a>',
});

const ign = new TileLayer({
  source: ign_source,
});

map.addLayer(ign);
