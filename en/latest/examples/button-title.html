Custom Tooltips / 自定义按钮提示（Bootstrap Tooltip）

custom7 tooltip2

This example shows how to customize the buttons tooltips with Bootstrap. / 展示如何使用 Bootstrap 定制地图控件按钮的悬浮提示工具（Tooltips）。

This example shows how to customize the buttons tooltips with Bootstrap. For the tooltips to work in fullscreen mode, set the container property to a selector that matches the map target. 本示例展示如何使用 Bootstrap 自定义 OpenLayers 地图控件按钮的悬停提示气泡（Tooltips）。在全屏（Fullscreen）模式下，必须将 Tooltip 的 container 属性指定为匹配地图容器的选择器（如 #map），确保提示气泡不会被全屏伪类层级或顶层容器遮挡。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构原理 (Core Architecture) OpenLayers 默认通过原生 DOM 元素的 title 属性实现基础的浏览器原生鼠标悬浮提示。原生 title 存在延迟长、样式无法统一定制、在各操作系统与移动端交互不一致等缺陷。 - DOM 挂载与全屏隔离：Bootstrap 等 UI 库的 Tooltip 默认挂载到 document.body。当地图进入全屏模式（Fullscreen API）时，由于全屏伪元素（:fullscreen）将地图容器提升为独立顶层渲染层，挂载到 body 上的元素会被完全遮蔽或不可见。因此必须通过 container: '#map' 将悬停气泡插入地图容器 DOM 树内。 - 控件类名规范：OpenLayers 核心内置控件均带有一致的 BEM 风格样式类：

  • 放大按钮：.ol-zoom-in
  • 缩小按钮：.ol-zoom-out
  • 指北重置：.ol-rotate-reset
  • 属性控件：.ol-attribution button 通过标准选择器可无侵入地为原生控件附加现代化交互框架的弹窗组件。

2. 关键实现与代码拆解 (Code Deep Dive) ```javascript // Query standard control buttons and bind Bootstrap Tooltips // 查询标准控件按钮并批量初始化 Bootstrap Tooltip document

.querySelectorAll('.ol-zoom-in, .ol-zoom-out, .ol-rotate-reset') .forEach(function (el) { new bootstrap.Tooltip(el, { container: '#map', // Crucial for Fullscreen API: append within the map DOM / 全屏模式关键：挂载至地图容器内部 }); });

#### 3. 生产实战避坑与考量 (Production Pitfalls) - <strong>动态销毁与内存泄漏</strong>：在 SPA 单页应用中，若地图组件频繁挂载与卸载，Bootstrap Tooltip 实例需在组件销毁钩子中显式调用 <code>tooltip.dispose()</code>，否则游离的 DOM 事件监听会导致内存泄漏。 - <strong>移动端触控优化</strong>：移动端设备上长按或点击可能导致 Tooltip 滞留不散，生产环境建议配置 <code>trigger: 'hover'</code> 或在触屏设备上通过媒体查询 <code>(hover: none)</code> 动态禁用 Tooltip。 - <strong>无障碍访问（a11y）兼容</strong>：替换 Tooltip 时切勿直接清空元素的 <code>aria-label</code> 属性，保持读屏软件依然可正常播报按钮功能。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';

// Initialize map with an initial rotation
// 初始化带有初始旋转角的地图实例
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: new View({
    center: [-8730000, 5930000],
    rotation: Math.PI / 5,
    zoom: 8,
  }),
});

// Query default control buttons and bind Bootstrap Tooltips
// 查找默认缩放和旋转重置按钮，挂载 Bootstrap Tooltip 提示组件
document
  .querySelectorAll('.ol-zoom-in, .ol-zoom-out, .ol-rotate-reset')
  .forEach(function (el) {
    new bootstrap.Tooltip(el, {
      container: '#map', // Ensure tooltips display properly in fullscreen mode / 确保全屏模式下提示依然能够正常显示在地图容器内
    });
  });
