Shared Views / 共享视图多屏联动 (Shared Views)

side-by-side1 xyz6 maptiler26

Road (道路路网)

Aerial (卫星航拍)

Two maps share view properties. / 演示两个独立的地图实例共享同一个 View 对象，实现道路底图与卫星影像的高性能无缝双屏联动。

Two maps (one Road, one Aerial) share the same center, resolution and rotation.

在此示例中，两个完全独立的地图容器（左侧为标准道路底图，右侧为高分辨率卫星航拍影像）共享同一个 ol/View 视图实例。无论用户在任意一个分屏中进行鼠标拖拽平移、滚轮缩放还是按住 Shift 旋转，两个地图都能以 60FPS 的渲染帧率绝对零延迟完美同步。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 视图模型与渲染容器的彻底解耦（Decoupled View Pattern）： 在 OpenLayers 的底层设计中，ol/Map 本质上是 DOM 容器、交互控制器（Interactions）和图层渲染管线（Layer Renderers）的宿主；而 ol/View 则是一个纯粹的二维几何视口数学模型（封装了空间坐标系、分辨率、中心点与旋转状态）。 因此，一个 View 实例可以被同时注入到任意数量的 Map 实例中。
  • 零延迟与防死锁优势（Zero-Latency Synchronization）： 传统的多屏地图联动通常采用“事件监听法”——监听 Map A 的 move 事件去命令 Map B setCenter，反之亦然。这种方案不仅需要大量胶水代码来防止“相互触发”的事件死循环，而且由于微任务队列与帧渲染调度时差，鼠标拖拽时总会有明显的“拖影”与“迟滞感”。 而共享同一个 View 实例时，底层的属性变更直接通知两个 Map 的渲染器在同一个 requestAnimationFrame 周期内完成画布绘制，达到了性能与体验的极致。

2. 源码与关键 API 剖析

  • const view = new View({ center, zoom })：统一声明唯一的视口状态控制器。
  • new Map({ target: 'roadMap', layers: [roadLayer], view: view }) 与 new Map({ target: 'aerialMap', layers: [aerialLayer], view: view })：将同一视口分别绑定到不同地图容器中。

3. 生产实践踩坑与性能调优

  • 不同图层源的最大缩放级别（MaxZoom）冲突： 道路底图（矢量切片或栅格切片）通常支持到 22 级，而卫星航拍图受限于遥感卫星分辨率，往往只支持到 18~20 级。 当用户放大到 21 级时，卫星图可能会因为找不到瓦片而出现空白。在生产环境中，可配置航拍图层的 maxResolution 或为瓦片源开启重采样插值（Overzoom / Tile Oversampling）。
  • 分屏动态销毁内存泄露： 在业务系统中切换“单屏/双屏对比模式”时，若关闭第二个分屏，必须执行 map2.setTarget(null) 解绑 DOM 容器，并移除不需要的图层，但不要销毁仍然在主屏中运行的共享 view。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import ImageTile from 'ol/source/ImageTile.js';

// MapTiler API Key and attribution notices
// MapTiler API 访问密钥与版权信息
const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Road street map tile layer
// 标准矢量道路路网瓦片图层
const roadLayer = new TileLayer({
  source: new ImageTile({
    attributions: attributions,
    url: 'https://api.maptiler.com/maps/streets-v2/{z}/{x}/{y}.png?key=' + key,
    tileSize: 512,
    maxZoom: 22,
  }),
});

// Aerial satellite imagery tile layer
// 高分辨率卫星遥感航拍图层
const aerialLayer = new TileLayer({
  source: new ImageTile({
    attributions: attributions,
    url: 'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
    tileSize: 512,
    maxZoom: 20,
  }),
});

// Single shared view instance across both maps
// 两张地图全局共享的单一 View 实例，实现原生零延迟联动
const view = new View({
  center: [-6655.5402445057125, 6709968.258934638],
  zoom: 13,
});

// First map instance: displaying Road layer
// 第一个地图实例：渲染道路图层，绑定共享 View
const map1 = new Map({
  target: 'roadMap',
  layers: [roadLayer],
  view: view,
});

// Second map instance: displaying Aerial layer
// 第二个地图实例：渲染卫星航拍图层，绑定同一个 View
const map2 = new Map({
  target: 'aerialMap',
  layers: [aerialLayer],
  view: view,
});
