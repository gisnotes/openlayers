Print to scale example / 按指定比例尺高精打印导出 PDF

print1 printing1 scale4 scaleline2 export4 pdf2 grid8

Example of printing a map to a specified scale. / 按工程制图指定比例尺（如 1:10000 至 1:500000）将地图、比例尺与注记导出为 PDF。

Example of printing a map to a specified scale. The print is exported as a PDF using the jsPDF library. Unlike the Export PDF example the on screen map is only used to set the center and rotation. The extent printed depends on the scale and page size. To print the scale bar and attributions the example uses the html2canvas library.

本示例演示了如何按照工程测绘指定的精确比例尺（如 1:10000、1:25000、1:50000、1:100000、1:250000、1:500000）将地图打印导出为 PDF。 与常规的 Export PDF 示例 不同，屏幕上的实时地图仅用于确定当前视图的中心点与旋转角度；最终打印的物理空间范围由用户选定的真实比例尺与纸张尺寸联合计算决定。此外，示例结合 html2canvas 库，实现了将比例尺标尺（ScaleLine）和版权信息（Attribution）DOM 节点同步无损合成到 PDF 页面中。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 工程测绘级“按比例尺出图”（True Scale Cartographic Output）： 普通网页地图截图仅按屏幕物理视口截取，图上 1 厘米在现实中代表多少米是不确定的。而在自然资源调查、城市规划与土木测绘中，必须保证打印在 A4/A3 纸张上的 1cm 严格对应现实中 100米（1:10,000）或 500米（1:50,000）。
  • 投影变形与真实点分辨率修正（getPointResolution）： 由于墨卡托等投影在不同纬度存在固有的面积与距离拉伸变形，不能直接使用简单的线性常数。OpenLayers 提供了 getPointResolution(projection, resolution, point)，能够根据当前地图中心点的地理纬度，精确求得该纬度下单位米对应的切片像素跨度，保证比例尺换算达到毫米级精度。
  • DOM 控件与 Canvas 画布混合捕获（html2canvas Pipeline）： OpenLayers 的比例尺和版权信息是原生 HTML DOM，而地图内容是 Canvas 画布。通过 html2canvas(map.getViewport(), exportOptions) 将整个视口（包含 Canvas 与绝对定位的 DOM 控件）统一转译为高分辨率图像，实现了地图要素与辅助制图图饰的完美合一。

2. 源码与关键 API 剖析

  • scaleResolution = scale / getPointResolution(projection, resolution / 25.4, center)：标准比例尺换算核心数学公式。将目标比例分母（如 25000）与每毫米像素数（DPI / 25.4）代入点分辨率函数，推导出地图 View 在该打印比例下必须设置的确切分辨率值。
  • scaleLine.setDpi(resolution)：通知 ol/control/ScaleLine 控件当前目标物理 DPI，控件内部自动调整 CSS 像素跨度，使打印出的比例尺线段在实体纸张上测量时分毫不差。
  • exportOptions.ignoreElements：利用样式类名过滤回调，智能屏蔽放大缩小等无关交互控件，仅保留 .ol-scale 比例尺与 .ol-attribution 版权标示。

3. 生产实践踩坑与性能调优

  • 纸张高 DPI 与 DOM 布局延迟： 将 map.getTargetElement().style.width = width + 'px' 动态放大到数千像素后，必须调用 map.updateSize() 迫使引擎刷新视口尺寸，并必须在 map.once('rendercomplete') 回调中触发 html2canvas，否则会截取到空白或切片尚未完全加载的过渡画面。
  • 状态复原保护（Cleanup）： PDF 生成完毕后，必须严格将容器的行内样式清空（style.width = ''）、重设 scaleLine.setDpi(undefined)，并恢复原始 viewResolution，防止屏幕主界面布局错乱。
main.js 
import html2canvas from 'html2canvas';
import {jsPDF} from 'jspdf';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ScaleLine from 'ol/control/ScaleLine.js';
import {defaults as defaultControls} from 'ol/control/defaults.js';
import WMTSCapabilities from 'ol/format/WMTSCapabilities.js';
import TileLayer from 'ol/layer/Tile.js';
import {getPointResolution, get as getProjection} from 'ol/proj.js';
import {register} from 'ol/proj/proj4.js';
import WMTS, {optionsFromCapabilities} from 'ol/source/WMTS.js';
import proj4 from 'proj4';

// Define British National Grid projection (EPSG:27700)
// 定义英国国家网格坐标投影 (EPSG:27700)
proj4.defs(
  'EPSG:27700',
  '+proj=tmerc +lat_0=49 +lon_0=-2 +k=0.9996012717 ' +
    '+x_0=400000 +y_0=-100000 +ellps=airy ' +
    '+towgs84=446.448,-125.157,542.06,0.15,0.247,0.842,-20.489 ' +
    '+units=m +no_defs',
);

register(proj4);

const proj27700 = getProjection('EPSG:27700');
proj27700.setExtent([0, 0, 700000, 1300000]);

const raster = new TileLayer();

const url =
  'https://tiles.arcgis.com/tiles/qHLhLQrcvEnxjtPr/arcgis/rest/services/OS_Open_Raster/MapServer/WMTS';
fetch(url)
  .then(function (response) {
    return response.text();
  })
  .then(function (text) {
    const result = new WMTSCapabilities().read(text);
    const options = optionsFromCapabilities(result, {
      layer: 'OS_Open_Raster',
    });
    options.attributions =
      'Contains OS data © Crown Copyright and database right ' +
      new Date().getFullYear();
    options.crossOrigin = '';
    options.projection = proj27700;
    options.wrapX = false;
    raster.setSource(new WMTS(options));
  });

// Initialize map with EPSG:27700 view
// 初始化地图，采用 EPSG:27700 投影视图
const map = new Map({
  layers: [raster],
  controls: defaultControls({
    attributionOptions: {collapsible: false},
  }),
  target: 'map',
  view: new View({
    center: [373500, 436500],
    projection: proj27700,
    zoom: 7,
  }),
});

// Add scale line control with bar and text
// 添加带分段标尺和文本的比例尺控件
const scaleLine = new ScaleLine({bar: true, text: true, minWidth: 125});
map.addControl(scaleLine);

// Paper dimensions in millimeters
// 纸张物理尺寸规格（单位：毫米）
const dims = {
  a0: [1189, 841],
  a1: [841, 594],
  a2: [594, 420],
  a3: [420, 297],
  a4: [297, 210],
  a5: [210, 148],
};

// Export options for html2canvas
// html2canvas 导出捕获配置选项
const exportOptions = {
  useCORS: true,
  ignoreElements: function (element) {
    const className = element.className || '';
    return (
      className.includes('ol-control') &&
      !className.includes('ol-scale') &&
      (!className.includes('ol-attribution') ||
        !className.includes('ol-uncollapsible'))
    );
  },
};

const exportButton = document.getElementById('export-pdf');

// Export map to PDF at specified scale
// 按指定工程比例尺导出地图为 PDF
exportButton.addEventListener(
  'click',
  function () {
    exportButton.disabled = true;
    document.body.style.cursor = 'progress';

    const format = document.getElementById('format').value;
    const resolution = document.getElementById('resolution').value;
    const scale = document.getElementById('scale').value;
    const dim = dims[format];
    const width = Math.round((dim[0] * resolution) / 25.4);
    const height = Math.round((dim[1] * resolution) / 25.4);
    const viewResolution = map.getView().getResolution();
    // Calculate scale resolution based on point resolution at view center
    // 基于视图中心点的地理点分辨率反求工程比例尺分辨率
    const scaleResolution =
      scale /
      getPointResolution(
        map.getView().getProjection(),
        resolution / 25.4,
        map.getView().getCenter(),
      );

    // Listen for render completion to export with html2canvas
    // 监听渲染完成事件，使用 html2canvas 捕获视口与 DOM 控件
    map.once('rendercomplete', function () {
      exportOptions.width = width;
      exportOptions.height = height;
      html2canvas(map.getViewport(), exportOptions).then(function (canvas) {
        const pdf = new jsPDF('landscape', undefined, format);
        pdf.addImage(
          canvas.toDataURL('image/jpeg'),
          'JPEG',
          0,
          0,
          dim[0],
          dim[1],
        );
        pdf.save('map.pdf');

        // Reset original map size and controls
        // 恢复原始地图尺寸、分辨率与比例尺控件状态
        scaleLine.setDpi(undefined);
        map.getTargetElement().style.width = '';
        map.getTargetElement().style.height = '';
        map.updateSize();
        map.getView().setResolution(viewResolution);
        exportButton.disabled = false;
        document.body.style.cursor = 'auto';
      });
    });

    // Set print size and DPI
    // 应用打印物理尺寸并同步比例尺 DPI
    scaleLine.setDpi(resolution);
    map.getTargetElement().style.width = width + 'px';
    map.getTargetElement().style.height = height + 'px';
    map.updateSize();
    map.getView().setResolution(scaleResolution);
  },
  false,
);
