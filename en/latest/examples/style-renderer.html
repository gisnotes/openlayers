Style renderer / 样式渲染器（自定义渲染函数）

vector86 geojson11 style27 custom6 renderer1

 

Example of a style with a custom renderer. / 使用自定义 renderer 渲染函数的样式示例。

A custom style renderer and a clip path are used to render the flag of a country as fill for the country shape.

使用自定义样式渲染器（Custom Style Renderer）和 Canvas 剪裁路径（Clip Path），将各个国家的国旗图标作为填充图像渲染到对应国家的几何轮廓中。

📚 学习记录与技术解析 (Learning Notes)

1. 核心概念：什么是自定义样式渲染器 (Style 的 renderer)？

  • 传统样式的局限：OpenLayers 默认通过 Fill、Stroke、Icon、Text 等规则定义要素样式，适合常规 GIS 可视化；但当遇到需要任意形状图元剪裁（Clip）、Canvas 纹理混合、粒子动画等高度定制化的视觉效果时，标准样式配置难以满足。
  • 自定义渲染器机制：在 Style 中配置 renderer 回调函数：
    new Style({
  renderer: function (pixelCoordinates, state) { ... }
})
    该函数在地图渲染每一帧时逐要素触发，开发者可以直接获取底层 HTML5 Canvas 2D 上下文（state.context），利用原生 Canvas 2D API 自由操控几何图元的绘制管线。

2. 自定义渲染函数中的关键参数与执行步骤

  • 核心入参：
    • pixelCoordinates：OpenLayers 已预先将该要素的几何坐标转换为当前视图帧下的屏幕像素坐标（Pixel Coordinates），免去了手动投影计算的繁琐步骤。
    • state：当前渲染帧的上下文状态对象，常用属性包括：
      • state.context：当前图层渲染所在的 HTML5 Canvas 2D 绘图上下文（CanvasRenderingContext2D）。
      • state.geometry：要素原始的地理几何对象。
      • state.feature：当前正在渲染的要素实例（Feature）。
  • 关键执行步骤：
    1. 像素坐标映射与边界计算：
      const geometry = state.geometry.clone();
geometry.setCoordinates(pixelCoordinates);
      克隆要素几何体并赋予像素坐标，通过 geometry.getExtent() 快速获得屏幕像素空间的外包矩形，利用 getWidth、getHeight 计算图片宽高，以及通过 getBottomLeft 获取绘制起点。
    2. 上下文状态栈管理 (context.save() / context.restore())： 底层 Canvas 是整个图层共享的，任何剪裁、变换或样式修改都会影响后续绘制。因此在设置剪裁与贴图前必须调用 context.save() 保存状态，绘制完成后必须通过 context.restore() 彻底还原。
    3. 路径构建与几何剪裁 (toContext + context.clip())：
      • 使用 OpenLayers 核心工具 toContext(context) 包装原生 Canvas 绘图上下文。
      • 通过 renderContext.setFillStrokeStyle(fill, stroke) 设置白色轮廓边框样式。
      • 调用 renderContext.drawGeometry(geometry) 绘制国家多边形路径，紧接着执行原生 context.clip()，将后续的绘制区域精确锁定在该国家多边形轮廓范围之内。
    4. 国旗图片贴图绘制 (context.drawImage())： 调用原生 context.drawImage(flag, left, bottom, width, height) 在外包矩形内绘制国旗图片。得益于先前的 clip() 剪裁路径，超出国家边界的图片内容被自动遮罩截除，呈现出与国家轮廓严丝合缝的国旗填充效果。

3. 动态图片加载与要素更新时机

  • 按需拉取国旗：在矢量数据源（VectorSource）上监听 addfeature 事件。国家要素加载解析完成后，根据其两字母代码（iso_a2）向 FlagCDN 异步请求对应的国旗图片。
  • 属性变更触发重绘：图片加载完成时（img.onload），执行 feature.set('flag', img) 将图片实例挂载到要素上。在 OpenLayers 中，调用 feature.set() 会自动触发要素变更事件（change），通知图层发起重新渲染，使得自定义 renderer 在下一帧中获取到国旗图片并完成绘制。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {getBottomLeft, getHeight, getWidth} from 'ol/extent.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import VectorLayer from 'ol/layer/Vector.js';
import {toContext} from 'ol/render.js';
import VectorSource from 'ol/source/Vector.js';
import Fill from 'ol/style/Fill.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

// Fill and stroke for the country outline
// 国家边界轮廓的填充与描边样式
const fill = new Fill();
const stroke = new Stroke({
  color: 'rgba(255,255,255,0.8)',
  width: 2,
});

// Custom style with a canvas renderer function
// 带有自定义 Canvas 渲染器函数（renderer）的样式
const style = new Style({
  renderer: function (pixelCoordinates, state) {
    const context = state.context;
    const geometry = state.geometry.clone();
    geometry.setCoordinates(pixelCoordinates);
    const extent = geometry.getExtent();
    const width = getWidth(extent);
    const height = getHeight(extent);
    const flag = state.feature.get('flag');
    if (!flag || height < 1 || width < 1) {
      return;
    }

    // Stitch out country shape from the blue canvas
    // 绘制国家几何图形边界，作为 Canvas 剪裁路径（Clip Path）
    context.save();
    const renderContext = toContext(context, {
      pixelRatio: 1,
    });
    renderContext.setFillStrokeStyle(fill, stroke);
    renderContext.drawGeometry(geometry);
    context.clip();

    // Fill transparent country with the flag image
    // 在剪裁区域内绘制国旗图片，实现图片填充国家多边形
    const bottomLeft = getBottomLeft(extent);
    const left = bottomLeft[0];
    const bottom = bottomLeft[1];
    context.drawImage(flag, left, bottom, width, height);
    context.restore();
  },
});

// Vector layer with GeoJSON source
// 使用 GeoJSON 格式世界国家数据的矢量图层
const vectorLayer = new VectorLayer({
  source: new VectorSource({
    url: 'https://openlayersbook.github.io/openlayers_book_samples/assets/data/countries.geojson',
    format: new GeoJSON(),
  }),
  style: style,
});

// Load country flags and set them as `flag` attribute on the country feature
// 异步加载对应国家的国旗图片，并将其设置为国家要素的 `flag` 属性
vectorLayer.getSource().on('addfeature', function (event) {
  const feature = event.feature;
  const img = new Image();
  img.onload = function () {
    feature.set('flag', img);
  };
  img.src =
    'https://flagcdn.com/w320/' + feature.get('iso_a2').toLowerCase() + '.png';
});

// Initialize the map
// 初始化地图
new Map({
  layers: [vectorLayer],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 1,
  }),
});
