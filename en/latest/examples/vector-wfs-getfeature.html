WFS - GetFeature / WFS 空间矢量要素过滤查询与叠加

vector87 WFS3 GetFeature1 filter3 maptiler26

Example of making a WFS GetFeature request with a filter. / 使用 OGC WFS 协议结合属性复合过滤器执行 GetFeature 空间查询并将矢量要素动态叠加至地图的示例。

This example generates a GetFeature request which uses a PropertyIsEqualTo and a PropertyIsLike filter, and then posts the request to load the features that match the query.

本示例演示了如何生成符合 OGC WFS 规范的 GetFeature 矢量要素查询请求。请求中组合了 PropertyIsEqualTo（属性完全等值）与 PropertyIsLike（通配符模糊匹配）复合空间过滤器，通过 HTTP POST 提交给服务后端，并将查询匹配的真实矢量要素反序列化加载到矢量图层中，自动缩放至要素包围盒范围。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • WMS vs WFS：栅格呈现与矢量互操作的质变： WMS 服务向客户端传输的是“图片”，客户端无法修改图元样式或进行二次空间拓扑分析；而 WFS（Web Feature Service）直接分发包含完整点、线、面坐标几何与业务属性字典的真实矢量要素。客户端接收后可在前端执行富交互绘制、高亮选中、缓冲区分析甚至图形编辑后提交回写（WFS-T）。
  • OGC Filter Encoding 规范化 XML 生成： 传统 URL GET 请求受制于长度限制，无法承载极度复杂的空间几何或多重 SQL 逻辑。OpenLayers 提供了 ol/format/WFS 与 ol/format/filter，能够在内存中通过链式语法构建标准 XML 格式的 OGC Filter（包含逻辑运算符 And / Or / Not、空间比较符 BBOX / Intersects / Within 及属性比较符 EqualTo / Like），通过 POST 请求安全可靠地传递给 GIS 服务器。

2. 源码与关键 API 剖析

  • writeGetFeature(options)：
    • srsName: 'EPSG:3857'：告知 GIS 服务器按目标坐标系统投影输出坐标。
    • featureNS 与 featurePrefix：对应 GeoServer 发布服务时绑定的 XML 命名空间 URI 与图层前缀。
    • outputFormat: 'application/json'：要求服务端直接将矢量结果以 GeoJSON 格式返回，便于前端高效反序列化。
  • andFilter(likeFilter('name', 'Mississippi*'), equalToFilter('waterway', 'riverbank'))：在客户端构建条件表达式，筛选名称以“密西西比”开头且水系类型为“河岸”的水体要素。
  • map.getView().fit(vectorSource.getExtent())：收到要素集合后，计算几何外包矩形，驱动视口平滑聚焦到查询结果区域。

3. 生产实践踩坑与性能调优

  • 工作区命名空间（Namespace）严密对齐： 若 featureNS 或 featurePrefix 与 GeoServer 控制台配置存在大小写或拼写不一致，服务端将直接返回 ServiceException: Feature type unknown。
  • 大数据量防爆保护（maxFeatures / resultType）： WFS 涉及几何坐标明文传输，若 SQL 过滤未加约束导致返回数万个复杂多边形，不仅网络传输长达数秒，还会导致前端反序列化时浏览器卡死。生产调用必须显式设置 maxFeatures: 100 或 count: 100 进行分页保护。
  • CORS 跨域预检与 POST 预热： POST XML 请求属于非简单请求（Non-Simple Request），浏览器会自动发起 OPTIONS 预检。GIS 服务器（如 GeoServer、ArcGIS Server）必须妥善配置 CORS Filter 允许 Content-Type: application/xml 与 POST 方法。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import WFS from 'ol/format/WFS.js';
import {
  and as andFilter,
  equalTo as equalToFilter,
  like as likeFilter,
} from 'ol/format/filter.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import ImageTile from 'ol/source/ImageTile.js';
import VectorSource from 'ol/source/Vector.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

// Vector source and layer for holding query results
// 用于承载查询结果矢量要素的数据源与图层
const vectorSource = new VectorSource();
const vector = new VectorLayer({
  source: vectorSource,
  style: new Style({
    stroke: new Stroke({
      color: 'rgba(0, 0, 255, 1.0)',
      width: 2,
    }),
  }),
});

const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Base satellite layer from MapTiler
// MapTiler 卫星影像基础底图
const raster = new TileLayer({
  source: new ImageTile({
    attributions: attributions,
    url: 'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
    tileSize: 512,
    maxZoom: 20,
  }),
});

// Initialize map view
// 初始化地图视图
const map = new Map({
  layers: [raster, vector],
  target: document.getElementById('map'),
  view: new View({
    center: [-8908887.277395891, 5381918.072437216],
    maxZoom: 19,
    zoom: 12,
  }),
});

// Generate a WFS GetFeature XML request with compound filters
// 使用复合过滤器生成符合 OGC WFS 规范的 GetFeature XML 请求
const featureRequest = new WFS().writeGetFeature({
  srsName: 'EPSG:3857',
  featureNS: 'http://openstreemap.org',
  featurePrefix: 'osm',
  featureTypes: ['water_areas'],
  outputFormat: 'application/json',
  filter: andFilter(
    likeFilter('name', 'Mississippi*'),
    equalToFilter('waterway', 'riverbank'),
  ),
});

// Post the request and add the received features to the vector layer
// 提交 HTTP POST 请求并将接收到的要素添加至矢量图层
fetch('https://ahocevar.com/geoserver/wfs', {
  method: 'POST',
  body: new XMLSerializer().serializeToString(featureRequest),
})
  .then(function (response) {
    return response.json();
  })
  .then(function (json) {
    const features = new GeoJSON().readFeatures(json);
    vectorSource.addFeatures(features);
    map.getView().fit(vectorSource.getExtent());
  });
