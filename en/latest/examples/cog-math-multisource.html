NDVI+NDWI from two 16-bit COGs / 基于两个 16 位 COG 同时计算 NDVI 与 NDWI

cog16 ndvi4 ndwi1 sentinel1 geotiff5

Calculating NDVI+NDWI as green and blue values. / 跨越不同空间分辨率的 16 位云原生 GeoTIFF 影像，在 GPU 中同时解算植被指数 (NDVI) 与水体指数 (NDWI)。

The GeoTIFF layer in this example calculates the Normalized Difference Vegetation Index (NDVI) and Normalized Difference Water Index (NDWI) from two cloud-optimized Sentinel 2 GeoTIFFs: one with 10 m resolution and red and a near infrared bands, and one with 60 m resolution and a short wave infrared channel. The NDVI is shown as green, the NDWI as blue. The 4th band is the alpha band, which gets added when a source has a nodata value configured.

本示例中的 GeoTIFF 图层从两幅不同分辨率的云优化哨兵 2 号（Sentinel-2）GeoTIFF 中同时计算归一化植被指数（NDVI）与归一化水体指数（NDWI）： 第一幅影像为 10 米空间分辨率，包含红光（Red）与近红外（NIR）波段；第二幅影像为 60 米空间分辨率，包含短波红外（SWIR）波段。 在最终渲染中，NDVI 强度被映射为绿色分量，NDWI 强度被映射为蓝色分量。当数据源配置了 nodata 值时，第 4 波段会自动作为 Alpha 透明度通道参与遮罩裁切。

📚 学习记录与技术深度解读 (Learning Notes)

1. 双指数复合遥感解译：NDVI 与 NDWI

  • 归一化植被指数 (NDVI)： $$\text{NDVI} = \frac{\text{NIR} - \text{Red}}{\text{NIR} + \text{Red}} = \frac{\text{Band 2} - \text{Band 1}}{\text{Band 2} + \text{Band 1}}$$
    • 本例中将 NDVI 乘以 255 赋予 Green 通道，健康植被呈现明亮绿色。
  • 归一化水体指数 (NDWI, McFeeters / Gao 变体)： $$\text{NDWI} = \frac{\text{SWIR} - \text{Red}}{\text{SWIR} + \text{Red}} = \frac{\text{Band 3} - \text{Band 1}}{\text{Band 3} + \text{Band 1}}$$
    • 水体在短波红外（SWIR）与红光处的吸收特性形成显著反差。
    • 本例中将 NDWI 乘以 255 赋予 Blue 通道，湖泊、河流、湿地等水体呈现鲜艳蓝色。
  • 地表混杂特征（差异绝对值赋予 Red 通道）： $$\text{Red} = 255 \times |\text{NDVI} - \text{NDWI}|$$ 红通道突出显示植被与水体指数差异极大的过渡区域（如沙滩、城市人工地表、裸露岩石），三色通道融合成丰富的地物多光谱伪彩图！

2. 跨空间分辨率动态重采样（10m 与 60m 融合）

  • 在现实遥感应用中，不同传感器波段的空间分辨率通常不同（如哨兵 2 号的 B04/B08 是 10 米，而大气校正与特定短波红外波段是 20 米或 60 米）。
  • OpenLayers 的 ol/source/GeoTIFF 支持同时声明多个异构 sources：
    • sources[0]：10 米分辨率，提取 bands: [3, 4]；
    • sources[1]：60 米分辨率，提取 bands: [9]；
  • WebGLTile 渲染管线会在显卡显存中对较低分辨率的波段自动执行双线性插值采样（Bilinear Interpolation），开发者无需在后端离线执行耗时的“重采样对齐网格”，即可直接在前端完成多尺度波段代数运算！

3. 无效值处理：nodata: 0 与 case 条件遮罩

  • 卫星影像在拍摄边界外常填充值为 0 的黑边。
  • 通过配置 nodata: 0 以及在着色器中使用 ['case', ['any', ['==', ['band', 1], 0], ...], [0, 0, 0, 0], ...]，只要任何一个波段无数据，立即将像元 Alpha 设为 0 完全透明，完美剔除影像周边黑框。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import GeoTIFF from 'ol/source/GeoTIFF.js';

// Multi-source GeoTIFF combining two images of different spatial resolutions (10m and 60m)
// 多源 GeoTIFF，融合两幅不同空间分辨率的卫星影像（10 米与 60 米）
const source = new GeoTIFF({
  sources: [
    {
      // 10m resolution image containing Red and NIR bands
      // 10 米分辨率影像，包含红光和近红外波段
      url: 'https://cloudlessdownloads.eox.at/api/public/dl/jvu06wnt/OpenLayers_Sentinel-2_samples/R10m.tif',
      bands: [3, 4],
      nodata: 0,
    },
    {
      // 60m resolution image containing Shortwave Infrared (SWIR) band
      // 60 米分辨率影像，包含短波红外 (SWIR) 波段
      url: 'https://cloudlessdownloads.eox.at/api/public/dl/jvu06wnt/OpenLayers_Sentinel-2_samples/R60m.tif',
      bands: [9],
      nodata: 0,
    },
  ],
  normalize: false,
});
source.setAttributions(
  "<a href='https://s2maps.eu'>Sentinel-2 cloudless</a> by <a href='https://eox.at/'>EOX IT Services GmbH</a> (Contains modified Copernicus Sentinel data 2019)",
);

// NDVI expression: (NIR - Red) / (NIR + Red)
// NDVI 表达式：(近红外 - 红光) / (近红外 + 红光)
const ndvi = [
  '/',
  ['-', ['band', 2], ['band', 1]],
  ['+', ['band', 2], ['band', 1]],
];

// NDWI expression: (SWIR - Red) / (SWIR + Red)
// NDWI 表达式：(短波红外 - 红光) / (短波红外 + 红光)
const ndwi = [
  '/',
  ['-', ['band', 3], ['band', 1]],
  ['+', ['band', 3], ['band', 1]],
];

// WebGL layer with combined multi-band shader: Red = |NDVI - NDWI|, Green = NDVI, Blue = NDWI
// WebGL 图层，采用复合多波段着色器：红通道 = |NDVI - NDWI|，绿通道 = NDVI，蓝通道 = NDWI
const map = new Map({
  target: 'map',
  layers: [
    new TileLayer({
      style: {
        color: [
          'case',
          [
            'any',
            ['==', ['band', 1], 0],
            ['==', ['band', 2], 0],
            ['==', ['band', 3], 0],
          ],
          [0, 0, 0, 0],
          [
            'color',
            // red: | NDVI - NDWI | / 红通道：植被与水体指数差异绝对值
            ['*', 255, ['abs', ['-', ndvi, ndwi]]],
            // green: NDVI / 绿通道：NDVI 植被指数
            ['*', 255, ndvi],
            // blue: NDWI / 蓝通道：NDWI 水体指数
            ['*', 255, ndwi],
          ],
        ],
      },
      source,
    }),
  ],
  view: new View({
    center: [1447120, 6165360],
    zoom: 11,
  }),
});
