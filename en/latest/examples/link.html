Map Link / 地图状态与 URL 参数双向同步

link1 permalink2 url1 query1 search1 params1

Synchronizing map state with the URL. / 演示使用 Link 交互将地图视图状态（中心、层级、旋转角等）与浏览器 URL 查询参数实时双向同步。

The Link interaction allows you to synchronize the map state with the URL. The view center, zoom level, and rotation will be reflected in the URL as you navigate around the map. Layer visibility is also reflected in the URL. Reloading the page restores the map view state.

The interaction can also be used to track other parts of your application state. For example, toggling the checkbox below updates the URL. Navigating back through history will also update the state of the checkbox.

Link 交互可将地图状态与浏览器地址栏中的 URL 参数进行双向自动同步。当你在地图上平移漫游、缩放或旋转时，中心点坐标（x, y）、缩放级别（z）以及旋转角度（r）会即时更新到 URL 查询字符串中。同样，图层的显隐状态也可在 URL 中反映，刷新页面或将链接分享给他人即可完美复原当前的地图视角与状态。

此外，该交互还提供了强大的自定义状态追踪能力（link.track() 与 link.update()）。例如勾选下方的复选框会向 URL 写入 example=checked 参数；当通过浏览器后退/前进导航时，复选框的勾选状态也会自动同步更新。

📚 学习记录与技术深度解读 (Learning Notes)

1. 为什么官方推出 Link 交互？

  • HTML5 History API 驱动：传统自研方案往往需要开发者手动监听地图 moveend 事件拼接哈希字符串，极易产生循环触发或地址栏刷新抖动。
  • 双向无缝响应：ol/interaction/Link 既能主动监听 Map 状态更新 URL，也能响应浏览器的前进/后退（popstate）事件并驱动视图同步过渡。

2. 自定义业务参数扩展机制

  • link.update(key, value)：将业务状态写入 URL 参数；若值为 null 则自动从 URL 中清理移除该键。
  • link.track(key, callback)：监听 URL 中该参数的变化并触发回调，使外部 UI 控件与 URL 历史保持一致。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Link from 'ol/interaction/Link.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';

// Initialize the map
// 初始化地图实例
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// Create Link interaction to sync map state with URL query parameters
// 创建 Link 交互实例，用于在地图状态与 URL 查询参数之间实现双向同步
const link = new Link();

const exampleCheckbox = document.getElementById('example-checkbox');
exampleCheckbox.addEventListener('change', function () {
  if (exampleCheckbox.checked) {
    link.update('example', 'checked');
  } else {
    // updating to null will remove the param from the URL
    // 将参数值更新为 null 可从 URL 中移除该查询参数
    link.update('example', null);
  }
});

// Track changes to the 'example' URL parameter
// 监听 'example' URL 参数变化以响应浏览器前进/后退
const initialValue = link.track('example', (newValue) => {
  exampleCheckbox.checked = newValue === 'checked';
});

exampleCheckbox.checked = initialValue === 'checked';

map.addInteraction(link);
