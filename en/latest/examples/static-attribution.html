Static Attribution / 静态常驻版权署名 (Static Attribution)

attributions2 openstreetmap22

Example of an attributions control with a static attribution. / 演示如何配置与图层生命周期完全解耦、即使隐藏所有图层也始终常驻展示的静态版权署名控件。

This example shows how to add an attribution that never disappears from the map. It works by passing a static string or HTML string into the attribution options, which is not linked to the layers. Click the 'Toggle layer' button to show that, even with no layers on, the static attribution remains on screen.

此示例演示了如何向地图添加一个永不消失的常驻版权署名。 其实现原理是直接将静态字符串或 HTML 片段注入到 ol/control/Attribution 控件的配置选项中，使其与具体图层解绑。 点击下方的“切换图层显隐（Toggle layer）”按钮，可以看到即使地图中的所有业务图层均被隐藏，该静态版权署名依然清晰常驻在屏幕右下角。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 动态图层聚合版权 vs 控件静态常驻版权： OpenLayers 的 Attribution 控件具备双源合流机制： 1. 动态图层流： 自动收集当前视口范围内、处于可见状态（layer.getVisible() === true）的所有图层源的版权说明； 2. 控件静态流： 通过控件自身的 attributions 选项注入。该部分版权属于宿主平台自身，与任何单一图层的加载、隐藏或销毁彻底解耦。
  • 统一 UI 规范与零额外 DOM 开销： 许多前端开发者习惯在地图容器外编写自定义的 <div class="icp-footer">，这往往导致层级穿透、移动端缩放遮挡或与地图原生控件冲突。 利用 Attribution 控件的静态属性，可以将平台法律免责声明、企业资质、ICP 备案号以及底图版权统一整合进原生控件，共享折叠动画与无障碍辅助特性。

2. 源码与关键 API 剖析

  • new Attribution({ attributions: '<a href="...">...</a>' })：注入静态 HTML 署名。
  • l.setVisible(l.getVisible() ? false : true)：图层显隐切换。

3. 生产实践踩坑与性能调优

  • HTML 注入与 XSS 安全防御： 由于 attributions 支持直接渲染 HTML 字符串（如超链接和图标），若版权内容由后端 API 提供或来源于不可信第三方配置，必须经过严格的 HTML 清洗与安全转义，防止潜在的跨站脚本注入（XSS）。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Attribution from 'ol/control/Attribution.js';
import {defaults as defaultControls} from 'ol/control/defaults.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';

// Initialize Attribution control with static attribution string (independent of layer lifecycle)
// 初始化版权署名控件并传入常驻静态 HTML 字符串（独立于图层生命周期）
const attribution = new Attribution({
  collapsible: false,
  attributions: `<a href="https://openlayers.org">I'm a static attribution. I never disappear</a>`,
});

// Create map and inject custom attribution control while disabling default
// 创建地图实例，禁用默认版权控件并注入包含静态常驻版权的自定义控件
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  controls: defaultControls({attribution: false}).extend([attribution]),
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// Toggle visibility of all layers on button click to demonstrate static persistence
// 按钮点击事件：切换地图中所有图层的显隐状态，验证即使无可见图层静态版权依然常驻
document.getElementById('toggleLayerButton').addEventListener('click', () => {
  map.getLayers().forEach((l) => {
    l.setVisible(l.getVisible() ? false : true);
  });
});
