Sphere Mollweide / 球形摩尔威特等面积投影 (Sphere Mollweide)

graticule3 Mollweide1 projection14 proj4js6

Demonstrates the Sphere Mollweide equal-area projection with a graticule layer. / 演示结合经纬网图层（Graticule）展示全球球形摩尔威特等面积伪圆柱投影（Sphere Mollweide / ESRI:53009）。

This example shows how to configure and render the global Sphere Mollweide equal-area pseudo-cylindrical projection (ESRI:53009), overlaid with a graticule layer (ol/layer/Graticule) to visualize area-preserving geometry and elliptical meridian curves.

本例展示了如何配置并渲染全球球形摩尔威特等面积伪圆柱投影（Sphere Mollweide / ESRI:53009），并叠加经纬网图层（ol/layer/Graticule）直观观察其几何等积特征与椭圆经纬线弧度。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 摩尔威特等面积伪圆柱投影数学原理： 摩尔威特投影是由德国数学家卡尔·摩尔威特（Karl Mollweide）于 1805 年设计的等面积投影，全球轮廓呈现为一个长宽比为 $2:1$ 的完整椭圆。 其经度方向展平为连续的对称半椭圆，纬线为平行直线。将球体半径设为 $R = 6,371,000\text{ m}$ 时，平面正算公式如下： $$x = \frac{2\sqrt{2}}{\pi} R (\lambda - \lambda_0) \cos\theta, \quad y = \sqrt{2} R \sin\theta$$ 其中辅助参量角 $\theta$ 通过迭代求解超越方程确定：$2\theta + \sin(2\theta) = \pi \sin\varphi$。 全球外包半长轴 $x_{\max} = 2\sqrt{2} R \approx 18,019,909.21\text{ m}$，半短轴 $y_{\max} = \sqrt{2} R \approx 9,009,954.61\text{ m}$。
  • worldExtent 与经纬网（Graticule）图层的协同： Graticule 图层在非墨卡托投影下绘制等经线与等纬线时，必须依赖投影对象的 worldExtent 明确经纬度的起止绘制边界。 代码中配置了 worldExtent: [-179, -89.99, 179, 89.99]，适度内缩极点和日界线边缘，有效避免了极点投影在椭圆两极产生数学奇异与线段断裂。

2. 源码与关键 API 剖析

  • proj4.defs('ESRI:53009', '+proj=moll ...')：通过 Proj4js 声明摩尔威特投影参数。
  • register(proj4)：将自定义投影同步注册至 OpenLayers 投影字典。
  • new Graticule()：在自定义椭圆投影下自适应绘制经纬线网格。

3. 生产实践踩坑与性能调优

  • 矢量要素客户端即时重投影性能： 全球生态大区矢量数据为 EPSG:4326 GeoJSON。OpenLayers 结合 Proj4js 在客户端对上万个几何顶点执行球面到椭圆平面的动态正算转换，配合样式表达式 ['string', ['get', 'COLOR_BIO'], '#eee'] 实现零后端依赖的高性能纯前端渲染。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import Graticule from 'ol/layer/Graticule.js';
import VectorLayer from 'ol/layer/Vector.js';
import Projection from 'ol/proj/Projection.js';
import {register} from 'ol/proj/proj4.js';
import VectorSource from 'ol/source/Vector.js';
import proj4 from 'proj4';

// 向 Proj4js 注册基于标准球体（半径 6371000m）的全球摩尔威特等面积伪圆柱投影 (Sphere Mollweide / ESRI:53009)
proj4.defs(
  'ESRI:53009',
  '+proj=moll +lon_0=0 +x_0=0 +y_0=0 +a=6371000 ' +
    '+b=6371000 +units=m +no_defs',
);
// 将定义同步至 OpenLayers 投影表
register(proj4);

// 为球形摩尔威特投影配置平面 Extent 及 WGS84 经纬度 WorldExtent。
// 这两个范围配置对于 Graticule 经纬网图层精准解算经纬线绘制范围至关重要：
// 1. extent: 椭圆平面外接矩形范围 [-2*sqrt(2)*R, -sqrt(2)*R, 2*sqrt(2)*R, sqrt(2)*R]；
// 2. worldExtent: 经纬度合法起止范围（微小内缩以避开极点与日界线数学奇异点）。
const sphereMollweideProjection = new Projection({
  code: 'ESRI:53009',
  extent: [
    -18019909.21177587, -9009954.605703328, 18019909.21177587,
    9009954.605703328,
  ],
  worldExtent: [-179, -89.99, 179, 89.99],
});

// 初始化地图实例
const map = new Map({
  // 允许通过键盘快捷键进行平移缩放交互
  keyboardEventTarget: document,
  layers: [
    // 全球生态大区矢量图层（原生数据为 EPSG:4326 GeoJSON，加载时自动在客户端重投影）
    new VectorLayer({
      source: new VectorSource({
        url: 'https://openlayers.org/data/vector/ecoregions.json',
        format: new GeoJSON(),
      }),
      // 矢量样式：提取要素的 COLOR_BIO 字段颜色属性进行填充
      style: {
        'fill-color': ['string', ['get', 'COLOR_BIO'], '#eee'],
      },
    }),
    // 经纬网图层：自动依摩尔威特投影的曲率解算经纬线对称椭圆弧网格
    new Graticule(),
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    projection: sphereMollweideProjection,
    zoom: 2,
  }),
});
