WMS GetLegendGraphic / WMS 动态图例获取与尺度自适应

GetLegendGraphic1 getLegendUrl1 WMS14

Legend / 图例：

Example of a WMS GetLegendGraphic. / 演示如何使用 getLegendUrl 方法向 WMS 服务动态获取图例图片，并随分辨率变化实时更新。

WMS supports the getLegendGraphic request. This example demonstrates the use of the getLegendUrl method.

As a legend can be responsive to the scale it is updated on every change of the resolution. WMS 规范支持 GetLegendGraphic 图例获取请求。 本示例演示如何使用 source.getLegendUrl() 方法动态生成图例图片的请求地址。 由于许多地图图例具备比例尺自适应能力（根据缩放级别展示不同要素类别的符号），因此每当地图视图分辨率发生变化时，图例图片均会实时响应更新。

📚 学习记录与技术深度解读 (Learning Notes)

1. 什么是 GetLegendGraphic？ * 在 GIS 制图标准中，地图样式通常由服务端的 SLD（Styled Layer Descriptor）文件定义。 * GetLegendGraphic 请求用于直接向 WMS 服务端索取当前图层在指定样式下的官方图例图片：

https://.../wms?SERVICE=WMS&VERSION=1.3.0&REQUEST=GetLegendGraphic&FORMAT=image/png&LAYER=topp:states&SCALE=...
  • 前端完全不需要自己硬编码图例的颜色色块、线条样式和文字说明，直接显示服务端返回的图例图片即可。

2. source.getLegendUrl(resolution, params) 的内部封装 OpenLayers 的 ol/source/ImageWMS 和 ol/source/TileWMS 均内置了 getLegendUrl 辅助方法： * 自动比例尺推算：传入当前视图的 resolution（分辨率），OpenLayers 会自动将其转换为 WMS 规范所依赖的大地比例尺分母（SCALE 参数）； * 响应式监听：通过监听视图的 change:resolution 事件：

map.getView().on('change:resolution', function (event) {
  const resolution = event.target.getResolution();
  updateLegend(resolution);
});

当用户放大进入大比例尺时，如果服务端规则启用了特定细节符号（如仅在大比例尺下显示的县界、公路等级符号），图例图片会自动刷新显示最新的图元规则。

main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ImageLayer from 'ol/layer/Image.js';
import TileLayer from 'ol/layer/Tile.js';
import ImageWMS from 'ol/source/ImageWMS.js';
import OSM from 'ol/source/OSM.js';

// Single image WMS source for US states
// 美国各州边界单图像 WMS 数据源
const wmsSource = new ImageWMS({
  url: 'https://ahocevar.com/geoserver/wms',
  params: {'LAYERS': 'topp:states'},
  ratio: 1,
  serverType: 'geoserver',
});

// Update the legend image element using getLegendUrl with current resolution
// 使用当前分辨率调用 getLegendUrl 方法动态刷新图例图片地址
const updateLegend = function (resolution) {
  const graphicUrl = wmsSource.getLegendUrl(resolution);
  const img = document.getElementById('legend');
  img.src = graphicUrl;
};

const layers = [
  new TileLayer({
    source: new OSM(),
  }),
  new ImageLayer({
    extent: [-13884991, 2870341, -7455066, 6338219],
    source: wmsSource,
  }),
];

const map = new Map({
  layers: layers,
  target: 'map',
  view: new View({
    center: [-10997148, 4569099],
    zoom: 4,
  }),
});

// Fetch initial legend for current view resolution
// 获取当前视图初始分辨率下的图例
const resolution = map.getView().getResolution();
updateLegend(resolution);

// Listen to resolution changes and update the scale-responsive legend
// 监听分辨率变化事件，实时更新支持比例尺响应式的图例
map.getView().on('change:resolution', function (event) {
  const currentRes = event.target.getResolution();
  updateLegend(currentRes);
});
