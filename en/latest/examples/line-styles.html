Line Styles / 线条与多边形描边样式全解（Stroke 全属性实验室）

line3 vector86 style27 offset1

Showing the line styling possibilities with canvas rendering / 演示 Canvas 渲染下 ol/style/Stroke 的全部线条样式属性（端帽、转角、虚线、法向偏移等）及实时绘制交互。

This example demonstrates the line stroke styling capabilities when rendering with canvas. All stroke properties provided by ol/style/Stroke.js can be modified dynamically to observe their visual effect. In addition to the predefined line features, you can draw new lines directly on the map to experiment with different stroke configurations in real time.

本示例全方位演示了在使用 Canvas 渲染矢量要素时，ol/style/Stroke 所提供的全部线条描边样式能力。 你可以通过地图下方的控制面板动态修改 ol/style/Stroke.js 的所有属性，实时观察它们的视觉变化。除了地图上预置的测试线条与多边形要素外，你还可以直接在地图上绘制新的多边形（Draw），或拖拽已有要素的顶点（Modify + Snap）（例如将折角拖成极尖的锐角来测试斜接限制 miterLimit）。

📚 学习记录与技术深度解读 (Learning Notes)

1. ol/style/Stroke 八大核心属性全景速查表

属性名 类型 默认值 核心作用与视觉效果
color Color | ColorLike #3399CC 线条颜色，支持 Hex（#004D7D）、rgb()、rgba() 或 Canvas 渐变/图案对象
width number 1.25 线条像素宽度（单位：px）
lineCap 'butt' | 'round' | 'square' 'round' 线端帽样式（控制开放线段的两端，以及每一段虚线的两端如何收尾）
lineJoin 'bevel' | 'round' | 'miter' 'round' 折线转角连接样式（控制两条线段在顶点交汇处的外侧拐角形态）
miterLimit number 10 斜接长度限制（仅当 lineJoin: 'miter' 时生效，防止锐角拐弯处产生过长的尖刺）
lineDash Array<number> undefined 虚线排列模式，如 [10, 5] 表示“10px 实线 + 5px 空白”循环交替
lineDashOffset number 0 虚线起始相位偏移量（px），动态递增该值即可实现“蚂蚁线 / 管网流向动画”
offset number 0 平行法向偏移量（px），沿几何路径法线方向左/右平移线条（或多边形内缩/外扩描边）

2. 深度解析：lineCap（端帽）与 lineJoin（转角）的几何差异

（1）lineCap 三种端帽对比
几何端点位置:       |                     |
butt   (平直截断):  |=====================|     (精确停在端点处，不向外延伸)
round  (半圆端帽): (|=====================|)    (两端各附加一个半径为 width/2 的半圆)
square (方形端帽): [|=====================|]    (两端各向外延伸一个长为 width/2 的矩形)
  • 💡 实用技巧（圆点虚线）：当把 lineCap 设为 'round'，将 Width 调大（如 10），并将 Line Dash 设为 1, 15（实线极短、间距较大）时，每一段实线都会变成一个圆润的圆点（Dotted Line）！
（2）lineJoin 三种转角与 miterLimit 防尖刺机制
  • round（圆角）：拐角外侧用圆弧平滑过渡，最适合道路、河流等自然要素。
  • bevel（斜角/平切）：像用刀把拐角外侧直接削平，形成一个平直切面。
  • miter（尖角/斜接）：延伸两侧外边缘直至相交成尖角。但当两条线段夹角极小时（锐角），交点会飞出很远形成难看的“长矛尖刺”。
    • 此时 miterLimit 登场：它限制了 斜接尖角长度 / 线宽 (width) 的最大比值（默认 10）。你可以在地图上把 lineJoin 切为 miter，将 Width 调到 15，然后用鼠标把折线顶点拖成一个极窄的锐角，再调小 Miter Limit（如改为 2 或 3），就能亲眼看到尖刺在超过阈值瞬间自动回退变成 bevel 平切角！

3. OpenLayers 特色几何能力：offset（平行法向偏移）与多样式叠加

原生 HTML5 Canvas 2D 并没有“平行偏移线”的 API，但 OpenLayers 在 ol/style/Stroke 中内置了几何级 offset 属性：

  • 双线道路 / 境界线内侧色带：在 GIS 制图中，常需要沿着行政区划边界内部画一条半透明色带（内缩描边），或沿着道路中心线两侧画双轨线。只需设置正/负 offset 像素值即可轻松实现，无需借助 Turf.js 重新计算缓冲偏移几何！
  • 多样式数组叠加（Array<Style>）： 细看代码第 44~54 行，当检测到 Math.abs(offset) > 0 时，代码向 styles 数组中 push 了第二个灰色的虚线 Style（不带 offset）。这展示了 OpenLayers 样式系统的强大特性——一个要素可以同时绑定多个 Style 实例组成的数组，引擎会按数组顺序依次叠加绘制，从而在渲染偏移线条的同时，把原始几何中心线作为灰色虚线基准参考线画出来！

4. 代码工程技巧：使用原生 FormData 优雅收集多表单项

面对包含颜色、单选框、文本、数字等 8 个控件的复杂表单，本示例没有写 8 个 document.getElementById 去逐一读取，而是直接利用浏览器原生的 new FormData(styleOptionsForm) 配合表单整体的 'change' 事件委托，仅用几行代码就完成了所有样式的响应式收集与更新。

main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import Draw from 'ol/interaction/Draw.js';
import Modify from 'ol/interaction/Modify.js';
import Snap from 'ol/interaction/Snap.js';
import {defaults as defaultInteractions} from 'ol/interaction/defaults.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

// 1. 创建矢量数据源：加载预置的测试线条与多边形 GeoJSON 数据
const source = new VectorSource({
  url: 'data/geojson/line-samples.geojson',
  format: new GeoJSON(),
});

// 2. 创建矢量图层
const vector = new VectorLayer({source: source});

// 3. 获取样式配置表单，并定义响应式更新图层样式的函数
const styleOptionsForm = document.getElementById('line-style-options-form');
function updateStyles() {
  // 使用浏览器原生 FormData 一次性读取表单中所有控件的当前值
  const formData = new FormData(styleOptionsForm);
  const styles = [
    new Style({
      stroke: new Stroke({
        color: formData.get('color'), // 线条颜色
        lineCap: formData.get('lineCap'), // 线端帽样式：'butt' | 'round' | 'square'
        lineJoin: formData.get('lineJoin'), // 转角连接样式：'bevel' | 'round' | 'miter'
        // 将逗号分隔的字符串（如 "1, 3"）解析为数字数组 [1, 3] 作为虚线排列模式
        lineDash: formData
          .get('lineDash')
          ?.split(',')
          ?.map((value) => Number(value)),
        lineDashOffset: formData.get('lineDashOffset'), // 虚线起始相位偏移量（px）
        miterLimit: formData.get('miterLimit'), // 尖角斜接长度限制比值（仅在 lineJoin 为 'miter' 时生效）
        width: formData.get('width'), // 线条像素宽度（px）
        offset: formData.get('offset'), // 平行法向偏移像素值（正负值控制向左/向右或向内/向外偏移）
      }),
    }),
  ];

  // 如果设置了非零的法向偏移（offset），则追加第二个灰色细虚线样式
  // 用于在原始几何位置绘制一条无偏移的基准参考线，方便直观对比偏移前后的位置关系
  if (Math.abs(formData.get('offset')) > 0) {
    styles.push(
      new Style({
        stroke: new Stroke({
          color: '#aaa',
          width: 1,
          lineDash: [3, 3],
        }),
      }),
    );
  }

  // 将样式数组应用到矢量图层（图层会按数组顺序依次叠加渲染每个 Style）
  vector.setStyle(styles);
}

// 初始化执行一次样式设置，并监听表单整体的 change 事件实现实时更新
updateStyles();
styleOptionsForm.addEventListener('change', updateStyles);

// 4. 创建编辑与绘制交互：支持拖拽修改现有顶点（Modify）、绘制新多边形（Draw）及顶点吸附（Snap）
const modify = new Modify({source});
const draw = new Draw({source, type: 'Polygon'});
const snap = new Snap({source: source});

// 5. 初始化地图实例，并将 Modify / Draw / Snap 扩展到默认交互集合中
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
    vector,
  ],
  target: 'map',
  view: new View({
    center: [-8161939, 6095025],
    zoom: 8,
  }),
  interactions: defaultInteractions().extend([modify, draw, snap]),
});
