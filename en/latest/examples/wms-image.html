Single Image WMS / 单图像动态 WMS 服务

wms14 image8

Example of a single image WMS layer. / 使用 ol/source/ImageWMS 请求与当前视口完全匹配的单张全屏大图，保证复杂注记与水系制图的完美无缝呈现。

WMS can be used as an Image layer, as shown here, or as a Tile layer, as shown in the Tiled WMS example. Tiles can be cached, so the browser will not re-fetch data for areas that were viewed already. But there may be problems with repeated labels for WMS servers that are not aware of tiles, in which case single image WMS will produce better cartography.

WMS 既可以作为单图像图层使用（如本例所示），也可以作为瓦片图层使用（详见 瓦片式动态 WMS 示例）。 瓦片支持客户端缓存，因此浏览器不需要重新拉取已经查看过的可视区域； 但若 WMS 服务端不支持瓦片注记智能排版，瓦片切片可能会导致跨网格边界的标注文字重复或截断，此时采用单图像 WMS 能够呈现更精美的地图制图学品质。

📚 学习记录与技术深度解读 (Learning Notes)

1. 单图像 WMS（ImageWMS）的核心机制

  • 按视口整幅请求： 与将地图拆解为几十个小网格的 TileWMS 不同，ImageWMS 在每次地图平移结束（moveend）或缩放后，仅向服务端发起单次 HTTP 请求，请求一幅与当前视口像素尺寸完全对应的全屏位图：
    https://.../wms?SERVICE=WMS&VERSION=1.3.0&REQUEST=GetMap&LAYERS=topp:states&WIDTH=1280&HEIGHT=720&CRS=EPSG:3857&BBOX=minx,miny,maxx,maxy
  • 完美制图学表现（Cartography Integrity）： 由于整幅地图一次性渲染，GIS 服务器（如 GeoServer、MapServer、ArcGIS Server）能够全面掌控当前视野内所有地物的空间关系，完美执行：
    • 复杂等高线、河流沿线注记标注；
    • 密集要素图标自动碰撞检测与避让（Collision Avoidance）；
    • 复杂多边形阴影与晕渲渲染。

2. 关键参数解析：ratio（视口外缓冲比例）

  • 代码中配置了 ratio: 1：
    • ratio: 1 表示请求的图片长宽与浏览器视口画布尺寸严格保持 1:1，网络传输量最小；
    • 若将 ratio 设置为 1.5（默认值），OpenLayers 会在当前视口四周额外预加载 50% 范围的周边图像。当用户轻微平移拖拽地图时，视口边缘依然有已经渲染好的图像内容，避免每次拖拽都出现短暂白屏等待。

3. 架构选型对照：TileWMS vs ImageWMS

  • 优先选用 TileWMS：大并发基础底图浏览、漫游平移高频、对文字偶尔轻微截断不敏感的场景；
  • 优先选用 ImageWMS：业务专题图（气象预警面、洪水淹没风险图、高精度地籍测量红线、人口密度热点图），必须确保全屏文字标注清晰无重影、无截断。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ImageLayer from 'ol/layer/Image.js';
import TileLayer from 'ol/layer/Tile.js';
import ImageWMS from 'ol/source/ImageWMS.js';
import OSM from 'ol/source/OSM.js';

// Configure map layers: OSM base and a single image WMS layer
// 配置地图图层：OSM 基础瓦片底图与单图像 WMS 业务图层
const layers = [
  new TileLayer({
    source: new OSM(),
  }),
  new ImageLayer({
    // Bounding box constraint for US states
    // 限制图层仅在美国各州范围内请求单张大图
    extent: [-13884991, 2870341, -7455066, 6338219],
    source: new ImageWMS({
      url: 'https://ahocevar.com/geoserver/wms',
      params: {'LAYERS': 'topp:states'},
      // ratio: 1 fetches an image exactly matching the map viewport size
      // ratio: 1 请求与当前地图视口尺寸完全一致的图像（不额外预加载周边缓冲）
      ratio: 1,
      serverType: 'geoserver',
    }),
  }),
];

// Initialize map centered on the United States
// 初始化地图实例，中心对齐美国本土
const map = new Map({
  layers: layers,
  target: 'map',
  view: new View({
    center: [-10997148, 4569099],
    zoom: 4,
  }),
});
