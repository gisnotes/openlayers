Measure using vector styles / 使用矢量样式进行测量

Example of measuring lengths and areas using vector styles. / 使用矢量样式（Vector Styles）测量长度与面积的示例。

Using vector styles instead of overlays makes it easy to set up, then modify and clear a measure. Additional information such as the lengths of individual segments or sides can be included as required.

The getLength() and getArea() functions calculate spherical lengths and areas for geometries. Lengths are calculated by assuming great circle segments between geometry coordinates. Areas are calculated as if edges of polygons were great circle segments.

Note that the geometry.getLength() and geometry.getArea() methods return measures of projected (planar) geometries. These can be very different than on-the-ground measures in certain situations — in northern and southern latitudes using Web Mercator for example. For better results, use the functions in the ol/sphere module.

使用矢量样式（Vector Styles）代替 DOM 叠加层（ol/Overlay），可以极其轻松地建立、修改（Modify）和清除测量结果。同时还能按需附加上每一段折线（或每一条多边形边）的分段长度等额外信息。

ol/sphere 模块中的 getLength() 与 getArea() 函数用于计算几何图形在球面上的真实长度与面积：长度通过假设几何坐标之间为大圆弧段（Great Circle Segments）进行计算；面积则将多边形的各条边视作大圆弧段进行球面多边形积分计算。

请注意，几何对象自带的 geometry.getLength() 与 geometry.getArea() 方法返回的是投影平面（Planar）上的欧氏几何测量值。在许多场景下（例如在 Web 墨卡托投影的高纬度南北地区），平面测量值与地面真实距离/面积会产生巨大偏差。为了获得准确的地面测量结果，请务必使用 ol/sphere 模块中的球面计算函数。

📚 学习记录与技术深度解读 (Learning Notes)

1. 为什么用“矢量样式（Style）”代替“DOM 叠加层（Overlay）”做测量？

在传统的测量实现（如 measure.html）中，往往每画一个图形就创建一个 HTML <div> 并挂载为 ol/Overlay。当需要显示每一段边的分段长度，或者支持拖拽顶点实时修改（Modify）时，DOM 方案会面临繁琐的节点创建、位置同步与销毁清理问题。 而本示例完全基于 Canvas 矢量渲染管线，通过一个动态样式函数 styleFunction(feature, segments, drawType, tip) 返回一个 Style 数组，一次性完成所有测量要素的绘制：

样式对象 作用目标 几何位置绑定（setGeometry） 视觉效果与实现技巧
style 被测量的主折线 / 多边形及绘制光标点 默认绑定要素自身几何 半透明白底填充 + 黑色虚线描边（lineDash: [10, 10]）+ 圆形顶点光标
labelStyle 总长度 / 总面积主气泡标签 多边形内部点 getInteriorPoint() 或折线终点 getLastCoordinate() Text（带 backgroundFill 黑底与 offsetY: -15）+ 倒三角形 RegularShape（points: 3, angle: Math.PI）拼成纯 Canvas 指向气泡框
segmentStyles[i] 每一条线段的分段长度小气泡 线段中点 segment.getCoordinateAt(0.5) 通过 line.forEachSegment(a, b) 遍历每条边，并采用样式对象池（Object Pool）按需克隆复用 segmentStyle.clone()
tipStyle 绘制过程中的鼠标跟随操作提示 绘制交互的 Point 草图几何 在光标右侧（offsetX: 15）显示点击开始/继续绘制提示
modifyStyle 顶点拖拽修改（Modify）提示 Modify 交互的捕捉光标点 当鼠标吸附到已有图形的顶点或边上时，显示“拖拽以修改图形”

2. 纯 Canvas 气泡指向框（Callout Bubble）的合成技巧

在 OpenLayers 的单个 Style 对象中，可以同时配置 text（文本样式）和 image（点符号样式），它们会渲染在同一个锚点坐标上：

  • 气泡矩形主体：由 new Text({ backgroundFill, padding: [3, 3, 3, 3], textBaseline: 'bottom', offsetY: -15 }) 绘制，向上偏移 15 像素。
  • 气泡底部倒三角尖角：由 new RegularShape({ radius: 8, points: 3, angle: Math.PI, displacement: [0, 10], fill }) 绘制。正三角形旋转 Math.PI（180°）后尖角朝下，再通过 displacement: [0, 10] 向上平移与文本框底边无缝拼接，无需任何外部图片或 HTML DOM 即可在 Canvas 内合成带箭头的气泡标签。

3. 分段测量与样式对象池（Style Object Pooling）

  • 折线直接使用自身 geometry.forEachSegment(...) 遍历每条线段；多边形则提取外环坐标构造临时折线 new LineString(geometry.getCoordinates()[0]) 后遍历每条边。
  • 由于 styleFunction 会在鼠标移动和地图重绘时高频触发（每秒可达 60 次），如果每次都在循环内 new Style(...) 会产生大量临时对象并引发垃圾回收（GC）卡顿。代码通过 segmentStyles 数组维护了一个样式对象池：只有当线段序号 count 超过池子现有长度时才调用 segmentStyle.clone() 扩容，后续帧直接复用已有实例并更新 setGeometry(segmentPoint) 和 setText(label)。

4. Draw 与 Modify 双交互的提示语互斥与平滑交接

同时启用 Draw（绘制）和 Modify（修改）两个交互时，如果不做控制，两者的鼠标提示框会重叠在一起。本示例通过三步实现无缝衔接：

  1. 悬停已有图形时隐藏绘制提示：在 styleFunction 中判断 !modify.getOverlay().getSource().getFeatures().length。一旦鼠标靠近已有图形触发了 Modify 的顶点捕捉图层，其内部草图源中就会出现捕捉点要素，此时自动隐藏 Draw 的 tipStyle，只显示 Modify 的“拖拽以修改图形”。
  2. 开始绘制时临时禁用修改：监听 drawstart 事件，执行 modify.setActive(false)，防止正在画新图形时误触旧图形的顶点拖拽。
  3. 结束绘制时的平滑过渡：监听 drawend 事件重新启用 modify.setActive(true)，并利用 modifyStyle.setGeometry(tipPoint) 将修改提示暂时固定在刚结束的终点位置，直到下一次鼠标移动（map.once('pointermove', ...)）再恢复跟随。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import LineString from 'ol/geom/LineString.js';
import Point from 'ol/geom/Point.js';
import Draw from 'ol/interaction/Draw.js';
import Modify from 'ol/interaction/Modify.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';
import {getArea, getLength} from 'ol/sphere.js';
import CircleStyle from 'ol/style/Circle.js';
import Fill from 'ol/style/Fill.js';
import RegularShape from 'ol/style/RegularShape.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';
import Text from 'ol/style/Text.js';

// 获取页面表单控件：测量几何类型下拉框、是否显示分段长度复选框、是否清除上次测量复选框
const typeSelect = document.getElementById('type');
const showSegments = document.getElementById('segments');
const clearPrevious = document.getElementById('clear');

/**
 * 1. 基础几何图形样式（用于渲染被测量的折线、多边形以及绘制时的光标圆点）
 */
const style = new Style({
  fill: new Fill({
    color: 'rgba(255, 255, 255, 0.2)',
  }),
  stroke: new Stroke({
    color: 'rgba(0, 0, 0, 0.5)',
    lineDash: [10, 10], // 10px 实线 + 10px 空白的虚线描边
    width: 2,
  }),
  image: new CircleStyle({
    radius: 5,
    stroke: new Stroke({
      color: 'rgba(0, 0, 0, 0.7)',
    }),
    fill: new Fill({
      color: 'rgba(255, 255, 255, 0.2)',
    }),
  }),
});

/**
 * 2. 总测量结果（总长度 / 总面积）的主气泡标签样式
 * 巧妙地利用 Text（带黑底背景框，向上偏移 15px）+ RegularShape（旋转 180° 的倒正三角形，向上位移 10px）
 * 在纯 Canvas 中拼合成带底部指示尖角的气泡标签（Callout Bubble）
 */
const labelStyle = new Style({
  text: new Text({
    font: '14px Calibri,sans-serif',
    fill: new Fill({
      color: 'rgba(255, 255, 255, 1)',
    }),
    backgroundFill: new Fill({
      color: 'rgba(0, 0, 0, 0.7)',
    }),
    padding: [3, 3, 3, 3],
    textBaseline: 'bottom',
    offsetY: -15,
  }),
  image: new RegularShape({
    radius: 8,
    points: 3, // 正三角形
    angle: Math.PI, // 旋转 180°，使三角形尖角朝下指向锚点
    displacement: [0, 10], // 向上平移 10px，与上方 Text 背景框底部无缝衔接
    fill: new Fill({
      color: 'rgba(0, 0, 0, 0.7)',
    }),
  }),
});

/**
 * 3. 绘制过程中的鼠标跟随操作提示样式（如“Click to start measuring”）
 */
const tipStyle = new Style({
  text: new Text({
    font: '12px Calibri,sans-serif',
    fill: new Fill({
      color: 'rgba(255, 255, 255, 1)',
    }),
    backgroundFill: new Fill({
      color: 'rgba(0, 0, 0, 0.4)',
    }),
    padding: [2, 2, 2, 2],
    textAlign: 'left',
    offsetX: 15, // 在光标右侧 15px 处显示提示文字
  }),
});

/**
 * 4. 顶点编辑（Modify 交互）时的捕捉点与操作提示样式（“Drag to modify”）
 */
const modifyStyle = new Style({
  image: new CircleStyle({
    radius: 5,
    stroke: new Stroke({
      color: 'rgba(0, 0, 0, 0.7)',
    }),
    fill: new Fill({
      color: 'rgba(0, 0, 0, 0.4)',
    }),
  }),
  text: new Text({
    text: 'Drag to modify',
    font: '12px Calibri,sans-serif',
    fill: new Fill({
      color: 'rgba(255, 255, 255, 1)',
    }),
    backgroundFill: new Fill({
      color: 'rgba(0, 0, 0, 0.7)',
    }),
    padding: [2, 2, 2, 2],
    textAlign: 'left',
    offsetX: 15,
  }),
});

/**
 * 5. 每一条线段（或边）中点处的分段长度小气泡标签样式模板
 */
const segmentStyle = new Style({
  text: new Text({
    font: '12px Calibri,sans-serif',
    fill: new Fill({
      color: 'rgba(255, 255, 255, 1)',
    }),
    backgroundFill: new Fill({
      color: 'rgba(0, 0, 0, 0.4)',
    }),
    padding: [2, 2, 2, 2],
    textBaseline: 'bottom',
    offsetY: -12,
  }),
  image: new RegularShape({
    radius: 6,
    points: 3,
    angle: Math.PI,
    displacement: [0, 8],
    fill: new Fill({
      color: 'rgba(0, 0, 0, 0.4)',
    }),
  }),
});

// 分段长度样式对象池：避免在每帧重绘时重复 new Style() 造成垃圾回收抖动
const segmentStyles = [segmentStyle];

/**
 * 计算并格式化折线的球面大圆距离（使用 ol/sphere 的 getLength）
 * @param {LineString} line 折线几何对象
 * @return {string} 格式化后的长度字符串（m 或 km）
 */
const formatLength = function (line) {
  const length = getLength(line);
  let output;
  if (length > 100) {
    output = Math.round((length / 1000) * 100) / 100 + ' km';
  } else {
    output = Math.round(length * 100) / 100 + ' m';
  }
  return output;
};

/**
 * 计算并格式化多边形的球面真实面积（使用 ol/sphere 的 getArea）
 * @param {import('ol/geom/Polygon.js').default} polygon 多边形几何对象
 * @return {string} 格式化后的面积字符串（m² 或 km²）
 */
const formatArea = function (polygon) {
  const area = getArea(polygon);
  let output;
  if (area > 10000) {
    output = Math.round((area / 1000000) * 100) / 100 + ' km\xB2';
  } else {
    output = Math.round(area * 100) / 100 + ' m\xB2';
  }
  return output;
};

// 底图图层（OSM）
const raster = new TileLayer({
  source: new OSM(),
});

// 存放已完成测量的矢量要素源
const source = new VectorSource();

// 创建 Modify 交互，允许用户随时拖拽已绘制测量图形的顶点或边，实时重算测量值
const modify = new Modify({source: source, style: modifyStyle});

// 记录绘制结束瞬间光标所在的 Point 几何，用于平滑交接 Modify 提示框位置
let tipPoint;

/**
 * 核心动态样式函数（同时服务于已完成的 VectorLayer 和正在绘制的 Draw 交互草图图层）
 * @param {import('ol/Feature.js').FeatureLike} feature 当前渲染的要素
 * @param {boolean} segments 是否显示每条线段的分段长度
 * @param {string} [drawType] 当前正在绘制的几何类型（仅在 Draw 样式回调中传入）
 * @param {string} [tip] 当前鼠标跟随提示文本（仅在 Draw 样式回调中传入）
 * @return {Array<Style>} 叠加渲染的样式数组
 */
function styleFunction(feature, segments, drawType, tip) {
  const styles = [];
  const geometry = feature.getGeometry();
  const type = geometry.getType();
  let point, label, line;
  if (!drawType || drawType === type || type === 'Point') {
    styles.push(style);
    if (type === 'Polygon') {
      // 多边形：总面积气泡锚定在内部代表点（Interior Point），并提取外环作为折线用于分段测距
      point = geometry.getInteriorPoint();
      label = formatArea(geometry);
      line = new LineString(geometry.getCoordinates()[0]);
    } else if (type === 'LineString') {
      // 折线：总长度气泡锚定在最后一个顶点，自身直接用于分段测距
      point = new Point(geometry.getLastCoordinate());
      label = formatLength(geometry);
      line = geometry;
    }
  }
  // 若勾选了“显示分段长度”，遍历每条线段并在其中点（0.5 处）添加分段长度小气泡
  if (segments && line) {
    let count = 0;
    line.forEachSegment(function (a, b) {
      const segment = new LineString([a, b]);
      const label = formatLength(segment);
      // 样式对象池容量不足时，通过 clone() 扩容
      if (segmentStyles.length - 1 < count) {
        segmentStyles.push(segmentStyle.clone());
      }
      const segmentPoint = new Point(segment.getCoordinateAt(0.5));
      segmentStyles[count].setGeometry(segmentPoint);
      segmentStyles[count].getText().setText(label);
      styles.push(segmentStyles[count]);
      count++;
    });
  }
  // 添加总长度 / 总面积主气泡样式
  if (label) {
    labelStyle.setGeometry(point);
    labelStyle.getText().setText(label);
    styles.push(labelStyle);
  }
  // 添加鼠标跟随提示：仅在当前要素是光标点（Point）且 Modify 交互未吸附到任何已有顶点时才显示，避免两个提示框重叠
  if (
    tip &&
    type === 'Point' &&
    !modify.getOverlay().getSource().getFeatures().length
  ) {
    tipPoint = geometry;
    tipStyle.getText().setText(tip);
    styles.push(tipStyle);
  }
  return styles;
}

// 承载已完成测量图形的矢量图层
const vector = new VectorLayer({
  source: source,
  style: function (feature) {
    return styleFunction(feature, showSegments.checked);
  },
});

const map = new Map({
  layers: [raster, vector],
  target: 'map',
  view: new View({
    center: [-11000000, 4600000],
    zoom: 15,
  }),
});

map.addInteraction(modify);

let draw; // global so we can remove it later（保存当前 Draw 交互实例的全局引用，以便切换测量类型时移除重建）

function addInteraction() {
  const drawType = typeSelect.value;
  const activeTip =
    'Click to continue drawing the ' +
    (drawType === 'Polygon' ? 'polygon' : 'line');
  const idleTip = 'Click to start measuring';
  let tip = idleTip;
  draw = new Draw({
    source: source,
    type: drawType,
    style: function (feature) {
      return styleFunction(feature, showSegments.checked, drawType, tip);
    },
  });
  draw.on('drawstart', function () {
    if (clearPrevious.checked) {
      source.clear();
    }
    // 绘制过程中暂时禁用 Modify 交互，防止误触已有顶点拖拽
    modify.setActive(false);
    tip = activeTip;
  });
  draw.on('drawend', function () {
    // 绘制完成瞬间，将 Modify 提示框暂时固定在结束点，并重新启用 Modify 交互
    modifyStyle.setGeometry(tipPoint);
    modify.setActive(true);
    // 下一次鼠标移动时解除固定几何，恢复 Modify 默认的捕捉点跟随行为
    map.once('pointermove', function () {
      modifyStyle.setGeometry(null);
    });
    tip = idleTip;
  });
  modify.setActive(true);
  map.addInteraction(draw);
}

// 切换测量类型（长度 LineString / 面积 Polygon）时重建 Draw 交互
typeSelect.onchange = function () {
  map.removeInteraction(draw);
  addInteraction();
};

addInteraction();

// 切换“显示分段长度”复选框时，立即触发已完成矢量图层和正在绘制的草图图层重绘
showSegments.onchange = function () {
  vector.changed();
  draw.getOverlay().changed();
};
