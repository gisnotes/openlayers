Sentinel Hub Custom Script / 哨兵影像 Evalscript 在线波段解译与水分指数（NDMI）

SentinelHub4 process4 Evalscript1

Updating the Evalscript used by the Sentinel Hub source. / 演示如何使用 CodeMirror 在线编辑并在客户端动态热更 Sentinel Hub Evalscript 脚本，计算归一化差值水分指数（NDMI）。

This example demonstrates how a custom script can be used to render tiles from Sentinel Hub. Edit the setup() and evaluatePixel() functions above and click the update button to change the visualization. See the Sentinel Hub documentation on Evalscript for more information.

See the basic Sentinel Hub example for details on authentication.

本示例展示如何利用集成在界面顶部的 CodeMirror 6 代码编辑器，实时在线编写并在服务端即时编译执行 Sentinel Hub Evalscript 算法脚本。用户可自由修改 setup()（订阅光谱波段）与 evaluatePixel()（像素级波段代数与分类色带映射）逻辑，点击提交后通过 source.setEvalscript() 即时更新瓦片。

内置默认脚本演示了归一化差值水分指数（NDMI = (B08 - B11) / (B08 + B11)）的计算：通过比对近红外（B08）与短波红外（B11）的吸收反射差异，将地表水体、湿润植被与干燥裸土以冷暖色阶鲜明区分。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构原理 (Core Architecture)

在传统卫星遥感处理流程中，波段代数运算需要在本地桌面软件（如 ENVI、QGIS、ArcGIS）中经历重重投影、拼接、裁剪与栅格重分类，周期长且无法直接用于 Web 端交付。

  • Evalscript 实时边缘解译体系：Sentinel Hub 允许将 JavaScript 函数作为请求载荷的一部分发送至云端。在瓦片生成的毫秒级窗口内，服务端 V8 引擎直接将算法注入到原始多光谱像素流中，就地执行代数运算并即时返回渲染后的 RGB/RGBA 瓦片。
  • NDMI 水分指数机理： $$\text{NDMI} = \frac{\text{B08(NIR)} - \text{B11(SWIR)}}{\text{B08(NIR)} + \text{B11(SWIR)}}$$
    • $\text{NDMI} > 0.4$：高含水量水体或茂密多汁植被（渲染为深蓝色 [0, 0, 0.7]）；
    • $0 < \text{NDMI} \le 0.4$：中低水分草木（渲染为不同饱和度的青蓝色）；
    • $\text{NDMI} \le 0$：干燥裸露地表与岩石（按 $3 \times \text{RGB}$ 真彩色正常输出）。

3. 生产实战避坑与考量 (Production Pitfalls)

  • //VERSION=3 头部语法约束：Sentinel Hub 要求现代 Evalscript 脚本首行必须显式声明 //VERSION=3，否则会被旧版引擎判定为过时的 V1/V2 格式而直接抛出解析语法错误。
  • 实时编辑防抖与限流保护：在线编辑脚本时切勿将更新绑定在 input 或实时按键事件上，每次修改脚本都会导致全图切片重新向云端请求，高频重发极易耗尽 Sentinel Hub Processing API 的月度 Processing Units（PU）免费配额并触发 429 速率限制。使用明确的“提交按钮”是最佳防线。
main.js 
import {javascript} from '@codemirror/lang-javascript';
import {EditorView, basicSetup} from 'codemirror';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import {useGeographic} from 'ol/proj.js';
import SentinelHub from 'ol/source/SentinelHub.js';

useGeographic();

// Initialize Sentinel Hub source over the Nile River delta / Faiyum Oasis, Egypt
// 初始化 Sentinel Hub 数据源（定位至埃及尼罗河与法尤姆绿洲）
const source = new SentinelHub({
  data: [
    {
      type: 'sentinel-2-l2a',
      dataFilter: {
        timeRange: {
          from: '2024-05-15T00:00:00Z',
          to: '2024-05-25T00:00:00Z',
        },
      },
    },
  ],
});

const map = new Map({
  layers: [new TileLayer({source})],
  target: 'map',
  view: new View({
    center: [30.674, 29.935],
    zoom: 10,
    minZoom: 13,
    maxZoom: 15,
  }),
});

document.getElementById('auth-form').addEventListener('submit', (event) => {
  const clientId = event.target.elements['id'].value;
  const clientSecret = event.target.elements['secret'].value;
  source.setAuth({clientId, clientSecret});
});

// Default Evalscript computing Normalized Difference Moisture Index (NDMI)
// 默认 Evalscript：计算归一化差值水分指数 (NDMI)
const script = `//VERSION=3
function setup() {
  return {
    input: ['B02', 'B03', 'B04', 'B08', 'B11'],
    output: {bands: 3},
  };
}

function evaluatePixel(sample) {
  // Normalized Difference Moisture Index / 归一化差值水分指数
  const ndmi = (sample.B08 - sample.B11) / (sample.B08 + sample.B11);
  if (ndmi <= 0) {
    return [3 * sample.B04, 3 * sample.B03, 3 * sample.B02];
  }
  if (ndmi <= 0.2) {
    return [0, 0.8, 0.9];
  }
  if (ndmi <= 0.4) {
    return [0, 0.5, 0.9];
  }
  return [0, 0, 0.7];
}`;

// Instantiate CodeMirror 6 code editor
// 初始化嵌入式 CodeMirror 6 代码编辑器
const editor = new EditorView({
  doc: script,
  extensions: [basicSetup, javascript()],
  parent: document.getElementById('evalscript'),
});

// Update Evalscript dynamically upon form submission
// 提交表单时动态将编辑器内的代码赋给数据源并触发重绘
document
  .getElementById('evalscript-form')
  .addEventListener('submit', (event) => {
    event.preventDefault();
    source.setEvalscript(editor.state.doc.toString());
  });

source.setEvalscript(script);

source.on('change', () => {
  if (source.getState() === 'error') {
    alert(source.getError());
  }
});
