Layer Clipping / 图层几何遮罩裁切

Layer clipping example / 使用贝塞尔曲线与 Canvas 路径对图层进行几何蒙版裁切。

Layer clipping example. Demonstrates clipping a layer using arbitrary Canvas 2D paths.

本示例演示了如何通过监听图层的 prerender 事件，利用 HTML5 Canvas 2D 上下文的 ctx.clip() 方法对瓦片底图进行几何蒙版裁切。示例中使用贝塞尔曲线（Bézier Curves）在屏幕中心构造了一个爱心形状的矢量剪切蒙版，并根据地图的像素比（PixelRatio）与旋转角（Rotation）对变换矩阵进行反向抵消与动态校准，使裁切轮廓稳定居中显示。

📚 学习记录与技术深度解读 (Learning Notes)

1. 逆像素变换矩阵与屏幕空间锚定 (Inverse Pixel Transform & Rotation Decoupling)

  • 动态矩阵解析: 当地图发生平移、旋转（Rotation）或运行在高分屏（Retina / HiDPI）时，Canvas 2D 上下文已被 OpenLayers 预先施加了仿射变换。event.inversePixelTransform 提供了当前变换的逆矩阵 $[a, b, c, d, e, f]$。
  • 几何参数提取: $$\text{canvasPixelRatio} = \sqrt{a^2 + b^2}, \quad \text{canvasRotation} = -\text{atan2}(b, a)$$ 通过矩阵元素提取画布真实的物理像素比与视口旋转弧度，为屏幕空间固定形状的裁切提供了数学依据。
  • 居中对齐与旋转抵消: 通过 ctx.translate(width/2, height/2) 配合 ctx.rotate(-canvasRotation)，将坐标系锚定在屏幕绝对几何中心并抵消地图旋转角度，使蒙版无论地图如何旋转拖拽，始终端正居中。

2. 三次贝塞尔曲线路径与 ctx.clip()

  • 参数化路径造型: 利用 ctx.moveTo 与 6 段 ctx.bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y) 构建闭合心形矢量轮廓。
  • 硬件级像素裁剪: 调用 ctx.clip() 将当前 Canvas 上下文的绘制限制在闭合路径之内。随后的切片栅格化渲染只在心形蒙版区域生效，其余部分保持透明。

3. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices)

  • 成对的 save 与 restore: 状态保护至关重要。prerender 中调用的 ctx.save() 必须与 postrender 中的 ctx.restore() 一一严格配对。如果因代码异常中断未执行 restore()，裁剪蒙版将永久驻留，后续绘制的任何图层都将被裁切。
  • 矩阵变换逆操作顺序: 在执行 ctx.clip() 之后，如果需要恢复或继续在该图层上绘制其他内容，必须严格按照正向变换的逆顺序撤销平移和缩放（scale(1/scale) -> rotate -> translate），否则容易造成局部坐标系污染。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';

// OpenStreetMap tile layer subject to geometric clipping
// OpenStreetMap 切片图层：作为待裁切的目标底图
const osm = new TileLayer({
  source: new OSM(),
});

// Initialize map centered at [0, 0]
// 初始化地图实例：中心位于经纬度原点 [0, 0]，初始缩放层级为 2
const map = new Map({
  layers: [osm],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// Hook into prerender to establish the Bézier heart clipping mask
// 监听底图的 prerender 事件：在切片栅格化之前构建贝塞尔心形裁切蒙版
osm.on('prerender', function (event) {
  const ctx = event.context;

  // Calculate the pixel ratio and rotation of the canvas from inversePixelTransform
  // 根据事件逆变换矩阵计算 Canvas 画布的物理像素比与视口旋转角度
  const matrix = event.inversePixelTransform;
  const canvasPixelRatio = Math.sqrt(
    matrix[0] * matrix[0] + matrix[1] * matrix[1],
  );
  const canvasRotation = -Math.atan2(matrix[1], matrix[0]);
  ctx.save();

  // Center the canvas and neutralize rotation to position clipping mask in screen space
  // 将原点移至画布中心并抵消地图旋转，确保裁切蒙版稳定居中且保持竖直
  ctx.translate(ctx.canvas.width / 2, ctx.canvas.height / 2);
  ctx.rotate(-canvasRotation);

  // Scale and translate into local heart curve coordinates
  // 缩放并平移至心形局部坐标系
  ctx.scale(3 * canvasPixelRatio, 3 * canvasPixelRatio);
  ctx.translate(-75, -80);

  // Construct Bézier heart shape path
  // 利用三次贝塞尔曲线构建闭合爱心矢量路径
  ctx.beginPath();
  ctx.moveTo(75, 40);
  ctx.bezierCurveTo(75, 37, 70, 25, 50, 25);
  ctx.bezierCurveTo(20, 25, 20, 62.5, 20, 62.5);
  ctx.bezierCurveTo(20, 80, 40, 102, 75, 120);
  ctx.bezierCurveTo(110, 102, 130, 80, 130, 62.5);
  ctx.bezierCurveTo(130, 62.5, 130, 25, 100, 25);
  ctx.bezierCurveTo(85, 25, 75, 37, 75, 40);
  ctx.clip();

  // Reverse local scale and translation transformations
  // 反向撤销局部平移与缩放变换
  ctx.translate(75, 80);
  ctx.scale(1 / 3 / canvasPixelRatio, 1 / 3 / canvasPixelRatio);

  // Reapply canvas rotation and position back to original coordinate system
  // 恢复画布原有的旋转与居中位置
  ctx.rotate(canvasRotation);
  ctx.translate(-ctx.canvas.width / 2, -ctx.canvas.height / 2);
});

// Restore canvas context state after rendering completes
// postrender 阶段：恢复 Canvas 绘图状态栈，释放裁剪区
osm.on('postrender', function (event) {
  const ctx = event.context;
  ctx.restore();
});
