Earthquakes with custom symbols / 自定义矢量符号渲染地震点位（toContext 离屏绘制）

KML9 vector87 style27 canvas7 symbol3

Demonstrates the use of `toContext` to create custom icon symbols. / 演示如何使用 `toContext` 在离屏 Canvas 上直接绘制矢量几何，以生成自定义图标符号。

This example parses a KML file and renders the features as a vector layer. The layer is given a style that renders earthquake locations with a custom lightning symbol and a size relative to their magnitude.

本示例解析一份 KML 文件并将要素渲染为矢量图层。图层配置了一个动态 style 函数，使用自定义的闪电矢量符号来渲染地震位置，并根据震级（Magnitude）大小动态缩放闪电符号的尺寸。

核心知识点与代码解析

1. 离屏矢量渲染利器：toContext 与立即渲染器（Immediate Renderer）

  • 当内置的 CircleStyle（圆形）和 RegularShape（正多边形/星形）无法满足复杂异形符号（如本例中的不规则闪电、自定义风向标、战术标绘符号）需求，且又不想引入外部静态图片时，ol/render.js 中的 toContext 是最佳解决方案。
  • 工作原理：toContext(canvas.getContext('2d'), options) 将一个标准的原生 HTML5 Canvas 2D 上下文包装为 OpenLayers 的 CanvasImmediateRenderer（即 VectorContext 立即渲染器）。
  • 核心优势：开发者无需编写繁琐的原生 Canvas 路径指令（如 beginPath、moveTo、lineTo、stroke），而是可以直接调用 vectorContext.setStyle(style) 和 vectorContext.drawGeometry(geometry)，复用 OpenLayers 完整的几何变换 API 与样式系统，在内存中的离屏 <canvas> 上把矢量多边形光栅化为位图，再将其直接传给 new Icon({ img: canvas }) 作为点要素图标使用。

2. 闪电多边形的几何变换与包围盒归一化（getSymbolOutline）

  • 闭包预构造基础图形：代码通过 IIFE（立即执行函数表达式）在初始化阶段创建了一个由 6 个顶点组成的闭合闪电多边形 symbolOutline，并调用 symbolOutline.rotate(1.2, path[0]) 绕起点旋转 1.2 弧度（约 68.75°）。由于旋转操作只需执行一次，放在闭包外层避免了每次生成图标时重复计算三角函数。
  • 克隆与按震级缩放：在返回的函数中，先调用 symbolOutline.clone() 克隆基础几何体（防止污染原始模板），再调用 outline.scale(scale, scale, path[0]) 按震级比例 scale = 1 + 4 * (magnitude - 5) 等比放大。
  • 为什么必须执行 translate 平移归一化？
    • 经过旋转和缩放后，多边形的部分顶点坐标可能变为负数或偏离原点。如果直接绘制到 Canvas 上，位于负坐标象限的图形会被画布边界截断！
    • 同时，图形具有 lineWidth = 2 的描边宽度，描边会向多边形轮廓外侧扩展 lineWidth / 2（即 1 像素）。
    • 因此，代码先通过 const origin = getBottomLeft(outline.getExtent()) 获取几何体包围盒的最小坐标 [minX, minY]，再调用 outline.translate(offset - origin[0], offset - origin[1])（其中 offset = Math.ceil(lineWidth / 2)），将整个闪电多边形严丝合缝地平移到 [offset, offset] 起点处，既消除了负坐标截断，又在左上角预留了描边安全边距。
  • 画布尺寸精确计算：平移完成后，getTopRight(outline.getExtent()) 返回的 [maxX, maxY] 即为图形右下角极值，再加上右下侧的半个线宽 Math.ceil(n + lineWidth / 2)，就得到了能够完整包裹整个闪电及其描边的最小离屏 Canvas 逻辑宽高 size。

3. 高分屏（Retina / HiDPI）无损抗锯齿范式（DEVICE_PIXEL_RATIO）

  • 在 Mac Retina 屏或高分辨率移动设备上，直接将普通 Canvas 作为 Icon 渲染会出现明显的边缘模糊和锯齿。本示例展示了 OpenLayers 官方推荐的高分屏二步适配法：
    1. 物理像素超采样绘制：在 toContext 配置中传入 pixelRatio: DEVICE_PIXEL_RATIO（例如在 2 倍屏上为 2）。toContext 会自动将离屏 Canvas 的实际物理宽高（canvas.width / canvas.height）扩大 DEVICE_PIXEL_RATIO 倍，并在内部绘制 outline 和 Stroke 时自动按该倍率放大坐标与线宽。
    2. 逻辑像素等比还原：在构造 new Icon({ img: canvas, scale: 1 / DEVICE_PIXEL_RATIO }) 时，通过将 scale 设为 1 / DEVICE_PIXEL_RATIO，把高分辨率的离屏画布缩回到原有的 CSS 逻辑像素尺寸，从而在高分屏上呈现出刀刻般锐利的矢量级画质。

4. 性能优化双保险：featuresloadend 静默预处理 + styleCache 缓存

  • 数据加载期一次性提取属性（featuresloadend + silent: true）：
    • KML 文件中的震级隐藏在 <name> 标签文本（如 "M 5.8 - ..."）中。本示例没有在高频触发的 style 渲染函数里反复截取字符串，而是监听 vector.getSource().on('featuresloadend', ...) 事件，在数据加载完毕时一次性解析并写入 magnitude 属性。
    • 关键细节 f.set('magnitude', val, true)：第三个参数 true 表示 silent（静默更新），即修改属性时不派发要素的 change 事件。如果省略该参数，遍历上千个要素调用 set() 会连续触发上千次图层重绘通知，造成不必要的首屏卡顿。
  • 按震级缓存离屏 Canvas（styleCache[magnitude]）：
    • 创建 <canvas> DOM 节点并执行 2D 上下文光栅化属于重量级操作。由于震级数值通常保留一位小数（如 5.0 ~ 9.0 之间仅有几十种离散值），通过 styleCache[magnitude] 字典缓存生成的 Style 对象，使得成百上千个同震级地震要素直接共享同一个离屏 Canvas 纹理，渲染帧率与原生静态图片别无二致。

main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {getBottomLeft, getTopRight} from 'ol/extent.js';
import KML from 'ol/format/KML.js';
import Polygon from 'ol/geom/Polygon.js';
import {DEVICE_PIXEL_RATIO} from 'ol/has.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import {toContext} from 'ol/render.js';
import StadiaMaps from 'ol/source/StadiaMaps.js';
import VectorSource from 'ol/source/Vector.js';
import Fill from 'ol/style/Fill.js';
import Icon from 'ol/style/Icon.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

/**
 * 闭包函数：生成指定缩放比例和偏移量的不规则闪电多边形几何轮廓。
 * 通过 IIFE（立即执行函数表达式）预先定义基础图形并执行一次旋转，
 * 避免在渲染循环中重复创建和旋转多边形模板，提升运行效率。
 */
const getSymbolOutline = (function () {
  // 闪电符号的 6 个特征顶点（形成一个闭合折线环）
  const path = [
    [0, 0],
    [4, 2],
    [6, 0],
    [10, 5],
    [6, 3],
    [4, 5],
    [0, 0],
  ];
  // 基于顶点坐标构建基础多边形
  const symbolOutline = new Polygon([path]);
  // 绕原点 [0, 0] 顺时针旋转 1.2 弧度（约 68.75 度），使其呈现倾斜俯冲的闪电姿态
  symbolOutline.rotate(1.2, path[0]);

  /**
   * @param {number} scale 几何体缩放倍数（与震级挂钩）
   * @param {number} offset 坐标内边距偏移量（通常取描边宽度的一半），防止绘制时边缘描边被画布裁剪
   * @return {Polygon} 缩放并平移归一化后的多边形几何对象
   */
  return function (scale, offset) {
    // 克隆旋转后的几何模板，避免直接修改污染原多边形
    const outline = symbolOutline.clone();
    // 绕起点按指定倍率进行等比缩放
    outline.scale(scale, scale, path[0]);
    // 获取旋转缩放后几何体包围盒的左下角极值 [minX, minY]
    const origin = getBottomLeft(outline.getExtent());
    // 将几何体平移到 [offset, offset] 正坐标象限内，确保所有坐标均大于 0 且留有半线宽安全边距
    outline.translate(offset - origin[0], offset - origin[1]);
    return outline;
  };
})();

// 样式缓存字典：以震级数值为键，复用已生成的 Icon 样式实例
const styleCache = {};

// 地震矢量点图层：从 KML 加载数据，并通过动态 style 函数配合 toContext 离屏绘制闪电图标
const vector = new VectorLayer({
  source: new VectorSource({
    url: 'data/kml/2012_Earthquakes_Mag5.kml',
    format: new KML({
      // 禁用 KML 内置样式提取，完全由自定义 style 函数接管视觉表现
      extractStyles: false,
    }),
  }),
  /**
   * 动态样式回调函数
   * @param {import('ol/Feature.js').default} feature 当前渲染的地震要素
   * @return {Style} 匹配该地震震级的图标样式
   */
  style: function (feature) {
    const magnitude = feature.get('magnitude');
    let style = styleCache[magnitude];
    if (!style) {
      // 震级换算为缩放倍数：基准为 5 级地震（scale = 1），每增加 1 级放大 4 倍
      const scale = 1 + 4 * (magnitude - 5);
      const lineWidth = 2;
      // 生成平移归一化后的闪电几何轮廓，预留半线宽边距（1 像素）
      const outline = getSymbolOutline(scale, Math.ceil(lineWidth / 2));
      // 创建离屏 Canvas DOM 元素
      const canvas = document.createElement('canvas');
      // 将离屏 Canvas 上下文包装为 OpenLayers 立即渲染器（VectorContext）
      const vectorContext = toContext(canvas.getContext('2d'), {
        // 画布尺寸：基于多边形包围盒右上角坐标（即最大 X 和最大 Y），加上半线宽预留
        size: getTopRight(outline.getExtent()).map((n) =>
          Math.ceil(n + lineWidth / 2),
        ),
        // 设备像素比（高分屏适配）：按实际设备倍率超采样放大画布物理分辨率
        pixelRatio: DEVICE_PIXEL_RATIO,
      });
      // 在离屏渲染器上设置多边形的填充与描边样式
      vectorContext.setStyle(
        new Style({
          fill: new Fill({color: 'rgba(255, 153, 0, 0.4)'}), // 半透明亮橙色填充
          stroke: new Stroke({
            color: 'rgba(255, 204, 0, 0.2)', // 柔和的金黄色描边
            width: 2,
          }),
        }),
      );
      // 在离屏 Canvas 上直接绘制几何图形
      vectorContext.drawGeometry(outline);
      // 将离屏 Canvas 包装为 Icon 样式，并将 scale 设为 1 / DEVICE_PIXEL_RATIO 缩回 CSS 逻辑尺寸
      style = new Style({
        image: new Icon({
          img: canvas,
          scale: 1 / DEVICE_PIXEL_RATIO,
        }),
      });
      // 缓存该震级对应的样式对象，避免相同震级重复创建 Canvas
      styleCache[magnitude] = style;
    }
    return style;
  },
});

// 2012_Earthquakes_Mag5.kml stores the magnitude of each earthquake in a
// standards-violating <magnitude> tag in each Placemark.  We extract it from
// the Placemark's name instead.
// 注：该 KML 文件中的 <magnitude> 标签不符合官方规范，KML 解析器默认会忽略它。
// 因此我们从要素的名称（Placemark name，格式如 "M 5.9 - ..."）中截取前缀并解析浮点数震级。
function parseMagnitudeFromName(name) {
  return parseFloat(name.substr(2));
}

// 监听要素加载完成事件：一次性遍历并解析写入 magnitude 属性
vector.getSource().on('featuresloadend', function (evt) {
  evt.features.forEach((f) => {
    // 第三个参数传入 true 表示静默模式（silent），不触发要素的 change 事件，避免批量更新时造成重复重绘
    f.set('magnitude', parseMagnitudeFromName(f.get('name')), true);
  });
});

// 底图图层：采用黑白单色调的 Stadia Maps (Stamen Toner) 瓦片图层
const raster = new TileLayer({
  source: new StadiaMaps({
    layer: 'stamen_toner',
  }),
});

// 创建地图实例
const map = new Map({
  layers: [raster, vector],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});
