Sentinel Hub Custom Format / 哨兵影像切片格式动态切换（WebP / PNG / JPEG）

SentinelHub4 process4

Updating the format used by the Sentinel Hub source. / 演示如何动态更新 Sentinel Hub 数据源的切片图像压缩格式以优化传输带宽与加载延迟。

This example demonstrates how a custom format can be used to render tiles from Sentinel Hub. Select a format from the dropdown and click the update button to change the format. See the Sentinel Hub Examples for more information.

本示例展示如何在运行时动态配置 Sentinel Hub Processing API 返回的切片图像压缩格式。通过下拉菜单选择目标格式（PNG、JPEG 或现代化高效压缩的 WebP）并提交，OpenLayers 会调用 source.setFormat() 动态更新请求头与载荷结构，刷新并重新加载切片。不同格式在传输带宽消耗、加载解码时延与图像保真度之间提供不同的工程权衡方案。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构原理 (Core Architecture)

海量高分辨率多光谱卫星影像的瓦片网络传输是制约 WebGIS 交互流畅度的核心瓶颈：

  • 切片格式特征对比：
    • image/png：无损压缩，完整保留透明通道（Alpha），是包含云掩膜（Cloud Mask）或无数据区（NoData）专题切片的理想格式，但体积相对庞大；
    • image/jpeg：高压缩比有损格式，不支持 Alpha 透明通道，适合纯陆地真彩色卫星正射影像；
    • image/webp：新一代图像压缩标准，兼具微小体积与 Alpha 透明通道支持，比相同质量的 JPEG 节省 25%~34% 字节，比 PNG 节省 26%~70% 带宽。
  • source.setFormat() 动态热更流水线：调用该方法会同步重构内部发送给 Sentinel Hub Processing API 的 JSON 载荷中的 output.responses[0].format.type，并自动清空当前图层切片缓存（tileCache.clear()），触发全图以新格式无缝重载。

2. 关键实现与代码拆解 (Code Deep Dive)

const format = document.getElementById('format');

function updateInputData() {
  // 动态更新请求格式，并自动刷新切片重绘
  source.setFormat(format.value);
}

format.addEventListener('change', () => updateInputData());

3. 生产实战避坑与考量 (Production Pitfalls)

  • 透明通道丢失陷阱：若您的 evalscript 脚本中使用了透明度逻辑（如将水体或云层标记为透明），千万不要切换到 image/jpeg 格式，否则原本透明的区域会被强制填充为黑色或白色纯色背景。
  • 浮点数据格式延伸：除了前端直接可见的 RGB 栅格图，Sentinel Hub 还支持 image/tiff（配合 16 位整型或 32 位浮点），可在前端结合 GeoTIFF 解码器直接读取原始地表反射率数值并开展科学分析。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import {useGeographic} from 'ol/proj.js';
import SentinelHub from 'ol/source/SentinelHub.js';

useGeographic();

// Configure Sentinel Hub source with default PNG format
// 配置 Sentinel Hub 数据源，初始默认使用 PNG 格式
const source = new SentinelHub({
  data: [
    {
      type: 'sentinel-2-l2a',
      dataFilter: {
        timeRange: {
          from: '2024-05-30T00:00:00Z',
          to: '2024-06-01T00:00:00Z',
        },
      },
    },
  ],
  evalscript: {
    setup: () => ({
      input: ['B12', 'B08', 'B04'],
      output: {bands: 3},
    }),
    evaluatePixel: (sample) => [
      2.5 * sample.B12,
      2 * sample.B08,
      2 * sample.B04,
    ],
  },
  format: 'image/png',
});

const map = new Map({
  layers: [new TileLayer({source})],
  target: 'map',
  view: new View({
    center: [-121.75, 46.85],
    zoom: 10,
    minZoom: 7,
    maxZoom: 13,
  }),
});

// Authenticate via OAuth form
// 监听认证表单提交，设置鉴权密钥
document.getElementById('auth-form').addEventListener('submit', (event) => {
  const clientId = event.target.elements['id'].value;
  const clientSecret = event.target.elements['secret'].value;
  source.setAuth({clientId, clientSecret});
});

const format = document.getElementById('format');

/**
 * Update image format on the Sentinel Hub source dynamically.
 * 动态调用 source.setFormat() 切换目标切片压缩格式。
 */
function updateInputData() {
  source.setFormat(format.value);
}

format.addEventListener('change', () => updateInputData());
updateInputData();

source.on('change', () => {
  if (source.getState() === 'error') {
    alert(source.getError());
  }
});
