Dynamic clusters / 动态交互聚合（凸包预览、点击缩放与重叠点蛛网展开）

marker6 cluster3 vector86 style27 convexhull1

Clusters with zoom-to-cluster, hull view, and uncluttering of overlapping features. / 支持点击缩放至聚合范围、悬停显示凸包（Convex Hull）边界以及重叠要素环形蛛网展开（Spiderfier）的高级聚合示例。

This example shows open data of subsidized photovoltaic installations in Vienna. Different style functions are used for cluster display, single feature display, convex hull of a cluster, and an expanded view of overlapping features. Hovering over a cluster shows its convex hull. Clicking on a cluster zooms to the extent of the contained features. Clicking on a cluster consisting of features that are very close to each other reveals an expanded view of the features, along a circle around the cluster.

Features are styled differently depending on the power of the photovoltaic installation.

本示例展示了维也纳市受补贴光伏发电设施的开放数据。代码中针对聚合点显示、单要素显示、聚合包的凸包（Convex Hull）多边形以及重叠要素的环形散开视图（Spiderfier）分别设计了独立的样式函数：当鼠标悬停在某个聚合点上时，会高亮显示该聚合包所涵盖点位的凸包范围；点击普通聚合点时，地图会平滑缩放至其内部所有子要素的边界范围（Extent）；而当点击一个由彼此距离极近（或完全同址重叠）的要素组成的聚合点时，则会围绕聚合中心沿圆周展开显示各个独立要素。

此外，单个光伏设施要素会根据其装机功率（属性字段 LEISTUNG）的不同而渲染不同的图标样式。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构设计：为什么要用 3 个 VectorLayer 共享同一个 Cluster 数据源？

阅读代码第 191~215 行会发现一个非常巧妙的图层组织技巧：全局只创建了一个 clusterSource，却同时挂载给了三个独立的矢量图层（按从底到顶的渲染顺序排列）：

图层变量名 渲染层级（Z-Order） 绑定的样式函数 职责与分离原因
clusterHulls 底层（最先绘制） clusterHullStyle 仅在鼠标悬停时绘制当前聚合包的橙色半透明凸包多边形（Convex Hull）。放在最底层可确保凸包多边形永远不会遮挡上方的聚合圆圈和数字
clusters 中层（常规层） clusterStyle 绘制常规的双层同心圆聚合徽章（size > 1）或单个光伏电站图标（size === 1，按功率 LEISTUNG > 5 区分深色/浅色图标）
clusterCircles 顶层（最后绘制） clusterCircleStyle 仅在点击同址重叠聚合点时，绘制环形蛛网展开线（Spider Legs）与散开后的子要素图标，确保展开后的图标浮在所有常规聚合点之上，不被遮挡

性能优势：当鼠标移动触发 hoverFeature 变化时，只需调用 clusterHulls.setStyle(clusterHullStyle) 局部重绘底层的凸包图层，而无需重新计算和重绘上千个常规聚合点！

2. 悬停凸包计算（monotoneChainConvexHull）

  • 什么是凸包（Convex Hull）？ 就像用一根橡皮筋套住聚合包内的所有离散点位，橡皮筋收紧后形成的最外圈凸多边形边界。它能直观告诉用户：“这个聚合圆圈里的点到底分布在多大的地理区域内”。
  • 实现方式：在 clusterHullStyle(cluster) 中，提取出聚合包内所有原始要素的坐标数组 points，直接传入轻量级算法库 monotoneChainConvexHull(points)（基于 Andrew 单调链算法，时间复杂度 O(n log n)），拿到按顺序排列的外环顶点坐标后构造 new Polygon([ring]) 并赋给 Style.geometry 即可直接渲染。

3. 点击聚合点的智能分流策略：“缩放定位（view.fit）” vs. “蛛网展开（Spiderfier）”

在实际业务中，点击聚合点最怕遇到“同址多点（如同一栋大楼安装了 10 个光伏电站，坐标完全相同）”——如果一味执行 view.fit(extent) 放大，哪怕放到最大级别 maxZoom: 19，这 10 个点依然叠在一起无法分开！ 本示例在 map.on('click')（第 266~277 行）中给出了工业级标准解法：

if (
  view.getZoom() === view.getMaxZoom() ||
  (getWidth(extent) < resolution && getHeight(extent) < resolution)
) {
  // 分支 A：已达最大缩放级别，或所有子要素的地理跨度在当前分辨率下不足 1 个像素（同址重叠） -> 触发环形蛛网展开！
  clickFeature = features[0];
  clickResolution = resolution;
  clusterCircles.setStyle(clusterCircleStyle);
} else {
  // 分支 B：子要素在空间上可区分 -> 平滑缩放至子要素包围盒，让聚合自然解开
  view.fit(extent, {duration: 500, padding: [50, 50, 50, 50]});
}

4. 环形蛛网展开算法（generatePointsCircle）数学原理

借鉴自著名的 Leaflet.markercluster（Spiderfier）：

  1. 根据子要素个数 count 动态计算圆周长与半径：
    • 设定相邻两个展开图标在圆周上的弧长间距 circleFootSeparation = 28（像素），计算总圆周长 circumference = 1 * 28 * (2 + count)。
    • 由圆周长公式反推像素半径 legLength = circumference / (2 * Math.PI)，并限制最小半径为 35px（确保展开后的图标一定落在聚合圆圈外部），再乘以当前分辨率 resolution 换算为地图投影坐标长度。
  2. 按角度均匀分布并绘制牵引线：
    • 将圆周 2 * Math.PI 等分为 count 份（angleStep），利用三角函数 cos(angle) 和 sin(angle) 算出每个子要素在圆周上的新坐标 coordinates。
    • 在 reduce 循环中，使用 styles.unshift(...) 将连接中心点与圆周点的牵引线（LineString）插入样式数组头部（先画线），再使用 styles.push(...) 将子要素图标追加到数组尾部（后画图标盖住线头），细节极其考究。
main.js 
import monotoneChainConvexHull from 'monotone-chain-convex-hull';
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {createEmpty, extend, getHeight, getWidth} from 'ol/extent.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import LineString from 'ol/geom/LineString.js';
import Point from 'ol/geom/Point.js';
import Polygon from 'ol/geom/Polygon.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import {fromLonLat} from 'ol/proj.js';
import Cluster from 'ol/source/Cluster.js';
import ImageTile from 'ol/source/ImageTile.js';
import VectorSource from 'ol/source/Vector.js';
import CircleStyle from 'ol/style/Circle.js';
import Fill from 'ol/style/Fill.js';
import Icon from 'ol/style/Icon.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';
import Text from 'ol/style/Text.js';

// 环形蛛网展开（Spiderfier）算法的几何常量：间距倍数、相邻图标圆周弧长间距（28px）、起始角度（90° 正上方）
const circleDistanceMultiplier = 1;
const circleFootSeparation = 28;
const circleStartAngle = Math.PI / 2;

// 1. 预定义复用的填充、描边、同心圆与图标样式实例
// 悬停凸包多边形（Convex Hull）的半透明橙色填充与深橙色描边（该描边也复用于蛛网展开牵引线）
const convexHullFill = new Fill({
  color: 'rgba(255, 153, 0, 0.4)',
});
const convexHullStroke = new Stroke({
  color: 'rgba(204, 85, 0, 1)',
  width: 1.5,
});
// 聚合点双层同心圆（外圈浅橙色半径 20px + 内圈深橙色半径 14px）与中心数字样式
const outerCircleFill = new Fill({
  color: 'rgba(255, 153, 102, 0.3)',
});
const innerCircleFill = new Fill({
  color: 'rgba(255, 165, 0, 0.7)',
});
const textFill = new Fill({
  color: '#fff',
});
const textStroke = new Stroke({
  color: 'rgba(0, 0, 0, 0.6)',
  width: 3,
});
const innerCircle = new CircleStyle({
  radius: 14,
  fill: innerCircleFill,
});
const outerCircle = new CircleStyle({
  radius: 20,
  fill: outerCircleFill,
});
// 单个光伏设施图标：装机功率 > 5kW 使用深色实心笑脸图标，<= 5kW 使用浅色轮廓笑脸图标
const darkIcon = new Icon({
  src: 'data/icons/emoticon-cool.svg',
});
const lightIcon = new Icon({
  src: 'data/icons/emoticon-cool-outline.svg',
});

/**
 * Single feature style, users for clusters with 1 feature and cluster circles.
 * 单个要素的图标样式函数（同时服务于仅含 1 个要素的聚合点，以及环形蛛网展开后的每个子要素点）
 * @param {Feature} clusterMember A feature from a cluster.
 * @return {Style} An icon style for the cluster member's location.
 */
function clusterMemberStyle(clusterMember) {
  return new Style({
    geometry: clusterMember.getGeometry(),
    image: clusterMember.get('LEISTUNG') > 5 ? darkIcon : lightIcon,
  });
}

let clickFeature, clickResolution;
/**
 * Style for clusters with features that are too close to each other, activated on click.
 * 针对内部子要素距离过近（或同址重叠）的聚合点的环形展开样式函数（点击时激活）
 * @param {Feature} cluster A cluster with overlapping members.
 * @param {number} resolution The current view resolution.
 * @return {Array<Style>|null} A style to render an expanded view of the cluster members.
 */
function clusterCircleStyle(cluster, resolution) {
  // 仅对当前点击选中的那个聚合点生效；一旦点击其他要素或地图发生缩放（resolution 改变），立即收起展开视图
  if (cluster !== clickFeature || resolution !== clickResolution) {
    return null;
  }
  const clusterMembers = cluster.get('features');
  const centerCoordinates = cluster.getGeometry().getCoordinates();
  return generatePointsCircle(
    clusterMembers.length,
    cluster.getGeometry().getCoordinates(),
    resolution,
  ).reduce((styles, coordinates, i) => {
    const point = new Point(coordinates);
    const line = new LineString([centerCoordinates, coordinates]);
    // 使用 unshift 将牵引线（LineString）插入数组头部，确保牵引线先绘制在底层
    styles.unshift(
      new Style({
        geometry: line,
        stroke: convexHullStroke,
      }),
    );
    // 使用 push 将展开到圆周上的子要素图标追加到数组尾部，确保图标后绘制并覆盖在牵引线末端之上
    styles.push(
      clusterMemberStyle(
        new Feature({
          ...clusterMembers[i].getProperties(),
          geometry: point,
        }),
      ),
    );
    return styles;
  }, []);
}

/**
 * From
 * https://github.com/Leaflet/Leaflet.markercluster/blob/31360f2/src/MarkerCluster.Spiderfier.js#L55-L72
 * Arranges points in a circle around the cluster center, with a line pointing from the center to
 * each point.
 * 借鉴自 Leaflet.markercluster 的蛛网展开算法：将聚合包内的所有子要素围绕聚合中心按圆周均匀排列
 * @param {number} count Number of cluster members.
 * @param {Array<number>} clusterCenter Center coordinate of the cluster.
 * @param {number} resolution Current view resolution.
 * @return {Array<Array<number>>} An array of coordinates representing the cluster members.
 */
function generatePointsCircle(count, clusterCenter, resolution) {
  const circumference =
    circleDistanceMultiplier * circleFootSeparation * (2 + count);
  let legLength = circumference / (Math.PI * 2); //radius from circumference（由圆周长反推像素半径）
  const angleStep = (Math.PI * 2) / count;
  const res = [];
  let angle;

  legLength = Math.max(legLength, 35) * resolution; // Minimum distance to get outside the cluster icon.（最小半径 35px，确保展开点落在聚合圆外部，并乘以分辨率换算为地图坐标长度）

  for (let i = 0; i < count; ++i) {
    // Clockwise, like spiral.（按角度步长围绕中心均匀计算圆周坐标）
    angle = circleStartAngle + i * angleStep;
    res.push([
      clusterCenter[0] + legLength * Math.cos(angle),
      clusterCenter[1] + legLength * Math.sin(angle),
    ]);
  }

  return res;
}

let hoverFeature;
/**
 * Style for convex hulls of clusters, activated on hover.
 * 聚合包的凸包（Convex Hull）多边形样式函数（鼠标悬停时激活）
 * @param {Feature} cluster The cluster feature.
 * @return {Style|null} Polygon style for the convex hull of the cluster.
 */
function clusterHullStyle(cluster) {
  if (cluster !== hoverFeature) {
    return null;
  }
  const originalFeatures = cluster.get('features');
  const points = originalFeatures.map((feature) =>
    feature.getGeometry().getCoordinates(),
  );
  // 使用 monotoneChainConvexHull 计算包络所有子要素坐标的最小凸多边形外环顶点
  return new Style({
    geometry: new Polygon([monotoneChainConvexHull(points)]),
    fill: convexHullFill,
    stroke: convexHullStroke,
  });
}

/**
 * 常规聚合图层样式函数：多要素显示为双层同心圆 + 数量文本，单要素直接显示光伏电站图标
 * @param {import('ol/Feature.js').FeatureLike} feature 聚合要素
 * @return {Array<Style>|Style} 渲染样式
 */
function clusterStyle(feature) {
  const size = feature.get('features').length;
  if (size > 1) {
    return [
      new Style({
        image: outerCircle,
      }),
      new Style({
        image: innerCircle,
        text: new Text({
          text: size.toString(),
          fill: textFill,
          stroke: textStroke,
        }),
      }),
    ];
  }
  const originalFeature = feature.get('features')[0];
  return clusterMemberStyle(originalFeature);
}

// 原始光伏电站 GeoJSON 矢量数据源
const vectorSource = new VectorSource({
  format: new GeoJSON(),
  url: 'data/geojson/photovoltaic.json',
});

// 聚合数据源（聚合像素距离 35px），同时供给下方 3 个不同职责的 VectorLayer 共享使用
const clusterSource = new Cluster({
  attributions:
    'Data: <a href="https://www.data.gv.at/auftritte/?organisation=stadt-wien">Stadt Wien</a>',
  distance: 35,
  source: vectorSource,
});

// Layer displaying the convex hull of the hovered cluster.
// 第 1 层（底层）：用于渲染鼠标悬停聚合包的凸包（Convex Hull）多边形
const clusterHulls = new VectorLayer({
  source: clusterSource,
  style: clusterHullStyle,
});

// Layer displaying the clusters and individual features.
// 第 2 层（中层）：用于渲染常规聚合同心圆徽章与单个光伏电站图标
const clusters = new VectorLayer({
  source: clusterSource,
  style: clusterStyle,
});

// Layer displaying the expanded view of overlapping cluster members.
// 第 3 层（顶层）：用于渲染点击重叠聚合点时的环形蛛网展开视图（Spiderfier）
const clusterCircles = new VectorLayer({
  source: clusterSource,
  style: clusterCircleStyle,
});

// 维也纳官方灰色底图（basemap.at）
const raster = new TileLayer({
  source: new ImageTile({
    attributions:
      'Base map: <a target="_blank" href="https://basemap.at/">basemap.at</a>',
    url: 'https://maps{1-4}.wien.gv.at/basemap/bmapgrau/normal/google3857/{z}/{y}/{x}.png',
  }),
});

const map = new Map({
  layers: [raster, clusterHulls, clusters, clusterCircles],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
    maxZoom: 19,
    // 限制视图范围为维也纳市区，并允许查看完整范围
    extent: [
      ...fromLonLat([16.1793, 48.1124]),
      ...fromLonLat([16.5559, 48.313]),
    ],
    showFullExtent: true,
  }),
});

// 监听鼠标移动：异步碰撞检测当前像素下的聚合点，悬停时绘制底层凸包并切换手型光标
map.on('pointermove', (event) => {
  clusters.getFeatures(event.pixel).then((features) => {
    if (features[0] !== hoverFeature) {
      // Display the convex hull on hover.
      hoverFeature = features[0];
      clusterHulls.setStyle(clusterHullStyle);
      // Change the cursor style to indicate that the cluster is clickable.
      map.getTargetElement().style.cursor =
        hoverFeature && hoverFeature.get('features').length > 1
          ? 'pointer'
          : '';
    }
  });
});

// 监听鼠标点击：智能判断是“平滑缩放至子要素范围”还是“原地触发环形蛛网展开”
map.on('click', (event) => {
  clusters.getFeatures(event.pixel).then((features) => {
    if (features.length > 0) {
      const clusterMembers = features[0].get('features');
      if (clusterMembers.length > 1) {
        // Calculate the extent of the cluster members.
        // 计算该聚合包内所有子要素的地理包围盒（Extent）
        const extent = createEmpty();
        clusterMembers.forEach((feature) =>
          extend(extent, feature.getGeometry().getExtent()),
        );
        const view = map.getView();
        const resolution = map.getView().getResolution();
        if (
          view.getZoom() === view.getMaxZoom() ||
          (getWidth(extent) < resolution && getHeight(extent) < resolution)
        ) {
          // Show an expanded view of the cluster members.
          // 若已达最大缩放级别，或所有子要素间距不足 1 像素（同址重叠），则触发环形蛛网展开视图
          clickFeature = features[0];
          clickResolution = resolution;
          clusterCircles.setStyle(clusterCircleStyle);
        } else {
          // Zoom to the extent of the cluster members.
          // 否则平滑缩放至子要素包围盒范围（500ms 动画，四周留白 50px）
          view.fit(extent, {duration: 500, padding: [50, 50, 50, 50]});
        }
      }
    }
  });
});
