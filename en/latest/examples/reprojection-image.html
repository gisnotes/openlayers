单幅静态图像客户端重投影 (Image Reprojection)

reprojection8 projection14 proj4js6 image8 imagestatic1

演示单幅静态图像（ImageStatic）在客户端由特定投影实时重投影到地图视图投影。

本例展示了 OpenLayers 在客户端对单幅静态图像数据源（ol/source/ImageStatic）进行实时栅格重投影（Raster Reprojection）的能力。

核心机制与原理解析

  1. 静态图像源的跨投影贴合：

    • 示例中的静态图片是维基共享资源中以英国国家格网坐标系（EPSG:27700 / British National Grid）绘制的英国全境网格图。
    • 地图视图采用主流的 Web 墨卡托投影（EPSG:3857）。
    • 通过在 ol/source/ImageStatic 中明确声明 projection: 'EPSG:27700' 和其在源投影下的几何范围 imageExtent: [0, 0, 700000, 1300000]，OpenLayers 结合 Proj4js 的坐标转换参数，自动在客户端 Canvas 画布上构建非线性三角形映射网格，将原本为横轴墨卡托投影（Airy 椭球）的图像实时扭曲变形并精确叠加到全球 OSM 底图上。

  2. 双线性插值平滑控制（interpolate 参数）：

    • 勾选 双线性插值平滑（Interpolate） 时，OpenLayers 在重投影像素重采样时采用双线性插值算法，有效消除倾斜拉伸带来的马赛克锯齿，使文字、地貌线条过渡更柔和。
    • 取消勾选时，采用最近邻采样（Nearest Neighbor），像元保持原始像素块形态。在遥感土地利用分类图或离散数值栅格等场景中，关闭插值可避免分类边界混合出不存在的过渡伪值。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import {getCenter} from 'ol/extent.js';
import ImageLayer from 'ol/layer/Image.js';
import TileLayer from 'ol/layer/Tile.js';
import {transform} from 'ol/proj.js';
import {register} from 'ol/proj/proj4.js';
import Static from 'ol/source/ImageStatic.js';
import OSM from 'ol/source/OSM.js';
import proj4 from 'proj4';

// 向 Proj4js 注册英国国家格网坐标系（EPSG:27700，基于 Airy 1830 椭球体的横轴墨卡托投影）
proj4.defs(
  'EPSG:27700',
  '+proj=tmerc +lat_0=49 +lon_0=-2 +k=0.9996012717 ' +
    '+x_0=400000 +y_0=-100000 +ellps=airy ' +
    '+towgs84=446.448,-125.157,542.06,0.15,0.247,0.842,-20.489 ' +
    '+units=m +no_defs',
);
// 将 proj4 投影定义同步至 OpenLayers 投影注册表
register(proj4);

// 静态图片在源坐标系 EPSG:27700 下的有效范围 [minX, minY, maxX, maxY]（单位：米）
const imageExtent = [0, 0, 700000, 1300000];

// 创建用于承载重投影静态图像的单图像图层
const imageLayer = new ImageLayer();

// 初始化地图实例（视图投影默认为 EPSG:3857 Web 墨卡托）
const map = new Map({
  layers: [
    // 基础 OSM 瓦片底图（EPSG:3857）
    new TileLayer({
      source: new OSM(),
    }),
    imageLayer,
  ],
  target: 'map',
  view: new View({
    // 将图像在 EPSG:27700 下的几何中心点，转换为地图当前视图投影 EPSG:3857 坐标
    center: transform(getCenter(imageExtent), 'EPSG:27700', 'EPSG:3857'),
    zoom: 4,
  }),
});

// 获取插值开关复选框 DOM
const interpolate = document.getElementById('interpolate');

/**
 * 重新构建并设置静态图像源
 * 当切换 interpolate 状态时，重新创建 ImageStatic 数据源并更新图层
 */
function setSource() {
  const source = new Static({
    url:
      'https://upload.wikimedia.org/wikipedia/commons/thumb/1/18/' +
      'British_National_Grid.svg/2000px-British_National_Grid.svg.png',
    crossOrigin: '',
    // 指定该图片本身的原始空间参考坐标系
    projection: 'EPSG:27700',
    // 指定该图片在源坐标系下的外包矩形范围
    imageExtent: imageExtent,
    // 是否启用双线性插值平滑（true 为双线性平滑，false 为最近邻离散像元采样）
    interpolate: interpolate.checked,
  });
  imageLayer.setSource(source);
}

// 首次执行初始化数据源
setSource();

// 监听插值开关切换事件
interpolate.addEventListener('change', setSource);
