Earthquakes in KML / KML 地震点位符号化与悬浮提示框（Tooltip）

KML9 vector87 style27 tooltip2

Demonstrates the use of a Shape symbolizer to render earthquake locations. / 演示解析 KML 地震数据，利用样式缓存（Style Cache）按震级大小渲染圆形符号，并结合 Bootstrap Tooltip 实现鼠标跟随信息提示。

This example parses a KML file and renders the features as a vector layer. The layer is given a style that renders earthquake locations with a size relative to their magnitude.

本示例解析了一份 KML 地震数据文件并将其渲染为矢量图层。图层通过自定义动态样式函数（styleFunction），根据每次地震的震级（Magnitude）按比例动态渲染不同半径大小的半透明橙色圆圈符号，并在鼠标悬停或点击时通过 Bootstrap Tooltip 展示地震详情。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心性能优化：为什么在 styleFunction 中必须使用 styleCache（享元模式）？

查看代码第 13~38 行：

const styleCache = {};
const styleFunction = function (feature) {
  const name = feature.get('name');
  const magnitude = parseFloat(name.substr(2));
  const radius = 5 + 20 * (magnitude - 5);
  let style = styleCache[radius];
  if (!style) {
    style = new Style({ ... });
    styleCache[radius] = style;
  }
  return style;
};
  • 问题背景：2012_Earthquakes_Mag5.kml 中包含 1,500 多个 5 级以上地震点要素，而震级一般精确到小数点后一位（如 5.0、5.1、...、8.6），这意味着实际上只有 30~40 种不同的半径（radius）。
  • 如果不加 styleCache 会怎样？
    • 地图每次平移或缩放重绘时，styleFunction 会被调用 1,500 多次。如果每次都执行 new Style({ image: new CircleStyle(...) })，不仅会在内存中瞬间创建上千个重复对象，更致命的是：OpenLayers 的 CircleStyle 在底层会为每一个实例创建一个独立的离屏 Canvas 贴图缓存（Sprite Atlas）！1,500 个不同引用的 CircleStyle 会导致浏览器频繁创建离屏 Canvas，严重拖慢帧率。
  • 加入 styleCache[radius] 后：所有震级相同（例如同为 5.2 级）的几百个地震点，在内存中共享同一个 Style 与 CircleStyle 实例，离屏 Canvas 只绘制 30 余次即可复用上千次，内存与渲染开销直接降低 95% 以上！

2. 脱离 ol/Overlay 实现轻量级鼠标跟随 Tooltip 的五大细节

本示例没有使用 ol/Overlay，而是直接在 #map 容器内放了一个 1px × 1px 的绝对定位锚点 <div id="info"></div>，配合 Bootstrap 5 的 bootstrap.Tooltip 实现了极速跟随提示框（第 65~115 行）：

  1. 防鼠标事件遮挡（pointer-events: none）：
    • 同时设置了 info.style.pointerEvents = 'none' 与 Bootstrap Tooltip 配置项 customClass: 'pe-none'。这保证了悬浮在地图上方的提示框 DOM 永远不会拦截鼠标的移动、点击或滚轮缩放事件。
  2. 过滤地图控件区域（target.closest('.ol-control')）：
    • 当鼠标移动到左上角的缩放按钮（+ / -）或右下角的版权折叠按钮上时，如果底部恰好压着一个地震圆圈，普通碰撞检测仍会触发弹窗。通过 target.closest('.ol-control') ? undefined : map.forEachFeatureAtPixel(...)，巧妙屏蔽了控件按钮区域上的要素拾取。
  3. 拖拽地图时自动隐藏（if (evt.dragging)）：
    • 在 pointermove 中优先判断 evt.dragging，一旦用户按住鼠标拖动地图，立即隐藏 Tooltip 并清空 currentFeature，防止拖拽过程中高频触发像素碰撞检测造成卡顿。
  4. 按需更新内容与位置（currentFeature 状态缓存）：
    • 只有当拾取到的要素发生变化（feature !== currentFeature）时，才调用 tooltip.setContent(...) 修改 DOM 文本。
    • 当鼠标在同一个大圆圈内部移动（currentFeature 已存在）时，只调用轻量的 tooltip.update() 更新位置，而不重复调用 tooltip.show()。
  5. 鼠标移出地图容器时清理（pointerleave）：
    • 监听 map.getTargetElement().addEventListener('pointerleave', ...)，确保鼠标移出地图画布边缘时提示框立即消失，不会残留在屏幕边缘。

3. 同一份地震数据集（2012_Earthquakes_Mag5.kml）的三种可视化范式横向对比

OpenLayers 官方围绕同一份 2012 年全球地震 KML 数据提供了 3 个递进示例，代表了海量点位可视化的三种核心方案：

示例名称 核心技术方案 适用场景与视觉特点
本示例（kml-earthquakes） VectorLayer + CircleStyle + styleCache 样式缓存 + Bootstrap Tooltip 适合需要直观查看每一个独立震中位置与精确震级大小，并通过鼠标悬停逐一查看单点详情的场景
地震点位聚合（earthquake-clusters） ol/source/Cluster + 动态包围盒半径 + Select 悬停原地散开五角星 适合在小比例尺下消除密集点位重叠杂乱，宏观展示各区域地震数量，同时保留悬停查看局部个体的能力
地震分布热力图（heatmap-earthquakes） ol/layer/Heatmap（WebGL 两阶段高斯核累加与色带映射） 适合宏观分析全球地震高发带（如环太平洋火山地震带）的能量密度分布，不关注单个点边界，渲染性能最高
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import KML from 'ol/format/KML.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import StadiaMaps from 'ol/source/StadiaMaps.js';
import VectorSource from 'ol/source/Vector.js';
import CircleStyle from 'ol/style/Circle.js';
import Fill from 'ol/style/Fill.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

// 样式缓存字典（享元模式）：以圆圈像素半径 radius 为键缓存 Style 实例，避免为相同震级的上千个地震点重复创建离屏 Canvas 贴图
const styleCache = {};
const styleFunction = function (feature) {
  // 2012_Earthquakes_Mag5.kml stores the magnitude of each earthquake in a
  // standards-violating <magnitude> tag in each Placemark.  We extract it from
  // the Placemark's name instead.
  // 2012_Earthquakes_Mag5.kml 将每次地震的震级保存在了不符合 KML 标准的 <magnitude> 标签中，
  // 因此我们改为直接从 Placemark 的 name 属性（如 "M 5.8 - ..."）中截取解析震级数值。
  const name = feature.get('name');
  const magnitude = parseFloat(name.substr(2));
  // 震级 M5.0 对应基础半径 5px，震级每增加 1 级半径放大 20px
  const radius = 5 + 20 * (magnitude - 5);
  let style = styleCache[radius];
  if (!style) {
    style = new Style({
      image: new CircleStyle({
        radius: radius,
        fill: new Fill({
          color: 'rgba(255, 153, 0, 0.4)',
        }),
        stroke: new Stroke({
          color: 'rgba(255, 204, 0, 0.2)',
          width: 1,
        }),
      }),
    });
    styleCache[radius] = style;
  }
  return style;
};

// 创建地震矢量图层：加载 2012 年 5 级以上地震 KML 数据（关闭 KML 内置样式提取）
const vector = new VectorLayer({
  source: new VectorSource({
    url: 'data/kml/2012_Earthquakes_Mag5.kml',
    format: new KML({
      extractStyles: false,
    }),
  }),
  style: styleFunction,
});

// 创建 StadiaMaps (Stamen Toner 黑白底图) 瓦片图层
const raster = new TileLayer({
  source: new StadiaMaps({
    layer: 'stamen_toner',
  }),
});

const map = new Map({
  layers: [raster, vector],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// 获取地图容器内的 1px × 1px 绝对定位锚点 DOM，并初始化手动控制的 Bootstrap Tooltip
const info = document.getElementById('info');
info.style.pointerEvents = 'none'; // 禁止锚点拦截鼠标事件
const tooltip = new bootstrap.Tooltip(info, {
  animation: false,
  customClass: 'pe-none', // 为弹出的 Tooltip DOM 添加 pointer-events: none 类，防止遮挡地图交互
  offset: [0, 5],
  title: '-',
  trigger: 'manual',
});

// 缓存当前鼠标悬停/点击命中的要素引用，避免在同一要素内移动时重复设置文本内容
let currentFeature;
const displayFeatureInfo = function (pixel, target) {
  // 若鼠标当前位于地图控件按钮（.ol-control）上方，则跳过要素拾取
  const feature = target.closest('.ol-control')
    ? undefined
    : map.forEachFeatureAtPixel(pixel, function (feature) {
        return feature;
      });
  if (feature) {
    // 将 #info 锚点直接移动到当前鼠标像素坐标处
    info.style.left = pixel[0] + 'px';
    info.style.top = pixel[1] + 'px';
    if (feature !== currentFeature) {
      tooltip.setContent({'.tooltip-inner': feature.get('name')});
    }
    if (currentFeature) {
      // 如果上一帧已经显示了 Tooltip，只需轻量更新其位置
      tooltip.update();
    } else {
      // 否则首次弹出显示 Tooltip
      tooltip.show();
    }
  } else {
    tooltip.hide();
  }
  currentFeature = feature;
};

// 监听鼠标移动：拖拽地图时立即隐藏提示框，非拖拽状态下实时拾取并跟随显示地震信息
map.on('pointermove', function (evt) {
  if (evt.dragging) {
    tooltip.hide();
    currentFeature = undefined;
    return;
  }
  displayFeatureInfo(evt.pixel, evt.originalEvent.target);
});

// 监听地图点击（兼顾移动端触屏点击查看详情）
map.on('click', function (evt) {
  displayFeatureInfo(evt.pixel, evt.originalEvent.target);
});

// 当鼠标移出地图容器边界时，立即隐藏提示框并清空选中状态
map.getTargetElement().addEventListener('pointerleave', function () {
  tooltip.hide();
  currentFeature = undefined;
});
