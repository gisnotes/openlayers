WMS GetFeatureInfo (Image Layer) / WMS 单图要素属性查询与像素探测

getfeatureinfo2 getData2

 

Using an image WMS source with GetFeatureInfo requests / 基于单张图像 WMS 数据源执行 GetFeatureInfo 点击查询与 getData 悬浮像素命中探测。

This example shows how to trigger WMS GetFeatureInfo requests on click for a WMS image layer. Additionally layer.getData(pixel) is used to change the mouse pointer when hovering a non-transparent pixel on the map.

本示例演示了如何为 WMS 单张图像图层（Image Layer）绑定点击事件以触发 OGC GetFeatureInfo 要素属性查询请求。此外，还展示了利用 layer.getData(pixel) 在光标滑动时检测像素透明度，在悬停于非透明有效要素上方时动态切换鼠标指针为手型（pointer）。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • 光栅服务端要素穿透查询（WMS GetFeatureInfo）： WMS 服务向客户端分发的是已经光栅化的图片（PNG/JPEG），客户端 Canvas 本身并不包含矢量几何对象。为了实现“点击地图查询图斑属性”，OGC 制定了 GetFeatureInfo 协议规范。OpenLayers 提供了 getFeatureInfoUrl()，能够根据用户点击的地理坐标、当前视图分辨率与投影，精确反算出对应的像素点与视口 BBOX 请求参数，向服务端发起反查。
  • 客户端即时像素拾取（Client-Side Pixel Probing）： 若每次 pointermove 都向后端发送网络请求以判断是否显示手型指针，网络开销将极其庞大。OpenLayers 提供了 layer.getData(pixel)，直接从当前已渲染的 Canvas 像素缓冲区中同步提取 RGBA 四通道数值。通过判断 Alpha 透明度 data[3] > 0，零网络延迟实现光标手型悬停高亮。

2. 源码与关键 API 剖析

  • wmsSource.getFeatureInfoUrl(coordinate, resolution, projection, params)： 核心 URL 组装器。根据传入的坐标自动拼接 QUERY_LAYERS、X/Y（或 I/J）坐标、WIDTH/HEIGHT 及 BBOX。
  • 'INFO_FORMAT': 'text/html'：指定服务端返回的富文本格式（亦可指定 application/json 直接解析属性并注入自定义 Vue/React 弹窗）。
  • const data = wmsLayer.getData(evt.pixel)：返回 Uint8ClampedArray [R, G, B, A]，透明背景处 data[3] === 0，陆地或图斑处 data[3] > 0。

3. 生产实践踩坑与性能调优

  • CORS 跨域与 `getData` 失败风险： layer.getData(pixel) 依赖底层 canvas.getImageData()。若数据源未设置 crossOrigin: 'anonymous'，浏览器安全机制会判定画布受污染（Tainted），直接导致 getData 报错崩溃。
  • 点击容差（Tolerance / Buffer）： 在点要素或极细河流要素上，用户手指或鼠标极难分毫不差地正中单像素。在 GeoServer 服务端中，可在请求参数中补充 buffer: 10（像素缓冲），显著提高要素命中的容错率。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ImageLayer from 'ol/layer/Image.js';
import ImageWMS from 'ol/source/ImageWMS.js';

// Single-image WMS source
// 单张视口图像 WMS 数据源
const wmsSource = new ImageWMS({
  url: 'https://ahocevar.com/geoserver/wms',
  params: {'LAYERS': 'ne:ne'},
  serverType: 'geoserver',
  crossOrigin: 'anonymous',
});

const wmsLayer = new ImageLayer({
  source: wmsSource,
});

const view = new View({
  center: [0, 0],
  zoom: 1,
});

// Initialize map
// 初始化地图
const map = new Map({
  layers: [wmsLayer],
  target: 'map',
  view: view,
});

// Single-click listener for WMS GetFeatureInfo
// 单击地图触发 WMS GetFeatureInfo 属性查询
map.on('singleclick', function (evt) {
  document.getElementById('info').innerHTML = '';
  const viewResolution = view.getResolution();
  const url = wmsSource.getFeatureInfoUrl(
    evt.coordinate,
    viewResolution,
    'EPSG:3857',
    {'INFO_FORMAT': 'text/html'},
  );
  if (url) {
    fetch(url)
      .then((response) => response.text())
      .then((html) => {
        document.getElementById('info').innerHTML = html;
      });
  }
});

// Pointer move listener to probe pixel alpha and toggle cursor
// 指针移动事件监听：探测像素 Alpha 通道并动态切换鼠标光标手型
map.on('pointermove', function (evt) {
  if (evt.dragging) {
    return;
  }
  const data = wmsLayer.getData(evt.pixel);
  const hit = data && data[3] > 0; // transparent pixels have zero for data[3]
  map.getTargetElement().style.cursor = hit ? 'pointer' : '';
});
