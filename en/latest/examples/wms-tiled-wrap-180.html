Tiled WMS Wrapping / 瓦片式 WMS 跨 180° 经线连续环绕

wms14 tile10 dateline2 wrap2 1802

Example of a tiled WMS layer that wraps across the 180° meridian. / 演示瓦片式 WMS 图层在横跨 180° 经线（国际日界线）时的连续无缝环绕漫游机制。

By default, WMS tiles are reused across the 180° meridian. This behavior can be disabled by setting the wrapX option to false.

默认情况下，WMS 切片在跨越 180° 经线（国际日期变更线）时会自动跨世界副本重复复用（wrapX: true）。可以通过将 wrapX 选项设为 false 来禁用这一连续环绕行为。

📚 学习记录与技术深度解读 (Learning Notes)

1. 什么是 wrapX（世界连续水平卷绕）？

  • 在 Web 墨卡托投影（EPSG:3857）或等经纬度投影（EPSG:4326）中，全球经度范围是 $[-180^\circ, +180^\circ]$。
  • 当用户在宏观尺度下向东或向西无限制连续平移地图时，视口会漫游到全球范围之外（即“世界副本 -1”、“世界副本 +1”等）。
  • wrapX: true（默认）： OpenLayers 会将超界坐标自动取模折算回 $[-180^\circ, +180^\circ]$，向 WMS 服务端请求标准范围内的切片，并在当前漫游位置无缝复用绘制，形成地球如同连续旋转圆柱体的视觉体验。
  • wrapX: false： 当只需要聚焦特定国家区域（如仅展示美国本土或某单个省市），禁止在世界其他副本重复绘制时，可将 wrapX: false，超出真实经度范围的区域将保持空白。

2. 服务端支持与边界要求

  • 要使全球 WMS 图层在跨 180° 经线处无缝拼接，WMS 服务端发布的数据源本身必须完整覆盖全球范围，或者数据在边界处具有合法的拓扑闭合。
  • 本示例加载的是 Natural Earth 全球国家行政区划（ne:ne_10m_admin_0_countries），完美展现了横跨白令海峡与太平洋时的平滑连续视图。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';
import TileWMS from 'ol/source/TileWMS.js';

// Layer definitions: OSM base and a global WMS layer with seamless wrapX across 180° meridian
// 图层定义：OSM 底图与支持跨 180° 经线连续无缝环绕的全球 WMS 图层
const layers = [
  new TileLayer({
    source: new OSM(),
  }),
  new TileLayer({
    source: new TileWMS({
      url: 'https://ahocevar.com/geoserver/ne/wms',
      params: {'LAYERS': 'ne:ne_10m_admin_0_countries', 'TILED': true},
      serverType: 'geoserver',
      // wrapX is true by default, enabling tiles to repeat across the dateline
      // wrapX 默认为 true，切片可自动跨越国际日界线在各世界副本中循环复用
    }),
  }),
];

const map = new Map({
  layers: layers,
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 1,
  }),
});
