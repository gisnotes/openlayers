Image Load Events / 单张图像加载事件与进度指示

image8 events3 loading8

Example using image load events. / 演示如何监听单张图像（ImageWMS）数据源的加载生命周期事件并渲染动态进度条。

Image sources fire events related to image loading. You can listen for imageloadstart, imageloadend, and imageloaderror type events to monitor image loading progress. This example registers listeners for these events and renders an image loading progress bar at the bottom of the map. The progress bar is shown and hidden according to the map's loadstart and loadend events.

图像数据源（如 ImageWMS、ImageStatic）在图像请求与解析期间会触发细粒度生命周期事件。你可以通过监听 imageloadstart、imageloadend 和 imageloaderror 事件实时掌握图像资源的传输与就绪状态。

本示例演示了如何通过封装一个轻量级进度条组件，监听数据源的加载状态变更进度条宽度，并结合地图实例级别的 loadstart 与 loadend 事件控制进度条的整体显隐，呈现优雅流畅的加载反馈动效。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计机制 (Core Architecture & Mechanics)

  • 单张图像与瓦片加载生命周期的差异： 瓦片数据源（TileSource）一次视口变更是由数十个切片并发请求组成的，而单张图像数据源（ImageSource，如 ImageWMS、ImageStatic 等）在每次平移或缩放停顿后向服务端请求单张覆盖当前视口 BBOX 的大幅面栅格图。
  • 双层生命周期协同管道：
    • Map 容器层：loadstart 与 loadend 标志着地图视口渲染任务的开始与结束（包括所有图层的所有渲染队列），常用于全局蒙版、骨架屏或顶层指示器的显示与隐藏。
    • Source 数据源层：imageloadstart 标志着底层创建图像请求并向网络发起调用；imageloadend 标志着图像二进制完全下载并解码完毕；imageloaderror 则在 4xx/5xx 或跨域 CORS 拦截时触发，避免 UI 卡死在 Loading 状态。

2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns)

  • 加载计数器模型（Progress Counter）：
    source.on('imageloadstart', function () {
  progress.addLoading(); // loading 计数递增并更新百分比宽度
});
source.on(['imageloadend', 'imageloaderror'], function () {
  progress.addLoaded();  // loaded 计数递增，完成或失败均推进进度
});
    即使发生网络异常（imageloaderror），也必须将其归入 addLoaded() 计算，确保进度条能平稳闭合至 100% 并淡出，杜绝死锁。
  • 淡出延迟与重置： 在 loadend 事件触发后，通过 setTimeout(..., 250) 延迟隐藏 DOM，让用户肉眼捕捉到 100% 满格反馈，随后重置宽度为 0px，优化人机交互微动效。

3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices)

  • 防抖与高频视口拖拽丢弃： 用户连续拖拽或滚轮极速缩放时，OpenLayers 会自动中断上一帧废弃的 WMS 图片请求（通过重设 img.src = '' 或取消挂载）。因此在生产环境中，若手动管理加载锁，必须确保每个 imageloadstart 对应的实例都能正确闭合，推荐使用计数器差值比或 WeakMap 关联。
  • CORS 跨域像素读取污染： 若后续需要在 Canvas 中对图像执行像素分析（如 forEachLayerAtPixel 或 WebGL 滤镜），ImageWMS 需显式配置 crossOrigin: 'anonymous'，否则图片虽然能正常显示，但 Canvas 会被“污染（tainted）”从而抛出安全异常。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ImageLayer from 'ol/layer/Image.js';
import ImageWMS from 'ol/source/ImageWMS.js';

/**
 * Renders a progress bar. / 渲染并管理进度条状态的组件类
 * @param {HTMLElement} el The target element. / 目标 DOM 容器元素
 * @class
 */
function Progress(el) {
  this.el = el;
  this.loading = 0;
  this.loaded = 0;
}

/**
 * Increment the count of loading tiles. / 递增加载中计数
 */
Progress.prototype.addLoading = function () {
  ++this.loading;
  this.update();
};

/**
 * Increment the count of loaded tiles. / 递增已完成（成功或失败）计数
 */
Progress.prototype.addLoaded = function () {
  ++this.loaded;
  this.update();
};

/**
 * Update the progress bar. / 更新进度条 DOM 宽度百分比
 */
Progress.prototype.update = function () {
  const width = ((this.loaded / this.loading) * 100).toFixed(1) + '%';
  this.el.style.width = width;
};

/**
 * Show the progress bar. / 显示进度条
 */
Progress.prototype.show = function () {
  this.el.style.visibility = 'visible';
};

/**
 * Hide the progress bar. / 隐藏并重置进度条
 */
Progress.prototype.hide = function () {
  const style = this.el.style;
  setTimeout(function () {
    style.visibility = 'hidden';
    style.width = '0px';
  }, 250);
};

// Initialize progress bar instance / 实例化进度条组件
const progress = new Progress(document.getElementById('progress'));

// Configure ImageWMS source / 配置单张图像 WMS 数据源
const source = new ImageWMS({
  url: 'https://ahocevar.com/geoserver/wms',
  params: {'LAYERS': 'topp:states'},
  serverType: 'geoserver',
});

// Listen for image load start / 监听单张图像开始请求
source.on('imageloadstart', function () {
  progress.addLoading();
});
// Listen for image load completion or error / 监听单张图像加载结束或异常
source.on(['imageloadend', 'imageloaderror'], function () {
  progress.addLoaded();
});

// Initialize map with single-image WMS layer / 初始化包含单张图像图层的地图实例
const map = new Map({
  layers: [new ImageLayer({source: source})],
  target: 'map',
  view: new View({
    center: [-10997148, 4569099],
    zoom: 4,
  }),
});

// Toggle progress bar visibility based on map load events / 结合地图视口级别加载事件控制进度条显隐
map.on('loadstart', function () {
  progress.show();
});
map.on('loadend', function () {
  progress.hide();
});
