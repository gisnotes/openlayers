Animated GIF / 动态 GIF 图标渲染

Example of using an animated GIF as an icon. / 演示如何使用动态 GIF 作为矢量要素的图标（基于 Gifler 逐帧解码与离屏 Canvas）。

Example of using an animated GIF as an icon. Animation is achieved using the Gifler library.

这是一个将动态 GIF 动图作为矢量要素图标（Icon）进行渲染的示例。 该动画效果借助了开源的 Gifler GIF 逐帧解码库来实现。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心技术痛点：为什么 new Icon({ src: 'xxx.gif' }) 动不起来？

在很多 WebGIS 初学者的直觉中，既然 HTML 的 <img> 标签可以直接播放 GIF，那么直接给 OpenLayers 的 Icon 传入 GIF 地址应该也能动：

// ❌ 错误常识：这样地图上只会显示一张定格的静态图片！
new Icon({ src: 'globe.gif' })
  • 底层原理：OpenLayers 的矢量图层默认基于 HTML5 Canvas 2D API 进行渲染。
  • 浏览器规范限制：Canvas 规范中的 ctx.drawImage(img, ...) 传入 GIF 图片对象时，浏览器只会截取并绘制该 GIF 的第一帧静态画面，Canvas 内部根本不会自动推进 GIF 的多帧播放时间轴。

2. 破局之道：四步组合拳实现 Canvas 动态渲染

本示例展示了在 Canvas 渲染管线下播放 GIF 的行业标准解法：

  1. 引入解码库 Gifler：由于浏览器原生 JavaScript 没有暴露 GIF 逐帧解码 API，引入轻量级库 gifler，它负责异步下载 GIF 二进制流，并精确按照每帧的延迟毫秒数调度播放。
  2. 创建离屏画布（Offscreen Canvas）：在内存中创建一个游离的 <canvas> 画布，作为动态帧图像的“画板”。
  3. 利用 Icon({ img: canvas })：OpenLayers 的 ol/style/Icon 不仅支持 src 字符串，还支持传入 img: HTMLCanvasElement，即把离屏 Canvas 直接作为图标的数据源。
  4. 每帧刷新驱动 map.render()：每当 Gifler 解码并把最新一帧绘制到离屏 Canvas 上时，立即调用 map.render()，通知 OpenLayers 请求下一帧渲染，完成画面同步。

3. 关键性能优化细节

  • 单次绑定样式（Avoid Repeated Allocation）：
    if (!iconFeature.getStyle()) {
  iconFeature.setStyle(new Style({
    image: new Icon({ img: ctx.canvas, opacity: 0.8 })
  }));
}
    代码中通过 if (!iconFeature.getStyle()) 做了保护，仅在第一帧初始化时创建一次 Style 实例。在后续几十次/秒的 GIF 播放循环中，离屏 Canvas 内存地址保持不变，避免在动画循环中频繁 new Style() 引起 JavaScript 内存暴涨与频繁 GC（垃圾回收卡顿）。
  • 非阻塞重绘 map.render()： map.render() 底层基于浏览器的 requestAnimationFrame 实现。它是异步批处理机制，即使一秒触发多次，也会被浏览器自动合并同步到屏幕的 60Hz/120Hz 刷新率中，性能极高。

4. 关键 API 深度解析

  • ol/style/Icon 的 img 参数：
    • 类型：HTMLImageElement | HTMLCanvasElement
    • 作用：直接绑定一个内存中的图片或 Canvas DOM 元素作为图标载体。
  • map.render()：
    • 作用：请求地图重新执行一次渲染管线。适合在有外部动画循环、视频纹理流或外部数据定时刷新时主动通知地图重绘。
  • map.hasFeatureAtPixel(pixel) 与手型悬停交互：
    • 作用：快速检测屏幕像素点下方是否存在矢量要素。配合 map.on('pointermove') 事件，动态切换 cursor: pointer，提升用户交互体验。

5. 替代方案对比：Canvas 方案 vs CSS Overlay 方案

在 WebGIS 实际开发中，渲染动图或富交互图标通常有两种思路：

  • 方案 A：本示例方案（离屏 Canvas + 矢量 Icon）：
    • 优点：要素是纯原生的 Vector Feature，可以完美参与图层层级控制、随地图无缝缩放平移、支持几千个要素的高性能渲染与要素拾取。
    • 缺点：需要借助 Gifler 等解码库。
  • 方案 B：OpenLayers Overlay（DOM 叠加层）：
    • 优点：直接用原生 <img src="xxx.gif"> 塞进 new Overlay({ element })，无需任何第三方库。
    • 缺点：每个动图都是独立的真实 DOM 元素，数量超过几十上百个时，浏览器 DOM 树开销剧增，地图平移时容易产生拖影与掉帧。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Point from 'ol/geom/Point.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import StadiaMaps from 'ol/source/StadiaMaps.js';
import VectorSource from 'ol/source/Vector.js';
import Icon from 'ol/style/Icon.js';
import Style from 'ol/style/Style.js';

// Create a point feature at [0, 0] (Null Island) to hold the animated GIF icon
// 创建一个位于坐标 [0, 0] 的点要素，用于挂载动态 GIF 图标
const iconFeature = new Feature({
  geometry: new Point([0, 0]),
});

// Create vector source and add the point feature
// 创建矢量数据源并加入该点要素
const vectorSource = new VectorSource({
  features: [iconFeature],
});

// Create vector layer to host the vector icon
// 创建矢量图层用于承载矢量图标
const vectorLayer = new VectorLayer({
  source: vectorSource,
});

// Create raster tile layer using Stadia Maps (Stamen Toner monochrome style) as basemap
// 创建栅格瓦片底图图层，使用 Stadia Maps 的 Stamen Toner 黑白极简风格
const rasterLayer = new TileLayer({
  source: new StadiaMaps({
    layer: 'stamen_toner',
  }),
});

// Initialize the map, mount to 'map' container, and configure center and zoom
// 初始化地图并挂载到 target 'map' DOM 容器，设置中心点与缩放级别
const map = new Map({
  layers: [rasterLayer, vectorLayer],
  target: document.getElementById('map'),
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// URL to the animated GIF asset
// 动态 GIF 动图资源的相对路径
const gifUrl = 'data/globe.gif';

// Initialize the Gifler decoder instance (global variable loaded via HTML resources)
// 初始化 Gifler GIF 解码器实例（注意：gifler 是通过 HTML resources 全局脚本引入的）
const gif = gifler(gifUrl);

// Decode and render each frame into an offscreen canvas
// 逐帧解码并绘制到一个离屏（内存中的）Canvas 画布上
gif.frames(
  document.createElement('canvas'),
  function (ctx, frame) {
    // Initialize the icon style only once on the first frame to avoid GC pressure
    // 仅在第一帧初始化要素样式，避免在动画播放循环中频繁创建 Style 实例造成内存垃圾回收压力
    if (!iconFeature.getStyle()) {
      iconFeature.setStyle(
        new Style({
          image: new Icon({
            img: ctx.canvas, // Use the offscreen canvas as the dynamic image source / 将离屏 Canvas 作为图标的数据源
            opacity: 0.8,
          }),
        }),
      );
    }
    // Clear previous frame and draw the new frame onto the offscreen canvas
    // 清除离屏画布上一帧的内容，并将新解码的帧绘制到画布指定位置
    ctx.clearRect(0, 0, frame.width, frame.height);
    ctx.drawImage(frame.buffer, frame.x, frame.y);

    // Request OpenLayers to re-render the map to reflect the new frame on screen
    // 请求 OpenLayers 重绘地图，将离屏 Canvas 的最新一帧同步更新到屏幕上
    map.render();
  },
  true, // Loop the animation continuously / 循环无限次播放动画
);

// Change mouse cursor to pointer when hovering over the icon feature
// 监听鼠标指针移动事件：当鼠标悬停在要素上方时切换光标为手型（pointer），离开时恢复默认
map.on('pointermove', function (e) {
  const hit = map.hasFeatureAtPixel(e.pixel);
  map.getTargetElement().style.cursor = hit ? 'pointer' : '';
});
