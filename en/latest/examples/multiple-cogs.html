多 COG 数据源重投影与波段合成 (Multiple COG sources)

cog16 webgl19 projection14 reprojection8

展示两个位于不同 UTM 投影分带的 Sentinel-2 云原生 GeoTIFF (COG) 数据源，并在同一个 WebGL 图层中进行多波段动态合成与重投影显示。

本例展示了如何在同一个 WebGL 瓦片图层（ol/layer/WebGLTile）中同时加载并拼接两个跨越不同投影分带（UTM Zones）的 Sentinel-2（哨兵 2 号）云原生 GeoTIFF（COG）数据源，并在客户端实现多波段假彩色合成与实时重投影。

核心机制与原理解析

  1. 跨 UTM 投影分带的边缘拼接与实时重投影：

    • 卫星影像通常依据其所处的全球通用横轴墨卡托（UTM）6度分带进行正射纠正与存储。本例展示的两个相邻地块刚好位于不同分带的交界处：
      • 西侧地块属于 UTM Zone 31N（EPSG:32631）；
      • 东侧地块属于 UTM Zone 32N（EPSG:32632）。
    • 由于两个投影的中央子午线和椭球切面不同，无法直接在单一坐标系下拼接。
    • OpenLayers 的 ol/layer/WebGLTile 支持绑定多个数据源（sources: [source1, source2]），在 WebGL 片段着色器中独立执行像素反向映射与纹理重采样，将两者无缝投影至全局地图视图（EPSG:3857）中，完美消除分带接缝。

  2. 多波段光谱合成（Band Combination）与 WebGL 样式表达式：

    • 每个地块均读取了 4 个单波段 GeoTIFF 文件：B04（红光）、B03（绿光）、B02（蓝光）、B08（近红外 NIR）。
    • 借助 WebGL 样式表达式（style），将图层颜色组织为动态变量映射： color: ['array', ['band', ['var', 'red']], ['band', ['var', 'green']], ['band', ['var', 'blue']], ['band', 5]] 其中第 5 波段为哨兵数据自带的有效区域 Alpha 掩模。
    • 切换下拉菜单通过 layer.updateStyleVariables() 触发毫秒级 GPU 动态重绘，即可自由切换真彩色合成（4-3-2）与监测植被生长的标准假彩色合成（8-4-3）。

  3. 多数据源元数据的异步范围融合：

    • 通过 Promise.all(sources.map(s => s.getView())) 并发异步读取各 COG 的瓦片头信息；
    • 使用 transformExtent 将两个不同 UTM 坐标系下的外包矩形统一转换至 EPSG:3857，并用 extend(extent, ...) 合并出总全景边界，实现视口的精确居中与缩放适配。
main.js 
import Map from 'ol/Map.js';
import {createEmpty, extend, getCenter} from 'ol/extent.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import {transformExtent} from 'ol/proj.js';
import {register} from 'ol/proj/proj4.js';
import GeoTIFF from 'ol/source/GeoTIFF.js';
import proj4 from 'proj4';

// 向 Proj4js 注册两个相邻的 UTM 投影坐标系：
// EPSG:32631 (WGS 84 / UTM zone 31N，中央经线 3°E)
// EPSG:32632 (WGS 84 / UTM zone 32N，中央经线 9°E)
proj4.defs('EPSG:32631', '+proj=utm +zone=31 +datum=WGS84 +units=m +no_defs');
proj4.defs('EPSG:32632', '+proj=utm +zone=32 +datum=WGS84 +units=m +no_defs');
register(proj4);

// RGB 通道选择器标识列表
const channels = ['red', 'green', 'blue'];
for (const channel of channels) {
  const selector = document.getElementById(channel);
  selector.addEventListener('change', update);
}

/**
 * 读取当前下拉框所选取的波段通道映射变量
 * @return {Object<string, number>} 包含 red、green、blue 对应波段索引的对象
 */
function getVariables() {
  const variables = {};
  for (const channel of channels) {
    const selector = document.getElementById(channel);
    variables[channel] = parseInt(selector.value, 10);
  }
  return variables;
}

// 哨兵 2 号（Sentinel-2 L2A）单波段文件名：
// B04: 红光 (Red, 665nm, 10m 分辨率)
// B03: 绿光 (Green, 560nm, 10m 分辨率)
// B02: 蓝光 (Blue, 490nm, 10m 分辨率)
// B08: 近红外 (NIR, 842nm, 10m 分辨率)
const sourceNames = ['B04', 'B03', 'B02', 'B08'];

// 创建两个相邻分区的 COG 数据源：
// 第 1 个数据源：位于 UTM 31N 分带（瓦片代号 31TGJ）
// 第 2 个数据源：位于 UTM 32N 分带（瓦片代号 32TLP）
const sources = [
  new GeoTIFF({
    sources: sourceNames.map(function (name) {
      return {
        url: `https://sentinel-cogs.s3.us-west-2.amazonaws.com/sentinel-s2-l2a-cogs/31/T/GJ/2022/7/S2A_31TGJ_20220703_0_L2A/${name}.tif`,
        max: 3000,
      };
    }),
  }),
  new GeoTIFF({
    sources: sourceNames.map(function (name) {
      return {
        url: `https://sentinel-cogs.s3.us-west-2.amazonaws.com/sentinel-s2-l2a-cogs/32/T/LP/2022/7/S2A_32TLP_20220703_0_L2A/${name}.tif`,
        max: 3000,
      };
    }),
  }),
];

// 创建 WebGL 瓦片图层：
// 1. sources: 同时挂载两个不同分区的 COG 数据源，WebGL 渲染器会自动分别重采样并无缝拼合；
// 2. style: 使用 WebGL 动态表达式，将红绿蓝三通道映射到对应的波段索引变量，波段 5 为 Alpha 透明度掩模。
const layer = new TileLayer({
  sources: sources,
  style: {
    variables: getVariables(),
    color: [
      'array',
      ['band', ['var', 'red']],
      ['band', ['var', 'green']],
      ['band', ['var', 'blue']],
      ['band', 5],
    ],
  },
});

/**
 * 当用户更改波段选择时，更新 WebGL 图层样式变量，触发 GPU 实时重绘
 */
function update() {
  layer.updateStyleVariables(getVariables());
}

// 初始化地图实例
const map = new Map({
  target: 'map',
  layers: [layer],
  // 异步合并两个数据源的包围盒范围并初始化视图：
  // 1. 并发获取两个 COG 的元数据视口配置；
  // 2. 将各自在 UTM 31N / 32N 下的范围通过 transformExtent 统一转换至目标地图投影（EPSG:3857）；
  // 3. 通过 extend 函数合并为一个完整外接矩形范围；
  // 4. 返回包含该合并范围与中心点的视图配置对象。
  view: Promise.all(
    sources.map(function (source) {
      return source.getView();
    }),
  ).then(function (options) {
    const projection = 'EPSG:3857';
    const extent = createEmpty();
    options.forEach(function (options) {
      extend(
        extent,
        transformExtent(options.extent, options.projection, projection),
      );
    });
    return {
      projection: projection,
      center: getCenter(extent),
      zoom: 0,
      extent: extent,
    };
  }),
});
