Zoomify 亿级超大图像金字塔 (Zoomify)

zoomify1 deepzoom1 IIP1 pixel2 projection14

演示使用 Zoomify 数据源以像素笛卡尔坐标系展示超高分辨率大图的金字塔深度缩放（Deep Zoom），并支持 Retina 高清屏自适应。

Zoomify 是一种经典的超高分辨率图像深度切片金字塔（Deep Zoom）格式，广泛应用于数字病理病理切片扫描、博物馆高精度艺术品数字化鉴赏以及深空天文图库。本例展示了如何在 OpenLayers 中通过像素笛卡尔坐标系加载 Zoomify 图像源，并支持 Retina 高清屏渲染。

核心机制与原理解析

  1. 纯像素空间坐标系（Pixel Projection）：

    • 数字化绘画、医学病理或工业扫描图并非真实的地理地球表面，其空间坐标系统是基于像素网格（Pixel Coordinates）建立的。
    • ol/source/Zoomify 仅需传入图像原始宽高 size: [width, height]，即可自动构建从 [0, -height] 到 [width, 0] 的无缝像素切片网格（TileGrid），无需任何地理椭球体或投影定义。

  2. 视口缩放与平移约束（resolutions 与 constrainOnlyCenter）：

    • 锁定金字塔分辨率：通过 resolutions: layer.getSource().getTileGrid().getResolutions() 将视图缩放级别精准约束在 Zoomify 切片金字塔原生生成的各级物理分辨率上，防止非整数缩放带来的像元插值虚化。
    • 中心点约束：设置 constrainOnlyCenter: true 配合 extent，仅限制视口中心点不超出图像边界，用户可以自由拖拽至图片边缘，交互体验平滑自然。
    • 采样层级导向（zDirection: -1）：强制选取等于或高于当前屏幕分辨率的切片层级，杜绝模糊。

  3. Retina 视网膜高清屏优化（tilePixelRatio & tileSize）：

    • 切换至 高清 Zoomify (Retina 2x) 模式时，数据源配置了 tilePixelRatio: 2 和 tileSize: 256 / 2 = 128。
    • OpenLayers 会从更高一级的金字塔层级拉取 256 像素的高清切片，但在画布上将其压缩至 128 设备独立像素（CSS 像素）进行物理渲染，从而在高 DPI 屏幕上实现纤毫毕现的微观细节展示。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import Zoomify from 'ol/source/Zoomify.js';

// 超高分辨率图像原始像素尺寸（宽度 4000px，高度 3000px）
const imgWidth = 4000;
const imgHeight = 3000;

// Zoomify 瓦片金字塔服务根路径
const zoomifyUrl = 'https://ol-zoomify.surge.sh/zoomify/';

// 1. 标准 Zoomify 数据源（针对 1x 普通屏幕）
const source = new Zoomify({
  url: zoomifyUrl,
  size: [imgWidth, imgHeight],
  crossOrigin: 'anonymous',
  // zDirection: -1 确保在缩放过渡中优先选取分辨率等于或高于当前屏幕像素的瓦片层级，避免模糊
  zDirection: -1,
});
// 提取切片网格对应的像素有效外包范围
const extent = source.getTileGrid().getExtent();

// 2. 高清 Retina 数据源（针对 2x 视网膜高清屏）
const retinaPixelRatio = 2;
const retinaSource = new Zoomify({
  url: zoomifyUrl,
  size: [imgWidth, imgHeight],
  crossOrigin: 'anonymous',
  zDirection: -1,
  // 指定瓦片像素比为 2x，并让逻辑瓦片尺寸减半为 128px，
  // 这样 OpenLayers 会从更高一级的金字塔拉取 256px 图像并在 128px 空间内渲染，呈现极佳细节
  tilePixelRatio: retinaPixelRatio,
  tileSize: 256 / retinaPixelRatio,
});

// 创建瓦片图层并挂载标准数据源
const layer = new TileLayer({
  source: source,
});

// 初始化地图实例
const map = new Map({
  layers: [layer],
  target: 'map',
  view: new View({
    // 将视图的缩放级别精准对齐到 Zoomify 切片金字塔提供的物理分辨率阶梯
    resolutions: layer.getSource().getTileGrid().getResolutions(),
    // 约束范围：将漫游限制在整幅图像有效像素外包盒内
    extent: extent,
    // 仅限制中心点不移出范围，允许图片边角移至屏幕视口边缘
    constrainOnlyCenter: true,
  }),
});
// 自动缩放自适应整个图像视野
map.getView().fit(extent);

// 监听高清模式切换下拉菜单
const control = document.getElementById('zoomifyProtocol');
control.addEventListener('change', function (event) {
  const value = event.currentTarget.value;
  if (value === 'zoomify') {
    layer.setSource(source);
  } else if (value === 'zoomifyretina') {
    layer.setSource(retinaSource);
  }
});
