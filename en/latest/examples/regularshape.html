Regular Shapes / 正多边形与星形矢量符号（RegularShape 全解）

Example of some Regular Shape styles / 演示使用 ol/style/RegularShape 纯代码绘制正方形、长方形、三角形、五角星、十字丝、叉号及堆叠组合符号。

This example shows how several regular shapes or symbols (representing x, cross, star, triangle, square and stacked) can be created. A rectangle is produced by scaling a square created without rotation. Style stacked represents possibility to stack multiple shapes with offset.

本示例展示了如何使用 ol/style/RegularShape 在不加载任何外部图片（PNG/SVG）的情况下，纯代码生成多种常用测量与制图几何符号：包括 叉号（x）、十字丝（cross）、五角星（star）、三角形（triangle）、正方形（square）、长方形（rectangle） 以及 上下堆叠符号（stacked）。 点击地图下方的按钮，还可以动态切换所有正方形符号的填充颜色，并观察共享样式实例的高效重绘机制。

📚 学习记录与技术深度解读 (Learning Notes)

1. 为什么要用 RegularShape？（对比 Icon 外部图片）

在 WebGIS 中绘制海量散点（如 250 个甚至上万个传感器、控制点、采样点）时，ol/style/RegularShape 相比 ol/style/Icon 有三大优势：

  1. 零网络请求：无需下载任何外部 PNG/SVG 图标资源，直接在内存中的离屏 Canvas 上通过几何公式矢量化绘制。
  2. 参数化动态生成：只需调整 points（顶点数）、radius（外半径）、radius2（内半径）和 angle（起始角），一套代码即可衍生出正 N 边形、星形、十字丝等数十种专业测绘符号。
  3. 高清无损与动态换色：可通过 setFill() / setStroke() 随时动态修改填充色与描边，无需考虑跨域（CORS）或白底正片叠底限制。

2. 核心几何原理：7 种符号的参数构造秘籍

RegularShape 的核心机制是围绕圆心计算顶点坐标：

  • 当不传 radius2 时：在半径为 radius 的圆周上等分取 points 个顶点，连成正多边形。
  • 当传入 radius2 时：在外圆（radius）和内圆（radius2）上交替取 2 × points 个顶点，连成星形或十字放射线（当 radius2: 0 时）。
  • 默认起始角（angle: 0）：第 1 个顶点默认指向正上方（12 点钟方向）。
符号名称 points radius (外圆) radius2 (内圆) angle (起始角) 其他变换参数 几何成型原理解析
square（正方形 □） 4 10 未设置 Math.PI / 4 (45°) — 若 angle: 0，4 个顶点在上下左右，呈菱形 ◇；将起始角旋转 45°（Math.PI / 4） 后，4 个顶点落入四角，变成水平正放的正方形 □
rectangle（长方形 ▭） 4 10 / √2 10 0 scale: [1, 0.5] 先构造一个不带旋转的正方形包络，再通过 scale: [1, 0.5] 将 Y 轴高度压缩一半，形成宽扁长方形
triangle（三角形 △） 3 10 未设置 0 rotation: Math.PI / 4 points: 3, angle: 0 生成正立等边三角形 △，再通过 rotation 将整个图形顺时针旋转 45°
star（五角星 ☆） 5 10 4 0 — 5 个外尖角落在半径 10 的外圆上，5 个内凹角落在半径 4 的内圆上，交替相连成标准五角星
cross（十字丝 +） 4 10 0 0 — 精髓技巧：当内圆半径 radius2: 0 时，所有内凹顶点全部坍缩到圆心 [0, 0]！angle: 0 时 4 个外顶点指向上下左右，形成正十字 +
x（叉号 ×） 4 10 0 Math.PI / 4 (45°) — 与 cross 完全相同，仅将起始角旋转 45°（Math.PI / 4），正十字 + 即变成对角叉号 ×
stacked（堆叠符号） 4 + 4 5 + 10 未设置 Math.PI / 4 displacement: [0, 10] 使用 Style 数组叠加两个正方形：小正方形（radius: 5）通过 displacement: [0, 10] 向上偏移 10px，恰好叠在大正方形（radius: 10）正上方

3. 易混概念辨析：angle vs rotation 与 displacement 坐标系

  1. angle 与 rotation 有什么区别？
    • angle：在生成多边形顶点路径阶段（执行 scale 缩放之前）旋转顶点的起始角度。例如要把菱形转成正方形，再用 scale: [1, 0.5] 压扁成长方形，必须用 angle: Math.PI / 4；如果误用了 rotation: Math.PI / 4，图形会先压扁再歪着转 45°，变成斜平行四边形！
    • rotation：在整个符号（含 scale 缩放）绘制成型之后，围绕锚点对最终图形进行的整体旋转。
  2. displacement: [dx, dy] 的 Y 轴方向注意：
    • 在 RegularShape（以及 Circle、Icon）中，displacement: [dx, dy] 的 X 轴向右为正，Y 轴向上为正（与数学笛卡尔坐标系一致，而与屏幕像素向下为正相反）。因此在 stacked 中，displacement: [0, 10] 是将小正方形向上推移 10 像素。

4. 性能优化范式：样式实例复用 + 原地修改 + vectorLayer.changed()

  • 示例中生成了 250 个随机点要素，但并没有创建 250 个 Style 对象，而是所有要素共享 styles 字典中的 7 个样式实例（极大节省内存与离屏 Canvas 数量）。
  • 当点击按钮修改所有正方形颜色时（代码第 139~145 行）：
    styles.square.getImage().setFill(new Fill({color: colors[currentColor % colors.length]}));
vectorLayer.changed();
    直接调用 styles.square.getImage().setFill(...) 原地替换该共享符号的填充色，随后调用一次 vectorLayer.changed() 通知图层重绘，地图上几十个正方形即可在瞬间同步变色，无需遍历要素调用 feature.setStyle()！
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Point from 'ol/geom/Point.js';
import VectorLayer from 'ol/layer/Vector.js';
import VectorSource from 'ol/source/Vector.js';
import Fill from 'ol/style/Fill.js';
import RegularShape from 'ol/style/RegularShape.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';

// 定义所有符号共用的基础黑色描边（宽 2px）与红色填充
const stroke = new Stroke({color: 'black', width: 2});
const fill = new Fill({color: 'red'});

// 预定义 7 种 RegularShape 几何符号样式字典（供 250 个要素共享复用）
const styles = {
  // 1. 正方形（□）：4 个顶点，起始角旋转 45°（Math.PI / 4）使四条边水平/垂直正放
  'square': new Style({
    image: new RegularShape({
      fill: fill,
      stroke: stroke,
      points: 4,
      radius: 10,
      angle: Math.PI / 4,
    }),
  }),
  // 2. 长方形（▭）：构造正方形包络后，通过 scale: [1, 0.5] 将垂直方向（Y 轴）压缩一半
  'rectangle': new Style({
    image: new RegularShape({
      fill: fill,
      stroke: stroke,
      radius: 10 / Math.SQRT2,
      radius2: 10,
      points: 4,
      angle: 0,
      scale: [1, 0.5],
    }),
  }),
  // 3. 三角形（△）：3 个顶点，angle: 0 生成正立等边三角形，再通过 rotation 整体顺时针旋转 45°
  'triangle': new Style({
    image: new RegularShape({
      fill: fill,
      stroke: stroke,
      points: 3,
      radius: 10,
      rotation: Math.PI / 4,
      angle: 0,
    }),
  }),
  // 4. 五角星（☆）：points: 5，同时指定外圆半径 radius (10) 和内凹顶点半径 radius2 (4)
  'star': new Style({
    image: new RegularShape({
      fill: fill,
      stroke: stroke,
      points: 5,
      radius: 10,
      radius2: 4,
      angle: 0,
    }),
  }),
  // 5. 十字丝（+）：points: 4 且内半径 radius2: 0（内顶点坍缩至中心点），angle: 0 时指向正上下左右
  'cross': new Style({
    image: new RegularShape({
      fill: fill,
      stroke: stroke,
      points: 4,
      radius: 10,
      radius2: 0,
      angle: 0,
    }),
  }),
  // 6. 叉号（×）：与十字丝相同（points: 4, radius2: 0），仅将起始角旋转 45°（Math.PI / 4）
  'x': new Style({
    image: new RegularShape({
      fill: fill,
      stroke: stroke,
      points: 4,
      radius: 10,
      radius2: 0,
      angle: Math.PI / 4,
    }),
  }),
  // 7. 堆叠组合符号（stacked）：使用 Style 数组叠加两个正方形
  'stacked': [
    // 上方小正方形（radius: 5），通过 displacement: [0, 10] 向正上方偏移 10 像素
    new Style({
      image: new RegularShape({
        fill: fill,
        stroke: stroke,
        points: 4,
        radius: 5,
        angle: Math.PI / 4,
        displacement: [0, 10],
      }),
    }),
    // 下方基准大正方形（radius: 10），位于要素原始坐标点
    new Style({
      image: new RegularShape({
        fill: fill,
        stroke: stroke,
        points: 4,
        radius: 10,
        angle: Math.PI / 4,
      }),
    }),
  ],
};

// 样式键名列表，用于随机分配给生成的测试点要素
const styleKeys = [
  'x',
  'cross',
  'star',
  'triangle',
  'square',
  'rectangle',
  'stacked',
];

// 在 [-4500000, 4500000] 坐标范围内随机生成 250 个点要素，并随机绑定上述 7 种样式之一
const count = 250;
const features = new Array(count);
const e = 4500000;
for (let i = 0; i < count; ++i) {
  const coordinates = [2 * e * Math.random() - e, 2 * e * Math.random() - e];
  features[i] = new Feature(new Point(coordinates));
  features[i].setStyle(
    styles[styleKeys[Math.floor(Math.random() * styleKeys.length)]],
  );
}

// 创建矢量数据源与矢量图层
const source = new VectorSource({
  features: features,
});

const vectorLayer = new VectorLayer({
  source: source,
});

// 初始化地图实例
const map = new Map({
  layers: [vectorLayer],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// 定义待轮换的填充颜色列表
const colors = ['blue', 'green', 'yellow', 'aqua', 'red'];
let currentColor = 0;

// 监听按钮点击事件：原地更新 styles.square 的填充色，并调用 vectorLayer.changed() 触发批量重绘
document.getElementById('color-changer').addEventListener('click', function () {
  styles.square
    .getImage()
    .setFill(new Fill({color: colors[currentColor % colors.length]}));
  // 通知矢量图层样式已发生内部变更，触发地图重绘使所有正方形同步变色
  vectorLayer.changed();
  currentColor++;
});
