Stepping through the time dimension of a GeoZarr cube with a slider. / 使用滑块动态步进 GeoZarr 科学数据立方体的时间轴，实时更新雷达双极化复合遥感影像。

A GeoZarr array can have non-spatial dimensions such as time. This example steps through the time axis of a Sentinel-1 radar cube with a slider: getDimensions() reports the axis with its size and units, updateDimensions() reloads the chosen slice in place, and getValue reads the axis value to label it with the acquisition date.

The cube images the 2021 Cumbre Vieja eruption on La Palma as a dual-polarization composite: the VV and VH bands (vertical transmit, vertical vs. horizontal receive) map to red and green, and their ratio to blue. GeoZarr 数组可以包含非空间维度，例如 time（时间轴）。 本示例演示如何通过滑块沿哨兵 1 号（Sentinel-1）雷达数据立方体的时间轴逐步漫游： 调用 getDimensions() 获取维度的轴长度与物理单位，调用 updateDimensions() 原地重载所选时间切片，调用 getValue() 读取时间戳数值并格式化为卫星过境采集日期。 该数据立方体完整记录了 2021 年西班牙拉帕尔马岛老峰火山（Cumbre Vieja）喷发的动态演变过程，采用双极化复合图呈现： VV 波段（同向垂直极化）映射至红通道，VH 波段（交叉极化）映射至绿通道，它们的比值 VV/VH 则映射至蓝通道。

📚 学习记录与技术深度解读 (Learning Notes)

1. 合成孔径雷达（SAR）双极化特征与火山熔岩解译 * 光学卫星 vs 雷达卫星：

  • 当拉帕尔马火山喷发时，火山口浓烟滚滚遮天蔽日，传统光学卫星（如 Sentinel-2、Landsat）视线完全被黑烟和火山灰阻挡；
  • 哨兵 1 号（Sentinel-1）搭载 C 波段合成孔径雷达（SAR），微波能够无视昼夜与浓烟，全天候穿透烟羽直达地表！
  • 双极化合成机理：
    • VV（垂直发射、垂直接收）：主要反映粗糙地表的镜面散射与面散射强度，红通道呈现明亮背景；
    • VH（垂直发射、水平接收）：主要反映植被冠层、碎屑与复杂粗糙岩石的体散射与去极化散射；
    • VV / VH 比值：对地表粗糙度极其敏感。滚烫、崎岖不平的新生玄武岩熔岩流具有极高的比值，在图像中呈现高亮荧光蓝色，清晰勾勒出熔岩侵入大西洋造就的“新熔岩三角洲”！

2. 原地时间切片重载：source.updateDimensions({time: index}) * 传统 WebGIS 切换时间序列时通常需要销毁重建图层或切换 WMS/WMTS URL，伴随剧烈的白屏闪烁。 * GeoZarr 提供了轻量级的 updateDimensions({time: index}) 原地切片方法：

  • 图层实例与 WebGL 着色器完全保持不变；
  • 数据源直接复用已建立的 Zarr 索引句柄，仅向云端发起目标时间切片对应分块的局部 HTTP 请求；
  • 配合滑块拖拽，犹如在浏览器中翻阅卫星雷达电影！

3. CF 元数据时间解码：getDimensions() 与 getValue('time', index) * 气候与预测元数据规范（CF Conventions）通常将时间记录为相对起算点，例如：

"nanoseconds since 1970-01-01"

  • source.getValue('time', index) 异步读取目标时间维度的标量浮点值，代码通过 Date(epoch + value / 1e6) 转化为标准 ISO 日期展示给用户。
main.js 
import Map from 'ol/Map.js';
import {
  getView,
  withExtentCenter,
  withHigherResolutions,
  withLowerResolutions,
  withZoom,
} from 'ol/View.js';
import TileLayer from 'ol/layer/WebGLTile.js';
import GeoZarr from 'ol/source/GeoZarr.js';
import OSM from 'ol/source/OSM.js';

// Point the url straight at the cube's `descending` orbit group, which keeps
// this a plain single-group source whose only non-spatial dimension is time.
// 将 URL 直接指向数据立方体的 `descending`（降轨）群组，使其成为单群组数据源且仅包含时间这一非空间维度
const url =
  'https://s3.explorer.eopf.copernicus.eu/esa-zarr-sentinel-explorer-fra/tests-output/sentinel-1-grd-rtc-staging/s1-rtc-28RBS.zarr/descending';
const source = new GeoZarr({url, bands: ['vv', 'vh']});

// Dual-polarization composite from two geo-bands: VV -> red, VH -> green, and
// their ratio VV/VH -> blue. Radar backscatter is a small float, so each
// channel is rescaled from a fixed [low, high] range to the 0-255 display range.
// 双极化雷达波段合成：VV 极化 -> 红通道，VH 极化 -> 绿通道，比值 VV/VH -> 蓝通道。
// 雷达后向散射系数为微小浮点数，因此每个通道线性拉伸重缩放到 0-255 显示区间。
const style = {
  color: [
    'color',
    ['interpolate', ['linear'], ['band', 1], 0, 0, 0.4, 255], // VV
    ['interpolate', ['linear'], ['band', 2], 0, 0, 0.1, 255], // VH
    ['interpolate', ['linear'], ['/', ['band', 1], ['band', 2]], 1, 0, 15, 255], // VV/VH
  ],
};

const map = new Map({
  target: 'map',
  layers: [new TileLayer({source: new OSM()}), new TileLayer({style, source})],
  view: getView(
    source,
    withLowerResolutions(1),
    withHigherResolutions(2),
    withExtentCenter(),
    withZoom(2),
  ),
});

const slider = document.getElementById('time');
const label = document.getElementById('time-label');

// Read time dimension metadata, sort chronological slices, and bind to slider
// 读取时间维度元数据，按时序排序各个切片，并与时间滑块交互绑定
source
  .getDimensions()
  .then(async ({time}) => {
    const {units} = time.attributes;
    // Units string is formatted as "nanoseconds since 1970-01-01"
    // 单位字符串格式形如 "nanoseconds since 1970-01-01"
    const epoch = Date.parse(units.split(' since ')[1]);
    const toDate = (value) => new Date(epoch + Number(value) / 1e6);

    const slices = await Promise.all(
      [...Array(time.size).keys()].map(async (index) => ({
        index,
        date: toDate(await source.getValue('time', index)),
      })),
    );
    // The cube stores its time slices out of chronological order, so sort them.
    // 数据立方体存储的时间切片可能未按时序排列，执行客户端升序排序
    slices.sort((a, b) => a.date - b.date);

    function showSlice(position) {
      const {index, date} = slices[position];
      // Reload the chosen time slice in place
      // 原地更新数据源时间维度切片（无需重建图层）
      source.updateDimensions({time: index});
      label.textContent = date.toISOString().slice(0, 16).replace('T', ' ');
    }

    slider.max = String(time.size - 1);
    slider.disabled = false;
    slider.addEventListener('input', () => showSlice(Number(slider.value)));
    showSlice(0);
  })
  .catch(
    () =>
      (label.textContent =
        'Failed to load the GeoZarr store. / 加载 GeoZarr 存储失败。'),
  );
