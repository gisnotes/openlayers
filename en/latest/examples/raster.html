Raster Source / 栅格数据源多波段像素代数运算与植被指数动态分析

raster7 pixel2 maptiler26

Demonstrates pixelwise operations with a raster source. / 演示如何使用 ol/source/Raster 在 Web Worker 中对卫星航拍切片执行逐像素运算，实时计算植被绿度指数（VGI）并联动 D3 直方图进行面积统计与阈值过滤。

This example uses a ol/source/Raster to generate data based on another source. The raster source accepts any number of input sources (tile or image based) and runs a pipeline of operations on the input pixels. The return from the final operation is used as the data for the output source.

In this case, a single tiled source of imagery is used as input. For each pixel, the Vegetation Greenness Index (VGI) is calculated from the input pixels. A second operation colors those pixels based on a threshold value (values above the threshold are green and those below are transparent).

本示例演示了如何利用 ol/source/Raster（栅格数据源）对输入数据源执行客户端逐像素级算术运算。栅格数据源支持接收任意数量的输入图层（切片或单图），在后台 Web Worker 线程流水线中处理输入像素，并将运算结果直接作为输出图层的可视化像素流。

本例以卫星航拍影像切片作为输入源，针对视口内每个像素点，实时计算植被绿度指数（VGI）。通过与右侧 D3.js 动态频数直方图联动，根据用户鼠标悬停选定的动态阈值，将高于阈值的健康植被高亮着色为半透明荧光绿，同时基于地图分辨率即时解算出当前地表覆盖英亩面积。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计机制 (Core Architecture & Mechanics)

  • Web Worker 多线程栅格处理流水线： 在主线程执行全图数十万甚至数百万像素的数学计算会导致 UI 帧率断崖式下跌。ol/source/Raster 内部维护了多线程 Web Worker 池：
    • 主线程准备当前视口各输入源的 ImageData 像素阵列；
    • 将像素缓冲区通过 postMessage 传递给后台 Worker；
    • Worker 内部无阻塞执行纯函数式数学变换并回传结果；
    • 最终由 ImageLayer 作为动态栅格画布完成无缝渲染。
  • 植被绿度指数（Vegetation Greenness Index, VGI）原理： 在没有近红外（NIR）波段的常规 RGB 航拍影像中，VGI 是一种经典的经验估算指数： $$\text{VGI} = \frac{2G - R - B}{2G + R + B}$$ 归一化后，绿色通道占比显著高于红蓝通道的像素点呈现出更高的 VGI 值（通常大于 0.2），代表地表覆盖有较高密度的健康绿色植被。

2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns)

  • Worker 沙箱隔离与 lib 辅助函数注入：
    const raster = new RasterSource({
  sources: [aerial],
  operation: function (pixels, data) {
    const pixel = pixels[0];
    const value = vgi(pixel);
    summarize(value, data.counts); // 统计直方图分箱
    if (value >= data.threshold) {
      pixel[0] = 0; pixel[1] = 255; pixel[2] = 0; pixel[3] = 128; // 高于阈值标绿
    } else {
      pixel[3] = 0; // 低于阈值完全透明
    }
    return pixel;
  },
  lib: {
    vgi: vgi,
    summarize: summarize, // 注入函数体至 Worker 全局上下文
  },
});
    由于 Web Worker 无法直接访问主线程闭包变量，必须通过 lib 属性显式注入依赖工具函数。
  • 双向双向事件管道与响应式图表联动：
    • beforeoperations：在计算启动前将主线程的状态（如 threshold 与空频数数组 data.counts）挂入事件上下文；
    • afteroperations：在计算完成时捕获 Worker 回传的聚合统计值，触发 schedulePlot 驱动 D3.js 绘制直方图柱状图与面积计算；
    • 直方图交互：鼠标滑过柱子时调用 raster.set('threshold', threshold); raster.changed();，触发栅格源以 60 FPS 重新计算渲染。

3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices)

  • 跨域 Canvas 像素污染（CORS Tainted Canvas）： ol/source/Raster 需要读取切片的底层二进制像素数组。输入切片源（aerial）必须显式声明 crossOrigin: ''。如果切片服务器未正确配置 Access-Control-Allow-Origin: *，浏览器 Canvas 会被标记为受污染，直接抛出 SecurityError 导致栅格运算崩溃。
  • 直方图重绘节流防抖（Debounced Plotting）： 在地图连续漫游平移时，每个渲染帧都会触发 afteroperations。代码中通过 setTimeout(..., 1000 / 60) 实现了基于 RAF 频率的轻量任务调度，避免高频 DOM 操作拖慢地图平移流畅度。
main.js 
import {max} from 'd3-array';
import {scaleLinear} from 'd3-scale';
import {select} from 'd3-selection';
import 'd3-transition';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import ImageLayer from 'ol/layer/Image.js';
import TileLayer from 'ol/layer/Tile.js';
import ImageTile from 'ol/source/ImageTile.js';
import RasterSource from 'ol/source/Raster.js';

const minVgi = 0;
const maxVgi = 0.5;
const bins = 10;

/**
 * Calculate the Vegetation Greenness Index (VGI) from an input pixel.
 * 从输入像素计算植被绿度指数 (VGI)，基于地表反射率近似假定
 * @param {Array<number>} pixel An array of [R, G, B, A] values. / 像素四通道值
 * @return {number} The VGI value for the given pixel. / 像素对应的 VGI 指数值
 */
function vgi(pixel) {
  const r = pixel[0] / 255;
  const g = pixel[1] / 255;
  const b = pixel[2] / 255;
  return (2 * g - r - b) / (2 * g + r + b);
}

/**
 * Summarize values for a histogram. / 将 VGI 指数值归入直方图分箱统计中
 * @param {number} value A VGI value. / 待统计的 VGI 指数值
 * @param {Object} counts An object for keeping track of VGI counts. / 统计容器对象
 */
function summarize(value, counts) {
  const min = counts.min;
  const max = counts.max;
  const num = counts.values.length;
  if (value < min) {
    // do nothing / 低于最小值忽略
  } else if (value >= max) {
    counts.values[num - 1] += 1;
  } else {
    const index = Math.floor((value - min) / counts.delta);
    counts.values[index] += 1;
  }
}

// MapTiler credentials and attributions / MapTiler 访问密钥与版权信息
const key = 'Get your own API key at https://www.maptiler.com/cloud/';
const attributions =
  '<a href="https://www.maptiler.com/copyright/" target="_blank">&copy; MapTiler</a> ' +
  '<a href="https://www.openstreetmap.org/copyright" target="_blank">&copy; OpenStreetMap contributors</a>';

// Aerial imagery source for pixel manipulation / 用于像素运算的卫星正射影像数据源
const aerial = new ImageTile({
  attributions: attributions,
  url: 'https://api.maptiler.com/maps/satellite/{z}/{x}/{y}.jpg?key=' + key,
  tileSize: 512,
  maxZoom: 20,
  crossOrigin: '',
});

/**
 * Raster source executing VGI operation and threshold coloring in Web Worker.
 * 在 Web Worker 中执行 VGI 运算与阈值着色的栅格数据源
 */
const raster = new RasterSource({
  sources: [aerial],
  /**
   * Run calculations on pixel data. / 逐像素运算核心执行函数
   * @param {Array<Array<number>>} pixels List of pixels (one per source). / 各输入源像素列表
   * @param {Object} data User data object passed from beforeoperations. / 用户上下文数据
   * @return {Array<number>} The output pixel. / 运算后输出的像素四通道值
   */
  operation: function (pixels, data) {
    const pixel = pixels[0];
    const value = vgi(pixel);
    summarize(value, data.counts);
    if (value >= data.threshold) {
      pixel[0] = 0;
      pixel[1] = 255;
      pixel[2] = 0;
      pixel[3] = 128;
    } else {
      pixel[3] = 0;
    }
    return pixel;
  },
  lib: {
    vgi: vgi,
    summarize: summarize,
  },
});
raster.set('threshold', 0.25);

/**
 * Create histogram counting structure. / 创建直方图统计数据结构
 * @param {number} min Minimum value / 最小值
 * @param {number} max Maximum value / 最大值
 * @param {number} num Number of bins / 分箱数量
 * @return {Object} Counts container / 统计结构对象
 */
function createCounts(min, max, num) {
  const values = new Array(num);
  for (let i = 0; i < num; ++i) {
    values[i] = 0;
  }
  return {
    min: min,
    max: max,
    values: values,
    delta: (max - min) / num,
  };
}

// Pass state to worker before operations start / 运算启动前将主线程状态传入 Worker 上下文
raster.on('beforeoperations', function (event) {
  event.data.counts = createCounts(minVgi, maxVgi, bins);
  event.data.threshold = raster.get('threshold');
});

// Update D3 histogram after worker finishes / Worker 计算完成后更新 D3 直方图
raster.on('afteroperations', function (event) {
  schedulePlot(event.resolution, event.data.counts, event.data.threshold);
});

// Initialize map with base satellite layer and computed raster overlay / 初始化地图
const map = new Map({
  layers: [
    new TileLayer({
      source: aerial,
    }),
    new ImageLayer({
      source: raster,
    }),
  ],
  target: 'map',
  view: new View({
    center: [-9651695, 4937351],
    zoom: 13,
    minZoom: 12,
    maxZoom: 19,
  }),
});

let timer = null;
/**
 * Throttled plotting scheduler. / 节流调度直方图重绘以避免高频更新阻塞
 * @param {number} resolution View resolution / 视图分辨率
 * @param {Object} counts Histogram counts / 直方图统计数据
 * @param {number} threshold Current VGI threshold / 当前阈值
 */
function schedulePlot(resolution, counts, threshold) {
  if (timer) {
    clearTimeout(timer);
    timer = null;
  }
  timer = setTimeout(plot.bind(null, resolution, counts, threshold), 1000 / 60);
}

const barWidth = 15;
const plotHeight = 150;
const chart = select('#plot')
  .append('svg')
  .attr('width', barWidth * bins)
  .attr('height', plotHeight);

const chartRect = chart.node().getBoundingClientRect();

const tip = select(document.body).append('div').attr('class', 'tip');

/**
 * Render D3 SVG histogram and bind interactive threshold drag/hover.
 * 渲染 D3 SVG 直方图并绑定柱条悬停动态调整阈值与面积气泡提示
 * @param {number} resolution View resolution / 视图分辨率
 * @param {Object} counts Histogram counts / 直方图统计数据
 * @param {number} threshold Current VGI threshold / 当前阈值
 */
function plot(resolution, counts, threshold) {
  const yScale = scaleLinear()
    .domain([0, max(counts.values)])
    .range([0, plotHeight]);

  const bar = chart.selectAll('rect').data(counts.values);

  bar.enter().append('rect');

  bar
    .attr('class', function (count, index) {
      const value = counts.min + index * counts.delta;
      return 'bar' + (value >= threshold ? ' selected' : '');
    })
    .attr('width', barWidth - 2);

  bar
    .transition()
    .attr('transform', function (value, index) {
      return (
        'translate(' +
        index * barWidth +
        ', ' +
        (plotHeight - yScale(value)) +
        ')'
      );
    })
    .attr('height', yScale);

  // Mousemove adjusts threshold in real time / 移动鼠标实时调整栅格源阈值并刷新
  bar.on('mousemove', function () {
    const index = bar.nodes().indexOf(this);
    const threshold = counts.min + index * counts.delta;
    if (raster.get('threshold') !== threshold) {
      raster.set('threshold', threshold);
      raster.changed();
    }
  });

  // Mouseover shows tooltip with calculated acreage / 悬停显示估算的覆盖英亩面积
  bar.on('mouseover', function (event) {
    const index = bar.nodes().indexOf(this);
    let area = 0;
    for (let i = counts.values.length - 1; i >= index; --i) {
      area += resolution * resolution * counts.values[i];
    }
    tip.html(message(counts.min + index * counts.delta, area));
    tip.style('display', 'block');
    tip
      .transition()
      .style('left', chartRect.left + index * barWidth + barWidth / 2 + 'px')
      .style('top', event.y - 60 + 'px')
      .style('opacity', 1);
  });

  bar.on('mouseout', function () {
    tip
      .transition()
      .style('opacity', 0)
      .on('end', function () {
        tip.style('display', 'none');
      });
  });
}

/**
 * Format tooltip text with commas for thousands. / 格式化提示框英亩面积与千分位
 * @param {number} value VGI threshold / VGI 阈值
 * @param {number} area Area in square meters / 面积（平方米）
 * @return {string} Formatted HTML string / 格式化后的 HTML 内容
 */
function message(value, area) {
  const acres = (area / 4046.86)
    .toFixed(0)
    .replace(/\B(?=(\d{3})+(?!\d))/g, ',');
  return acres + ' acres at<br>' + value.toFixed(2) + ' VGI or above';
}
