Icon modification / 图标点位拖拽修改

vector86 modify11 icon9 marker6

Example using a Modify interaction to edit an icon. / 演示使用 Modify 交互通过命中检测直接拖拽修改点标记图标位置。

The icon on this map can be dragged to modify its location.

The Modify interaction can be configured with a `hitDetection` option. With this option, the modification candidate will not be determined by the `pixelTolerance`, but match the visual appearance of the geometry.

地图上的标记图标可以直接通过鼠标或触控拖拽来修改其地理位置坐标。

Modify 交互支持配置 hitDetection（命中检测）选项。启用此选项后，判定是否可以拖拽不再仅仅依赖抽象几何点位周围的固定像素容差（pixelTolerance），而是严格根据图标渲染出来的实际视觉轮廓（Visual Appearance）进行像素级命中测试。

📚 学习记录与技术深度解读 (Learning Notes)

1. 为什么需要 hitDetection: vectorLayer？

  • 图标锚点偏移痛点：点要素的几何坐标通常对应于大头针底部针尖（例如 anchor: [0.5, 46]）。若不开启 hitDetection，Modify 交互仅以针尖几何点为中心按 pixelTolerance（默认 10px）探测，用户点击图标上部圆圈时无法触发修改！
  • 像素级精确拾取：配置 hitDetection: vectorLayer 让 OpenLayers 使用 Canvas 像素命中测试。只要点击落在图标非透明像素内，即可立即响应拖拽。

2. 光标手势与 Overlay 内部事件感知

  • 悬停反馈：通过监听 Modify 内部覆盖层数据源（modify.getOverlay().getSource()）的 addfeature / removefeature 事件，在光标移入图标时呈现手型光标（pointer）；
  • 拖拽反馈：监听 modifystart 与 modifyend 事件，拖拽中呈现抓手光标（grabbing），提供清晰明确的物理操作反馈。
main.js 
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import Point from 'ol/geom/Point.js';
import Modify from 'ol/interaction/Modify.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import OGCMapTile from 'ol/source/OGCMapTile.js';
import VectorSource from 'ol/source/Vector.js';
import Icon from 'ol/style/Icon.js';
import Style from 'ol/style/Style.js';

// Create a point feature at [0, 0] with attributes
// 在本初子午线与赤道交点 [0, 0] 创建带有业务属性的点要素
const iconFeature = new Feature({
  geometry: new Point([0, 0]),
  name: 'Null Island',
  population: 4000,
  rainfall: 500,
});

// Configure icon style with custom anchor (bottom-center)
// 配置图标样式，指定锚点位于底部中心针尖位置
const iconStyle = new Style({
  image: new Icon({
    anchor: [0.5, 46],
    anchorXUnits: 'fraction',
    anchorYUnits: 'pixels',
    src: 'data/icon.png',
  }),
});

iconFeature.setStyle(iconStyle);

const vectorSource = new VectorSource({
  features: [iconFeature],
});

const vectorLayer = new VectorLayer({
  source: vectorSource,
});

const rasterLayer = new TileLayer({
  source: new OGCMapTile({
    url: 'https://maps.gnosis.earth/ogcapi/collections/NaturalEarth:raster:HYP_HR_SR_OB_DR/map/tiles/WebMercatorQuad',
    crossOrigin: '',
  }),
});

const target = document.getElementById('map');
const map = new Map({
  layers: [rasterLayer, vectorLayer],
  target: target,
  view: new View({
    center: [0, 0],
    zoom: 3,
  }),
});

// Configure Modify interaction with hitDetection enabled on the vectorLayer
// 构造 Modify 交互，为 vectorLayer 启用 hitDetection 像素级命中测试
const modify = new Modify({
  hitDetection: vectorLayer,
  source: vectorSource,
});

// Update cursor style when dragging starts and ends
// 监听修改开始与结束事件，切换抓手与普通手型光标
modify.on(['modifystart', 'modifyend'], function (evt) {
  target.style.cursor = evt.type === 'modifystart' ? 'grabbing' : 'pointer';
});

// Listen to internal overlay features to toggle pointer cursor on hover
// 监听修改交互内部覆盖层要素的添加与移除，在鼠标悬停在图标上时提示手型
const overlaySource = modify.getOverlay().getSource();
overlaySource.on(['addfeature', 'removefeature'], function (evt) {
  target.style.cursor = evt.type === 'addfeature' ? 'pointer' : '';
});

map.addInteraction(modify);
