Accessible Map / 无障碍访问地图 (A11y)

accessibility2 tabindex2

Go to map / 跳转到地图

Example of an accessible map. / 支持全键盘导航与无障碍辅助技术的地图交互示例。

This page's map element has its tabindex attribute set to "0", that makes it focusable. To focus the map element you can either navigate to it using the "tab" key or use the skip link. When the map element is focused the + and - keys can be used to zoom in and out and the arrow keys can be used to pan.

Clicking on the "Zoom in" and "Zoom out" buttons below the map zooms the map in and out. You can navigate to the buttons using the "tab" key, and press the "enter" key to trigger the zooming action.

本页面的 map 容器元素将其 tabindex 属性显式设为 "0"，使其具备接收键盘焦点的能力。用户既可以通过键盘的 Tab 键逐步移动焦点，也可以使用页面顶部的跳跃链接（Skip link）直达地图。当地图容器获得焦点时，可通过 + 和 - 键进行放大缩小，使用方向键（↑ ↓ ← →）进行平移漫游。

点击下方的“放大”与“缩小”外部按钮可调整地图层级。这些按钮原生支持 Tab 导航，按下 Enter 或空格键即可触发缩放。

📚 学习记录与技术深度解读

1. 核心架构与设计思想

  • Web 内容无障碍指南（WCAG 2.1）在地图中的落地： 由于电子地图高度依赖鼠标拖拽与双击缩放，肢体残障或视障用户极易面临数字鸿沟。通过为地图容器设置 tabindex="0"，将原本非交互的 <div> 容器纳入标准浏览器 DOM 焦点序列，使盲用读屏软件（如 NVDA、JAWS）与纯键盘用户均能无障碍接入地图。
  • 跳跃导航链接（Skip Link 模式）： 页面顶部配置了 <a class="skiplink" href="#map">，默认在视觉上隐藏，仅在用户按 Tab 键获取焦点时显现。这使视障用户无需逐项遍历页面顶部的成百上千个导航菜单，一键直达核心地图视口。
  • 内置全键盘交互管线： OpenLayers 的默认交互集（defaults()）中内置了 ol/interaction/KeyboardPan 和 ol/interaction/KeyboardZoom。当且仅当地图容器获得当前文档焦点（Focused）时，底层事件监听器被激活，拦截按键并执行平滑视口动画。

2. 源码与关键 API 剖析

  • tabindex="0"：指示元素可以通过键盘导航访问，并保留在文档流自然的 Tab 键导航顺序中（若设为 -1 则仅能通过 JS 代码 focus() 激活）。
  • view.setZoom(zoom ± 1)：通过命令式调用 View 的层级操作接口，不仅支持鼠标点击，更能完美响应标准 <button> 的键盘 Enter / Space 击键。
  • 按键步进参数：默认情况下，方向键每次移动当前视口宽/高的固定比例（通常为 128 像素）；在保持按下状态时会触发平滑加速平移。

3. 生产实践踩坑与性能调优

  • 切勿暴力移除焦点轮廓（outline: none）： 部分前端开发为了视觉美观滥用 *:focus { outline: none; }，导致键盘用户根本无法判断当前焦点是否落在地图上。应使用高对比度的焦点环（如 outline: 3px solid #005fcc; outline-offset: 2px;）。
  • 全屏与弹窗焦点陷阱（Focus Trap）： 当地图包含弹窗或进入全屏状态时，键盘焦点切忌飘逸至底层被遮挡的网页元素，需配合 Focus Trap 逻辑将 Tab 循环限制在当前激活的地图控件内部。
  • ARIA 辅助属性补全： 生产环境中，地图容器建议显式补充 role="region" 和 aria-label="交互式空间地理地图"，以便屏幕阅读器在聚焦时能够清晰朗读其功能与用途。
main.js 
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import TileLayer from 'ol/layer/Tile.js';
import OSM from 'ol/source/OSM.js';

// Initialize accessible map
// 初始化支持无障碍访问的地图实例
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
  ],
  target: 'map',
  view: new View({
    center: [0, 0],
    zoom: 2,
  }),
});

// Accessible zoom-out button click listener
// 无障碍缩小按钮点击监听
document.getElementById('zoom-out').onclick = function () {
  const view = map.getView();
  const zoom = view.getZoom();
  view.setZoom(zoom - 1);
};

// Accessible zoom-in button click listener
// 无障碍放大按钮点击监听
document.getElementById('zoom-in').onclick = function () {
  const view = map.getView();
  const zoom = view.getZoom();
  view.setZoom(zoom + 1);
};

<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <title>Accessible Map / 无障碍访问地图 (A11y)</title>
    <link rel="stylesheet" href="node_modules/ol/ol.css">
    <style>
      .map {
        width: 100%;
        height: 400px;
      }
      a.skiplink {
        position: absolute;
        clip: rect(1px, 1px, 1px, 1px);
        padding: 0;
        border: 0;
        height: 1px;
        width: 1px;
        overflow: hidden;
      }
      a.skiplink:focus {
        clip: auto;
        height: auto;
        width: auto;
        background-color: #fff;
        padding: 0.3em;
      }
      #map:focus {
        outline: #4A74A8 solid 0.15em;
      }
    </style>
  </head>
  <body>
    <a class="skiplink" href="#map">Go to map / 跳转到地图</a>
    <div id="map" class="map" tabindex="0"></div>
    <button id="zoom-out">Zoom out / 缩小</button>
    <button id="zoom-in">Zoom in / 放大</button>

    <script type="module" src="main.js"></script>
  </body>
</html>
