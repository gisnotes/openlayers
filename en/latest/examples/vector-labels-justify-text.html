Vector Labels - Justify Text / 矢量注记文本对齐与段落对齐解耦

vector87 openstreetmap22 label4

Example of text justification within a label. / 演示在注记框内独立设置文本段落对齐（justify）与锚点对齐（textAlign）。

This example showcases how the text can be justified within the label box. By default, the text is justified according to the textAlign option. However, this option justifies also the label itself according to textAlign setting. To decouple the label placement from text placement (within the label box) use justify.

本示例展示了如何在注记框内部对多行文本进行段落对齐（Justification）。默认情况下，文本段落对齐完全由 textAlign 选项控制，但 textAlign 同时决定了整个注记框相对于几何锚点的摆放位置（如左对齐、居中、右对齐）。若要将注记框自身的空间摆放位置与框内多行文字的排版对齐方式彻底解耦，可以使用 justify 属性（可选 'left'、'center'、'right'）。

📚 学习记录与技术深度解读 (Learning Notes)

1. 空间锚定 (textAlign) 与框内段落排版 (justify) 的解耦

  • textAlign 的双重历史包袱: 在早期的 OpenLayers 版本中，textAlign 同时承担了两项职责：既决定整个注记包围盒相对于点几何坐标的锚接基准（如 left 表示注记框贴在点右侧），又控制框内多行文本是左对齐还是居中。这使得“注记整体贴在点右侧、但框内文字希望居中”的需求无法实现。
  • justify 属性的专业化: 引入 justify 属性后，textAlign 仅负责外层锚点定位，而 justify: 'left' | 'center' | 'right' 则专门负责多行文本在文字气泡框内的段落排版，两者形成了清晰的二维正交控制体系（支持 $3 \times 3 = 9$ 种排版变体）。

2. 文本背景气泡卡片设计 (backgroundFill 与 padding)

  • 免除切图标负担的纯样式气泡: 通过 Text 样式的 backgroundFill: new Fill({color: '...'}) 属性，引擎会自动根据当前文本渲染尺寸动态生成自适应的矩形背景色块。
  • 精确内边距盒模型: 配合 padding: [top, right, bottom, left]（类似于 CSS 盒模型规范），能为文字四周提供均匀舒适的视觉留白，有效提升密集文字在复杂卫星底图上的视觉可辨识度。

3. 生产实践陷阱与避坑指南 (Production Pitfalls & Best Practices)

  • justify 的多行必要条件: justify 的行内排版特性仅在文本存在换行符 '\n' 形成多行文本块时生效。若为单行文本，注记框宽度紧贴文本，justify 的视觉差异不可见。
  • 与 textBaseline 的协同搭配: 在调整水平定位的同时，若需对竖直方向进行控制，应配合 textBaseline（如 'top'、'middle'、'bottom'、'alphabetic'）使用，以达到像素级严谨的图文对齐。
main.js 
import Collection from 'ol/Collection.js';
import Feature from 'ol/Feature.js';
import Map from 'ol/Map.js';
import View from 'ol/View.js';
import GeoJSON from 'ol/format/GeoJSON.js';
import Point from 'ol/geom/Point.js';
import TileLayer from 'ol/layer/Tile.js';
import VectorLayer from 'ol/layer/Vector.js';
import OSM from 'ol/source/OSM.js';
import VectorSource from 'ol/source/Vector.js';
import CircleStyle from 'ol/style/Circle.js';
import Fill from 'ol/style/Fill.js';
import Stroke from 'ol/style/Stroke.js';
import Style from 'ol/style/Style.js';
import Text from 'ol/style/Text.js';

// Matrix of 9 feature configurations testing combinations of textAlign and justify
// 9 组要素配置矩阵：测试 textAlign（几何锚点定位）与 justify（段落内部对齐）的正交组合
const features = [
  {
    geometry: new Point([-8300000, 6095000]),
    textAlign: 'left',
  },
  {
    geometry: new Point([-8150000, 6095000]),
    textAlign: 'center',
  },
  {
    geometry: new Point([-8000000, 6095000]),
    textAlign: 'right',
  },
  {
    geometry: new Point([-8300000, 6025000]),
    textAlign: 'left',
    justify: 'center',
  },
  {
    geometry: new Point([-8150000, 6025000]),
    textAlign: 'center',
    justify: 'center',
  },
  {
    geometry: new Point([-8000000, 6025000]),
    textAlign: 'right',
    justify: 'center',
  },
  {
    geometry: new Point([-8300000, 5955000]),
    textAlign: 'left',
    justify: 'left',
  },
  {
    geometry: new Point([-8150000, 5955000]),
    textAlign: 'center',
    justify: 'left',
  },
  {
    geometry: new Point([-8000000, 5955000]),
    textAlign: 'right',
    justify: 'left',
  },
];

// Helper to create a composite style with red anchor circle and multi-line justified text card
// 辅助函数：创建复合样式，包含用于指示几何真值的红色锚点圆圈及多行段落对齐文本卡片
function createStyle({textAlign, justify = undefined}) {
  return new Style({
    image: new CircleStyle({
      radius: 10,
      fill: new Fill({color: 'rgba(255, 0, 0, 0.1)'}),
      stroke: new Stroke({color: 'red', width: 1}),
    }),
    text: new Text({
      font: '16px sans-serif',
      textAlign,
      justify,
      text:
        `Justify text inside box\ntextAlign: ${textAlign}` +
        (justify ? `\njustify: ${justify}` : ''),
      fill: new Fill({
        color: [255, 255, 255, 1],
      }),
      backgroundFill: new Fill({
        color: [168, 50, 153, 0.6],
      }),
      padding: [2, 2, 2, 2],
    }),
  });
}

// Vector layer containing all 9 point features
// 矢量图层：承载 9 个不同排版组合的点要素
const vectorPoints = new VectorLayer({
  source: new VectorSource({
    features: new Collection(
      features.map((featureOptions) => {
        const feature = new Feature({
          geometry: featureOptions.geometry,
        });
        feature.setStyle(createStyle(featureOptions));
        return feature;
      }),
    ),
    format: new GeoJSON(),
  }),
});

// Initialize map with OSM base and vector points layer
// 初始化地图实例：挂载 OSM 底图与矢量注记图层
const map = new Map({
  layers: [
    new TileLayer({
      source: new OSM(),
    }),
    vectorPoints,
  ],
  target: 'map',
  view: new View({
    center: [-8150000, 6025000],
    zoom: 8,
  }),
});
