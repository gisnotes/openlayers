Example of GeoJSON features with labels. / 演示如何针对 GeoJSON 中的点、线、面要素进行深度文本样式（Text Style）定制，涵盖沿线排版、折行截断、字重偏移与字体动态加载。

This example showcases a number of options that can be set on text styles. When "Text/Wrap" is chosen (for example for the line features), the label is wrapped by inserting the character \n, which will create a multi-line label. The "Open Sans" web font will be loaded on demand, to show dynamic font loading.

本示例是一个全功能的矢量文本标注（Text Style）交互实验工作台，全面展示了 OpenLayers 对点（Points）、折线（Lines）与多边形（Polygons）三类核心地理图元的丰富注记排版能力。

通过右侧面板，你可以实时调整文本对齐（Align）、基线（Baseline）、旋转角度（Rotation）、字重（Weight）、沿线布局（Placement: line vs point）、最大转折弯角（Max Angle）、超出长度限制（Overflow）以及描边光晕（Outline）。当选择“Wrap（换行）”时，代码通过算法在词间自动插入 \n 实现多行排版；同时演示了按需动态注入外部 Web 字体（Open Sans）的工程方案。

📚 学习记录与技术深度解读 (Learning Notes)

1. 核心架构与设计机制 (Core Architecture & Mechanics)

  • ol/style/Text 排版引擎双模式：
    • 点/质心模式 (placement: 'point')： 适用于点要素以及面要素的中心标注。OpenLayers 会自动计算多边形内部最宽敞的内切区域或几何质心（Interior Point），将文本锚定在此位置，配合 offsetX 与 offsetY 实现避让偏移。
    • 沿线蜿蜒模式 (placement: 'line')： 专为道路、河流、航线等线要素设计。文字不再保持水平，而是计算线段切线斜率，使每个字元紧贴线几何蜿蜒排列；当线段急剧拐角时，若转折角度超过 maxAngle（默认 45°），排版引擎会自动抑制此标注以防止文字严重重叠挤压变形。
  • 动态分辨率过滤（Resolution-based Level of Detail）： 地图标注是造成视觉杂乱（Clutter）的主要根源。代码在样式函数中通过 resolution > maxResolution 判定当前缩放层级：当视口处于宏观比例尺时自动返回空字符串（text = ''），仅在微观缩放时呈现详细文字，实现清晰优雅的无级缩放注记（LOD）。

2. 关键代码解析与 API 模式 (Code Deep Dive & API Patterns)

  • 字符串动态分词折行算法：
    function stringDivider(str, width, spaceReplacer) {
  if (str.length > width) {
    let p = width;
    // 向左寻找空格或破折号作为天然分词断点
    while (p > 0 && str[p] != ' ' && str[p] != '-') {
      p--;
    }
    if (p > 0) {
      const left = str.substring(0, p + (str[p] == '-' ? 1 : 0));
      const right = str.substring(p + 1);
      return left + spaceReplacer + stringDivider(right, width, spaceReplacer);
    }
  }
  return str;
}
    通过算法在单词边界插入换行符 \n，配合 lineHeight 实现优雅的多行折行，杜绝硬切断单词导致语义断裂。
  • Web 字体异步注入与重绘： Canvas 文本绘制要求对应字体必须在浏览器本地就绪。通过动态创建 <link rel="stylesheet"> 引入 Google Fonts，并在字体就绪后调用 vectorLayer.changed() 或重新应用样式函数，即可完成高品质个性化字体渲染。

3. 工程避坑与高可用实践 (Production Pitfalls & Best Practices)

  • 沿线标注字形方向反向颠倒防护： 折线要素在绘制时方向可能自西向东或自东向西。若直接按顶点顺序排列，会导致自东向西的道路注记呈现“倒立文字”。OpenLayers 内置了智能翻转机制，但在极端近乎垂直（90° 附近）的线段上，微小的视口旋转可能导致文字在正反向之间跳动闪烁。推荐在线要素处理中统一线拓扑流向。
  • 文本光晕（Text Halo / Outline）性能优化： 为了保证文字在复杂底图背景上的清晰辨识度，配置高对比度的白色描边（stroke: new Stroke({color: '#fff', width: 3})）是制图标准做法。但需注意：Canvas 2D 在绘制每个字元的描边时开销是纯填充的两倍。对于海量点位，建议开启图层的 declutter: true（标注避让）机制，自动剔除重叠冲突的文字。

/**
 * Resolve display text based on resolution and strategy.
 * 根据地图分辨率及截断/换行策略获取最终标注文本
 * @param {import('ol/Feature.js').default} feature Feature / 矢量要素
 * @param {number} resolution View resolution / 视图分辨率
 * @param {Object} dom Control DOMs / 表单 DOM 控件对象
 * @return {string} Processed text / 处理后的文本字符串
 */
const getText = function (feature, resolution, dom) {
  const type = dom.text.value;
  const maxResolution = dom.maxreso.value;
  let text = feature.get('name');

  if (resolution > maxResolution) {
    text = '';
  } else if (type === 'hide') {
    text = '';
  } else if (type === 'shorten') {
    text = truncate(text, 12);
  } else if (
    type === 'wrap' &&
    (!dom.placement || dom.placement.value !== 'line')
  ) {
    text = stringDivider(text, 16, '\n');
  }

  return text;
};

/**
 * Create dynamic ol/style/Text instance from user controls.
 * 根据界面表单配置动态创建 ol/style/Text 文本样式对象
 * @param {import('ol/Feature.js').default} feature Feature / 矢量要素
 * @param {number} resolution View resolution / 视图分辨率
 * @param {Object} dom Control DOMs / 表单 DOM 控件对象
 * @return {Text} Text style instance / 文本样式实例
 */
const createTextStyle = function (feature, resolution, dom) {
  const align = dom.align.value;
  const baseline = dom.baseline.value;
  const size = dom.size.value;
  const height = dom.height.value;
  const offsetX = parseInt(dom.offsetX.value, 10);
  const offsetY = parseInt(dom.offsetY.value, 10);
  const weight = dom.weight.value;
  const placement = dom.placement ? dom.placement.value : undefined;
  const maxAngle = dom.maxangle ? parseFloat(dom.maxangle.value) : undefined;
  const overflow = dom.overflow ? dom.overflow.value === 'true' : undefined;
  const rotation = parseFloat(dom.rotation.value);

  // Dynamically load Google Open Sans font if requested / 按需动态注入 Open Sans Web 字体
  if (dom.font.value === "'Open Sans'" && !openSansAdded) {
    const openSans = document.createElement('link');
    openSans.href = 'https://fonts.googleapis.com/css?family=Open+Sans';
    openSans.rel = 'stylesheet';
    document.head.appendChild(openSans);
    openSansAdded = true;
  }
  const font = weight + ' ' + size + '/' + height + ' ' + dom.font.value;
  const fillColor = dom.color.value;
  const outlineColor = dom.outline.value;
  const outlineWidth = parseInt(dom.outlineWidth.value, 10);

  return new Text({
    textAlign: align === '' ? undefined : align,
    textBaseline: baseline,
    font: font,
    text: getText(feature, resolution, dom),
    fill: new Fill({color: fillColor}),
    stroke: new Stroke({color: outlineColor, width: outlineWidth}),
    offsetX: offsetX,
    offsetY: offsetY,
    placement: placement,
    maxAngle: maxAngle,
    overflow: overflow,
    rotation: rotation,
  });
};

// Polygons style function / 多边形要素样式函数
function polygonStyleFunction(feature, resolution) {
  return new Style({
    stroke: new Stroke({
      color: 'blue',
      width: 1,
    }),
    fill: new Fill({
      color: 'rgba(0, 0, 255, 0.1)',
    }),
    text: createTextStyle(feature, resolution, myDom.polygons),
  });
}

function pointStyleFunction(feature, resolution) {

      stroke: new Stroke({color: 'red', width: 1}),

  });
}

/**
 * Truncate long string and append ellipsis. / 截断超出长度的字符串并追加省略号
 * @param {string} string Input string / 输入字符串
 * @param {number} n Max character count / 最大保留字符数
 * @return {string} Truncated string / 截断后字符串
 */
function truncate(string, n) {
  return string.length > n ? string.slice(0, n - 1) + '…' : string.slice();
}

/**
 * Wrap string at whitespace or hyphen boundaries. / 在空格或破折号处自动分词折行
 * @param {string} str Input string / 输入字符串
 * @param {number} width Line wrap threshold / 折行宽度阈值
 * @param {string} spaceReplacer Separator character (e.g. \n) / 换行替换符
 * @return {string} Wrapped multi-line text / 折行后多行文本
 */
function stringDivider(str, width, spaceReplacer) {
  if (str.length > width) {
    let p = width;
    while (p > 0 && str[p] !== ' ' && str[p] !== '-') {
      p--;
    }
    if (p > 0) {
      let left;
      if (str.substring(p, p + 1) === '-') {
        left = str.substring(0, p + 1);
      } else {
        left = str.substring(0, p);
      }
      const right = str.substring(p + 1);
      return left + spaceReplacer + stringDivider(right, width, spaceReplacer);
    }
  }
  return str;
}
