# 4.6.2

The v4.6.2 release fixes a regression that could cause tremendous amounts of unneeded vector data to be fetched from the source.

v4.6.2 版本修复了一处回归问题，该问题可能导致从数据源请求大量不必要的矢量数据。

## 修复
