# 4.6.3

The v4.6.3 release fixes a performance issue when `renderMode: 'image'` is set on an `ol.layer.Vector`.

v4.6.3 版本修复了在 `ol.layer.Vector` 上设置 `renderMode: 'image'` 时的性能问题。
